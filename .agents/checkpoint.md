## 一、 用户最高指示与立规沉淀（七大不可动摇的核心红线）

1. **【最高铁律 1（批次规模严格 <= 5 篇）】**：
   - **每次精修推进严禁超过 5 篇（单批严格限制在 <= 5篇）**！
   - **深刻病灶警惕**：一次性处理篇目过多会导致上下文过长、引发思维惯性退化，不自觉地滑向伪文言、虚词压缩、代词模糊与过度删减；
   - **执行流程**：改完 5 篇立即停步交付验收、复核确认，确认无误再进入下一批，严禁滚雪球。
2. **【最高铁律 2（严禁元叙事：禁止回顾提及和评议）】**：
   - **彻底根除清单打勾式回顾**：严禁出现类似“手、脚、胸口之后，还差嘴”、“在完成……之后，轮到……”、“这是第几次”等将剧情变成打卡清单的元叙事；
   - **禁止局外评述**：绝不站在局外向读者汇报进度、打卡清点；
   - **摄影机当刻沉浸**：镜头必须死死钉在**当下的时空、当下的触感、当下的呼吸与真实心理**；角色的一切犹豫、害羞与动作，完全由眼前当下具体的物理刺激与心理碰撞驱动。
3. **【最高铁律 3（彻底根除伪文言与文绉绉语料）】**：
   - **坚决杜绝把“如果”改成“若”，坚决杜绝把“以前”改成“以往/过往”**；
   - 全篇 0 处“宛若/如同/状若/仿若/自若/若是/此番/何须/言毕/除却/秋毫无犯/端坐于/相询/未曾/已然/遂/四肢百骸/徐徐/横陈/虚悬”等伪文言与小资修饰；
   - 坚守质朴现代生活流大白话与真实直接动词。
4. **【最高铁律 4（彻底废除字数死板一刀切，严禁过度删字数）】**：
   - 彻底废除 350~700 字限制，**严禁过狠删减字数与生活流细节**；
   - 复杂重头戏、精彩互动章按需自然展开至 **800 ~ 1300+ 字符**，给对白拉扯、情绪酝酿、环境铺垫与生理细节留足充裕的呼吸空间。
5. **【最高铁律 5（精彩对白 100% 保真与还魂）**：
   - 绝不删改角色的生动台词、口癖、娇嗔、调侃与互怼，绝不能转述为干瘪的第三人称概括；
   - 艾玛的学术调侃与大姐姐包容、卡兹尔的笨拙复述、月语者的克制真诚、法林的沉稳守护，100% 保真呈现。
6. **【最高铁律 6（主体人名清晰明确，拒绝通篇他/她）】**：
   - 清楚写出人名（艾玛、月语者、法林、卡兹尔等），主体明确，严禁通篇模糊的“他/她”；
   - 严禁在指代艾玛时用“大姐姐”代替主语；但允许且鼓励在形容修饰神态气质时使用（“带着大姐姐独有的包容与从容”）。
7. **【最高铁律 7（全角双引号与终止条件 3 纯物象定格）】**：
   - 全篇所有对话必须使用全角双引号 `“”`，严禁英文双引号 `""`；
   - 人物连续动作全部收拢至条件 2，**条件 3 必须是纯客观环境、器物与自然痕迹的余韵定格，0 角色动作**。
