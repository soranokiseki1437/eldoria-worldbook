## 一、 核心世界观与前置矛盾

### 1. 逃亡爱侣与黑道阴影
- **男主 (Leon / MC)** 与 **女主 (Amelia / 阿米莉亚)** 是一对相濡以沫、感情极深年轻夫妻；
- Amelia 拥有显赫而危险的黑道家族背景（父亲 Alfonse 为掌权黑帮高层），Leon 曾是该组织中的底层成员。因深爱彼此，两人毅然脱离帮派，隐姓埋名逃亡至一座新城市开始平静的生活；
- 虽已脱离组织，但黑帮高层（如卢修斯 Lucius）及昔日贴身保镖（盖斯特 Geist）的阴影始终笼罩在两人头顶。这种随时可能被发现的危险，构成了外部施压的核心动力学源泉。

### 2. 核心叙事动力学：恐惧向欲望的病态扭曲
本作区别于一般粗俗寝取作品的最大神髓，在于**男主 Leon 极其逼真、细腻且令人毛骨悚然的心理转变**：
- **原始恐惧 (Fear)**：Leon 最深沉的噩梦是“失去妻子”——因身份暴露被追兵掠夺，或妻子被更强大的男人夺走；
- **自欺防御与心理变异 (Coping Mechanism to Twisted Lust)**：在漫长的高压逃亡岁月中，潜意识为了对抗“必然失去”的绝望，发生了一种奇特的扭曲——**“既然恐惧失去她，不如渴望看见她在极致的快感中迷失自我”**；
- **占有欲的极性升华**：Leon 发现，当看到妻子受到外部猛男（私教 Brandon、黑帮保镖 Geist）的觊觎、言语调戏乃至肢体侵犯时，内心的自卑、嫉妒与极度的肉体欲望发生了剧烈的化学反应；
- **夫妻共谋契约 (Consensual Netorase)**：Amelia 并非被蒙在鼓里。她极度敏锐地察觉了丈夫的隐秘癖好。在深爱丈夫的前提下，她主动迎合甚至放纵这种背德游戏，形成了“外人以为在偷情/强占，实则是老夫老妻联手探索极限性刺激”的深度默契。

## 二、 双轨路线与核心癖好机制 (Variables & Mechanics)

游戏在底层脚本（`variables.rpy` 与 `gallery.rpy`）中设计了严密的数值与分支机制：

### 1. 态度双轨：强势夺回 vs 顺从羞辱
- **强势主导路线 (`rel_strong`)**：
  - 核心力学：**极限延宕后的绝对身体回收**。
  - 表现：Leon 在现场允许甚至鼓励外部挑逗，但事后以绝对的雄性威严与独占欲，猛烈贯入 Amelia，在激情碰撞中将妻子的身心从外人手中“夺回并重新标记”；
  - 经典台词：“*Cum while imagining taking back my ravaged, fucked body and making me yours again...!~*”（想象着重新夺回我被蹂躏、被操透的肉体，让我再次彻底归属于你，射出来吧……！）。
- **被动顺从路线 (`rel_passive`)**：
  - 核心力学：**被动沉沦与主奴反转**。
  - 表现：Leon 处于彻底的下风与羞耻中，Amelia 掌握完全的主导权，甚至在事后以女王般的姿态嘲弄丈夫的无能，享受看丈夫在自卑中硬得发痛的畸形快感。

### 2. 四大核心背德参数
- **`hum` (Humiliation / 羞辱度)**：是否开启言语侮辱、身体对比与尊严剥夺；
- **`groupsex` (Group Sex / 3P多人)**：是否开启与第三方猛男同时介入的双重贯入与多人轮流实战；
- **`cumkiss` (Cum Kiss / 精吻交换)**：在妻子口含他人口液或内射后，夫妻二人深情接吻，品尝并交换外部雄性的痕迹；
- **`irtalk` (Dirty Talk / 放浪言语)**：互动过程中毫不掩饰的粗鄙调情、反差自称与放浪对白。

## 三、 七级蓄压阶梯模型（对照 scenario-reference-vault 解构）

本作是极佳的“延宕穿刺、蓄满张力”范本，每个阶段的事件均严格符合七级递进：

```
[阶梯 1: 礼仪/公事包装的距离破界] ── 健身房私教纠正体态、海滩日光浴涂抹、黑帮昔日主仆问候
         │
[阶梯 2: 标志性防御物的局部瓦解] ── 紧身瑜伽裤勒出痕迹、微小比基尼滑落、领口大开露出锁骨
         │
[阶梯 3: 尊严剥夺与服从性微测试] ── 故意在丈夫目光注视下让外人扶住胯骨、听从命令不许发出声音
         │
[阶梯 4: 介质与非穿刺物理试探]   ── 冰凉的精油滑过大腿、健身器材阻隔身体无从借力、隔板后的抚触
         │
[阶梯 5: 绝望的自欺防线与缓兵承诺] ── “我只是为了帮丈夫打探消息”、“这只是普通的专业拉伸训练”
         │
[阶梯 6: 临界门槛的悬置与推拉]   ── 距离穿刺仅隔薄薄底裤、在更衣室/酒店屏风咫尺之遥急促喘息
         │
[阶梯 7: 终局突破与心智认知重构] ── 双重贯入、精液涂抹、知行彻底撕裂，在丈夫怀中彻底承认快感
```
