# 第七幕：清晨露营突袭、湖畔温泉与三人裸浴

**爱德华(丈夫)**：“诶？！”

**爱德华(心理旁白)**：“里奈和我都被浩大人的声音吓了一跳。”

**爱德华(心理旁白)**：“里奈把手从我的鸡巴上移开，它立刻就软了。”

**爱德华(心理旁白)**：“我感觉自己好像刚被扫了兴。”

**爱德华(心理旁白)**：“我知道我可能想得太多了，但这感觉像是故意的。”

**爱德华(心理旁白)**：“我看着里奈匆匆忙忙地穿上内裤和一件宽松的T恤。”

**爱德华(心理旁白)**：“我们俩一起走到外面去见浩大人。”

**浩(上司大人)**：“爱德华。里奈。”

**浩(上司大人)**：“抱歉把你吵醒了，但这件事很重要。”

**爱德华(丈夫)**：“没问题，先生。反正我们本来就没睡。”

**浩(上司大人)**：“哦，这真好。”

**浩(上司大人)**：“跟我来。”

**爱德华(心理旁白)**：“我们跟着他穿过林间小路。”

**爱德华(心理旁白)**：“这与我们昨天来的方向不同。”

**爱德华(心理旁白)**：“早晨很冷。”

**爱德华(心理旁白)**：“树叶上布满了露水。”

**爱德华(心理旁白)**：“而且，在我们前方的行进方向上，有一层薄雾。”

**爱德华(心理旁白)**：“我瞥了一眼里奈。”

**爱德华(心理旁白)**：“她穿得比较单薄，所以我担心她会不会觉得冷。”

**爱德华(心理旁白)**：“但她冲我笑了笑，仿佛在说她没事。”

**爱德华(心理旁白)**：“要是能有热水洗澡就好了。”

**爱德华(心理旁白)**：“浩大人终于停下了脚步。”

**浩(上司大人)**：“就是这个了。”

**爱德华(丈夫)**：“哦！”

**里奈(妻子)**：“哇。”

**爱德华(心理旁白)**：“就在我们正前方，有一片美丽的湖泊。”

**爱德华(心理旁白)**：“这片水域似乎是笼罩着树林的雾气的来源。”

**浩(上司大人)**：“每天这个时候，水温通常比较暖和。”

**爱德华(丈夫)**：“这真不错。”

**爱德华(心理旁白)**：“这是泡澡的最佳水温，尤其是现在天气这么冷的时候。”

**浩(上司大人)**：“这就是我们要洗澡的地方。”

**爱德华(丈夫)**：“好的。”

**爱德华(心理旁白)**：“我转过身去问浩大人，我们该按什么顺序下水。”

**爱德华(心理旁白)**：“结果我却看到他正在脱衣服。”

**爱德华(丈夫)**：“诶？”

**爱德华(丈夫)**：“浩大人……”

**爱德华(丈夫)**：“里奈等你做完，我就会回——来。”

**浩(上司大人)**：“啊，抱歉吓到你了，爱德华。”

**浩(上司大人)**：“我刚才忘了提，但这水不会保持太久。”

**浩(上司大人)**：“如果你决定再等等，到那时可能就太冷了。”

**里奈(妻子)**：“所以，你的意思是大家最好一起下湖。”

**浩(上司大人)**：“是的，是的。里奈。”

**爱德华(心理旁白)**：“诶？”

**爱德华(心理旁白)**：“这意味着……”

**里奈(妻子)**：“好的。”

**爱德华(心理旁白)**：“里奈毫不犹豫地站起身，脱下T恤，露出了赤裸的双乳。”

**爱德华(心理旁白)**：“她把衣服扔到地上，还脱下了内衣。”

**爱德华(心理旁白)**：“看着她，我的心怦怦直跳。”

**爱德华(心理旁白)**：“她难道没意识到，这里除了我之外，还有其他男人陪着她吗？”

**爱德华(心理旁白)**：“在踏入湖中之前，她转过身来看着我。”

**里奈(妻子)**：“亲爱的？你还没洗澡吗？”

**爱德华(丈夫)**：“我——我——我……”

**浩(上司大人)**：“爱德华——先生，水变冷之前，你也该下水了。”

**浩(上司大人)**：“此外，这水对我们当初来此的目的至关重要。”

**爱德华(丈夫)**：“咦？”

**爱德华(心理旁白)**：“我转过头，发现浩大人也已经脱得一丝不挂了。”

**爱德华(心理旁白)**：“他赤身裸体地站在湖边。”

**爱德华(心理旁白)**：“我简直不敢相信自己的眼睛。”

**爱德华(心理旁白)**：“说真的，他的鸡巴没健二的大。”

**爱德华(心理旁白)**：“但这仅就长度而言。”

**爱德华(心理旁白)**：“浩大人的鸡巴还是比我的长得多。”

**爱德华(心理旁白)**：“而且它的厚度和健二的一样。”

**爱德华(心理旁白)**：“而且……他已经完全勃起了。”

**爱德华(心理旁白)**：“我目瞪口呆地看着他走进湖里。”

**爱德华(心理旁白)**：“当水淹到他膝盖和腹股沟之间的一半时，他转过身来面对我。”

**浩(上司大人)**：“啊，爱德华，你再这样盯着我看，连我这个老头子都会觉得不好意思了。哈哈。”

**爱德华(丈夫)**：“对不起，浩大人。”

**爱德华(丈夫)**：“我刚才只是……”

**浩(上司大人)**：“哈哈。不用道歉，爱德华。”

**浩(上司大人)**：“说到底，我的身体之所以还能正常运转，全靠你和里奈。”

**浩(上司大人)**：“我真的很感谢你们两位，爱德华和里奈。”

**爱德华(丈夫)**：“先生，能为您提供帮助，我们深感荣幸。”

**爱德华(心理旁白)**：“这景象真奇怪；浩大人赤身裸体地站在湖里，还在向我道谢。”

**爱德华(心理旁白)**：“我瞥了里奈一眼，期待她能说点什么。”

**爱德华(心理旁白)**：“看起来她正盯着浩大人那根与水面平行挺立的硬挺阳具。”

**浩(上司大人)**：“即使这是真的，我仍然很感激你。”

**爱德华(心理旁白)**：“浩大人终于下水了，”

**爱德华(心理旁白)**：“只剩我一个人站在湖边，”

**爱德华(心理旁白)**：“-仍然穿着整齐。”

**爱德华(心理旁白)**：“我开始脱衣服。”

**爱德华(心理旁白)**：“但看到浩大人的“那玩意儿”以及我们之间的巨大差距后，”

**爱德华(心理旁白)**：“我不由得失去了所有的自信。”

**爱德华(心理旁白)**：“更糟的是，我的鸡巴因为天冷而软了，还缩了回去。”

**爱德华(心理旁白)**：“我用手捂住私处，然后走入湖中。”

**爱德华(心理旁白)**：“当身体浸入水中时，我感到有些胆怯。”

**爱德华(心理旁白)**：“要是我能有更大的鸡巴和更坚硬的勃起就好了……”

**爱德华(心理旁白)**：“那样的话，我也能像浩大人刚才那样，如此自信地站立了。”

**爱德华(心理旁白)**：“或者就像龙二当年在温泉里那样。”

**爱德华(心理旁白)**：“啊，这让我想起……”

**爱德华(丈夫)**：“浩大人……”

**浩(上司大人)**：“嗯？”

**爱德华(丈夫)**：“你——你刚才提到过，这个湖是我们最初目的的一部分。”

**浩(上司大人)**：“其实这很简单。”

**浩(上司大人)**：“你只需要让你的鸡巴在这水里保持勃起状态长达三十分钟，而且不能射精。”

**浩(上司大人)**：“它蕴藏着历经数个世纪积淀而成的庞大精神能量储备。”

**浩(上司大人)**：“如果你能照我说的做，你的阴茎会吸收一部分能量，从而变得稍微大一点、强壮一点。”

**爱德华(丈夫)**：“哦……”

**爱德华(心理旁白)**：“那么，他就是因为这个原因才在勃起状态下走进湖里的吗？”

**爱德华(心理旁白)**：“我原本还以为是因为我老婆那性感的身材呢。”

**爱德华(心理旁白)**：“哇。”

**爱德华(心理旁白)**：“现在，我在想到底要不要试一试。”

**爱德华(心理旁白)**：“仔细一想，这听起来真荒谬。”

**爱德华(心理旁白)**：“但万一有一线希望，说不定真的能行呢？”

**爱德华(心理旁白)**：“我该不该相信浩大人呢？”

**爱德华(心理旁白)**：“仅仅因为我不信任我那个狡猾的老板，就错失所有这些好处，那可就太可惜了。”

**爱德华(心理旁白)**：“我觉得试一试也没什么损失。”

**爱德华(心理旁白)**：“我就知道浩大人肯定在打什么主意。”
