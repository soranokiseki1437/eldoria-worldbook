## 二、 剧情硬伤防御与语言质感金标准

### 1. 剧情硬伤与世界基调防御（第一优先级）
世界书是**近现代奇幻同人故事**，绝非中国修仙武侠小说！在修订时必须逐项核查以下硬伤：

| 剧情硬伤 / 违和病灶（❌ 坚决拦截） | 世界观标准规范（✅ 必须纠正） | 改进理由 |
|:---|:---|:---|
| 场景写成“宗门洞府/深闺卧榻/暗岩禅房” | 场景纠正为“矮人祖厅/书房/帐篷/矿道石殿” | 符合近现代导力奇幻与矮人王国遗址场景 |
| 身体描写出现“四肢百骸/精关/气海/仙躯/云雨” | 身体描写使用“全身骨肉/深处/小腹/发烫的身体/交合” | 彻底清除修真玄幻味 |
| 动作写成“遂启唇相询/微敛双眸/引茎尽纳” | 动作使用“走到桌边轻声问/闭上眼睛/整根吞到底” | 保持通俗现代白话生活流 |
| 人物行为无动机突然发情/毫无预兆背德 | 补足心理因果、当前情境压力与长线情感铺垫 | 拒绝为了色情而硬写，动作必须由动因驱动 |
| 角色原本充满个性的台词被删减成哑剧动作 | 恢复角色台词，让人物开口说话，保持对白互动 | 有对白的人物才是活人 |

### 2. 真正的大纲边界：什么该留，什么该去
必须彻底纠正“大纲就是砍字数、砍台词、用文言缩写”的错误观念：
* **必须 100% 保留的内容（大纲的血肉与骨架）**：
  1. **所有对白与人物引语**：一句不漏，保留说话人的口吻与语气助词；
  2. **事件行动链与因果动机**：谁为什么去这里、为什么犹豫、为什么主动；
  3. **关键的情感转折与心理拉扯**：眼神交汇、心跳加速、事后的依恋与愧疚；
  4. **核心感官触觉**：温度（冰凉/滚烫）、质感（粗粝老茧/滑腻丝袜）、声音（水声/微弱喘息）。
* **应该精简剔除的冗余内容（不需要写成小说散文）**：
  1. 剔除长达数百字的环境静物散文描写（如描写窗外的云飘了五分钟）；
  2. 剔除旁观者上帝视角的抒情议论与说教；
  3. 剔除无意义的重复描写（同一章描写五次丝袜反光）；
  4. 剔除空洞的小资修饰副词（如“悄然”、“细微的”、“哪怕分毫”）。

### 3. 严禁伪文言与单字古雅词（坚守现代通俗白话）
* ❌ **绝对禁止将现代口语改造成单字文言**：
  * **严禁把“如果”改成“若/若是”**；
  * **严禁把“以前”改成“以往/过往”**；
  * **严禁古风书面语词**：“状若/宛若/仿若/自若/此番/何须/言毕/除却/秋毫无犯/端坐于/相询/横陈/虚悬/亵渎/未曾/已然/遂/徐徐”。
* ✅ **坚守直接的动词和现代通俗口语**（如“如果有人知道……”、“以前只进不出”、“坐在桌边”、“抱上床”、“用手指按住嘴唇”、“脱掉短靴”、“没动”、“抓着头发”）。

正文情境与所有元数据字段（核心、任务、终止条件）严禁打破第四面墙，禁止任何形式的回顾提及与进度评议！

* ❌ **绝对禁止的病灶典型**：
  * **禁止清单打勾式回顾提及**：严禁出现类似“手、脚、胸口之后，还差嘴”、“做完前置步骤，轮到……”、“继……之后，这次是……”等将亲密接触与剧情变成任务清单的打勾回顾；

* ✅ **合规标准与写作核心**：
  * **摄影机模型当刻沉浸**：镜头死死钉在**当下的时空、当下的触感、当下的呼吸与真实心理**，镜头对准谁就从谁此刻的感知展开；
  * **由当下动因自然触发**：角色的犹豫、紧张或探索，全部来自眼前当下具体的物理刺激与情感交织，由人物当下动机自然驱动。
