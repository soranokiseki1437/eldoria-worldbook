## 一、 角色声音合同与人设神髓 (Voice Contract)

### 1. 基础外貌与身份特征
* **身份**：埃雷波尼亚帝国托尔兹军官学院Ⅶ班班长、魔女之眷（Hexen Clan）继承人、古代史与地脉学者；使魔为黑猫瑟蕾奴（Celine）；
* **外貌特征**：修长丰润的成熟身姿、波浪编发、圆框眼镜（动情或泡泉时镜片常蒙上水汽）；
* **标志性衣饰与情欲符号**：
  * **深紫色丝袜（Purple Stockings）**：艾玛标志性的防线与私密载体。折叠、褪下、褪至膝弯、单腿高挽或被撕裂，均是情欲转折的关键锚点；
  * **银质吊带扣 / 学者长裙 / 软垫 / 魔导杖**：构成知性与欲望碰撞的独特仪式感。

### 2. 核心人设神髓（艾玛的灵魂定位）
* **“艾玛就是艾玛”（最高禁令 1：区分主语指代与形容修饰）**：
  * ❌ **严禁在指代艾玛时用“大姐姐”代替**：严禁出现“大姐姐跪了下来”、“紧拥住脱力的大姐姐”这种剥离人物视界、以上帝视角客体化角色的代称腔调；正文叙事必须始终沉浸在艾玛本人的视界、体温与呼吸中；
  * ✅ **“大姐姐”绝非全篇禁词，允许且鼓励在“形容修饰”时使用**：完全可以在形容艾玛的气质、神态、从容节奏与包容感时使用（例如“带着大姐姐独有的从容与耐心”、“大姐姐的节奏，不快但稳”等），这恰恰是凸显艾玛知性引导力与深沉母性魅力的绝佳韵味；
* **“包容与承担者”（深沉的母性与内敛的担当）**：
  * 艾玛的温柔绝非软弱顺从，而是一种“具有强大包容力的定海神针”；
  * 面对爱人（黎恩、法林），她愿意给予最柔软的安抚，同时在心底深处默默咽下秘密与愧疚（如 Ch439“低头咬着麦饼轻声应了句好，独自瞒下了秘密”）；
* **“知性从容与隐秘掌控”**：
  * 在私密情事中，艾玛具有极强的学姐/长姐引导力，绝非被动无措的雏鸟：
  * 擅长通过言语与动作轻柔主导节奏（如 Ch586“答错的话……可是要受罚的哦”、Ch439“你比上次乖多了呢……”）；
* **“古老魔女对待异化生灵的悲悯”**：
  * 面对牛头人等异化巨兽，艾玛展现的是魔女对古老血脉与痛苦生灵的悲悯安抚、探究与守护，而非堕落泄欲工具；在巨兽按膝克制中建立起跨越物种的温驯与信任。

### 3. 台词与语气规范
* **语气**：温和、从容、带着少许学姐式的轻柔关切；动情时声音软糯但条理清晰；极度放松时流露少见的娇憨（如 Ch597“水温刚好呢”、“头晕乎乎的”）；
* **省略号 `……`**：用于情动时的微弱喘息或内敛的思忖，严禁断句碎裂；
* ❌ **严禁生硬指令腔**：艾玛从不颐指气使，她的引导如春水漫过，温柔而坚定。

## 二、 语言质感与去浮华修辞金标准（用户实战立规）

### 1. 坚决杜绝小资浮华修辞与注水副词
世界书定位为**高密度情境大纲**，严禁滑向松散冗长的小说化散文。必须像刀刻斧凿般精准精炼：

| 常见注水浮词 / 网文发散（❌ 坚决剔除） | 质朴实感规范（✅ 采纳推荐） | 改进理由 |
|:---|:---|:---|
| 艾玛带着**加厚**软垫 | 艾玛带着软垫 | 剔除多余的属性修饰词 |
| 幽深的凉意顺着足心**悄然**漫了上来 | 幽深的凉意顺着足心漫了上来 | 剔除小资抒情副词，凉意动作更直接 |
| **细微的**摩擦声在石殿内格外清晰 | 摩擦声在石殿内格外清晰 | 剔除空洞虚词，摩擦声已足够传神 |
| 两只巨掌**握拳稳稳**压在膝头 | 两只巨掌**紧按**在膝头 | 动词更实感，消除刻意雕琢感 |
| 从始至终未曾伸手触碰她**哪怕分毫** | 始终没有伸手触碰她 | 消除翻译腔与夸张排比 |
| 用棉布**细细**擦净脚掌 | 用棉布**擦净**脚掌 | 消除刻意慢动作副词 |
| 滚烫白浊**猛然**喷涌而出……**缓缓**滑落 | 滚烫白浊喷涌而出……顺着足弓滑落 | 剔除对仗副词，动作真实自然 |
| **满眼**关切地叮嘱 / 心底**翻涌着**隐秘的愧疚 | 关切叮嘱 / 心底**泛起**隐秘的愧疚 | 符合艾玛内敛沉静的魔女心性 |

### 2. 严禁小说化注水与过度细节发散
* 拒绝拉长慢动作特写（如睫毛颤动三秒、指尖微毫米滑动）；
* 拒绝大段环境写景与心理独白旁白；
* 保持情境大纲的骨架张力：**“情境铺展 ➔ 触碰与敏感 ➔ 互动推向高潮 ➔ 释放与回落 ➔ 事后心理余韵与现实交汇”**。

### 3. 🚨 关键界限：区分“无效注水副词”与“核心主体反差美学”（极重要教训）
去浮华修辞绝不是把有力量的视觉反差与角色名字机械删光！必须严守界限：
* ❌ **必须剔除的无效浮华**：
  * 空洞的弱副词与小资点缀（悄然、细微的、稳稳、哪怕分毫、细细）；
* ✅ **必须誓死捍卫的核心美学与主体锚定（Ch641 核心范例）**：
  * **主体锚定（艾玛的名字）**：在多人混战（如矮人多尔金、哈根）等场景中，严禁写成无主语的“托起长腿”（沦为客体化零件），必须写 `多尔金托起艾玛雪白的长腿`，将叙事视角与情感重心死死锚定在艾玛身上；
  * **核心反差意象（雪白）**：在暗红熔炉、粗粝老茧与黝黑矮人工匠的环境中，“**雪白**”不是多余形容词，而是构建“**粗暴/黝黑/蛮力 vs 细腻/雪白/魔女修长身姿**”顶级性张力的核心支柱，绝不可当成“浮华副词”误杀！

### 3. 坚决杜绝文言文与半文半白腔调（现代大纲体铁律）
世界书是**现代通俗白话、生活流质感、动词精准直观**的大纲体文本，严禁滑向古代修真、文言志怪或古风武侠腔：
* ❌ **严禁字词**：“遂”、“未曾”、“其上”、“四肢百骸”、“徐徐”、“已然”、“伏案”、“未敢擅动”、“横陈”、“虚悬”、“亵渎”、“此番”、“何须”、“纵横交错”、“自此夜起”等。
* ✅ **白话规范**：用直接的动词和现代日常口语（如“坐在桌边”、“抱上床”、“用手指按住嘴唇”、“脱掉短靴”、“没动”、“抓着头发”）。
* **对白与心理**：人物对话必须符合轨迹系列与现代生活流，真诚直接，不作诗句式或戏剧古言念白。

### 4. 严禁计数型机械叙事（反数字标定病灶）
* ❌ **绝对禁止写“第几次如何”**：严禁“第二次释放”、“第三次被填满”、“这是她第一次……”等生硬的计数句式。
* 情境的递进与高潮必须通过感官张力、动作深度、呼吸变化来自然展现，绝不能依赖干瘪的数字统计来强行标定进度。

### 5. 根除老旧机械病灶（反 cc+deepseek 流水账与代码标签）
* ❌ **排查全篇漏标点**：早期老稿极易在段末漏句号，必须地毯式补全；
* ❌ **根除无主语代码流水账**：严禁“脱袜。握住。摩擦。射精。”式代码推进；每一个动词必须附着在人物具体生理感知与交互反馈上；
* ❌ **严禁空间/视角分割代码标签（Ch478 重构经验）**：严禁出现 `桌面以上：`、`桌面以下：`、`门内：/门外：` 等生硬的说明书式代码标签！空间对比与内外暗流必须熔铸在自然的镜头转接、对白掩护与肢体动线中。

## 三、 “核心”元数据字段严禁元叙事铁律 (LRN-20260910-005)

**“核心”字段是章节故事内部的情感与冲突实质，严禁打破第四面墙写编剧分析！**

* ❌ **绝对禁止**：
  * 禁止创作技巧分析与结构模型拆解（如“为……搭建了框架”、“形成了绝妙平衡”）；
  * 禁止分析性流程图与箭头（如“发现需求→想走→折返”、“心理博弈：A→B→C”）；
  * 禁止剧作意图旁白括号（如 `（秘密的线索，无人追问）`）；
* ✅ **合规标准**：
  * 纯粹陈述故事内部的人物情感矛盾、事件经过与隐秘羁绊。
  * *范例（Ch439）*：“艾玛以裸足为牛头人完成再次释放，巨兽学会双手按膝克制不碰，展现跨越物种的温驯与尊重。面对法林关切的陪伴叮嘱，艾玛在善意的应允中独自背负起守护异化巨兽的隐秘羁绊。”

## 四、 终止条件 3 纯物象定格规范

* **终止条件 3**：**必须是纯客观物象、自然环境或物理痕迹的余韵定格，绝对禁止包含人物连续动作**！
  * *范例（Ch586）*：“深夜书房只剩羊皮纸上洇开的墨迹，茶盘上的红茶升腾着微弱白汽，窗外月色清冷如水。”

## 五、 两类源稿的分流精修对策 (LRN-20260910-004)

在对全库艾玛章节进行润色时，必须首先诊断源稿类型，严禁“一刀切盲目重写”：

### 类型 A：高质量生动原稿（如 Ch517、Ch557、Ch597、Ch641）
* **特征**：叙事要素完备、生活化对白极其传神、情感饱满真挚；
* **对策**：**判定“原文更好”，敬畏原稿神韵，绝不推倒重来**！
* **操作重点**：
  1. 剔除偶现的外部标签代称（“大姐姐”全部改回“艾玛”）；
  2. 清理元数据中的无效空行；
  3. 检查终止条件 3，将人物动作收归条件 2，条件 3 改为纯物象定格。

### 类型 B：早期老旧机械稿（如 Ch375、Ch439 等 cc+deepseek 遗留稿）
* **特征**：末尾漏句号、代码流水账、缺乏主语、台词生硬指令化、核心字段带有元叙事分析；
* **对策**：**外科手术式重塑**！
* **操作重点**：
  1. 补全标点，赋予生理触感与感官流动；
  2. 运用“去浮华修辞金标准”，剔除网文散文化发散，控制在干练的大纲骨架区间；
  3. 重写核心字段，连根拔除流程图与分析括号；
  4. 规范终止条件 3 为纯物象定格。

## 七、 润色执行工作流与自检 Checklist

### 执行工作流
1. **诊断与定级**：运行 `wc` 查看字数，判断是类型 A（传神原稿）还是类型 B（老旧机械稿）；
2. **文本手术**：
   - 坚守“艾玛就是艾玛”，清剿所有“大姐姐”代称；
   - 贯彻去浮华副词标准，删减“悄然”、“细微”、“加厚”等注水词；
   - 检查道具前后一致性（如麦饼不可突变为面包）；
   - 确保核心字段 0 元叙事；
   - 终止条件 3 纯物象化；
3. **验证与入库**：
   - 运行 `python3 scripts/story_tool.py validate` 确保全库一致性 0 违规。

### 自检 Checklist
- [ ] **“艾玛就是艾玛”**：全篇 0 处“大姐姐/知性魔女”等外部标签化代称；
- [ ] **0 浮华注水副词**：无“悄然”、“细微的”、“哪怕分毫”、“细细擦净”等过度修饰；
- [ ] **0 元叙事**：核心字段无流程图箭头（`→`）、无创作手法拆解、无旁白括号；
- [ ] **终止条件 3 纯物象**：条件 2 收容所有人物连续动作，条件 3 纯环境物象定格；
- [ ] **道具一致**：食物、衣饰前后口径严格统一；
- [ ] **字数合规**：落入 400~650 字高密度大纲骨架，无网文小说化注水；
- [ ] **通过校验**：全库验证 872 章 0 违规。
