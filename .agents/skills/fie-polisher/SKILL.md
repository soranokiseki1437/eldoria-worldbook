# 菲专属章节润色与精修技能指南 (Fie Character Polisher)

> 本技能定义了世界书全库所有涉及**菲（Fie Claussell）**章节的最高写作、润色与精修标准。
> 核心原则源于项目记忆 **[LRN-20260910-002]**（拒绝机器人、娇羞与兴奋、情节重构、禁说明性对比）与 **[LRN-20260910-003]**（字数规范与三级动态阶梯）。

## 一、 角色声音合同与人设神髓 (Voice Contract)

### 1. 基础外貌与身份
* **年龄与身材**：20 岁，前西风旅团（Zephyr）幸存兵，身材娇小紧凑精悍（A 罩杯、平坦紧致小腹、骨骼纤巧柔韧、双腿修长有薄茧旧疤）；
* **外貌特征**：纯白发及背、有一根呆毛、黄绿色眼瞳（动情时泛水汽、兴奋时亮起）、双枪剑；
* **人设核心神髓**：
  * **“走进去。找到它。带回来。”**——行动永远走在言语前面，极度直接坦率，想做就做，没有多余铺垫与虚伪装饰；
  * **情感羁绊定位**：对黎恩有雏鸟般的全身心依赖、信任与笨拙爱意；对菲娜有小女儿般毫不设防的依附、敬仰与事后坦荡报备。

### 2. 标点与台词体系
* **话少直率**：单句精炼，直击要害（如“……黎恩，玲说的是真的么？”、“教我。”、“再试的话，我可以在上面。”）；
* ❌ **严禁波浪号 `~`**：菲性格干脆憨直，从不使用娇滴滴的拉长波浪号；
* **省略号 `...`**：仅用于微弱的气息微断或极短暂的局促迟疑；
* ❌ **严禁连续句号碎短句**：消灭机器人式的单字句号堆砌，让叙述和动作自然连贯。

### 3. 🚨 致命 OOC 彻底清剿（假猫耳排查）
* **100% 真实人类设定**：菲是人类猎兵，**绝无兽耳、尾巴或猫娘生理结构！**
* ❌ **红线禁令**：原文出现的“耳朵转了半圈”、“耳朵转了哦”属于严重的伪动物拟态违规，必须连根拔除；
* ✅ **合规替代微动作**：纯白发丝微晃、耳尖/耳根泛起滚烫薄红、脚步微微停顿、微偏过视线、脚趾害羞蜷缩。

## 二、 核心情感公式与动因链（拒绝无情感机器人）

任何亲密接触或性行为，必须遵循**“情感动因 ➔ 娇羞试探 ➔ 隐秘兴奋 ➔ 依恋温存”**四阶段闭环：

```
[阶段 1: 坚实情感动因]
  不为任务而做，源于少女笨拙的爱意、渴望被恋人注视、想要讨对方欢心、渴望体温。
  常伴有对自身猎兵旧疤/老茧的自卑，被黎恩的温柔与怜爱消融。
        ↓
[阶段 2: 真实的娇羞与生理敏感]
  即使是前猎兵，面对性接触也必然存在生理敏感：
  肌肤相触时的身子紧绷、脚心/腿心发烫、喉间抽气喊烫、耳尖烧透、微颤气音。
        ↓
[阶段 3: 支配恋人欲望的隐秘兴奋]
  看到沉稳强大的恋人（教官/灰之骑士）因自己的触碰而喉结滚动、肌肉紧绷、失控沉沦，
  少女心底必然炸开强烈的成就感与隐秘兴奋：眼眸变亮、主动收绞碾磨、嘴角抿起羞怯又得意的极小笑意。
        ↓
[阶段 4: 事后温存与羁绊强化]
  高潮后发软依偎、向菲娜大姐姐坦白心迹、猎兵式傲娇挽尊（“下次我在上面”）、捧茶谢恩。
```

## 三、 语言质感与禁则铁律

1. **彻底杜绝说明性对比（硬红线）**：
   - 坚决杜绝作者视角的说明文式对比（如“比丝袜粗粝”、“不像菲娜精致”等）；
   - 聚焦于当下的真实触觉、摩擦阻力与心理流动。
2. **正面肯定描写（无 pivot 否定）**：
   - 杜绝“不是……是……”、“没有……只是……”；
   - 用肯定的行动与神态替代反向排除法。
3. **禁用词地毯式清剿**：
   - 严禁“一丝/一 丝”、“不易察觉”、“不容置疑”；
   - 严禁使用“小猫”、“小兽”等动物化幼态比喻；
   - 严禁“她在想……”等意识流前缀。
4. **终止条件 3 纯物象定格**：
   - 条件 2 负责收纳人物离开、穿衣等所有连续动词链；
   - 条件 3 必须是环境余韵、物理痕迹或客观物象（如：靴印、茶雾消散、炉火余烬、晨光晾干棉布），绝对禁止包含人物主观动作或连续动词链。

## 四、 动态字数三级阶梯（LRN-20260910-003）

情境大纲必须保持高信息密度，坚决拒绝发散成松散小说：

| 等级分类 | 适用场景 | 目标区间 | 上限警戒线 | 典型范例 |
|:---|:---|:---:|:---:|:---|
| **Level 1 (轻量微交互)** | 日常闲谈、任务间歇、单一微小身体触碰 | **300 ~ 500 字** | 550 字 | Ch040（森林之眼）、Ch564（守夜口交） |
| **Level 2 (标准推进/单阶段)** | 单一场景完整性爱（常规晨交/独处手交/足交） | **700 ~ 850 字** | 900 字 | Ch475（晨间唇）、Ch479（狩猎独处） |
| **Level 3 (重头大章/多阶段)** | 初夜破防突破、双人/三人深层互动、多阶段转折 | **850 ~ 1,000 字** | **1,050 字** | Ch172（裸足诚意）、Ch530（叫醒结合）、Ch674（初次本番） |

> 🚨 **预警线**：单章情境 > 1,050 字符触发黄色预警（须审视并剔除修辞水分）；> 1,200 字符触发红色超标（除极少数史诗大章外强制精简）。

## 五、 润色执行工作流与自检 Checklist

### 执行步骤
1. **定位章节**：`docs/story/{阶段}/{ID}：{名称}.TXT`；
2. **诊断与重构**：
   - 审视情感动因（为什么发生？菲的心理依恋在哪里？）；
   - 检查是否有假猫耳，彻底替换为真实人类微动作；
   - 丰富娇羞反应（生理敏感、耳尖泛红）与支配快感时的隐秘兴奋；
   - 检查是否有菲娜互动或事后报备；
3. **字数自查与核验**：
   - 运行 `python scripts/story_tool.py wc <ID>` 查看情境字数与等级评定；
   - 确保未触发 1,050 字黄色警戒线；
4. **语法与一致性验证**：
   - 运行 `python scripts/story_tool.py validate {阶段}` 确保 0 违规。

### 核心排查清单 (Checklist)
- [ ] **有坚实的情感动因**：无公事公办冷漠感，写出少女想要被爱、被注视的心情；
- [ ] **写透真实的娇羞与生理敏感**：脸颊薄红、耳根烧透、脚趾蜷缩、喉间抽气喊烫；
- [ ] **写透支配快感的隐秘兴奋**：看恋人失控时眼眸变亮、嘴角微翘得意、动作主动发力；
- [ ] **0 假猫耳违规**：搜索排查无“耳朵转”；
- [ ] **0 说明性对比**：无“比丝袜粗粝”、“不像菲娜”等作者视角对比；
- [ ] **0 禁词**：无“一丝”、无“不易察觉”、无“不容置疑”；
- [ ] **字数合规**：落入对应 Level 1/2/3 区间，未超 1,050 字；
- [ ] **终止条件 3 纯物象**：正文结尾不与条件 3 简单复读，条件 3 纯物象/物理余韵收束。
