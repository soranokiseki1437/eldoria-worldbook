# 第二部（维里迪亚王国篇）大纲写作

> **定位声明**：本项目只写情境大纲，不写小说正文。幕级大纲、分阶段详规、章节 TXT 均为大纲。
> **基准风格**：**纯正日式 RPG 架空剑与魔法轻小说大纲（JRPG Western Fantasy & Light Novel Outline）**——以《英雄传说 轨迹系列》的细腻羁绊、生活流与战技美学为基底，融合《最终幻想》《勇者斗恶龙》《八方旅人》《无职转生》《狼与香辛料》《葬送的芙莉莲》。

- 通用文风、人称、称谓、词汇：按 [AGENTS.md](../../../AGENTS.md)、[writing-guards.md](../../rules/writing-guards.md)、[lexicon.md](../../rules/lexicon.md) 执行。
- 情境的白话写法（报备腔、话本腔、张弛）：按 [vernacular-fantasy-planner](../vernacular-fantasy-planner/SKILL.md) 执行。
- 本文件只写第二部独有的内容。第二部禁止使用第一部的 story-writer，也禁止引入第一部字段（战术隐蔽、爱意值、隐秘事件、背德事件等）。

## 1. 文档层级与格式

### 1.1 层级

| 层级 | 位置 | 写法 |
| :--- | :--- | :--- |
| 幕级大纲 | `方案/第二部/主线与世界扩充方案/分阶段详规/XX_第X幕_*/00_第X幕大纲与接口.md` | 条目骨架：`* **剧情路线**`、`* **主要人物**`、`* **核心意图**`、`* **情境推进**：1. … 2. …` |
| 分阶段详规 | 同目录下 `阶段*_*详规.md` | 情境叙述段，见 1.2 |
| 章节大纲 | `docs2/story/第X幕/{ID}：{名称}.TXT` | 9 字段 TXT，见 1.3 |

设定冲突时的权威顺序：`docs2/` 实体卡 > 母案方案（00~06）> 幕级大纲 > 分阶段详规。详规与 `docs2/` 不一致时，以 `docs2/` 为准，回改详规。

写到哪个角色、地点、生物，就去读对应的卡：

- 角色与 NPC：`docs2/character/`、`docs2/npc/`、`docs2/story/_character_attributes.txt`（外貌、装备、声线、称谓）
- 地点：`docs2/location/`（建筑材质、空间尺寸、门锁、声音和视线遮挡）
- 生物与武装：`docs2/creature/`
- 历史与制度：`docs2/world/`

**「二、情境推进」的写法**

- 每个 `###` 小节按时间顺序写若干段，交代在哪里、谁在场、做了什么、结果怎样。
- 对白与对话概括结合：推动剧情或体现人设的关键台词直接写出来，嵌在段落里（一段里可以有几句连贯对话）；长篇推理、重复交代、次要细节直接用一句话概括（如“用清脆的声线进行了一番严谨推理”、“继续说了一些他知道的事情”、“他认为……这就形成了一处至少有一刻钟的巡防死角”、“微笑地夸奖提米”）。
- 交代对话用「说、问、告诉、认为、夸奖」这类普通动词，禁止用「敲定、汇报、达成共识」这类公文词。
- 要写：写章节时用得上的事实，包括地点、时间、谁在哪里、物件交给了谁、谁知道了什么信息。
- 不写：冗长铺陈的推理过程、过细的道具参数与微观物理数值（如分贝、毫米级精度、抽气频率）。
- 不用列表写情境。扫描脚本会拦截 `- 1. **…` 和 `* **剧情路线**` 这类条目。
- 「二」的最后一段只写环境、静物、光线、声响，不写角色动作和心理。

### 1.3 章节大纲 TXT

```text
ID: {三位数字}
名称: {前半段}——{后半段}
NSFW: {是 或 否}
性行为等级: {0-10，仅 NSFW 章节填写}
黎恩知情: {描述，不适用留空}
主要人物: {角色1}, {角色2}
总情境数: {N}
情境:
  - 1. ...
  - N. ...
核心: {1~2 句}
```

- 只用这 9 个字段，顺序固定。`总情境数` 等于情境条数。
- 情境 4~9 条，按剧情需要定，不固定写 5 条。
- 2~4 条情境里要有角色直接对白。
- 第 N 条只写环境、静物、光线、声响，作为全章收尾。
- 名称：前半段写具体物件或场景，后半段写关键行动。
- 核心：不用破折号，不写 AI 式评价，不剧透后续章节。
- 细则见 [_TEMPLATE_RULES.md](../../../docs2/story/_TEMPLATE_RULES.md) 和 [_WORKFLOW.md](../../../docs2/story/_WORKFLOW.md)。

## 2. 第二部世界设定

### 2.1 双主线

- **艾德里安（主线 A）**：以北方商会商人身份伪装，调查家族城堡废墟，揭露三十一年前教廷的暗影实验和十九年前伪造的「山贼攻陷城堡」令，在王都真理广场发起审判，收回祖地。
- **雷恩（主线 B）**：以背誓流放者身份回国，面对十四年前屠杀平民、被剥夺誓言的真相，在圣殿校场当着全旗队清算大团长阿达尔伯特，重立晨光之誓，成为自由剑士。
- **黎恩与帝国先遣队**：负责战术支援、物资和情报中转。关键决定由艾德里安和雷恩自己做，黎恩一行不替他们做。

### 2.2 零导力

- 维里迪亚没有导力文明。原住民把导力光芒当成异端黑巫术或不明炼金器械，不会随口说出「导力」。
- ARCUS 装在乔治做的浸油皮革遮蔽盒里，外观像普通文书盒。
- 在王都和圣殿大要塞，不公开使用导力器、不放导力电弧和魔法，菲娜不展开光翼。战斗靠冷兵器、体术和战技配合。
- 本地照明和取暖：鲸油灯、牛油蜡烛、松脂火把、木柴壁炉。王室和教廷高层用天然发光的微光水精石或日光百合符文。

### 2.3 晨光教廷与圣殿骑士团

两者是不同组织，人员、据点、罪证互不混用。称谓对照见 lexicon.md 第十一节，「军」字禁令见 writing-guards.md。

| | 晨光教廷 | 圣殿骑士团 |
| :--- | :--- | :--- |
| 性质 | 跨国宗教神权，文职；总廷在大陆中央圣都 | 跨国独立武装修会；据点是圣殿大要塞，上级是大陆的圣殿大修会总团 |
| 人员 | 枢机主教克莱门特三世、异端审问厅执行官达米安、首席炼金工匠维克托、异端审问官、暗部斥候、发条机关兽、暗影忏悔死士 | 白鹰队长卢卡斯、典狱长莫尔茨、老副团长戈德弗里、老哨长巴恩斯、雷恩、重装骑士 |
| 据点 | 晨光大教堂（LOC_D2_19）、教廷秘库（LOC_D2_20）、晨光修道院（LOC_D2_07，附设药舍）、维克托的地下工坊 | 圣殿要塞（LOC_D2_21）、圣殿校场（LOC_D2_22）、圣殿地牢（LOC_D2_23，惩戒和水牢，不做机兽实验）、维里迪亚大门（LOC_D2_04） |
| 罪证 | 秘库：三十一年前暗影实验原案；十九年前艾斯特雷亚堡惨案的灭口令与嫁祸假案（克莱门特签字） | 要塞铁柜：前任大团长的屠杀自白血书；克莱门特二十年分赃与屠杀密令（阿达尔伯特用来防备教廷的底牌） |

- 教廷没有骑士团。教廷方的决斗者是「异端审问厅首席裁决剑士」。
- 禁止出现：教廷骑士、教会骑士、教廷审判骑士、圣殿主教、圣殿神官、圣殿修道院、要塞军权。
- 结局的法理：王权不单方面取缔教会或解散修会。三大物证和前任大团长自白分别交给「晨光总廷神圣议会」和「圣殿大修会总团」，罢黜责任人；新王朱利安签署《维里迪亚新协约》，和平收回要塞的管辖权与税权。

### 2.4 张弛节律

按下面三段循环安排阶段，不连续堆高压：

外部高压调查或战斗突围 → 旅途伪装、驿馆投宿 → 营地温情、工坊整备

### 2.5 潜入与隐秘场景的掩护来源

写潜入、偷听、交接密信、隐秘亲密场景时，用现场本来就有的声音、视线遮挡和固定周期制造紧张：

- **底层酒馆（黑野猪酒馆）**：楼下佣兵碰杯和鲁特琴声；薄木门外有人走过时门板会震。
- **公共浴场（圣泉大浴场）**：蒸汽浓到两步外看不清；石雕喷泉水声很大；水雾石隔断后有侍者的影子来回走。
- **半地下酒窖（艾斯特雷亚酒庄）**：两米高的橡木桶排成视线死角；桶匠每十几分钟敲一次铁箍。
- **王宫玻璃温室**：棕榈林的阴影；卫兵靴子踩碎石路，声音由远到近再走远。
- **双马篷车**：雨夜车轮碾碎石、暴雨打在生牛皮顶棚上的声音。

### 2.6 战斗

- 保留战技名，如「八叶一刀流·二之型——疾风」「亚尔赛德流——真·旋风断」。
- 大纲里写清：谁对谁、用什么、打中哪里、结果（破防、击退、拆掉机关部件）。分工写成「正面顶住 → 侧面封退路 → 标出弱点 → 斩断核心」这样的配合。
- 动作和武技词汇按 lexicon.md 第六节，禁止使用国术武侠的发力和招式。

### 2.7 风土实体

货币、道路、建筑、饮食、器物按 lexicon.md 第二至五节和 [lexicon_mapping.md](references/lexicon_mapping.md)。不写「六字以上假洋名长定语 + 括号英文」，如「高石围墙方庭合院式高级驿舍（Courtyard Coaching Inn）」，改成「石造大驿馆」「马车旅舍」这类短名。

## 5. 交付前自查

逐条过一遍。结果只在对话里汇报，不写进任何文档。

- [ ] 详规是按大纲写的（绝不写成正文）：长篇推理与次要对话已用一句话概括，已删掉特写式的装备描写与分贝、毫米等数值细节。
- [ ] 登场角色的外貌、装备、称谓已对照 docs2 卡核实。
- [ ] 教廷和圣殿的人员、据点、罪证没有混用。
- [ ] 全篇遵守零导力，无导力光弧外溢。
- [ ] 章节 TXT 只有标准 9 个字段，`总情境数` 与条数一致。
- [ ] 最后一段（或第 N 条）只写环境、静物、光线、声响，无角色动作和心理。
- [ ] `scan_viridia_diseases.py` 扫描为 0 违规。
