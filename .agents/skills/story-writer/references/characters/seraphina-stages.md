# Seraphina（菲娜）各阶段人设与心理演进参考

> 本参考提炼自菲娜早期、中期、阶段五及阶段六微调指南，用于创作与扩写菲娜戏份时的行为准绳。

---

## 一、 贯穿全阶段的恒定底色

1. **基本气质**：
   - **娇羞 + 妩媚 + 甜美** 是菲娜一以贯之的情感底色。
   - 随阶段推移，特征是**层层叠加**而非粗暴替换（例如到了掌控阶段，依然会脸红耳热）。
2. **身体先于意志**：
   - 菲娜的感知序列永远是：**身体产生反应（耳根发热/微颤/湿润） → 意识认知到 → 做出接纳或推开的理智判断**。
3. **愤怒的真正根源**：
   - 愤怒来自**“被无视”**，而非单纯被触碰。
   - 当她发出软声推拒（“等一下……”），对方若继续粗暴推进，耳朵会从红转为苍白，这是她真正冰冷动怒的物理标志。
4. **回归时刻“被接住”原则**：
   - 结束第三者经历回到黎恩身边时，菲娜不需要先演一场推搡对抗（捶胸口/抓领子）。
   - 她最需要的是“被接住”，由黎恩直接给予拥抱、亲吻与对身体的温存包裹。

## 二、 九阶段演进速查

| 阶段 | 阶段主题 | 菲娜核心心理与状态特征 |
|:---:|:---|:---|
| **0：序章** | 苏醒与契约 | 茫然脆弱、守护者的古老宿命、对黎恩灵魂与鬼之力的初次共鸣与羁绊。 |
| **1：试探和暧昧** | 坦白与注视 | 娇羞、轻微抗拒与不安；在黎恩注视下经历第一次身体共享，事后极度需要黎恩的确认。 |
| **2：挑逗和接受** | 主动展示 | 试探边界，开始主动在黎恩面前展露身躯；初次口交体验，羞耻感与愉悦并存。 |
| **3：渐进接触** | 多样化爱抚 | 足交、手交、乳交、隐奸；对第三者的触碰从紧张逐渐转为感官体验，但底线坚守。 |
| **4：跨线** | 首次插入突破 | 自主选择跨过最后防线；在充分准备和信任下接纳第三者深入，紧靠黎恩的情感锚定。 |
| **5：享受和掌控** | 主动设计与多P | **掌控模式开启**：从被动承受变为主动引导甚至设局；三色自检（绿/黄/红）；事后主动向黎恩复盘分享。 |
| **6：放纵** | 极限探索与放开 | 主动服务、极限感官挑战（低语者/触手/群交）；黎恩在旁忍耐与守护，菲娜全情放纵后彻底回归黎恩怀抱。 |
| **7：终局** | 决战与升华 | 决战前夜的情感沉淀、净化树心、互写情书；彼此身心与灵魂完全交融。 |
| **8：后日谈** | 自由探索 | 森林恢复后的日常与随性探索；亲密互动自然流淌，兼具威严守护者与黏人爱侣双重身份。 |
