# Seraphina（菲娜）各阶段人设与心理演进参考

> 本参考提炼自菲娜早期、中期、阶段五及阶段六微调指南，用于创作与扩写菲娜戏份时的行为准绳。

---

## 一、 贯穿全阶段的恒定底色

1. **基本气质**：
   - **娇羞 + 妩媚 + 甜美** 是菲娜一以贯之的情感底色；
   - 随阶段推移，特征是层层叠加而非粗暴替换。
2. **身体先于意志**：
   - 菲娜的感知序列永远是：身体产生微动作与体表反应 ➔ 意识认知到 ➔ 做出接纳或推开的理智判断。
3. **动怒的真正根源**：
   - 动怒来自被无视，而非单纯被触碰；
   - 当她发出软声推拒，对方若继续粗暴推进不予理会，耳朵会迅速褪去血色转为苍白，这是她真正动怒的物理标志。
4. **回归时刻“被接住”原则**：
   - 结束第三者经历回到黎恩身边时，菲娜不需要多余的推搡对抗；
   - 她最需要的是“被接住”，由黎恩直接给予拥抱、亲吻与对身体的温存包裹。
5. **受困与越界情境的叙事方法（教方法，杜绝死板套路）**：
   - **空间受困靠物理构建**：依托现场环境中的实体障碍物与体格差交代受困，以动作来回展现拉扯，不靠旁白说明；
   - **心智坚守从容与心软**：客观上虽处被动受侵境地，主观上绝不写万念俱灰、名节受损、怨恨悲戚或绝望哭喊；角色始终保底心软、娇羞与内心底气，面对同伴源于心软娇嗔，深陷时做深呼吸接纳放松；
   - **动作真切，杜绝抽象术语**：描写全部落到角色当下细微具体的微动作与呼吸变化上，严禁使用“生理”、“神经”、“生理性”等抽象伪科学词汇。

## 二、 九阶段演进速查

| 阶段 | 阶段主题 | 菲娜核心心理与状态特征 |
|:---:|:---|:---|
| **0：序章** | 苏醒与契约 | 茫然脆弱、守护者的古老宿命、对黎恩灵魂与鬼之力的初次共鸣与羁绊。 |
| **1：试探和暧昧** | 坦白与注视 | 娇羞、轻微抗拒与不安；在黎恩注视下经历第一次身体共享，事后极度需要黎恩的确认。 |
| **2：挑逗和接受** | 主动展示 | 试探边界，开始主动在黎恩面前展露身躯；初次口交体验，羞耻感与愉悦并存。 |
| **3：渐进接触** | 多样化爱抚 | 足交、手交、乳交、隐奸；对第三者的触碰从紧张逐渐转为感官体验，但底线坚守。 |
| **4：跨线** | 首次插入突破 | 自主选择跨过最后防线；在充分准备和信任下接纳第三者深入，紧靠黎恩的情感锚定。 |
| **5：享受和掌控** | 主动设计与多P | 掌控模式开启：从被动承受变为主动引导甚至设局；三色自检；事后主动向黎恩复盘分享。 |
| **6：放纵** | 极限探索与放开 | 主动服务、极限感官挑战；黎恩在旁忍耐与守护，菲娜全情放纵后彻底回归黎恩怀抱。 |
| **7：终局** | 决战与升华 | 决战前夜的情感沉淀、净化树心、互写情书；彼此身心与灵魂完全交融。 |
| **8：后日谈** | 自由探索 | 森林恢复后的日常与随性探索；亲密互动自然流淌，兼具威严守护者与黏人爱侣双重身份。 |
