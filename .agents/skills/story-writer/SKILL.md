# 章节创作与扩写技能指南 (Story Writer)

> 本技能定义了在世界书中新增章节 TXT、设计情境展开及补全元数据字段的标准操作指南。

---

## 一、 章节 TXT 标准格式规范

每个新建的章节文件必须保存于 `docs/story/{阶段}/` 下，严格遵循如下模板结构：

```text
ID: {纯数字编号}
名称: {前半段}——{后半段}
NSFW: {是 或 否}
性行为等级: {0-10}
阶段: {序章 / 试探和暧昧 / 挑逗和接受 / 渐进接触 / 跨线 / 享受和掌控 / 放纵 / 终局 / 后日谈}
第三者: {无 或 角色名（身份）}
黎恩知情: {知情并守护 / 共同在场 / 事后分享 等简述}
好感影响: {Seraphina: +2, 某角色: +3}
情境:
- {情境条目 1：起因与环境氛围铺垫}
- {情境条目 2：互动推进，身体本能与感官呈现}
- {情境条目 3：核心张力爆发或亲密突破}
- {情境条目 4：落地收敛，事后温存或回归黎恩}
核心: {1句话概括本章的核心设计意图与关系推进}
章节任务: {1句话明确剧情推进的阶段性目标}
章节终止条件:
- {明确具体的事件落地标志 1}
- {明确具体的事件落地标志 2}
```

---

## 二、 核心字段创作要点

### 1. 情境条目编写标准（3-5 条）
- **条目 1（起因）**：交代环境光影、起因事件、角色物理距离与初始心绪。
- **条目 2-3（交互）**：呈现真实的身体反应与言语试探，严格遵循“身体先于意志”；对话嵌入动作，严禁引语归属词“答/应”。
- **条目 4（收尾）**：若有第三者经历，必须有向黎恩“被接住”的回归时刻或温存闭环。
- **禁止项**：绝不出现现代工程词（“优化/提升”）、绝不写“不是……是……”否定句式、绝不滥用破折号。

### 2. 章节任务与终止条件设计（来自条件修复方案）
- **章节任务**：必须是具体的叙事行动目标（例：`"在暖岩石上完成精油推拿，并引导菲娜自愿接受指交体验"`），严禁虚无的心理大纲。
- **终止条件**：
  - 必须是**物理可判定**的事件节点（例：`"完成至少一次体内射精并抽出"`、`"黎恩将菲娜拉入怀中擦去泪痕"`）；
  - 严禁以不可判定的抽象心理状态（如`"两人心灵获得升华"`）作为终止条件。
