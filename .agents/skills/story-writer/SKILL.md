# 章节创作与扩写技能指南 (Story Writer)

> 本技能定义了在世界书中新增章节 TXT、设计情境展开及补全元数据字段的标准操作指南。

---

## 一、 章节 TXT 标准格式规范

每个新建的章节文件必须保存于 `docs/story/{阶段}/` 下，严格遵循如下模板结构：

```text
ID: {纯数字编号}
名称: {前半段}——{后半段}
NSFW: {是 或 否}
性行为等级: {0-10}
阶段: {序章 / 试探和暧昧 / 挑逗和接受 / 渐进接触 / 跨线 / 享受和掌控 / 放纵 / 终局 / 后日谈}
第三者: {无 或 角色名（身份）}
黎恩知情: {知情并守护 / 共同在场 / 事后分享 等简述}
好感影响: {Seraphina: +2, 某角色: +3}
情境:
  - {情境条目 1：起因与环境氛围铺垫，全章仅此处首句交代具体月份与时段}
  - {情境条目 2：互动推进，真实的身体本能反应、呼吸感与嵌入式特征对白}
  - {情境条目 3：核心张力爆发或亲密突破，微动作与感官拉扯}
  - {情境条目 4：落地收敛，事后温存或回归黎恩}
核心: {本章戏剧灵魂、角色心理反差、微动作情趣与标志性金句对白，严禁复读任务}
章节任务: {单句紧凑指令，明确系统推进的具体目标行动，严禁复读核心，严禁提具体日期}
章节终止条件:
  - {明确具体的事件落地标志 1（严禁提几月几日）}
  - {明确具体的事件落地标志 2：包含所有动作链闭环（严禁提几月几日）}
  - {纯物象/环境静态定格 3：零角色身体动作，零入睡概括（严禁提几月几日）}
```

> 🚨 **命名硬红线**：
> - 章节文件名必须为 `{ID}：{名称}.TXT`（注意中文全角冒号与双破折号）；
> - **标题（名称）全文本绝对严禁包含“章”字**（即便如“急就章”等文学双关词汇也绝对禁止）。

## 二、 核心字段创作要点

### 1. 情境条目编写标准（3-5 条）
- **条目 1（起因）**：交代环境光影、起因事件、角色物理距离与初始心绪。**全篇仅限在第 1 条首句交代具体月份与时段**（如“6月18日下午……”），严禁出现绝对年份。
- **条目 2-3（交互与呼吸感）**：
  - 呈现真实的身体反应与言语试探，严格遵循“身体先于意志”；
  - **必须包含角色特征对白与微声音工程**：即使在极度压抑、濒临暴露的极限逼仄情境下，也必须有贴耳的气音、咬牙的低语警告、带着角色独特个性的短台词（如菲娜的恶作剧娇嗔、凯尔的慌乱结巴、乔治的憨厚老实、黎恩的沉稳霸道），**严禁写成毫无台词的“动作说明书流水账”**。
- **条目 4（收尾）**：若有第三者经历，必须有向黎恩“被接住”的回归时刻或温存闭环。

---

### 2. 语言质感与表达禁令系统

为了坚守现代自然、生活化、富有日系轻小说呼吸感的世界观底色，严格执行以下禁令体系：

#### ① 彻底拔除古风文言修辞与成语串烧（硬红线）
* ❌ **严禁古风文言身体部位**：严禁使用“樱唇”、“檀口”、“香肩”、“秀足”、“玉手”、“玉足”、“玉腿”、“玉颈”、“天鹅颈”等修真/武侠套话。
  * 👉 **正确规范**：使用现代自然具体的身体部位描写（如“红润的双唇”、“圆润的肩膀”、“白皙的足弓与透粉的脚趾”、“丰腴柔嫩的大腿内侧”、“优美的脖颈”）。
* ❌ **严禁文言虚词与成语堆叠**：严禁出现“衣袂”、“素手”、“如凝脂”、“微咬银牙”、“微生怜惜”、“上下飞掠”、“尽数激射”等死板成语。
* ❌ **严禁医学科技术语出戏**：严禁使用“前列腺液”等现代临床解剖词汇，统一规范为“透明前液”、“湿滑前液”。

#### ② 彻底消灭神性佛性，保真“活生生的人”
* ❌ **严禁神圣化/去人性化称谓**：严禁使用“神使大人”、“端庄圣洁的精灵守护者”、“圣洁精灵”等悬浮神化辞藻。
* 👉 **人物本色定位**：菲娜是活生生、有体温、有七情六欲的少女，会害羞埋脸、会记仇报复、会恶搞调皮、也会娇憨撒娇，绝非不食人间烟火的神使木雕。

#### ③ 严禁第四面墙元叙事与机制解说
* ❌ **严禁作者视角出戏**：正文心理活动中严禁出现任何系统机制词汇（如*“跨线阶段特有的背德感冲垮了防线”*是致命硬伤，角色绝不知晓“阶段”概念）。
* ❌ **严禁元叙事评论**：严禁出现“作为伏笔”、“确立...契机”、“四重神髓”、“线索闭环”、“终极收拢”、“身心彻底归巢”等写给读者的大纲评论，全部必须转化为角色眼前的具体物象、身体感受与交互动作。

#### ④ 既有文风硬红线（持续生效）
* 严禁出现“一丝/一 丝”、“不易察觉/不易 察 觉”。
* 严禁出现“不容置疑”等一切“不容”开头的词汇（不容抗拒、不容反抗等）。
* 严禁使用“小猫”、“小兽”、“幼兽”等小动物比喻（替换为支配、掌控、狂热等词语）。
* 严禁描写“成熟女性”相关的描述（如“成熟女性的体热/体香”等，文中不存在此类成熟女性）。
* 严禁写“他推了推并不存在的隐形眼镜”。
* 绝不用“不是...是...”对比句式（直接写肯定句），不用“不是”的句式。
* 绝不出现“成本/效率/优化”等现代管理/工程词汇。
* 绝不使用括号堆砌补充解释，绝不写空泛金句结尾（“为...支撑”“奠定...基础”）。

#### ⑤ 生理器官词汇标准化使用
* 男性：鸡巴、肉棒、屌、大屌、龟头
* 女性：奶子、乳头、阴唇、阴蒂、阴道、蜜穴、小穴、菊穴

### 3. 【核心】与【章节任务】深度解绑规范（防同质化铁律）

> 🚨 **痛点教训**：严禁将【核心】与【章节任务】写成换汤不换药的“双胞胎复制粘贴”！两者职能截然不同：

| 维度 | **核心 (Dramatic Core)** | **章节任务 (System Objective)** |
| :--- | :--- | :--- |
| **定位** | **戏剧灵魂与情境精髓**（面向世界书构建与叙事张力检索） | **系统推进与执行目标**（面向任务引擎追踪与状态判定） |
| **内容** | 戏剧张力来源、人物心理反差、微动作情趣、**标志性角色金句/经典台词**。 | 简练明确的**单句目标指令**，回答“角色需在此章节做成什么事”。 |
| **范例 (Ch372)** | *黎恩在门外准备推门，菲娜在书架窄缝将凯尔按在隔板上死死捂嘴，一边贴耳气音威胁一边单手急速撸动，在黎恩脚步离开的刹那把精液尽数收进手帕，事后瘫软踢他出气：“差点被你害死”。* | *在黎恩门外驻足的高压环境下压制凯尔以防暴露，并在狭窄空间内完成急速手交与收缴灭痕。* |
| **范例 (Ch403)** | *替凯尔吞精——在黎恩的掩护下。桌下口交、黎恩假装不知道但全程配合、凯尔头上冒烟。事后她一边给黎恩手交一边说：在桌下，不好擦掉，只能吞下去。* | *在长桌会议掩护下完成桌底口交吞精，并在事后向黎恩完成手交与心理交付。* |
| **红线禁忌** | ❌ 严禁写成干瘪的任务指令；<br>❌ 严禁出现几月几日具体日期；<br>❌ 严禁包含元叙事字眼（闭环/伏笔等）。 | ❌ 严禁复读核心文本（语义重合度不得 > 50%）；<br>❌ 严禁出现几月几日具体日期；<br>❌ 严禁剧透细碎心理独白。 |

### 4. 章节终止条件设计标准

1. **结构格式**：严格使用标准 Markdown 连字符 `- ` 列表，严禁使用 `1. 2. 3.` 序号；
2. **日期隔离**：**终止条件 1、2、3 中严禁出现任何“几月几日几点”等具体时间字眼**；
3. **分工明确**：
   - **条件 1**：事件触发与物理阻力确立；
   - **条件 2**：核心互动与**全部动作链收拢**（包括高潮射精、清理擦拭、穿衣、言语交代、推门离开等）；
   - **条件 3**：**100% 纯客观物象与物理环境定格**（如光影斑驳、断裂笔尖、干涸茶渍、余烬青烟、门外风声），严禁包含人物肢体动作，严禁概括性“相拥入睡”。

---

### 5. 大纲尺度与动态字数阶梯

- 新建章节情境是供大模型跑团注入的**情境大纲 (Scenario Outline)**，兼顾戏剧骨架扎实与高信息密度：
  - **Level 1（轻量日常/单一微动作）**：**300 ~ 500 字符**；
  - **Level 2（标准推进/常规交互）**：**700 ~ 850 字符**；
  - **Level 3（复杂大章/多阶段反转/重头突破）**：**850 ~ 1,100 字符**（上限 1,150 字符）；
- 核心是**剔除作者解说与虚无白描，充实真实的身体微颤与角色特征对白**。
