# 情境大纲白话写法

本文件只补充大纲特有的问题。古风词、话本腔、四字成语、说书套话的完整排查，照常按 [writing-guards.md](../../rules/writing-guards.md) 与 [lexicon.md](../../rules/lexicon.md) 执行；不要因为本文件举了几个例词，就只查这几个词。

---

## 0. 写情境，不写正文

- 按时间顺序写情境段落：交代在哪里、谁在场、做了什么、结果怎样。
- 对白与对话概括结合：推动剧情或体现人设的精彩对话直接写出来，合在段落里连着写；长篇推理、重复交代、次要细节直接用一句话概括（如“进行了一番严谨推理”、“继续说了一些他知道的事情”、“他认为……”、“微笑地夸奖提米”）。不写特写式的装备逐项描写与分贝、毫米等数值化参数。
- 第二部详规的完整格式和示例见 [viridia-writer](../viridia-writer/SKILL.md) 第 1.2 节。

---

## 1. 行动动机：写角色的想法，删掉手续

- 角色日常行动的理由，直接写角色自己的需要或感情：累了想睡、饿了、想见同伴、顺手帮忙。
- 删掉换班轮休、调令、物资采办、审批这类手续性理由。例外：这项手续本身推动主线（如潜入要用的换岗时间、钥匙模具），才保留。
- 一个日常行动只给一个理由。出现「既是为了……也是顺便……」时，只留感情那一条。

## 2. 旁白位置：跟着角色，不站在台下讲

- 旁白紧跟当场的角色，写他们正在做什么、看到什么、听到什么，用主谓宾清楚的现代白话。
- 删掉替角色总结心情、向读者交代来龙去脉的句子。
- 「见……便……」这类话本连接，改成直接接动作或用「就」；「特意」「自告奋勇」这类书面套语，改成具体说法（如「一个人」）或直接删掉。

## 3. 张弛：高压主线之后给日常

- 主线连续高压的阶段之间，后方情境要放松下来。
- 放松靠具体的事：一顿热饭、睡个懒觉、一次随意的探望。不写道理，不写感悟。
- 角色在安全环境里时，可以用亲切、带点孩子气的口语（香香甜甜、暖烘烘），可以给东西起玩笑名字、互相打趣。

## 4. 用词：简单动词，保留感官

- 动作用最简单的口语动词：回、去、带着、睡着了。去掉「特意抽空」「连轴转」这类叠加的修饰。
- 温度、气味、声音这类现场感官细节要保留。要删的是手续和套话，感官细节不删。

## 5. 示例

示例只用来演示上面的规则。不要照搬其中的具体说法（如「爱丽榭牌独家美食」），每次按当场的人物和物件重新写。

**修改前**

> 趁着要塞工棚这两天换班轮休，黎恩与菲娜特意抽空回了酒庄后方营地一趟，既是为了替要塞车棚取批硬木卡榫与备用零件，也是顺便看望大家。菲娜此前在下城和要塞连轴转跑前跑后累坏了，一回到酒庄房间倒头就睡得香甜，这会儿估计还在暖烘烘的麦秸被窝里睡懒觉呢；黎恩见爱丽榭刚熬好了热腾腾的浓汤，便自告奋勇划着折叠舟送下暗河码头。刚一开门，刚出炉的黄油黑麦烤面包焦香、以及热气腾腾的野山菌牛肉浓汤气味瞬间在阴冷潮湿的溶洞内弥漫开来。

**修改后**

> 趁着圣殿大要塞的假期，黎恩和菲娜回了一趟酒庄看望大家。菲娜之前在下城和要塞跑前跑后累坏了，一回到酒庄房间就香香甜甜地睡着了，现在估计还在暖烘烘的麦秸被窝里睡懒觉呢；爱丽榭刚熬好了热腾腾的浓汤，黎恩就一个人带着“爱丽榭牌独家美食”去暗河码头。刚一开门，刚出炉的黄油黑麦烤面包焦香、以及热气腾腾的野山菌牛肉浓汤气味瞬间在阴冷潮湿的溶洞内弥漫开来。

**改动对照**

| 修改前 | 修改后 | 对应规则 |
| :--- | :--- | :--- |
| 要塞工棚这两天换班轮休 | 圣殿大要塞的假期 | 1：删手续细节 |
| 特意抽空回了……一趟，既是为了替要塞车棚取批硬木卡榫与备用零件，也是顺便看望大家 | 回了一趟酒庄看望大家 | 1：双重理由只留感情；4：删「特意抽空」 |
| 此前……连轴转跑前跑后 | 之前……跑前跑后 | 4：书面词换口语，删叠加修饰 |
| 倒头就睡得香甜 | 就香香甜甜地睡着了 | 3：安全环境用亲切口语 |
| 黎恩见……便自告奋勇划着折叠舟送下 | ……黎恩就一个人带着“爱丽榭牌独家美食”去 | 2：删话本连接和套语；1：删交通流程；3：玩笑名字 |
| 面包焦香、浓汤气味弥漫开来 | 原样保留 | 4：感官细节不删 |

## 6. 交付前自查

逐条过一遍，结果只在对话里汇报，不写进文档：

- [ ] 写成了情境大纲（绝不写成正文）：长篇推理与次要对话已用一句话概括，没有特写式装备描写和分贝、毫米等数值细节。
- [ ] 日常行动的理由写的是角色的想法或感情，没有拿手续、调令、采办当借口。
- [ ] 没有「既是为了……也是顺便……」的双重理由。
- [ ] 旁白紧跟当场角色，没有替角色总结心情或向读者交代来龙去脉。
- [ ] 没有话本连接词和书面套语（完整清单按 writing-guards.md / lexicon.md 查）。
- [ ] 高压阶段之后安排了放松的日常情境。
- [ ] 保留了现场的温度、气味、声音细节。
