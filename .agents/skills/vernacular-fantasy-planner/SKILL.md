# 情境大纲白话写法与动态迭代准则

> [!IMPORTANT]
> **动态迭代原则**
> 用户每次提出修改意见时，提炼底层写作力学同步更新本技能。新内容融入对应逻辑章节，**严禁罗列字句范例**（讲清本质力学与结构逻辑即可，绝不堆叠具体词句举例，避免范例带来狭隘局限性），不机械追加于文末，不罗列禁词表（具体词汇以 `lexicon.md` 与扫描脚本为准）。

本文件专注于情境大纲特有的写法规范。常规古风词、话本套话与错别字排查，照常按 [writing-guards.md](../../rules/writing-guards.md) 与 [lexicon.md](../../rules/lexicon.md) 执行。

## 0. 情境粒度与保留底线

- **情境推进而非小说正文**：按时间顺序连续叙述，交代地点、人物、核心行动与结果，不展开特写动作与慢镜头。
- **私密情节分步推进与时空适配**：
  - **适配插入而非推倒重写**：在时间流逝与微观动作转换处插入【时间 ｜ 地点】锚点，直接承接原有剧情，不推倒重写，不补写慢动作。
  - **原生节奏自适应**：节拍数由现场空间与角色动因决定，原文原本有几个节拍就保留几个节拍，不套固定模版。
- **双向平衡原则**：解决古风问题时，直接交代行动事实，不展开小说正文式的慢动作特写与抒情；精简大纲时，用简明通俗的现代白话概括，不滑向古风小生神态与言情温存套词。
- **核心交锋台词保真与次要事务概括**：推动剧情、展现角色核心性格与情绪交锋的关键对白必须保留，严禁将整句核心台词完全删除，仅可适度简化；日常说明性过渡、长篇技术推演与次要事务，一律用生动通俗的现代白话概括交代，不展开长篇低信息量引语。大纲压缩的是小说正文式的写景与冗余对话，保留主干交锋与关键抉择。
- **改动后通读自检（防新增病灶）**：修改调整时必须通读改动后的完整内容。严禁按下葫芦浮起瓢——在精简或修改时绝不能引入新的古风或中式市井词汇，也绝不能为了去古风而把大纲扩写成小说正文慢动作。改后文本必须同时满足无古风、无正文慢动作与无旁白自嗨。
- **杜绝公文物件清单式报账**：公文、凭证、采办等物件的名目，严禁在旁白中用冒号或并列连词像档案表格一样报备；直接交代物件转手事实，具体用途或名目由后续角色对白自然带出。
- **即时内心活动保留**：用全角括号 `（……）` 标注的角色即时心声与心理微反应属于轻小说核心呼吸感，完整保留。
- **高收益神态微动作精简保留**：用极少字数确立角色性格的生动微动作，保留核心动作，剥离修饰词，不作机械删除。复合微神态包含了角色细腻的情感层次与轻小说呼吸感，应精准提炼保留，严禁直接砍掉降级为单一平淡动词。
- **简化提炼而非粗暴删减**：情境大纲的核心是白话浓缩与提炼，而非大段机械剔除。人物登场、外貌关键特征、环境态势、台词对白与微反应必须完整保留并做轻量化提炼，严禁把角色台词整段抹去，严禁把关键人物初登场描写整段砍掉。
- **动宾微反应极简直连**：剥离小说式的动作铺垫与修饰副词，直接使用“人物 + 动作/即时状态 + 引出对白或核心结果”，让叙事骨架干脆清爽。
- **根除反复修饰、同位语堆叠与强凑并列习惯**：
  - **定性不前置重复**：已对事物或人物行为给出核心定性，前面严禁再堆叠同义动作或修饰词；
  - **后置动作不倒贴背景定语**：动作与宾语干净交代，前文已交代过的背景事实严禁作为修饰定语从句反复赘述；
  - **拒绝双并列凑字癖**：能用单一准确名词就绝不用双名词并列，避免中式对偶凑字病的拖沓冗余，保持叙事单线条利落挺拔。
- **短白话快速交代环境**：用口语短句直接交代现场物理状态，不铺展冗长的环境写景散文。
- **对白信息不前置复述**：后文台词中已点明的举动或物品，前文旁白不再预先描述，由角色对白自然带出情境。
- **标题纯净无工程标签**：小标题必须是纯粹的剧情事件与行动概述，严禁附加“切片x”、“模块x”等结构化、元叙事或工程管理标签，保持大纲标题自然干净。
- **战略动员与战术分工解耦**：战略动员（情感打气、地图道具破冰）与战术指引（核心异常剖析、分路走向）应解耦为独立节拍。大纲避免在角色对白中直接铺陈大段世界观或地理背景设定，背景设定沉淀至实体档案库；大纲只保留角色基于情报作出的行动研判、各自核心台词与微反应。对话中已自然明确各自分工的，尾部严禁再机械重复罗列清单式的分工定案（杜绝报备式公文清单），由现场具体商讨或微动作自然收束。
- **设定型关键道具的“场景内轻量物品卡 + 对白口语交代”法则**：当道具蕴含关键防护机制与后续主线伏笔时，严禁因精简大纲而完全抹除其功能说明。在对白中以简炼口语交代核心机制，并在道具交接处就地嵌入简明的轻量物品卡（仅保留外观与核心作用，杜绝在篇头集中堆砌长篇设定），做到大纲正文轻快、设定底座扎实。
- 第二部详规的完整格式和示例见 [viridia-writer](../viridia-writer/SKILL.md) 第 1.2 节。时空锚点标注标准详见 [分幕剧情点时间地点规范与时空锚点标注标准工作流.md](../../../方案/第二部/主线与世界扩充方案/分幕剧情点时间地点规范与时空锚点标注标准工作流.md)。

## 1. 行动动机：角色的想法代替手续

- 角色行动直接写内在需求或情感：累了想睡、饿了、想见同伴、顺手帮忙。
- 删去排班轮休、调令、采办、审批等手续性借口；仅在手续本身直接推动主线（如潜入所需的换岗时间、钥匙模具）时保留。
- 单一动机原则：出现双重理由（“既是为了……也是顺便……”）时，只保留情感驱动的一条。
- **借势破局的情境力学**：展现角色的策略博弈或借力打力时，不写孤身硬闯敌营或向上级哭诉说教；通过公共话题与社交场域发酵构建现实压力，让角色顺应现场众人迟疑、尴尬或利益纠葛的局势顺势提出对策，借现场多方目光与切实利益形成无可推卸的闭环。

## 2. 旁白视点：紧跟当场角色

- 旁白视线与场上角色保持一致，用主谓宾清楚的现代白话记录所见所闻所做。
- 不替角色总结心境，不向读者交代来龙去脉。
- 动词直接连接，替换文言连接词；删去说书套语。
- **人物称谓直呼其名，严禁泛化代称与前缀**：旁白一律直接使用角色名字，严禁使用身份标签作主语或代指；描写次要人物直接使用职业与客观身份，严禁附加中式话本修饰前缀。
- **天然物理遮蔽交代隐蔽环境**：私密情境直接交代客观物理遮蔽，通过现场环境呈现隐蔽性，不靠旁白解释。
- **拒绝武侠神怪式感官宣告**：不写超常感官定性，角色的察觉通过自然物理传播与即时动作呈现。
- **根除自嗨式叙述与情绪口号**：
  - 旁白只记录客观发生的动作、对白与身体反应，不当下场抒情。
  - **严禁旁白感叹号与情绪口号**：旁白禁用感叹号，禁止使用口号式词句。
  - **严禁替角色做抽象定性**：禁止使用概念化大词概括情绪，直接写具体微动作。
  - **严禁旁白充当解说员下场宣告宏观结局**：严禁旁白做宏观总结或战果宣告；段落与情节收束一律通过在场角色的自然对白、调侃打趣或具体微动作自然落地，杜绝宣告式盖棺定论。
  - **严禁绝对化与自满式断言**：严禁在叙事或大纲中使用“彻底”、“彻底化解”、“彻底消除”、“完全稳固”等旁白自嗨式大词；局势演进与身心状态由现场客观事件自然交代，杜绝旁白下场宣布盖棺定论。
- **高智商反派推演的“逻辑链保真”与“战略转向”力学**：大纲展现高智商反派时，必须保真其基于全局情报的严密推演过程与关键研判台词，杜绝粗暴削减为单薄脸谱；提炼其“信息差—权谋推导—自大盲区”的力学闭环，反派基于自身阶级偏见的严密推导恰好与主角真实意图错位，进而下达战略转向手令，为主角后续行动打出合理战略窗口；执行层动作可快速交代，决策层逻辑与关键对白全量保真。

## 3. 张弛节律：高压后置入日常

- 连续高压的主线阶段之间，后方情境应自然放松。
- 依靠具体事物放松：一顿热饭、睡个懒觉、随意的探望，不写道理与感悟。
- 安全环境采用亲切、带孩子气的口语称谓，穿插互相打趣与日常玩笑。

## 4. 语言质感：通俗动词与微反应

- **纯正白话动词**：使用基础口语动词，去掉叠加的修饰词；替换中式话本动词为日常口语。
- **引语动词现代白话化（严禁“xx道”）**：白话对话严禁使用“xx道”引语，这是典型的中式古风小生与话本腔调；统一使用现代口语“xx说”，或者直接以微动作和冒号自然引出台词。
- **肃清古风小生与士大夫文人书面套词**：严禁在叙述与心理描写中掺杂中式旧文人、士大夫戏文或旧白话评书的书面腔调。描述亲属家庭时使用纯正西幻与现代生活流称呼，不使用古代官府中式称谓；评价人物世故与市井作风时，还原为现代通俗大白话与 JRPG 生活流口吻，不使用文人贬称；表示取舍、抉择与让步时，转换为口语散句，杜绝文言书面副词与假古雅转折。现代白话大纲严禁滑向中式戏文、官僚奏疏或古装小生说辞；大纲只以白话概括核心事实与破局动作，绝不扩写为正文式长篇说教台词。严禁使用地域方言词汇，严禁随意降级或篡改既定的法定身份与角色称谓。
- **去戏剧化假腔调与现实逻辑沟通**：角色对话与心理描写严禁戏曲、苦情悲剧或旧话本式的哀怨套话与假崇高宣誓；现实阻碍直接用通俗白话讲明事实阻碍与利益利害（如事情卡在什么环节、如何取证、由谁从制度或现实层面去处理），说人话、讲实情，不搞戏剧式胸口大石、诉冤讨理的过度情绪化表演。
- **微反应替代套式神态与过度情绪**：
  - 情绪波动通过具体物理微动作呈现，不用抽象眼神定性或温存套词。
  - 削减段落内连环叠加的笑声与失态动作，保留轻微自然的笑意与打趣；成熟角色保持持重，不写呆滞失态。
  - 删去夸张惊恐词汇，突发状况还原为当下生理直觉与战术戒备，不写怯懦慌乱。
  - 旁白不替角色宣告心境震动，由现场物理细节与身体反应呈现冲击。
- **极简生活流对白立住情调**：保留关键口语感叹与打趣，用极少字数确立现场呼吸感。
- **自然动作代替武侠国术术语**：战斗与战技按西幻动作逻辑描写，不用传统武术行话，不展开多余参数拆解。
- **西幻工匠物象代替现代工程化工教科书腔**：描写锻造、机械与器物时，使用符合剑与魔法 RPG 的通俗白话，不用现代工科技术参数或化工冶炼书面语。
- **通俗烟火微神态代替古风修饰**：还原为日常物理微动作。
- **口语代称代替古风书目**：日常口语使用口语化表达，不使用古风典籍套话。
- **生活流日常用语**：安全环境中多用亲切的生活语言，替换公文化或说书腔的干瘪词汇。
- **保留现场感官**：保留温度、气味、声音等真实物理细节。

## 5. 示例

示例只用来演示上述规则。不要照搬其中的具体说法，每次按当场的人物和物件重新写。

### 示例一：去手续与报备腔

**修改前**

> 趁着要塞工棚这两天换班轮休，黎恩与菲娜特意抽空回了酒庄后方营地一趟，既是为了替要塞车棚取批硬木卡榫与备用零件，也是顺便看望大家。菲娜此前在下城和要塞连轴转跑前跑后累坏了，一回到酒庄房间倒头就睡得香甜，这会儿估计还在暖烘烘的麦秸被窝里睡懒觉呢；黎恩见爱丽榭刚熬好了热腾腾的浓汤，便自告奋勇划着折叠舟送下暗河码头。刚一开门，刚出炉的黄油黑麦烤面包焦香、以及热气腾腾的野山菌牛肉浓汤气味瞬间在阴冷潮湿的溶洞内弥漫开来。

**修改后**

> 趁着圣殿大要塞的假期，黎恩和菲娜回了一趟酒庄看望大家。菲娜之前在下城和要塞跑前跑后累坏了，一回到酒庄房间就香香甜甜地睡着了，现在估计还在暖烘烘的麦秸被窝里睡懒觉呢；爱丽榭刚熬好了热腾腾的浓汤，黎恩就一个人带着“爱丽榭牌独家美食”去暗河码头。刚一开门，刚出炉的黄油黑麦烤面包焦香、以及热气腾腾的野山菌牛肉浓汤气味瞬间在阴冷潮湿的溶洞内弥漫开来。

**改动对照**

| 修改前 | 修改后 | 对应规则 |
| :--- | :--- | :--- |
| 要塞工棚这两天换班轮休 | 圣殿大要塞的假期 | 1：删手续细节 |
| 特意抽空回了……一趟，既是为了……也是顺便…… | 回了一趟酒庄看望大家 | 1：双重理由只留感情；4：删叠加修饰 |
| 此前……连轴转跑前跑后 | 之前……跑前跑后 | 4：书面词换口语 |
| 倒头就睡得香甜 | 就香香甜甜地睡着了 | 3：安全环境用亲切口语 |
| 黎恩见……便自告奋勇划着折叠舟送下 | 黎恩就一个人带着“爱丽榭牌独家美食”去 | 2：删话本连接和套语；3：玩笑称谓 |
| 面包焦香、浓汤气味弥漫开来 | 原样保留 | 4：感官细节不删 |
