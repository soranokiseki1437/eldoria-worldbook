# 情境大纲白话写法与动态迭代准则

> [!IMPORTANT]
> **动态迭代原则**
> 用户每次提出修改意见时，提炼底层写作力学同步更新本技能。新内容融入对应逻辑章节，不机械追加于文末，不罗列禁词表（具体词汇以 `lexicon.md` 与扫描脚本为准）。

本文件专注于情境大纲特有的写法规范。常规古风词、话本套话与错别字排查，照常按 [writing-guards.md](../../rules/writing-guards.md) 与 [lexicon.md](../../rules/lexicon.md) 执行。

---

## 0. 情境粒度与保留底线

- **情境推进而非小说正文**：按时间顺序连续叙述，交代地点、人物、核心行动与结果，不展开特写动作与慢镜头。
- **私密情节结构化分步推进**：私密与激情戏不在大纲中写成密不透风的小说正文慢镜头，而是按行动步骤（前戏、体位推进、高潮与事后温存）清晰记录核心举动与体态互动，各关键节点保留时间地点锚点。
- **双向平衡原则**：解决古风问题时，直接交代行动事实，不展开小说正文式的慢动作特写与抒情；精简大纲时，用简明通俗的现代白话概括，不滑向古风小生神态与言情温存套词。
- **特色对白全量保留**：推动剧情、展现角色性格与情调的精彩对话完整保留，直接嵌入叙述段落中；长篇推理、技术交代与次要事务概括为一句话。大纲要压缩的是旁白慢镜头与多余抒情，不把角色的标志性心声与精彩对白抹去。
- **即时内心活动保留**：用全角括号 `（……）` 标注的角色即时心声与心理微反应属于轻小说核心呼吸感，完整保留。
- **高收益神态微动作精简保留**：用极少字数确立角色性格的生动微动作，保留核心动作，剥离修饰词，不作机械删除。
- **对白信息不前置复述**：后文台词中已点明的举动或物品，前文旁白不再预先描述，由角色对白自然带出情境。
- 第二部详规的完整格式和示例见 [viridia-writer](../viridia-writer/SKILL.md) 第 1.2 节。

## 1. 行动动机：角色的想法代替手续

- 角色行动直接写内在需求或情感：累了想睡、饿了、想见同伴、顺手帮忙。
- 删去排班轮休、调令、采办、审批等手续性借口；仅在手续本身直接推动主线（如潜入所需的换岗时间、钥匙模具）时保留。
- 单一动机原则：出现双重理由（“既是为了……也是顺便……”）时，只保留情感驱动的一条。

---

## 2. 旁白视点：紧跟当场角色

- 旁白视线与场上角色保持一致，用主谓宾清楚的现代白话记录所见所闻所做。
- 不替角色总结心境，不向读者交代来龙去脉。
- 动词直接连接，替换“见……便……”等文言连接；删去“特意”、“自告奋勇”等说书套语。
- **天然物理遮蔽交代隐蔽环境**：私密情境直接交代客观物理遮蔽（如两米高防风大岩石、百叶窗、深处隔断），通过现场环境自然呈现隐蔽性，不靠旁白解释“为什么没人发现”。
- **拒绝武侠神怪式感官宣告**：不写“耳力极佳/目力过人/神识敏锐”等评书神化结论；角色的察觉通过自然物理传播（顺着风声传来、石阶回音）与即时物理动作（停下手头的活、转头打量）呈现。

---

## 3. 张弛节律：高压后置入日常

- 连续高压的主线阶段之间，后方情境应自然放松。
- 依靠具体事物放松：一顿热饭、睡个懒觉、随意的探望，不写道理与感悟。
- 安全环境采用亲切、带孩子气的口语称谓，穿插互相打趣与日常玩笑。

---

## 4. 语言质感：通俗动词与微反应

- **纯正白话动词**：使用基础口语动词，去掉叠加的修饰词；替换“迎了出来”、“迎上前”等中式话本动词为日常口语。
- **具象微动作与微反应代替套式神态**：情绪波动通过低头、避开视线、拉紧衣领、倒吸凉气等物理微动作呈现；不用古风言情剧常见的眼神定性或抽象温存套词。
- **极简生活流对白立住情调**：几句关键的感叹、轻呼或调笑（如“嘶——好痛！”、“哇……水花溅起来了啦！”、火炉边嗅体香调笑），用极少字数确立现场呼吸感与亲密默契。
- **自然动作代替武侠国术术语**：战斗与战技按西幻动作逻辑描写，不用中式传统武术行话，也不展开工科机械力学拆解与多余参数。
- **西幻工匠物象代替现代工程化工教科书腔**：描写锻造、机械与器物时，使用符合剑与魔法 RPG 的真实感官白话（引水木轮、巨型厚皮大风箱、齿轮连杆咬合、滑轮铁索、矿石成色与杂质、冷泉淬火、冻裂），不用现代工科技术参数或化工冶炼书面语（如“生铁绞盘联动水力风箱”、“含硫率”、“冷锻卡榫”等教科书术语）。
- **通俗烟火微神态代替古风吞云吐雾**：不用“吐出一口浓烈烟草雾气”等古风仙侠式吞云吐雾套句，还原为日常物理微动作（拿下粗木烟斗、喷出一口呛人的白烟、磕了磕烟灰）。
- **口语代称代替古风书目**：日常口语用“书里写的一样/图册上见过的”代替“古籍/典籍所载”。
- **生活流日常用语**：安全环境中多用亲切的生活语言，替换公文化或说书腔的干瘪词汇。
- **保留现场感官**：保留温度、气味、声音等真实物理细节。

## 5. 示例

示例只用来演示上述规则。不要照搬其中的具体说法，每次按当场的人物和物件重新写。

### 示例一：去手续与报备腔

**修改前**

> 趁着要塞工棚这两天换班轮休，黎恩与菲娜特意抽空回了酒庄后方营地一趟，既是为了替要塞车棚取批硬木卡榫与备用零件，也是顺便看望大家。菲娜此前在下城和要塞连轴转跑前跑后累坏了，一回到酒庄房间倒头就睡得香甜，这会儿估计还在暖烘烘的麦秸被窝里睡懒觉呢；黎恩见爱丽榭刚熬好了热腾腾的浓汤，便自告奋勇划着折叠舟送下暗河码头。刚一开门，刚出炉的黄油黑麦烤面包焦香、以及热气腾腾的野山菌牛肉浓汤气味瞬间在阴冷潮湿的溶洞内弥漫开来。

**修改后**

> 趁着圣殿大要塞的假期，黎恩和菲娜回了一趟酒庄看望大家。菲娜之前在下城和要塞跑前跑后累坏了，一回到酒庄房间就香香甜甜地睡着了，现在估计还在暖烘烘的麦秸被窝里睡懒觉呢；爱丽榭刚熬好了热腾腾的浓汤，黎恩就一个人带着“爱丽榭牌独家美食”去暗河码头。刚一开门，刚出炉的黄油黑麦烤面包焦香、以及热气腾腾的野山菌牛肉浓汤气味瞬间在阴冷潮湿的溶洞内弥漫开来。

**改动对照**

| 修改前 | 修改后 | 对应规则 |
| :--- | :--- | :--- |
| 要塞工棚这两天换班轮休 | 圣殿大要塞的假期 | 1：删手续细节 |
| 特意抽空回了……一趟，既是为了……也是顺便…… | 回了一趟酒庄看望大家 | 1：双重理由只留感情；4：删叠加修饰 |
| 此前……连轴转跑前跑后 | 之前……跑前跑后 | 4：书面词换口语 |
| 倒头就睡得香甜 | 就香香甜甜地睡着了 | 3：安全环境用亲切口语 |
| 黎恩见……便自告奋勇划着折叠舟送下 | 黎恩就一个人带着“爱丽榭牌独家美食”去 | 2：删话本连接和套语；3：玩笑称谓 |
| 面包焦香、浓汤气味弥漫开来 | 原样保留 | 4：感官细节不删 |

### 示例二：私密情境分步推进与事后深情回收

**修改前**

> 后山木质水闸险些被山洪冲垮，朱利安、乔治和哈根跳进刺骨泥水里抢险，乔治为了顶住松动的原木，在激流里硬撑了两个小时，背上被断木狠狠撞了一下，整个右肩乌青肿了一大片。险情排除后，大家在大食堂喝了热汤，朱利安累得趴在桌上睡着了。菲娜看到乔治连胳膊都抬不起来，便拿着艾玛调好的草药油，拉着乔治去了营地东北边的天然地热温泉。温泉水面上全是白茫茫的温热蒸气，硫磺的气味混杂着山林泥土的清香，两米多高的天然防风大岩石把温泉隔在深处。乔治趴在池边大石头上，菲娜脱了外套，只穿轻薄短裙半跪在石台上把草药油按在乔治肿胀的肩膀上。乔治倒吸凉气：“嘶——好痛！”菲娜轻声笑道：“忍着点哦，淤血散开才好得快。”不一会儿菲娜身上的单衣就被水汽彻底浸湿了，薄薄布料贴在身上勾勒出纤细优美的身形。乔治转头想道谢，看见了菲娜湿透的单衣和温柔双眼，理智绷断，一把将菲娜拉进了温热的池子里。菲娜跌入怀中轻呼：“哇……水花溅起来了啦！”乔治在水中将菲娜按在池边平整石阶上，撩开湿透贴腿的裙摆从身后贯入抽送，激起阵阵浪花，菲娜抓紧池边灌木娇啼连连；随后乔治在水中半蹲抱坐菲娜颠弄，在温热矿物泉水冲刷与深长撞击中菲娜高潮，乔治深抵内射。事后菲娜裹着毛巾斗篷回到木屋，黎恩在火炉边给木茶壶添水，烤网上的黑麦面包散发着焦香，黎恩看到菲娜眼角眉梢全是温存后的媚意，坏笑拉她入怀嗅体香调笑，抱进被窝进行深情身体回收。

**修改后**

> 后山木质水闸险些被山洪冲垮，朱利安、乔治和哈根跳进刺骨泥水抢险，乔治顶住松动的原木硬撑两个小时，右肩乌青肿了一大片。

### 示例三：去古风神态、武术术语与冗余技术细节

**修改前**

> 大食堂前平整的空地上，黎恩手持未开刃的木太刀给菲示范八叶沉肩发力。菲身形敏捷旋身避开木刀，短木刃精准敲在刀背上发出哒哒轻响。不远处的木棚下，乔治满身机油味钻在货车底下给轴承打油，黎恩练完走过去递上一瓢清凉山泉水，商量加固底板。歇息喝麦茶时，艾德里安靠在木箱边隔着衣物按了按领口内侧焦黑的家徽，眼神微暗。在黎恩的招呼下，乔治和爱丽榭也从屋里迎了出来，巡哨同伴递过干粮时，艾德里安神色如常地接应，继续干完了一天的事务。

**修改后**

> 大食堂前平整的空地上，黎恩用木太刀给菲示范怎么拔刀发力。菲轻巧侧身避开木刀，短木刃精准敲在刀背上发出哒哒轻响。不远处的木棚下，乔治钻在货车底下保养轴承，黎恩练完走过去递上一瓢清凉山泉水，和乔治商量。休息喝麦茶时，艾德里安靠在木箱边隔着衣物按了按领口内侧焦黑的家徽，低头停了片刻，随即收回手把衣领整平。在黎恩的招呼下，乔治和爱丽榭也从屋里出来帮忙。同伴拿来爱丽榭做的好吃的时，艾德里安自然地接过来吃着，继续把手头的活干完。
