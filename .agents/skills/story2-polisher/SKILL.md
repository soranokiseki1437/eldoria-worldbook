## 三、 语言质感、微声音工程与动作分镜

1. **拒绝零对白与动作流水账**：
   - 即便在狭窄过道、暗道潜渡或要塞牢门外，也必须嵌入符合角色性格的压低气音、低语警告或特征对白；
2. **标点与停顿规范**：
   - 疑问与调侃用 `？`（严禁用句号结尾）；落地断言用 `。`；娇嗔拖音用 `~`；动作打断用 `——`；叙述中严禁滥用破折号无意义停顿；
3. **消除 pivot 否定句式**：
   - 直接写正面肯定陈述，避免“不是……是……”、“没有……只是……”；
4. **绝对禁止“否定式元叙述”与自卫性辩解**：
   - 严禁正文出现“没有摆出武侠姿势”、“并无流氓气”、“不像客栈老板”等破坏第四面墙的元叙事；
   - 100% 镜头物理呈现客观动作与环境（Show, Don't Tell）。

## 四、 雷达病灶置换核验清单 (Checklist)

精修后必须逐项比对以下病灶，确保彻底置换：

- [ ] **动作描写中彻底清除了“沉腰/坐马/下盘/马步”**：已置换为“压低身体重心/低位瞬步/低姿滑步/屈膝踏步/跨步沉身”；
- [ ] **称谓描写中彻底清除了“老兵/退伍老兵/大头兵/军官/守将/武将”**：已置换为“受封骑士/要塞守备骑士/先锋骑兵/哨位骑士/资深巡防骑士/要塞长官”；
- [ ] **军旅古风中彻底清除了“同袍/袍泽/草民/老朽/奴家”**：已置换为“同伴骑士/誓约同伴/昔日战友/旗队同僚/平民”；
- [ ] **教廷与圣殿二元边界清晰**：无“圣殿修道院”、“教廷骑士”、“教会骑士”等混淆词；
- [ ] **零导力隐蔽坚固**：ARCUS装配皮革遮蔽外壳，无魔法电弧外溢，全员以冷兵器与物理战技作战；
- [ ] **末尾情境纯物象化收束**：第 $N$ 条情境为残茶/余烬/车辙/微光/脚步远去/水渍等物理终态；
- [ ] **终端质检 0 违规**：在终端执行 `python scripts2/scan_viridia_diseases.py` 验证通过；
- [ ] **净室交付**：正文在接口交接处干净收束，绝对未将自检 CheckList 或排查记录写进文档本体。
