```

```

## 二、 分章批注修复协议（核心协议）

处理用户批注文件（如 Markdown 批注或分章要求）时，严格遵循以下等级：

1. **直接改写的文本 = 最终定稿**：
   - 逐字应用，不得自由发挥改动定稿字句（仅允许纠正明显笔误如“的/地/得”）。
2. **括号语法判定**：
   - **【新文本】**：精确替换原文对应位置。
   - **空【】**：明确的**删除标记**，彻底移除对应原文字句。
   - **与原文相同的【原文片段】**：标记为重点处理区，结合上下文或标题行指示调整。
3. **标题行批注 = 章节级最高统领**：
   - 如标题行批注“本章检查所有答字禁止出现”、“所有字段重新梳理”，必须作为整章的最高红线。
4. **未批注句 = 重写责任区**：
   - 深入代入角色当前阶段心理，消除生硬感与机械味。
   - **最小干预原则**：保留角色说话时的语气能量（如惊叹、撒娇叠词、呼名、娇嗔拖音），不擅自将语气“压平”。
5. **冲突裁定原则（LRN-20260806-005）**：
   - 若用户批注定稿与写作铁律产生直接冲突，**必须主动报告冲突请求用户裁定**，绝对禁止单方面擅自改写定稿。

## 五、 润色后自检 Checklist（红线扫描）

在完成章节编辑后，必须逐条对照以下禁令清单：

### 1. 元数据契约与规范
- [ ] **标题名称绝对不含“章”字**：检查 `{前半段}——{后半段}` 标题全文本，严禁出现“章”字（即便如“急就章”等文学双关也绝对禁止）。
- [ ] **元数据日期严格隔离与单章去日历化**：
  - **单章开头必须带有“某日”（如“某日午后”、“某日清晨”、“某日傍晚”、“某日黄昏”、“某日深夜”等自然时段）**，严禁使用具体日历日期（X月X日、X月下旬），亦不使用缺乏定冠的裸词；**双章故事根据情节需要自然选择时间跨度**（如“同一日午后”、“同一黄昏下”、“同一夜色下”、“第二天清晨”等）；
  - **核心、章节任务、终止条件 1/2/3 中绝对严禁出现任何几月几日等具体时间字眼**。
- [ ] **【核心】与【章节任务】彻底解绑（严禁同质化）**：
  - **核心 (Core)** 必须有戏骨：交代戏剧张力来源、人物心理反差、微动作情趣与**标志性金句/经典对白**；
  - **章节任务 (Objective)** 必须为单句紧凑指令：明确系统推进的具体目标行动；
  - 两者语义重合度绝对不得超过 50%，严禁复制粘贴！
- [ ] **终止条件 3 绝对纯物象定格**：
  - 动作叙事全部归入终止条件 2（射精、擦拭、穿衣、言语交代、离去等全部动作链）；
  - 终止条件 3 必须且只能是静态环境余韵、物理残存痕迹或客观物象（光影、残墨、断裂笔尖、干涸茶渍、门外风声），严禁包含人物肢体动作，严禁概括性“相拥入睡”。
  - 终止条件序号统一使用标准 Markdown `- ` 列表，严禁数字序号。

### 2. 文学质感与文风禁令
- [ ] **彻底无古风文言与成语串烧**：绝无樱唇、檀口、香肩、秀足、玉手、玉足、玉腿、玉颈、天鹅颈、衣袂、素手、如凝脂、微生怜惜等套话；绝无战袍、战鼓、衣襟、长案、案头、书案、案台、桐油、火盆、前襟等古代器物词；绝无晴空霹雳、雷霆炸响、化作一滩春水、涌上天灵盖、排山倒海、开闸岩浆、磐石、逾矩、欲火、清明、困兽、千钧一发、圆融、授业、毁坏身子、酡红、肉刃等古风玄幻套话；绝无全数、尽数、嗓音微哑、轻哑、吞咽入腹、雪乳、分身、心火、心燥、急火攻心、急就、凭栏、面门、面庞、眼波、微蹙、做贼心虚、不疑有他等公文假雅与言情恶俗八股词。
- [ ] **彻底无神性佛性词汇**：绝无神使大人、端庄圣洁、圣洁精灵等神化称谓，角色是活生生的凡人。
- [ ] **彻底无第四面墙元叙事**：正文心理与核心/任务中绝无“跨线阶段特有的背德感”、“作为伏笔”、“四重神髓”、“线索闭环”、“终极收拢”等作者/读者视角解说。
- [ ] **彻底无医学解剖词出戏**：绝无“前列腺液”（统一使用前液、湿滑黏液）。
- [ ] **无 pivot 否定结构与“不是”句式**：排查“不是……是……”、“没有……只是……”，绝不用“不是”句式，全部转换为正面肯定描写。
- [ ] **无违禁词汇与比喻（硬红线）**：
  - 严禁出现“一丝/一 丝”、“不易察觉/不易 察 觉”。
  - 严禁出现“不容置疑”等一切以“不容”开头的词汇（不容抗拒、不容反抗等）。
  - 严禁使用“小猫”、“小兽”、“幼兽”等小动物类的比喻（替换为支配、掌控、狂热等词语）。
  - 严禁描写“成熟女性”相关的描述（如“成熟女性的体热/体香”等，文中不存在成熟女性）。
  - 严禁写“他推了推并不存在的隐形眼镜”。
- [ ] **无现代工程与管理用语**：严禁出现“成本/效率/优化”等用语。
- [ ] **无括号堆砌补充解释与空泛结尾**：绝无括号补充说明，绝无“为...支撑”“奠定...基础”等假深刻结尾。
- [ ] **无“答/应”引语**：grep 检查是否残留“她答/他应/应道”。
- [ ] **标点准确**：所有疑问句与调侃句均使用 `？`，绝无句号收尾的真问句。
- [ ] **角色称谓与世界观物象准确**：多尔金为矮人铁匠/大师（严禁称“长老”）；月光百合发油（严禁民国风“雪花膏”）；冷锻炉/加热炉（严禁古风“火盆”）。
- [ ] **双视点镜头提示与女主描写保真**：采用第三者视角的章节，必须使用清晰的机位过渡提示（如“而在XX视线盲区的……”），且**绝对保留女主第一线的生理微颤、娇羞推拒与特征对白**，严禁以篇幅为由机械删减。
