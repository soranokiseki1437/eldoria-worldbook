# 章节润色与精修技能指南 (Story Polisher)

> 本技能定义了世界书章节 TXT 精修、润色与分章批注落地时的最高执行标准。

---

## 一、 执行工作流

```
Step 1: 定位原章节 TXT（docs/story/{阶段}/{ID}：{名称}.TXT）
Step 2: 对照用户批注或润色目标，执行精修（严格遵守批注协议）
Step 3: 调用 references/dialogue-forms.md 展开碎片短对话
Step 4: 运行润色自检清单（Checklist）排查违规
Step 5: 保存 TXT 并运行验证命令验证语法一致性
```

---

## 二、 分章批注修复协议（核心协议）

处理用户批注文件（如 Markdown 批注或分章要求）时，严格遵循以下等级：

1. **直接改写的文本 = 最终定稿**：
   - 逐字应用，不得自由发挥改动定稿字句（仅允许纠正明显笔误如“的/地/得”）。
2. **括号语法判定**：
   - **【新文本】**：精确替换原文对应位置。
   - **空【】**：明确的**删除标记**，彻底移除对应原文字句。
   - **与原文相同的【原文片段】**：标记为重点处理区，结合上下文或标题行指示调整。
3. **标题行批注 = 章节级最高统领**：
   - 如标题行批注“本章检查所有答字禁止出现”、“所有字段重新梳理”，必须作为整章的最高红线。
4. **未批注句 = 重写责任区**：
   - 深入代入角色当前阶段心理，消除生硬感与机械味。
   - **最小干预原则**：保留角色说话时的语气能量（如惊叹、撒娇叠词、呼名、娇嗔拖音），不擅自将语气“压平”。
5. **冲突裁定原则（LRN-20260806-005）**：
   - 若用户批注定稿与写作铁律产生直接冲突，**必须主动报告冲突请求用户裁定**，绝对禁止单方面擅自改写定稿。

## 三、 语言质感与对话五层填充法

1. **对话聚焦情感连接与性格展现**：
   - 避免单纯的一问一答式信息传递。
   - 对话中自然融入：**身体微动作**（嵌入引语）、**下意识试探**、**声调起伏**。
2. **引语归属去机械化**：
   - 严禁出现“她答：/他应道：/回答：”。
   - 将说话融入身体交互（例：“黎恩将披风拢在她肩头：`'山风凉，先进屋。'`”）。
3. **消除短对话碎句**：
   - 遇 1-3 字短对话，参考 [dialogue-forms.md](file:///home/nanhu2/comfyui/%E4%B8%96%E7%95%8C%E4%B9%A6/.agents/skills/story-polisher/references/dialogue-forms.md) 执行展开或融入叙事。

## 四、 润色后自检 Checklist（红线扫描）

在完成章节编辑后，必须逐条对照以下禁令：

- [ ] **无 pivot 否定结构与“不是”句式**：全篇搜索排查“不是……是……”、“没有……只是……”，绝不用“不是”句式，全部转换为正面肯定描写。
- [ ] **无违禁词汇与比喻（硬红线）**：
  - 严禁出现“一丝/一 丝”、“不易察觉/不易 察 觉”。
  - 严禁出现“不容置疑”等一切以“不容”开头的词汇（不容抗拒、不容反抗等）。
  - 严禁使用“小猫”、“小兽”、“幼兽”等小动物类的比喻（替换为支配、掌控、狂热等词语）。
  - 严禁描写“成熟女性”相关的描述（如“成熟女性的体热/体香”等，文中不存在成熟女性）。
  - 严禁写“他推了推并不存在的隐形眼镜”。
- [ ] **无现代工程与管理用语**：严禁出现“成本/效率/优化”等用语。
- [ ] **无括号堆砌补充解释与空泛结尾**：绝无括号补充说明，绝无“为...支撑”“奠定...基础”等假深刻结尾。
- [ ] **终止条件 3 绝对纯物象定格（硬红线）**：
  - 动作叙事必须全部归入终止条件 2（包括射精、言语交锋、穿衣、推门离去、落锁等全部动作链）。
  - 终止条件 3 必须且只能是静态的环境余韵、物理残存痕迹或客观物象定格（如：熄灭的屏幕红光、冷却的水碗、门缝外的风声、见底的精油瓶、床单上的干涸浊迹、蒸发的微弱紫烟、被尾巴扫开的积灰等），严禁包含任何人物主观动作或连续动词链。
- [ ] **大纲尺度与动态字数标准（按需讲清大纲，拒绝机械一刀切）**：
  - 世界书情境是为模型提供高信息密度的**情境大纲 (Scenario Outline)**，首要目标是“把大纲讲清楚、动作交代扎实、关键对白完整保真”。
  - **基于情节复杂度的动态篇幅**：
    - 轻量日常/单一微动作：**300 ~ 500 字符**；
    - 标准推进/常规交互：**500 ~ 800 字符**；
    - 复杂大章/多阶段反转/重头突破：**800 ~ 1200 字符**；
  - **核心准绳**：严禁无意义的文学冗余与流水账（大段风景空镜头、自问自答式意识流独白、操作手册式罗列）；只要是讲清楚事件骨架与交互阻力所必需的有效信息，按需充分交代，严禁强行过度削减关键细节。

- [ ] **登场人物与地点核验（docs 设定库对齐）**：
  - 登场人物必须在 `docs/character/` 或 `docs/npc/` 中有案可查（严格以总览为准，全库无莎拉）；
  - 故事舞台地点必须存在于 `docs/location/`。
- [ ] **新实体建档与总览同步（强制闭环）**：
  - 若确有必要引入新地点或新生物/怪物，必须已在 `docs/location/{名称}.TXT` 或 `docs/creature/{名称}.TXT` 创建标准档案，并已同步更新 `_地点总览.TXT` 或 `_怪物与生物总览.TXT`。
- [ ] **无自创名词，背景舞台契合**：
  - 绝无任何自创超维名词、现代工程科幻概念，故事舞台 100% 契合艾尔多利亚魔导与古代符文世界观。
- [ ] **对照档案防数据错误与防 OOC**：
  - 已比对人物/地点/生物档案，发色瞳色（菲白发猫瞳、菲娜粉发紫瞳、艾玛深紫辫、劳拉靛蓝发等）绝对无误，性格底色、台词习惯与武器装备完全忠实，绝无 OOC。
- [ ] **无连续短句三连**：检查句号结尾 ≤12 字的短句，不得连续出现三句。
- [ ] **无“答/应”引语**：grep 检查是否残留“她答/他应/应道”。
- [ ] **标点准确**：所有疑问句与调侃句均使用 `？`，绝无句号收尾的真问句。
- [ ] **黎恩与菲娜人设未崩**：菲娜身体先于意志、回归时刻被接住；黎恩温柔主导、温度先于安排。
- [ ] **主语显化明确**：动作发起者清晰，多人场景与段首首动词明确使用人名，严禁连续模糊代词“他/她”。
- [ ] **无 AI 虚假强调与流水账**：严禁“是真的XX”（如“是真的心虚”）、“他先…然后…”机械步骤、“即使…依然…”假对仗套话。
- [ ] **无心理引导前缀**：严禁“她在想……”等虚伪前缀，直接呈现心理与感官。
- [ ] **反应落地简洁化**：身体与高潮反应直率真切（如“没忍住发出了一声娇喘”），严禁悬浮文学化套话。
- [ ] **同段无核心词重复**：同段内同一特征描摹（如“双腿发软”）不得连续/首尾出现两次。
- [ ] **母语自然时序与语序**：动词时序自然顺畅（“最后一句声音低了下去”），因果与感知在前、动作在后（“被声音吸引，从锻造室走出来”），严禁欧化倒装。
