## 一、 执行工作流

```text
Step 1: 定位原章节 TXT（docs/story/{阶段}/{ID}：{名称}.TXT）
Step 2: 对照用户批注或精修目标，严格执行分章批注修复协议
Step 3: 调用微声音工程与角色声音契约，展开生硬短对白，注入身体微反应
Step 4: 对照润色自检清单（Checklist）排查违规与词汇偏差
Step 5: 保存 TXT 并运行语法校验脚本验证结构完整性
```

## 二、 分章批注修复协议（核心协议）

处理用户批注文件（如 Markdown 批注或分章修改要求）时，严格遵循以下等级：

1. **直接改写的文本 = 最终定稿**：
   - 逐字应用，不得自由发挥改动定稿字句（仅允许纠正明显笔误如“的/地/得”）。
2. **括号语法判定**：
   - **【新文本】**：精确替换原文对应位置；
   - **空【】**：明确的**删除标记**，彻底移除对应原文字句；
   - **与原文相同的【原文片段】**：标记为重点处理区，结合上下文或标题行指示调整。
3. **标题行批注 = 章节最高统领**：
   - 如标题行批注“本章检查所有答字禁止出现”、“所有字段重新梳理”，作为整章最高红线执行。
4. **未批注句 = 重写责任区**：
   - 代入角色心理，消除机械感；
   - **最小干预原则**：保留说话语气能量（惊叹、娇嗔拖音、撒娇叠词），不擅自将语调压平。
5. **冲突裁定原则**：
   - 若用户批注定稿与写作规范产生直接冲突，主动报告冲突请求用户裁定，严禁单方面擅自篡改定稿。

## 三、 语言质感与角色声音契约 (Voice Contract)

### 1. 微声音工程与对白生动化
- **拒绝零台词与动作流水账**：即便在仅隔一扇木门或布帘的高压隐秘场景，也必须有贴耳气音、咬牙低语警告、含糊娇嗔；
- **真实身体反应优先**：心跳漏拍、掌心微汗、呼吸骤促、耳根发烫、大腿微颤，动作与感官带出情绪；
- **标点自然落地**：疑问调侃用 `？`，陈述落地用 `。`，娇嗔拖音用 `~`，被打断用 `——`。

### 2. 核心角色声线锚定
- **菲娜（Seraphina）**：粉发紫瞳，320岁精灵守护者。表象沉静自持，底色娇羞妩媚、易脸红、爱撒娇。面对亲密越界时心软慌乱，事后扑入黎恩怀中温存坦白，获取踏实归属与双重情趣；
- **黎恩（Rean）**：灰之骑士内核，温柔幽默、沉稳可靠的爱人兼教官。对菲娜的占有与安排源于深爱与默契，接纳坦白时给予拥抱、抚顶与亲吻，事后身体回收彻底擦拭；

## 四、 润色后自检清单 (Checklist)

完成章节精修后，对照以下清单逐项核验：

### 1. 结构与格式规范
- [ ] **标题名称绝对不含“章”字**：检查 `{前半段}——{后半段}`，严禁出现“章”字；
- [ ] **开头时段合规**：单章统一以“某日+自然时段”（某日午后/某日清晨等）起笔，严禁具体日历日期；
- [ ] **废弃字段清理**：严禁出现 `章节任务` 与 `章节终止条件`；
- [ ] **总情境数一致**：元数据中 `总情境数: {N}` 与情境条目数量严格一致；
- [ ] **末尾物象收束**：第 $N$ 条情境为纯物象余韵定格（光影、余温、环境音），无动作退场；
- [ ] **核心 (Core) 戏骨扎实**：交代戏剧张力与标志性台词（1~2句），无元叙事解说与日历日期。

### 2. 语言与词表对照
- [ ] **词表映射达标**：对照 [`lexicon.md`](file:///d:/Siegfried/世界书/.agents/rules/lexicon.md)，排查替换所有古风器物、修真玄幻与明清艳情词汇；
- [ ] **消除 pivot 否定句式**：排查“不是……是……”、“没有……只是……”，全部转换为正面肯定陈述；
- [ ] **无神性与元叙事词汇**：无神使大人、圣洁精灵；无“跨线阶段特有的背德感”、“作为伏笔”等出戏解说；
- [ ] **标点与语流**：疑问句不用句号，无连续三句 ≤12 字的极短句堆砌，引语无“答/应”。

### 3. 人称与双视点保真
- [ ] **旁白直呼其名**：旁白一律使用“黎恩/菲娜/两人”，无“小妻子/娇妻/年轻剑圣/他”等代指；
- [ ] **菲娜双重人称**：在黎恩面前一律第一人称“我”；仅在外人身下刻意放浪时允许娇媚自称“菲娜”；
- [ ] **双视点女主细腻度**：若为第三人观察视点，机位过渡清晰，且完整保留女主在第一线的生理反应与对白拉扯。
