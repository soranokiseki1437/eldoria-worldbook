# 章节润色与精修技能指南 (Story Polisher)

> 本技能定义了世界书章节 TXT 精修、润色与分章批注落地时的最高执行标准。

---

## 一、 执行工作流

```
Step 1: 定位原章节 TXT（docs/story/{阶段}/{ID}：{名称}.TXT）
Step 2: 对照用户批注或润色目标，执行精修（严格遵守批注协议）
Step 3: 调用 references/dialogue-forms.md 展开碎片短对话并嵌入微声音工程
Step 4: 运行润色自检清单（Checklist）逐项排查违规
Step 5: 保存 TXT 并运行验证命令验证语法一致性与红线
```

---

## 二、 分章批注修复协议（核心协议）

处理用户批注文件（如 Markdown 批注或分章要求）时，严格遵循以下等级：

1. **直接改写的文本 = 最终定稿**：
   - 逐字应用，不得自由发挥改动定稿字句（仅允许纠正明显笔误如“的/地/得”）。
2. **括号语法判定**：
   - **【新文本】**：精确替换原文对应位置。
   - **空【】**：明确的**删除标记**，彻底移除对应原文字句。
   - **与原文相同的【原文片段】**：标记为重点处理区，结合上下文或标题行指示调整。
3. **标题行批注 = 章节级最高统领**：
   - 如标题行批注“本章检查所有答字禁止出现”、“所有字段重新梳理”，必须作为整章的最高红线。
4. **未批注句 = 重写责任区**：
   - 深入代入角色当前阶段心理，消除生硬感与机械味。
   - **最小干预原则**：保留角色说话时的语气能量（如惊叹、撒娇叠词、呼名、娇嗔拖音），不擅自将语气“压平”。
5. **冲突裁定原则（LRN-20260806-005）**：
   - 若用户批注定稿与写作铁律产生直接冲突，**必须主动报告冲突请求用户裁定**，绝对禁止单方面擅自改写定稿。

## 三、 语言质感与对话填充工程

### 1. 现代轻小说呼吸感 vs 拔除古风文言（文风防御）
- **杜绝陈腐武侠/修真文言**：坚决剔除“樱唇”、“檀口”、“香肩”、“秀足”、“玉手”、“玉足”、“玉腿”、“玉颈”、“天鹅颈”、“衣袂”、“素手”、“如凝脂”、“微咬银牙”、“微生怜惜”等古风词汇。
- **现代生动具象化**：改用现代日式轻小说生活化、具有真实触感与温度的描写（如“微肿红润的双唇”、“泛粉的饱满脚趾”、“圆润微颤的肩膀”、“丰腴柔嫩的大腿内侧”、“白皙优美的脖颈”）。
- **杜绝成语串烧与机械流水账**：严禁“上下飞掠”、“尽数激射”、“提至极限速度”等干瘪说明书式的快速赶场，沉下心刻画汗水、喘息、生理微颤与触感摩擦。

### 2. 极端高压情境下的微声音工程（对话保真）
- **严禁零台词假人**：即使在黎恩仅隔一扇虚掩木门或一道布帘的极限高压环境下，也绝对禁止完全剥夺角色的言语交流。
- **微声音填充**：嵌入贴耳气音、咬着牙根的低语威胁、含糊的呜咽、带着角色独特个性的断续碎语（如菲娜的坏心眼调戏、凯尔快要哭出来的求饶求确认）。对话中自然融入身体微动作，严禁引语归属词“答/应”。

### 3. 去神性佛性化：保真活生生的凡人少女
- **彻底杜绝神圣化/去人性化称谓**：严禁出现“神使大人”、“端庄圣洁的精灵守护者”、“圣洁精灵”等悬浮词汇。
- **还原真实少女身心**：菲娜是活生生的、有体温的粉发姑娘，会害羞埋脸、会记仇小报复、会调皮恶作剧、也会娇憨撒娇，绝非冷冰冰的神使造像。

## 四、 润色后自检 Checklist（红线扫描）

在完成章节编辑后，必须逐条对照以下禁令清单：

### 1. 元数据契约与规范
- [ ] **标题名称绝对不含“章”字**：检查 `{前半段}——{后半段}` 标题全文本，严禁出现“章”字（即便如“急就章”等文学双关也绝对禁止）。
- [ ] **元数据日期严格隔离**：
  - 全篇具体月份时段仅限在情境第 1 条首句合法出现（如“6月18日下午……”）；
  - **核心、章节任务、终止条件 1/2/3 中绝对严禁出现任何几月几日等具体时间字眼**。
- [ ] **【核心】与【章节任务】彻底解绑（严禁同质化）**：
  - **核心 (Core)** 必须有戏骨：交代戏剧张力来源、人物心理反差、微动作情趣与**标志性金句/经典对白**；
  - **章节任务 (Objective)** 必须为单句紧凑指令：明确系统推进的具体目标行动；
  - 两者语义重合度绝对不得超过 50%，严禁复制粘贴！
- [ ] **终止条件 3 绝对纯物象定格**：
  - 动作叙事全部归入终止条件 2（射精、擦拭、穿衣、言语交代、离去等全部动作链）；
  - 终止条件 3 必须且只能是静态环境余韵、物理残存痕迹或客观物象（光影、残墨、断裂笔尖、干涸茶渍、门外风声），严禁包含人物肢体动作，严禁概括性“相拥入睡”。
  - 终止条件序号统一使用标准 Markdown `- ` 列表，严禁数字序号。

### 2. 文学质感与文风禁令
- [ ] **彻底无古风文言与成语串烧**：绝无樱唇、檀口、香肩、秀足、玉手、玉足、玉腿、玉颈、天鹅颈、衣袂、素手、如凝脂、微生怜惜等套话。
- [ ] **彻底无神性佛性词汇**：绝无神使大人、端庄圣洁、圣洁精灵等神化称谓，角色是活生生的凡人。
- [ ] **彻底无第四面墙元叙事**：正文心理与核心/任务中绝无“跨线阶段特有的背德感”、“作为伏笔”、“四重神髓”、“线索闭环”、“终极收拢”等作者/读者视角解说。
- [ ] **彻底无医学解剖词出戏**：绝无“前列腺液”（统一使用前液、湿滑黏液）。
- [ ] **无 pivot 否定结构与“不是”句式**：排查“不是……是……”、“没有……只是……”，绝不用“不是”句式，全部转换为正面肯定描写。
- [ ] **无违禁词汇与比喻（硬红线）**：
  - 严禁出现“一丝/一 丝”、“不易察觉/不易 察 觉”。
  - 严禁出现“不容置疑”等一切以“不容”开头的词汇（不容抗拒、不容反抗等）。
  - 严禁使用“小猫”、“小兽”、“幼兽”等小动物类的比喻（替换为支配、掌控、狂热等词语）。
  - 严禁描写“成熟女性”相关的描述（如“成熟女性的体热/体香”等，文中不存在成熟女性）。
  - 严禁写“他推了推并不存在的隐形眼镜”。
- [ ] **无现代工程与管理用语**：严禁出现“成本/效率/优化”等用语。
- [ ] **无括号堆砌补充解释与空泛结尾**：绝无括号补充说明，绝无“为...支撑”“奠定...基础”等假深刻结尾。
- [ ] **无“答/应”引语**：grep 检查是否残留“她答/他应/应道”。
- [ ] **标点准确**：所有疑问句与调侃句均使用 `？`，绝无句号收尾的真问句。

### 3. 篇幅阶梯与结构
- [ ] **动态篇幅核验**：
  - Level 1（轻量微交互）：300 ~ 500 字符；
  - Level 2（标准推进/单阶段）：700 ~ 850 字符；
  - Level 3（重头大章/多阶段/高压突破）：850 ~ 1,100 字符（上限 1,150 字符）；
  - 运行 `python scripts/story_tool.py validate` 确保语法与红线全部绿灯通过。
