## 四、 句式、修辞与语言自然度

| 误区特征（冗余病句 / AI 假书面 / 廉价成语） | 正向自然表达（Show, Don't Tell / 现代口语节奏） | 规范逻辑 |
| :--- | :--- | :--- |
| **严禁 pivot 否定句式**<br>“他没有退缩，只是握紧了剑”<br>“不是害怕，是因为心虚” | **直接陈述事实**：<br>“他握紧了剑。”<br>“他有些心虚。” | 消除冗余的“不是……是……”、“没有……只是……”，肯定句直接落地。 |
| **尽数 / 全数** | **全部 / 一股脑儿 / 一滴不剩地** | 杜绝公文假雅。 |
| **一丝 / 丝毫** | **一点 / 半点 / 毫无** | 杜绝假高级虚词修饰（如“一丝不苟”改“格外严肃”）。 |
| **微蹙 / 阖眸 / 凭栏** | **微微皱眉 / 闭上眼睛 / 倚在露台栏杆边** | 文言单字动词转为自然现代口语。 |
| **轻步上前 / 轻步走去** | **放轻脚步 / 快步走上前 / 蹑手蹑脚地迈步** | 杜绝武侠古风“轻步”，用生活流动作展现轻缓。 |
| **嗓音微哑 / 轻哑 / 声音微哑** | **声音有些发颤 / 带着微促气音 / 喘息着低语** | 剔除晋江网文廉价套路词，还原真实喉腔喘息。 |
| **笑了就是笑了**<br>“胸腔震了一下”“喉咙里滚出一声低笑” | **“他笑了。” / “他忍不住笑出声。”** | 杜绝机械套路浮夸动作。 |
| **做贼心虚 / 不疑有他** | **害怕被撞破 / 满心慌乱 / 没有多想** | 成语套话转为角色当下第一人称真实的心理波动。 |

| **引语归属词“答 / 应”**<br>“她答道：/ 他应了一声：” | **动词直接嵌入引语，或用“说”**：<br>“‘我知道了。’她移开视线。” | 杜绝机械说书人体裁。 |
