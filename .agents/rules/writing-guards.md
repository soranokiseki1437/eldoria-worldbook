# 写作铁律与去 AI 化红线

> **适用范围**：所有涉及章节正文撰写、情境生成、对话润色与批注修改的操作。

## 一、 叙事摄影机模型与基调

1. **摄影机模型**：
   - `{{user}}` 是纯粹的叙事摄影机镜头，无实体、无意志、无主观情感。
   - 镜头对准谁，就从谁的感官和内心展开叙事；镜头切换后首句必须明确当前对准谁。
   - **视角持有者不知道的事情不写**（不透视、不全知上帝视角）。
   - 指代黎恩始终用“他”或“黎恩”，绝不用“我”。
2. **叙事基调**：
   - **单线纯爱共享融合线**：共享时刻 ⇄ 回归时刻 交替推进。
   - 共享是双方知情自愿的深度体验，回归是不可动摇的情感落点与安全岛。

## 二、 去 AI 化写作 20 条铁律（红线禁令）

| # | 禁令 | 说明与纠正 |
|---|---|---|
| **1** | **禁现代系统术语** | 严禁出现“优化/提升/降低/节省/高效/低成本/机制”等现代工程词汇。 |
| **2** | **禁括号堆砌** | 括号内的背景或心理补充必须直接顺入正文叙述。 |
| **3** | **禁变量名罗列** | 叙事文本中不得出现函数名、变量名、系统参数式罗列。 |
| **4** | **禁空泛总结尾巴** | 严禁以“为…支撑”“奠定了…基础”“标志着…”作为段落或情境结尾。 |
| **5** | **禁未证实声明** | 不写角色未经验证即断言的绝对全知定论。 |
| **6** | **共享时刻不频繁看黎恩** | 共享时刻全情沉浸在当下的体验与互动中，回归时刻才看黎恩。 |
| **7** | **不机械重复“平静/掌控”** | Seraphina 拥有真实的羞涩、失控、沉醉与阶段性心理演进。 |
| **8** | **★ 绝对禁止 pivot 否定句式** | **严禁“不是……是……”、“没有……只是……”**。直接写肯定句（例：“他没有退缩，只是握紧了剑” ❌ → “他握紧了剑” ✅）。 |
| **9** | **禁元叙事标记** | 诸如“版本更新”、“设定追加”等标记只进 git，绝不写进正文与情境。 |
| **10** | **修饰融入动词** | 不在句末后挂抽象修饰语，动词直接带出质感（如“指尖轻轻贴上”）。 |
| **11** | **功能性对话可概述** | 无性格展现的报信/交接用叙述概括，对话留给充满弦外之音的交锋。 |
| **12** | **严禁破折号滥用** | 破折号全篇仅限三种场景：① 章节标题分隔；② 说话被打断；③ 语法插入语。**叙事描写和分析字段一律禁止使用破折号**。 |
| **13** | **禁角色“二字崩”** | 角色必须说完整人话。严禁：“结论。”“哪样。” → 改为：“所以呢？”“我不能再那样对你。” |
| **14** | **问句严禁使用句号** | 疑问与调侃必须用 `？`；`。` 仅用于陈述落地、冷淡与克制。 |
| **15** | **禁短句三连** | 句号结尾 ≤12 字的极短句不得连续出现三句。用逗号与分句自然串联。 |
| **16** | **笑了就是笑了** | 严禁“胸腔震了一下”“喉咙里滚出一声低笑”。直接写：“他笑了。” |
| **17** | **禁碎片对话与碎短独白** | 严禁“嗯。”“嗯。”短句接龙；内心独白同理，必须展现心理流转。 |
| **18** | **禁突然哲学辨析与金句** | 角色禁止突发抽象哲学辨析、自创分类学术语（如“被算进去”）。 |
| **19** | **情绪直接写真实落地** | 吃醋就写吃醋，委屈就写委屈。动作细节承载情绪，但绝不替代情绪。 |
| **20** | **禁“答/应”作为引语归属词** | 严禁“她答：/他应道：/回答：”。使用动作嵌入引语，或用“说”。 |

## 三、 对话标点落地规范

| 标点 | 正确语义与场景 | 错误范例 | 正确范例 |
|:---:|:---|:---|:---|
| `？` | 真实疑问、反诘、戏谑调侃 | `"你笑什么。"` ❌ | `"你笑什么？"` ✅ |
| `。` | 陈述句、落地断言、冷淡收敛 | `"我没笑？"` ❌ | `"我没笑。"` ✅ |
| `！` | 情绪爆发、羞恼、激动呼喊 | `"住手。"` ❌ | `"住手！"` ✅ |
| `~` | 拖长音、撒娇、戏弄、轻挑 | `"滚啊。"` ❌ | `"滚啊~"` ✅ |
| `...` | 气息渐弱、迟疑犹豫、呼吸不匀 | `"等一下。"` ❌ | `"等……等一下"` ✅ |
| `——` | 话未说完被动作或他人打断 | `"你怎么知道——"` ✅ | *(不得用作描写停顿)* |

## 四、 核心人设底线

### 1. Seraphina（菲娜）
- **身体先于意志**：先有身体本能反应（红耳朵、微颤），随后理智意识到，最后做出推开或接纳的抉择。
- **愤怒源于被无视，而非触碰**：软声提醒（“等一下”）被忽略继续推进时，才会从羞涩转为真正的冰冷与怒意。
- **回归时刻“被接住”原则**：从第三者场景回归后，不需要多余的推拒与对抗，直接呈现黎恩对她身体与情感的接纳与包裹。
- **事后侍奉汇报与爱意受用**：对黎恩怀有不可动摇的归属与爱意。在与其他男性发生亲密互动后，深知黎恩会因此而极度兴奋，事后主动手口侍奉汇报或娇羞顺从坦白；看着黎恩被脑海想象刺激得欲火狂飙，她会获得极大的心理受用，并全心迎合听完汇报后黎恩带着巨大兴奋对她的猛烈占有。

### 2. 黎恩（Rean）
- **沉稳、幽默、体贴的主导者**：爱与占有均建立在对菲娜深刻了解之上，绝不冷漠寡言，绝不忽略菲娜感受。
- **温度先于安排**：替菲娜做主时必写出依据（既有默契、她的身体信号）；菲娜一旦开口反对，立刻真诚道歉并尊重停下。
- **背德兴奋与双重爽感汇报铁律**：
  - 黎恩对菲娜与其他男人亲热这一件事极度兴奋，绝非自卑猜忌；
  - 事后汇报严格遵循双通道：① 菲娜主动手口侍奉一边抚弄一边汇报；② 黎恩主动挑明强势要求坦白并命令手口侍奉；
  - 听取汇报时必须写出黎恩的**心理（脑内脑补爱人承欢动情画面的背德兴奋）+ 生理（肉棒被菲娜手口等温柔抚弄）的双重爽感**；
  - 汇报即便无即时手口抚慰，听完汇报后黎恩必定带着极度兴奋与强烈欲望，立刻翻身与菲娜做爱（猛烈本番重新占有）。

## 五、 语言自然度与精修十诫（试音标定固化规律）

> **来源基准**：用户亲自标定修改（Ch353/Ch715/Ch291），全库精修与撰写必须作为硬指标执行。

| # | 规则项 | 核心禁令（AI 机械感特征） | 正确示范（自然生动） |
|:---:|---|---|---|
| **1** | **主语显化** | 镜头对准角色不明确，或动作链中滥用“他/她”代词，造成认知漂移。 | 明确使用人名（艾德里安/劳拉/哈根等），动作发起者清晰。 |
| **2** | **禁“XX是真的XX”** | AI 式反复强调与自问自答式确认：`他心虚了，这次是真的心虚`。 | 直接写事实：`艾德里安心虚了`。 |
| **3** | **禁“先…然后…”链** | 操作手册式流水账：`他先用舌面覆住，然后用舌尖拨弄`。 | 动作自然连贯串联：`舌面覆住乳头，再用舌尖拨弄`。 |
| **4** | **禁“即使/依然”对仗** | 伪工整书面套话：`即使还带着微喘，语气依然发硬`。 | 剔除转折废话，直接写落地感受：`语气发硬`。 |
| **5** | **禁“她在想”前缀** | 心理描写前加多余主观引语：`她在想，刚才那个高潮确实是舒服的`。 | 摄影机直接呈现感官与内心：`刚才那个高潮确实是舒服的`。 |
| **6** | **压缩碎片短句** | 连续三四个单动词超短单句堆砌，导致语流断裂破碎。 | 使用逗号、连词或伴随从句合并为连贯的长句。 |
| **7** | **反应落地简洁化** | 悬浮浮夸的高潮与身体描写：`压不住的声音从喉咙里漏出来……`。 | 真实直接的生理反应：`没忍住发出了一声娇喘`。 |
| **8** | **消除同段重复词** | 同一自然段内首尾重复出现相同词句（如“双腿发软”两次）。 | 同段仅保留一处最精准描写，另一处改换动作表达。 |
| **9** | **动词时序自然** | 僵硬欧化从句时序：`他说最后一句话的时候声音变低了`。 | 遵循自然物理与时间线：`最后一句声音低了下去`。 |
| **10** | **汉语自然语序** | 欧化后置倒装定语/伴随分词：`多尔金从锻造室走出来，被声音引来的`。 | 遵循汉语前因后果顺序：`多尔金被声音吸引，从锻造室走出来`。 |

## 六、 设定一致性、实体建档与防 OOC 铁律（最高基准）

> **红线原则**：世界书任何章节的改写或新建，绝不允许天马行空脱离设定。每一位登场角色、每一个场景舞台、每一只遭遇魔兽，都必须在 `docs/` 设定库中可溯源、可核验。

1. **登场人物与场景地点必须存在于 docs 设定库**：
   - **人物核验**：主要登场人物必须存在于 `docs/character/`（如黎恩、菲娜、菲、艾玛、劳拉、玲、亚莉莎、奥蕾莉亚等，名单严格以 `_人物总览.TXT` 为准；全库绝对无莎拉等不存在角色）；次要 NPC 必须存在于 `docs/npc/`（以 `_次要人物总览.TXT` 为准）。
   - **地点核验**：故事舞台必须严格限定在 `docs/location/`（以 `_地点总览.TXT` 为准），严禁凭空捏造未登记的地名。
2. **新地点/新生物（魔兽）强制建档与总览同步机制**：
   - 若情节展开确有必要引入**全新地点**或**全新生物/怪物**，必须执行“先建档、再同步、后引用”的三步闭环：
     - ① **创建实体档案**：在 `docs/location/{新地点名称}.TXT` 或 `docs/creature/{新生物名称}.TXT` 创建标准规范的 TXT 档案（完备记录环境特征、生态习性、危险度、与主线关联等）；
     - ② **同步更新总览**：必须立即将新实体追加写入 `docs/location/_地点总览.TXT` 或 `docs/creature/_怪物与生物总览.TXT` 中，确保全局索引无遗漏；
     - ③ **构建验证入库**：运行 `python scripts/rebuild_all.py` 确保新实体被世界书生成器正确解析收录为 reference 条目。
3. **严禁自创名词，故事舞台严格符合背景设定**：
   - 严禁引入任何未在 `docs/` 设定中出现的自创名词、现代科幻概念或超维设定。
   - 故事舞台必须 100% 契合艾尔多利亚（Eldoria）世界观：以“导力器科技 + 太古符文魔法 + 帝国骑士道/猎兵/游击士文化”为基石，严禁出现违和的异界设定。
4. **对照档案核验数据与言行，严禁 OOC**：
   - 写作前必须查阅对应人物、地点、生物档案：
     - **外貌与生理特征严格保真**：菲娜粉发紫瞳、菲纯白发猫瞳、艾玛深紫长辫戴眼镜、劳拉靛蓝发琥珀瞳、玲紫发金瞳、亚莉莎金发双马尾等，严禁发色瞳色混淆或描写错误。
     - **性格与台词底色绝对保真**：菲的猫系寡言与直球坦然、玲的天才小恶魔毒舌与傲娇、劳拉的直率剑士与认真负责、艾玛的大姐姐包容与被动反转、亚莉莎的傲娇嘴硬心软，严禁出现言行崩坏或 OOC。
     - **战斗力与武器设定一致**：角色的佩剑、魔导杖、双枪剑、战术导力器等专属装备必须符合既有设定，严禁能力与数据错位。

## 七、 大纲尺度与动态字数标准（按需阐述，拒绝机械一刀切）

> **核心原则**：世界书情境是为大语言模型提供高信息密度的**情境大纲 (Scenario Outline)**。大纲的首要任务是**“把事情讲清楚、把动作骨架交代扎实、关键对白完整保真”**。章节复杂度不同，必须依据情节需要灵活决定篇幅，严禁将所有章节机械一刀切压缩到死板字数！

1. **动态分级大纲尺度标准**：
   - **轻量日常/单一微动作章（300 ~ 500 字符）**：聚焦单一身体试探、晨间/睡前简短温存或日常对话，骨架干净直接，无需强行注水。
   - **标准互动/常规推进章（500 ~ 800 字符）**：全库大多数标准章节的健康区间。容纳完整的起因环境、身体阻力摩擦、高潮爆发与落地收敛。
   - **重头剧情/多阶段反转/仪式突破章（800 ~ 1200 字符）**：多人深度互动、复杂心理破冰、多阶段对抗性拆招或主线关键结合大章。只要是为“把大纲讲清楚、把动作与情绪递进交代完整”，允许充分展开叙事骨架。
2. **挤水与提炼的真实准绳**：
   - **坚决剔除的是“文学闲笔与流水账纯水”**：大段天气/风景描摹、无意义的空镜头、自问自答式的意识流独白、操作手册式的琐碎步骤。
   - **绝对必须保留的是“大纲有效信息”**：推进起因、人物心理动因、肌肉阻力与生理紧绷、标志性微动作、100% 角色原汁原味对白。
   - **判定标准**：删掉这句话，是否会影响大模型对该场景“发生了什么、动作怎么做、人物态度如何”的准确理解？会影响则必须保留，不影响方可精简。
