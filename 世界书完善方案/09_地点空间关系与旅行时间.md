# 方案09：地点空间关系与旅行时间表

**日期**: 2026-06-27
**对应要求**: 第10条（地点地图或空间关系）

---

## 一、现状问题

20个地点在 `_地点总览.TXT` 中是扁平列表。各地点TXT中只有个别含位置描述（如"森林中央偏南""森林北部"），但：
- 无相对位置关系（A在B的哪个方向）
- 无旅行时间（从这里走到那里要多久）
- AI无法推断"巡逻从这里到那里需要多久"
- 事件中角色切换场景时缺乏空间参考

## 三、修改实施

### 3.1 修改 `docs/location/_地点总览.TXT`

在头部新增空间关系段落：

```
  - 空间关系概述：林间空地位于森林中央偏南，是所有活动的地理原点。
    空地本身是安全区（半径约5分钟步行范围内为日常活动区）。
    银流河从西向东横穿森林——空地在河的南侧。
    越往北走腐化浓度越高——低语林地和心木废墟在森林北部和东北部。
    森林边缘（雾帷边界）环绕整个Eldoria——从空地往任何方向走约20分钟可达南侧边界，
    但往北的边界被腐化区域阻断，实际无人到达过。
  - 旅行时间均以步行计算。影牙兽出没区域实际行进速度会更慢。
    导力通讯在安全区和缓冲区内正常，过渡区开始衰减，危险区基本无效。
```

## 五、设计原则

1. **时间是估算，不精确到秒**：旅行时间给整数分钟，"约15分钟"而不是"14分30秒"
2. **腐化影响速度**：越危险的区域走越慢——不是距离变长了，是移动变谨慎了
3. **以空地为原点**：所有方位描述从林间空地出发——因为这是AI最自然的"默认位置"
4. **空地是圆心**：安全区→缓冲区→过渡区→危险区→核心区，是一个同心圆+北部偏移的模型
