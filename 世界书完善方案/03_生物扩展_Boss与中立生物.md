## 二、方案设计

### 2.1 Boss/精英变体（新建3个）

#### A. `docs/creature/影牙兽首领.TXT` — Boss级

```
ID: CRT10
名称: 影牙兽首领
触发关键词: 影牙兽首领, 影牙首领, 巨影牙
始终触发: 否
注入深度: 3
内容:
  - 影牙兽的首领——比普通影牙兽大三倍，肩高接近两米。暗紫色鬃毛像火焰一样在脖颈处燃烧，
    红眼不再只是发光——它们在黑暗中留下残影轨迹
  - 普通影牙兽是狼——它是"狼王"。独自活动，只在Thalion发出召唤时带领族群出击。
    它的吼声能让影牙兽群从散乱变为列队
  - 腐化核心在它胸腔内——隐约可见暗紫色的搏动。这是它的弱点，也是它力量的来源。
    击败它不会让影牙兽消失，但会让它们暂时失去组织
  - 出现在腐化浓度最高的区域——心木废墟深处、Thalion领域入口。不会主动离开腐化区域
  - 叙事定位：中期强敌——它的出现标志着腐化威胁的升级。第一次击败它时，影牙兽群会陷入混乱
```

#### B. `docs/creature/腐化巨蟒.TXT` — 精英级

```
ID: CRT11
名称: 腐化巨蟒
触发关键词: 腐化巨蟒, 巨蟒, 暗紫蟒蛇
始终触发: 否
注入深度: 3
内容:
  - 被腐化吞噬的古森林蟒蛇——身长可达十米，暗紫色鳞片间嵌着腐化藤的倒刺。
    移动时地面会留下腐蚀的痕迹——腐化浓度在它经过后短暂上升
  - 缠绕是它的主要攻击方式——用身体将猎物卷起，倒刺注入麻痹毒素。
    腐化藤常常生长在巨蟒的巢穴周围——两者形成共生关系
  - 栖息在低语林地和心木废墟的地下通道。昼伏夜出——白天盘踞在腐化藤丛中休息
  - 鳞片硬度堪比轻甲——但圣光可以软化。过度依赖腐化能量——在圣光浓度高的区域行动迟缓
```

#### C. `docs/creature/堕落守护者残影.TXT` — 精英级

```
ID: CRT12
名称: 堕落守护者残影
触发关键词: 堕落守护者, 守护者残影, 腐化精灵战士
始终触发: 否
注入深度: 3
内容:
  - 精灵王国陷落时被腐化吞噬的守护者——他们的身体已经消散，但意志的碎片被腐化保留了下来。
    比低语者更强——低语者是普通精灵的残影，守护者残影保留了部分战斗技能
  - 外观：人形，半透明暗紫色，身上隐约可见生前的守护者铠甲轮廓。武器是圣光的扭曲形态——不再是金色，而是暗紫色
  - 行为：不像低语者那样沉默游荡——他们会"守护"特定的区域（生前守护的地点），任何靠近者都会被视为威胁。
    被击败后会短暂恢复人形和记忆——几秒内露出"谢谢"的表情后消散
  - 出现在心木废墟的重要节点——银塔广场、王室墓室入口、禁地石门前。Thalion的领域中没有——他无法容忍看到曾经的同伴
  - 叙事定位：悲剧性的精英敌人——每次战斗都是一段精灵王国陷落的小回忆。可以触发Seraphina认出某个残影的瞬间
```

### 2.2 中立/可驯服生物（新建2-3个）

#### D. `docs/creature/雾驹.TXT` — 可驯服

```
ID: CRT13
名称: 雾驹
触发关键词: 雾驹, 银白马, 雾中马
始终触发: 否
注入深度: 3
内容:
  - 银白色骏马——鬃毛如雾气般飘动，蹄子踏过草地不会留下痕迹。不是幽灵——是森林中最稀有的原生生物。
    能在雾帷中穿行而不迷路——它们天生能感知圣光的流向
  - 性格温顺，不惧人类，但对腐化极度敏感——会远远避开腐化区域。跑起来几乎没有声音——蹄子落在任何地面上都是轻的
  - 可驯服——但驯服方式不是"征服"，是"取得信任"。需要连续几天在同一时间同一地点为它梳理鬃毛。
    一旦建立信任，会主动跟随，允许骑乘
  - 目前已知只有两匹——一匹偶尔在林间空地边缘出现，另一匹在圣光花田附近被目击。
    Seraphina曾试图接近但被它跑掉了——"它可能觉得我的圣光太强了"
  - 叙事定位：浪漫的交通工具——骑乘雾驹在森林中奔跑是纯爱场景的天然素材。取得信任的过程本身就是一个小叙事
```

#### E. `docs/creature/森林龟.TXT` — 中立

```
ID: CRT14
名称: 森林龟
触发关键词: 森林龟, 巨龟, 石纹龟
始终触发: 否
注入深度: 2
内容:
  - 体型巨大的森林龟——背甲直径可达一米。背甲上长着青苔和小型蕨类——每只龟的"背花园"都是独一无二的。
    移动极其缓慢——一天只移动几十米
  - 性格完全无害——缩壳时背甲上的青苔可以当椅子坐（但没人试过）。背甲温度恒定——在寒冷夜晚靠近它能取暖
  - 分布在银流河两岸。喜欢在浅滩泡水——背甲上的青苔在阳光下蒸出淡淡的草药香
  - 精灵王国时代曾被当作"活凳子"——守护者会议时，几只森林龟会趴在圣殿院子里，谁坐下来它们也不介意
```

#### F. `docs/creature/光羽鹫.TXT` — 可驯服（已有翼蜥的补充）

```
ID: CRT15
名称: 光羽鹫
触发关键词: 光羽鹫, 金色巨鸟, 光羽
始终触发: 否
注入深度: 3
内容:
  - 金色羽毛的大型猛禽——翼展可达三米。羽毛在圣光环境下自身会发出淡金色微光。
    白天在高空气流中盘旋——从地面看像一粒金砂
  - 捕食银流鱼——俯冲时收起翅膀的姿态是森林中最精准的攻击。对腐化生物有天然的敌意——会主动攻击小型影牙兽
  - 可被驯服——但需要从小养起。艾玛曾找到一只受伤的幼鸟，治疗后放归。那只鸟偶尔会回来落在她肩膀上
  - 目前有一只成年光羽鹫在银流河上游筑巢。它的巢是金色树枝搭的——在月光下会发光，像一个悬挂在树梢的小太阳
  - 叙事定位：天空视角——如果某天需要"从天空俯瞰森林"的场景，光羽鹫就是天然的叙事工具。也是艾玛的第二只可召唤生物
```

## 四、设计原则

1. **精英/Boss服务于叙事节奏**：影牙兽首领 = "腐化在升级"，堕落守护者残影 = "精灵王国的悲剧仍在回响"
2. **中立生物服务于氛围**：森林龟和雾驹不参与战斗——它们让森林更像一个活着的世界
3. **可驯服生物服务于关系**：驯服雾驹是一个"取得信任"的过程——这与NTRS的核心主题（信任）一致
4. **不过度扩展**：6个新生物，总数从10→16——够了。不要为了填数量而加生物
