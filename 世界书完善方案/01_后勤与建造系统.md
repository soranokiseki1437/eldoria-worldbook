**日期**: 2026-06-27（更新于同日）
**对应要求**: 第1条
**关联设定**: 矮人三兄弟（多尔金/哈根/法林）

---

## 一、现状分析

### 1.1 已有系统文件（docs/system/）
- 巡逻、守夜、会议、矿石采集 —— 制度类
- 乔治的发明和维护、凯尔的研究、艾玛的魔法研究 —— 角色职能类
- 导力、导力器、导力通讯、光晶石 —— 技术类
- **缺失**：食物来源、烹饪、物资管理、房屋建造/修缮

### 1.2 角色技能分布（含矮人三兄弟）

| 角色 | 后勤职能 |
|------|--------|
| **多尔金（矮人）** | 魔法武器锻造、金属工具制作、锻炉维护 |
| **哈根（矮人）** | 建筑/工程器械、排水系统、木石结构建造修缮 |
| **法林（矮人）** | 魔法防具、日常魔法用品、魔力灯等工艺品 |
| 菲 | 前猎兵→狩猎、野外生存、战斗训练 |
| 乔治 | 工程师→导力设备维护、战术壳等发明 |
| 雷恩 | 前骑士→重体力劳动、伐木搬运 |
| 劳拉 | 剑士→可协助狩猎、体力劳动 |
| 艾玛 | 魔女→草药识别、药材采集、简单治疗 |
| 玲 | 前执行者→什么都会一点、灵活机动 |
| 爱丽榭 | 家务全能→烹饪、缝补、日常照料 |
| 艾德里安 | 前贵族商人→物资清点、贸易中介、弄到稀罕货 |

### 1.4 贸易（更新）

- 旅行商人偶尔误入Eldoria——艾德里安作为前商人负责与他们交涉
- 矮人三兄弟偶尔穿越雾帷去外界获取必要物资——他们知道安全的路径
- 艾德里安+矮人三兄弟 = 营地与外界之间的物资桥梁
- 仍无常规贸易路线——森林的隔绝本质不变，但"偶尔能弄到"的渠道更多了

## 二、方案设计

### 2.1 新建系统文件

#### A. `docs/system/食物与采集.TXT`

（内容与前版相同——爱丽榭主厨、菲/劳拉狩猎、银流鱼/月影鹿/野菜/月光百合花瓣）

#### B. `docs/system/建造与修缮.TXT`

更新建造团队——纳入矮人三兄弟：

```
- 建造团队：
  - 哈根（矮人）是建造和修缮的主导者——矮人工程世家的传人，石木结构是他的祖传手艺。
    "石头知道怎么待着。你只需要问它——用正确的方式问。"
  - 乔治协助导力相关的建设——导力照明、光晶石冷藏箱等设备
  - 雷恩和菲承担重体力劳动——伐木、搬运石材、打地基
  - 多尔金负责金属构件——门轴、铁钉、支架等锻造部件
  - 法林为建筑刻防护符文——符文防护层让建筑更耐久
  - 劳拉偶尔帮忙——尤其是需要精确切割的木材处理（剑术的延伸运用）
- 现有建筑：（同前版，新增）:
  - 矮人祖厅——矮人岩丘的半山石砌大厅，光晶锻炉至今燃烧。符文防护使此处不受腐化侵蚀
```

#### C. `docs/system/物资与贸易.TXT` — 新增

```
ID: SYS13
名称: 物资与贸易
触发关键词: 物资, 贸易, 补给, 旅行商人, 稀罕货, 采购
始终触发: 否
注入深度: 2
内容:
  - 营地的基本物资（食物、木材、矿石、草药）来自森林本身——自给自足是常态
  - 稀有物资来源：
    - 艾德里安是营地与外界的主要贸易中介——前贵族商人的经验让他知道如何与旅行商人打交道。
      旅行商人偶尔穿过雾帷误入——艾德里安负责交涉、评估货物、以物易物
    - 矮人三兄弟偶尔穿越雾帷去外界——他们知道安全路径。通常采购特殊材料
      （稀有金属、锻造用油、工程零件）和矮人私酿酒。"路？当然有路。矮人走的路——你走不了。太矮。"
    - 咖啡、茶叶、布料、纸张、特殊药物——这些森林不能自产的东西通过上述渠道获得
  - 没有货币流通——营地内部不存在买卖关系。和旅行商人交易时以光晶石或精灵王国的古物交换——
    外界商人视光晶石为珍贵的魔法矿物
  - 物资管理由艾德里安和亚莉莎共同负责——艾德里安管"进"，亚莉莎管"存"
```

### 2.2 修改 `docs/system/_系统总览.TXT`

在"日常运作"段落后新增：

```
  - --- 后勤保障 ---
  - 食物来自森林本身——狩猎、捕鱼、采集构成完整的食物链。爱丽榭是主要烹饪者，晚餐是全员到齐的固定时刻
  - 建造和修缮由哈根（矮人）主导——乔治协助导力设备。所有建筑使用森林材料和矮人工程技艺
  - 锻造和魔法物品由矮人三兄弟提供——多尔金锻造武器工具，法林制作防具和日常魔法用品
  - 稀有物资通过艾德里安和矮人三兄弟与外界旅行商人交易获得——没有常规贸易路线但渠道足够
```
