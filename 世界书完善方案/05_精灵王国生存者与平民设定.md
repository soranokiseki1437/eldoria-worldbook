# 方案05：精灵王国生存者与平民设定

**日期**: 2026-06-27
**对应要求**: 第5条

---

## 一、问题

当前设定中，精灵王国陷落时：
- "许多人被腐化吞噬变为影牙兽"
- "另一些穿越雾帷逃往人类王国"
- "幸存的精灵极少"

但留下了一个模糊空间：**"极少"是多少？他们在哪？怎么活下来的？**

同时，如果森林里存在"普通平民"（不论是精灵还是人类），会产生连锁问题：
- 他们住在哪？吃什么？
- 200年腐化环境中如何存活？
- 为什么从未在事件中被提及？

---

## 二、核心决策：森林中无物理生存的精灵平民

### 方案：Seraphina是唯一活着的精灵

**设定陈述**：

> 精灵王国陷落后，Eldoria森林中**不再有物理形态存活的精灵**。
> Seraphina是唯一的例外——作为守护者，心木树以共生契约维系了她的生命。
>
> 其他精灵的结局只有三种：
> 1. **变为低语者** — 被腐化吞噬，失去自我。精灵的灵魂仍在残影中，但意识已消解。
>    低语者是精灵的残影。影牙兽是腐化能量直接具现化的野兽——两者无关
> 2. **逃往森林外界** — 穿越雾帷离开Eldoria。他们在外面发生了什么——
>    可能建立了新的国度，可能和其他种族混居，可能融入了人类王国。
>    Seraphina不了解——200年来她从未离开过森林，对外界一无所知
> 3. **成为先灵** — 在陷落时肉体消亡，但灵魂因强烈意志未被腐化带走，沉睡在废墟中

### 为什么这是最好的方案

| 理由 | 说明 |
|------|------|
| **不稀释Seraphina的孤独** | 如果还有其他精灵幸存者，她的"200年孤独"就打了折扣 |
| **不产生后勤问题** | 没有平民=不需要平民的食物/住所/安全系统 |
| **先灵已提供"幸存者"功能** | 古老先灵可以传递知识、揭示历史——不需要活着的精灵平民来做这件事 |
| **符合已有设定** | "幸存的精灵极少"→ 极少数=1 |
| **外部世界留白** | "逃往人类王国"的那一批精灵发生了什么——可以是未来的伏笔，但现在不需要展开 |

### 关于森林中的"人"

当前Eldoria森林中的14个人：

| 类别 | 人物 | 如何来到Eldoria |
|------|------|----------------|
| 精灵 | Seraphina | 自始至终在此，守护者 |
| 人类（帝国） | 黎恩 | 时空裂隙拉入 |
| 人类（帝国） | 雷恩 | 被流放后独自进入 |
| 人类（帝国） | 凯尔 | 时空裂隙拉入 |
| 人类（帝国） | 艾德里安 | 旅行商人误入 |
| 人类（帝国） | 乔治 | 追踪黎恩的信号 |
| 人类（帝国） | 劳拉/菲/亚莉莎/艾玛/玲/爱丽榭/亚尔缇娜 | VII班，追踪黎恩被陆续拉入 |

**没有一个是"自古以来生活在森林里的平民"。**

## 三、需要修改的文件

### A. `docs/world/精灵王国.TXT`

"陷落"段修改为：

```
  - 陷落: 200年前影牙降临——王国在一天内从鼎盛坠入毁灭。
    银塔的圣光一盏接一盏熄灭——那是守护者一个接一个倒下的信号。
    精灵王在最后一刻将自己的生命注入心木树根部——用最后的圣光保住了树的根。
    精灵的结局有三种：
      - 被腐化吞噬——变为低语者（沉默的残影，不是影牙兽——影牙兽是腐化能量直接具现的野兽）
      - 穿越雾帷逃往外界——此后下落不明。可能建立了新国度，可能和其他种族混居。
        Seraphina不了解外界的状况
      - 成为先灵——肉体消亡但灵魂因强烈意志未被腐化带走，沉睡在废墟中
    森林中不再有常住的精灵平民。Seraphina是唯一的例外——心木树的共生契约维系了她的生命。
```

### B. `docs/world/守护者.TXT`

如果其中有"精灵幸存者"的模糊表述，一并修正为"Seraphina是最后的精灵"。

### C. 全局grep

搜索全TXT中的"幸存精灵""精灵平民""精灵居民""精灵族人"等词——确认是否有残留的模糊设定，统一修正。

## 四、连锁影响

| 影响 | 处理 |
|------|------|
| 没有平民 → 没有平民聚餐/集市/社交 | 已有——营地篝火和晚餐就是全部社交 |
| 没有平民 → 建筑无人居住 | 已有——心木废墟是空的，其他建筑是VII班自己造的 |
| 没有平民 → 不需要治理/法律 | 已有——会议是唯一的决策机制 |
| 先灵是唯一"幸存者" | 古老先灵的角色需要更明确——它是"幸存者的声音" |
