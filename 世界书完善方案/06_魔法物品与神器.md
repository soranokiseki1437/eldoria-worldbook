### 2.2 4个新增神器

#### A. 心木树种子

```
ID: MAG06
名称: 心木树种子
触发关键词: 心木树种子, 心木种子, 树种
始终触发: 否
注入深度: 3
内容:
  - 心木树在濒死前结出的唯一一粒种子——大小如核桃，外壳是暗金色的木质纹理。
    握在手心里会感到微温的脉动——像一颗极小的心脏在跳
  - 种子需要同时注入圣光与暗影才能发芽——单一的圣光或单一的暗影都无法唤醒它。
    这是心木树在濒死时的新适应：它感知到了黎恩的存在，知道未来的净化需要两个人的力量
  - 当前状态：Seraphina保管着它，用一个小木盒挂在木屋的梁上。种子还在沉睡——等待被唤醒的时刻
  - 潜在用途：如果心木树被完全净化后死亡，种子可以种下新的树。但新树需要数百年才能长成——
    它不是"救急方案"，是"留给未来的方案"
```

#### B. 守护者法杖（Thalion的旧物）

```
ID: MAG07
名称: 守护者法杖
触发关键词: 守护者法杖, Thalion的法杖, 圣光法杖
始终触发: 否
注入深度: 3
内容:
  - 曾是Thalion的武器——精灵王国时代最强大的守护者法杖之一。杖身是心木树的枝条，杖头镶嵌着拳头大的圣光晶石
  - 现在被腐化完全包裹——杖身爬满暗紫色纹路，圣光晶石的光芒被压制到只剩微弱的淡金色核心。腐化藤从杖头蔓延到握柄
  - Thalion仍在使用它——但不再是施展圣光，而是引导腐化。法杖是他唯一没有丢弃的旧物——"他握着它的时候，手指的姿势和从前一样"（Seraphina的描述）
  - 如果法杖被净化——它将恢复原有的圣光力量！但Thalion是否能在净化后重新握住它，是另一个问题
  - 叙事定位：最终战斗的关键物品——击败Thalion后法杖会碎裂，还是被净化后回到Seraphina手中？取决于终局事件的走向
```

#### C. 先灵之镜

```
ID: MAG08
名称: 先灵之镜
触发关键词: 先灵之镜, 灵魂之镜, 镜湖之镜
始终触发: 否
注入深度: 3
内容:
  - 镜湖湖底的一面圆形石镜——直径约半米，镜面是抛光的黑曜石。不是精灵制造的——比精灵王国更古老，
    古老先灵也说不清它的来历。"它一直在那里——森林出现之前就在"
  - 功能：映照灵魂残影。将它对准某个区域，镜面会显示该地曾经发生过的重要事件——
    不是精确的影像，而是情感的回声。金色是圣光时刻，紫色是腐化时刻，银色是普通记忆
  - 限制：只能在满月光直射镜面时激活。每次只能看一个场景，而且无法选择具体时间点——只能看到"最强烈的情感印记"
  - 当前状态：仍在镜湖水下。Seraphina曾用它看过精灵王国陷落的那一天——只看了一眼就把它放回了水底。"有些记忆不需要镜子来提醒"
  - 叙事定位：揭示过去的工具——可以在关键时刻让角色"看到"精灵王国的黄金时代、Thalion堕落的瞬间、或精灵王的最后时刻
```

#### D. 银塔圣光碎片

```
ID: MAG09
名称: 银塔圣光碎片
触发关键词: 银塔碎片, 圣光碎片, 符文残片
始终触发: 否
注入深度: 2
内容:
  - 精灵王国银塔倒塌后的碎片——散落在心木废墟各处。小的如指甲，大的如手掌。银色金属质地，断口处仍刻着残存的古精灵符文
  - 满月之夜会发出微弱的金色光——是银塔曾经储存的圣光在缓慢释放。大部分碎片的能量已经耗尽，但仍有个别大块碎片保留了较强的圣光残留
  - 用途：
    - 黎恩用它来感知腐化——碎片在他手中时，越靠近腐化源，光芒越暗
    - Seraphina用它们来标记巡逻路线的安全节点——埋在路口，碎片的光芒可以驱散小型影牙兽
    - 凯尔收集了几块在研究——试图解读上面的符文含义
  - 不是"神器"级别——更像是精灵王国留下的日常遗物。但它们的存在让废墟不只是"死了的城市"——还有微弱的光在继续亮着
```

## 四、设计原则

1. **每个神器服务于叙事**：心木树种=未来的希望，法杖=Thalion的人性残留，先灵之镜=揭示过去的窗口，银塔碎片=废墟中的余温
2. **有限制/代价**：神器不是万能道具——先灵之镜只能看情感印记且需满月，种子需要两人之力才能唤醒，法杖被腐化包裹无法直接使用
3. **不创造新魔法系统**：神器只是已有力量体系（圣光/暗影/符文）的物理载体
