#### A. 新增 "创世传说" 段

```
  - 创世传说——"第一缕圣光"：
    - 精灵族最古老的传说：世界诞生于黑暗中的第一缕圣光。那光不是来自某位神——光是"自己决定亮起来的"。
      光落地的地方长出了第一棵心木树。树的根向地下延伸触碰到了暗影——不是对立，是相遇。
      光与暗在根部握手的那一刻，第一个精灵从树下的土地中走出来。
    - 所以精灵族并不把黑暗视为敌人——"没有暗影的地方，圣光照不到自己的深度"。
      这也是为什么守护者的刻印同时含有金色脉络（圣光）和灰色纹路（暗影）——
      守护者的本质是同时接纳光与影
```

#### B. 新增 "心木树的信仰仪式" 段

```
  - 心木树的信仰仪式:
    - 精灵族不建庙宇——他们相信心木树就是最直接的神圣载体。祈祷不需要语言——把额头贴在树根上即可，
      树会感知你的情感。心木树从不"回应"——它只是感知。"树听到了"就够了
    - 守护者宣誓仪式：在心木树下，守护者候选人将手按在树根上，说出自己的守护誓言。
      誓言不是对树说的——是对自己说的。树只是见证。"我说给我自己听。树帮我记住。"
    - 生命仪式：精灵的新生儿出生后第三天，父母会将婴儿放在心木树的根脉上——
      金色脉络会在婴儿身上短暂亮起，标记"你被森林认识了"。死者被埋在心木树根部的土壤中，
      精灵相信逝者的生命会回到树中——"明年开的花里有一瓣是他的"
    - 月下行礼：每日日落时分，精灵面向心木树的方向微微欠身——不是义务，是习惯。
      "做了几千年了。不欠一下身，一天不完整。"
```

#### C. 新增 "精灵日历与节日" 段

```
  - 精灵日历与节日:
    - 精灵以心木树的开花周期纪年——一年分为四个季节，每季由心木树的一个状态标记：
      萌芽季（春）、繁荫季（夏）、金叶季（秋）、沉眠季（冬）。
      一年有十二次满月——每次满月都有一个名字和意义
    - 四个主要节日：
      - 萌芽祭（萌芽季第一次满月）：庆祝新生和希望。精灵会用圣光点亮银塔的每一扇窗户——
        城市发光持续整夜。儿童在这一天收到刻有自己名字的圣光符文石
      - 繁荫之夜（繁荫季第三次满月——夏至）：一年中最长的白天。精灵从日落开始聚在心木树下，
        不说话、不唱歌、不点灯——"你只需要存在。和树一起存在。"是最安静也是最盛大的节日
      - 金叶祭（金叶季第二次满月）：感恩和告别的节日。精灵将写了感谢的树叶投入银流河，
        任其漂流到森林的每一处——"让森林知道你感激什么"。这是精灵王国陷落前最后的节日——
        金叶祭那天，银塔的圣光开始变暗
      - 沉眠之夜（沉眠季第一次满月——冬至）：一年中最长的夜晚。每家每户在门口点一盏圣光灯——
        示意"我在此处，光也在"。守护者在心木树下守夜整晚——这是加入守护者的最后一道考验。
        Seraphina的沉眠之夜守了二十年——"不是考验。我想陪树。"
    - 陷落后，节日自然消失了——Seraphina独自一人的200年，不再有点灯的窗户，不再有漂流的树叶。
      直到VII班到达——他们不知道精灵的节日，但他们在篝火边唱歌的行为，意外地像某个古老节日的复现
```

#### D. 新增 "历史传说——三位守护者的故事" 段

```
  - 历史传说——三位守护者:
    - 第一守护者·Eryndor：传说中精灵族的始祖——从心木树下走出的第一个精灵。
      他守护的不是森林，是"第一缕圣光"。他的格言刻在心木树根部："光无需被守护——需要被守护的是愿意接住光的手。"
      他是唯一一个不接受精灵王称号的守护者——"我不是王。我是第一个排队的人。"
    - 第七守护者·Sylvanna：唯一一位在和平年代放弃守护者身份的精灵。
      她爱上了人类王国的游侠，离开森林，在人类王国度过了余生。
      精灵王国对此没有指责——心木树也没有。"树没有挽留她。树只是在她走的那天多开了一朵花。"
      她是劳拉的祖辈——劳拉的剑术流派中有精灵守护者的痕迹，这是遗传的直觉
    - 第十二守护者·Thalion（堕落之前）：Seraphina的导师。他亲手在低语林地种下了第一片圣光花田——
      "腐化会来。当它来的时候，需要有东西在边缘等着它。"圣光花是第一批在腐化边缘生存下来的原生植物。
      Seraphina后来在花田边种下了月光百合——"他在边缘种防御。我在边缘种等待。"
```

## 四、设计原则

1. **节日服务于角色**：每个节日的描述最后都落回Seraphina身上——繁荫之夜她独自守了200年，沉眠之夜她陪树
2. **传说不只是设定**：三位守护者的故事各有叙事潜力——Eryndor是哲学基础，Sylvanna是劳拉的遗传线，Thalion的圣光花田是悲剧的预表
3. **信仰是体验不是教条**：精灵不祷告、不念经、不建庙——他们把额头贴上树根。这个动作任何角色都可以在后日谈事件中做
4. **不与VII班割裂**：节日段末尾留了一个钩子——篝火边的唱歌意外地复现了古老节日。这是"意外发现"而非"刻意复活"
