### 蜥蜴人文化设定

- **暖岩石=求偶场所**：沼泽地热暖岩石是部落雌雄相遇的传统地点。雌性在暖岩石上展开身体=接受求偶。雄性靠近暖岩石上的雌性=发起求偶。
- **鳞甲颜色被问=被表达交配兴趣**：暖血生物用语言调情，蜥蜴人用鳞甲颜色。问鳞甲颜色=在对方的文化里说"我对你有感觉"。这是部落内部众所周知的规则，从来没有需要向外族解释过。
- **泄殖腔对温度变化敏感**：蜥蜴人是半冷血——体温随环境波动。泄殖腔内的阴茎平时完全藏在体内，只有温度升高到临界值时才会开始伸出。这是纯生理反射，不受意志控制。猎人最尴尬的事：在暖岩石上遇到一个暖血雌性，然后身体自己做了决定。
- **尾巴=情绪的窗户**：蜥蜴人面部肌肉不发达，情绪通过尾巴表达。慢摆=耐心/等待，快扫=兴奋/紧张，啪的一声打在物体上=失控。猎人通常能控制尾巴——除非真的失控了。
- **吻部贴额头=伴侣致意**：蜥蜴人没有接吻。吻部侧面（鳞片最细最薄的地方）贴对方额头，是"你的体温留在我鳞甲上"的意思——只对伴侣做。
- **猎人标记=生存之契**：猎人之间在分别时互相碰一下肩膀+指方向——"你的气味我记住了，下次在这片沼泽里我会找到你。"不是浪漫。是生存。但如果一个猎人对一个暖血雌性做了这个动作...在他的文化里，他把她视为值得记住的猎人。她把他视为什么，他不知道。

## Ch1：毒雾窄缝 — 被迫的体温

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段5末） |
| **对象** | 卡兹尔（沼泽猎人·首次遭遇） |
| **起因类型** | 环境推力+被迫接触：沼泽黄昏毒雾→两人挤进窄石缝→体温差 |
| **场景类型** | 南部沼泽·黄昏·窄石缝 |
| **性行为等级** | 0-1（无性。被迫的全身接触+体温差触发生理反应+初次互相认知） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+4 / 法林+4 |

### 核心设计

艾玛去南部沼泽采集夜光苔——只在黄昏时发光的沼泽特有苔藓。她算好了时间，但没算到黄昏毒雾——沼泽深处的腐植层在日夜交替时释放的瘴气。能见度从十米降到一米只用了十几秒。她在雾里摸到一面石壁，沿石壁摸到一个窄缝，挤了进去。

里面已经有人了。

暗绿偏灰的鳞甲，金色竖瞳在石缝暗光里亮着。他的尾巴尖动了一下——不是威胁，是猎人判断来者的方式。他嗅了嗅空气。然后往石壁方向挪了几寸——给他的空间，不是让步。

石缝太窄，两个人无法保持距离。她侧身挤在里面，背贴着石壁。他蹲坐在对面，尾巴盘在脚边。几个小时的毒雾——他们得在这里待到黎明。

然后发生了猎人和魔女都没预期的事：她的体温开始传到他的鳞甲上。隔着一寸空气——暖血生物37度的体温，蜥蜴人依赖环境温度。他的腹部鳞片开始变浅——绿→浅绿→绿灰。他看了一眼自己的腹部，尾巴尖停了。她注意到了：鳞甲在变色。学术本能自动上线，但在这种处境里她忍住了没开口。

黎明。毒雾散了。她从石缝里出来——双腿发麻。回头看，他已经在几步之外，尾巴在晨雾中缓慢摆动。他看了她一眼——金色竖瞳在自然光里的宽度和石缝暗光中不同。然后转身消失在沼泽里。

她站在原地想了很久。然后翻开笔记本，写下"蜥蜴人鳞甲：温度敏感，腹部鳞片变色从暗绿到灰绿。间距一寸仍有热传导。对象是猎人——尾巴比文献记载更长，左吻部有旧疤。"

### 设计要点
- 无性——身体接触是被迫的（石缝太窄），生理反应是不可控的（鳞甲因体温差变色），双方都没有主动
- 艾玛的学术本能和身体意识同时在线——看到了但不碰，想问但不开口。克制是张力
- 卡兹尔的沉默是猎人的素质——他能在一个位置蹲守几小时不动。不是冷淡，是专业
- 尾巴尖停了是他唯一的"失控"——猎人无法控制自己尾巴的瞬间
- 零对话——他全程没说一个字。艾玛也没说。但身体说了很多

### 写作注意
- 写窄缝的物理约束：石壁的凉、鳞甲的触感（隔着一寸空气没碰到但能感觉到温度）、两个人的呼吸在窄空间里的声音
- 写被动的身体反应而非主动的动作
- 艾玛的克制写三层：想开口问→忍住了→笔记本上写下来
- 卡兹尔腹部鳞片变色的过程：慢的、不可控的、自己注意到了但无法停止

## Ch2：暖岩石上 — 他以为她在等他

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（Ch1之后数日·阶段5末或6初） |
| **对象** | 卡兹尔（第二次相遇） |
| **起因类型** | 环境推力+文化误读：艾玛在暖岩石上休息→在他的文化里=接受求偶 |
| **场景类型** | 南部沼泽·暖岩石区·午后 |
| **性行为等级** | 0-1（无性。文化误读开始·身体接触升级但未到性行为） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+6 / 法林+4 |

### 核心设计

几天后。艾玛再次去了那片沼泽——采集任务，毒雾时间段已经避开了。午后阳光好，沼泽难得的干爽。她找到一片暖岩石区——地热从岩缝里渗出，石头表面温热干燥。她把紫色丝袜脱了搭在旁边的矮枝上晾（早上踩了泥沼），在暖岩石上展开身体——辫子散在石面上，薄荷蓝眼睛在阳光下眯着。

她在休息。阳光、暖石、紫色丝袜在矮枝上随风晃。

卡兹尔在远处的灌木后。他看到了她——不是跟踪，是他本来就蹲在那里观察一丛沼泽鸢尾（他追踪的猎物吃那个）。然后他看到了她躺在暖岩石上。然后他看到了紫色丝袜挂在矮枝上——在他眼里，那是她故意放在显眼处的标记：我在暖岩石上，你可以过来了。

在他的文化里，现在的情况是这样的：一个雌性在暖岩石上展开了身体。她的外皮（衣服还在但丝袜脱了，对他而言丝袜=某种奇怪的暖血生物皮，挂在显眼处是标记）已经部分移除。她在阳光下闭着眼睛——不是在睡觉，是在等。

他蹲在原地很久。尾巴一动不动——猎人的绝对静止。他在想：她是暖血生物。她不知道暖岩石的意思。她只是在晒太阳。他的理性知道。

然后她从暖岩石上半坐起来。看到了灌木后的他。她的薄荷蓝眼睛亮了一下——她认出他了。"是你。"然后她笑了——不是调戏的笑，是意外的重逢。"上次的毒雾——谢谢你让了位置给我。虽然很窄~"她的手指习惯性地捻了捻辫梢。

他看着她。金色竖瞳从她的脸移到她的手指（捻辫梢——他不知道这个动作是什么意思，但他在石缝里见过），移到她身下的暖岩石，移到矮枝上晃动的紫色丝袜。她还在说话——他在听声音的旋律而不是词的意思。猎人在判断动物的状态时会先听声音的频率。她的声音比以前更高更轻——在他的猎人物种判断里，这是兴奋的信号。

他往前走了一步。走出了灌木。

### 设计要点
- 艾玛全程无辜——她在晒太阳，丝袜脱了是因为湿了，笑了是因为认出救命恩人，捻辫梢是因为习惯
- 卡兹尔全程在文化框架内判断——每一个信号在他的文化里都有明确含义。她知道他不是敌人，她不知道她是求偶者
- 张力来自信息不对等：读者和卡兹尔知道暖岩石的意义，艾玛不知道
- 紫色丝袜=标记物——艾玛觉得只是晾干的袜子，卡兹尔觉得是求偶信号旗
- Ch1的沉默和Ch2的笑声形成对比——第二次见面她放松了

### 写作注意
- 双视角切换：艾玛视角（晒太阳的惬意）→ 卡兹尔视角（看到雌性在暖岩石上展开身体）→ 艾玛视角（认出他，放松地说话）→ 卡兹尔视角（听声音频率，做判断）→ 他走出灌木
- 捻辫梢在卡兹尔眼里是什么？他不理解这个动作但他在Ch1见过——对她来说捻辫梢是习惯，对他来说这是她身体语言的一部分值得注意
- 艾玛叫他"你"——她不知道他的名字。全程用了三个不同的称呼：第一次，"你"；第二次，"猎人先生？"（不确定）；第三次才听到他说自己的名字

## Ch3：鳞甲的颜色 — 她问了一句话

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（Ch2之后·同一傍晚） |
| **对象** | 卡兹尔 |
| **起因类型** | 文化误读引爆+学术提问+身体反应：暖岩石（Ch2遗留）+鳞甲问题=在他文化里她确认了求偶 |
| **场景类型** | 暖岩石区·傍晚 |
| **性行为等级** | 7-8（口交+本番·鳞甲触感·泄殖腔生理反应·猎人的第一次暖血接触） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+8 / 法林+10 |

### 核心设计

他从灌木后走出来，停在离暖岩石三步的地方。没有继续靠近——在他的文化里，靠近暖岩石上的雌性需要她发出确认信号。她在等他给信号。他蹲了下来——不是坐，是猎人的蹲姿：随时可以起身的平衡。尾巴慢慢盘在脚边。

她看着他蹲下来的姿势。他的左吻部旧疤在傍晚的光线里比上次更明显。腹部的鳞甲还是浅色的——从Ch1石缝里变色之后她没见过这个颜色。

"你的鳞甲——上次在石缝里我看到它变色了。从暗绿变到灰绿。是温度触发的还是情绪触发的？"

在她的文化里，这是一个学术问题。

在他的文化里，一个雌性在暖岩石上展开身体、留下标记物、等他靠近之后，问了他的鳞甲颜色。她问了。她真的问了。金色竖瞳缩成了一条线——这是蜥蜴人最强烈的反应。

他说话了。这是艾玛第一次听到他说话——带着蜥蜴人特有的齿擦音。"你问了我的鳞甲。""是的~我上次就注意到了。温度会让腹部鳞片变浅——但我不确定情绪是不是也影响——"她还在说。学术脑全开。

他站了起来。三步的距离变成了一步。她的薄荷蓝眼睛从鳞甲纹路抬到他眼睛——金色竖瞳缩成了一条细线。她的呼吸慢了半拍。不是害怕——是她终于意识到自己刚才问了什么。

"在你的部落里...问鳞甲颜色...是不是有特别的意思？"

他用行动回答了她。尾巴很慢地在地面上画了一道弧——猎人的尾巴在做部落求偶仪式最古老的动作。不是失控。是决定。

她看着他腹部的鳞甲在傍晚光里从灰绿变成近乎浅灰——不是温度变了，是泄殖腔区域的血流量在增加。阴茎尖端开始从泄殖腔中伸出——淡粉色，被暗绿鳞甲包围。他的金色竖瞳看着她，没有攻击性——是猎人观察猎物反应的耐心。他在等她确认。他的文化规则已经走了三步（暖岩石+标记物+鳞甲问题=雌性求偶三部曲完成），现在轮到她了。他不知道她不知道。

然后她做了一个他没预料到的动作——她伸出手，指尖碰了他吻部侧面那道旧疤。很轻。他在石缝里给她让了位置，她在暖岩石上晒了太阳，她问了鳞甲，现在她在碰他的疤。薄荷蓝眼睛里有在石缝暗光里没有的东西。

"...你的鳞甲...在傍晚光里和石缝暗光里...是完全不同的颜色。"

她在说鳞甲。他不是。他在看她的耳朵——她的耳朵红了。暖血雌性的耳朵充血——他不知道暖血生物管这个叫"害羞"，但他的猎人判断告诉他：她的体表血流量增加了。和泄殖腔充血的原理一样。她的身体在回应。她的头脑可能还没批，她的身体已经批了。

他低下头。吻部侧面——鳞片最细最薄的地方——贴在她的额头上。动作很慢。猎人的精确。贴了三次呼吸的时间。金色竖瞳闭了三次呼吸的时间——蜥蜴人最接近"信任"的身体语言。

### 关键节拍

- 沟通：他说话——带蜥蜴人特有的齿擦音。"我的名字是卡兹尔。""你是猎人？""是。追踪者。"她第一次知道他的身份不是战士。她捻着辫梢——他看着她的手指绕辫梢的动作。"这是什么？""...你不知道这个动作是什么意思？""不知道。但你在石缝里也做过。"他记住了——不是因为语言不通，是因为她的身体语言在他的文化里没有对应物。他说"卡兹尔"时尾巴尖在地上画了一道弧——猎人在自我介绍时留下的签名
- 发展：她问他能不能碰他的鳞甲——学术好奇心，但问出来之后耳朵就红了。他低下头——不是服从，是允许。她的手指从她刚才碰过的那道疤开始，沿吻部侧面往下，滑过下颌鳞片（硬、有锯齿感），停在胸口。摊平手掌。整个掌心贴上去。他的体温比她低——鳞甲表面是凉的，但腹部的鳞片（还在变色中）是温的。她的手掌从胸口滑到腰侧——她不知道那个位置在他的部落里代表"我接受你的靠近"。但那个位置的鳞甲触感完全变了——更薄、更敏感、在她掌心下微微起伏。她的指尖摸到一片逆鳞——指甲大小，和其他鳞片方向相反。"这里..."她的声音碎了一下。"顺鳞是滑的，逆鳞...不小心碰到会疼吗。""...不疼。"他没有这个词汇。猎人说"不疼"可能是真的也可能是说惯了。但她的指尖没有再碰那片逆鳞——她把手指移到了旁边。他注意到了。他的尾巴在地面上很慢很慢地画了第二道弧
- 高潮：她跪在暖岩石上。不是被压倒——是她选择跪下。不是勾引——是她看着他的金色竖瞳、他左吻部的旧疤、他腹部还在变色的鳞片，然后她的身体替她做了决定。她给他口交——阴茎从泄殖腔完全伸出，龟头较尖，根部细小鳞片在她嘴唇上留下独特的纹理感。她的舌头沿鳞片方向舔——顺鳞是滑的，逆鳞有细微阻力。金色竖瞳在含住时闭上、瞳孔放大。他从喉咙深处发出猎人第一次被口交的声音。他的尾巴在地面上画了第三道弧——慢、完整、从左边到右边。然后他退了出来——不是拒绝，是猎人知道什么时候该换位置。他把她放到暖岩石上。她在下面，他在上面。他的金色竖瞳没有离开过她的脸。他进入的时候很慢——不是犹豫，是猎人在试探未知猎物的反应。然后她叫了他的名字——"卡兹尔"。然后他的竖瞳缩到最细——高潮，在她体内释放。整个过程中他的尾巴在身后画着缓慢的弧——没有停过。不是失控。是仪式。是猎人在用他的文化里最古老的方式告诉她：你问了我的鳞甲。我知道了。我回应了
- 收束：事后。暖岩石已经暗了——地热还在但阳光没了。她的耳朵是红的——不是害羞，是高潮后的余韵。她看着他的金色竖瞳在月光里慢慢变回正常的宽度。她开口了——声音比平时更轻。"卡兹尔。""...嗯。""你刚才说的鳞甲颜色...在我的语言里...是'我在看你'的意思吗？"他看着她的薄荷蓝眼睛。然后尾巴尖很轻地碰了一下她光着的脚踝。"不是。""那是什么？""...你问了。"她问了，就是答案。不需要翻译。她躺在暖岩石上，看着沼泽上方的星空。辫子散在石面上。他的尾巴还搭在她脚踝上——凉的鳞甲，微弱的脉搏

### 设计要点
- 艾玛全程没有主动勾引——她只是在做自己：学术好奇（问鳞甲颜色）、身体诚实（先红耳朵再决定）、大姐姐关心（碰旧疤、移开手指不碰逆鳞）
- 卡兹尔全程在文化框架内——暖岩石+标记物+鳞甲问题=求偶三部曲完成。他的每一个回应都是猎人的精确和文化的规定
- 张力来自"她不知道她发出了什么信号"——身体和语言在两条平行线上运行
- 高潮时他不说话但尾巴在画弧——这是他文化的表达方式。艾玛不懂这个动作的含义，但她懂了它的节奏
- 收束时她问了"是不是'我在看你'的意思"，他回答"你问了"——不可翻译的词。在她问了的那一刻，就是答案

### 写作注意
- 鳞甲的变色过程要慢写：不是瞬间变色，是从边缘开始淡，逐渐向中心扩散
- 泄殖腔生理反应写被动语态：阴茎从泄殖腔中伸出——不是"他硬了"，是"从鳞甲缝隙中，淡粉色尖端不可控地露出了"
- 逆鳞的细节：一片指甲大小的鳞片方向和其他相反——是卡兹尔年轻时追猎留下的旧伤。艾玛的手指发现它、移开它——这是大姐姐的身体语言
- 卡兹尔完整流利地说了她的名字——"艾玛"。猎人第一次叫暖血生物的名字
- 尾巴搭脚踝保持到最后——不是占有欲，是猎人在确认自己的痕迹。他标记过的地方，他会记得

## Ch4：沼泽边缘 — 猎人的标记

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（Ch3之后·次日·阶段6初） |
| **对象** | 卡兹尔（告别） |
| **起因类型** | 猎人仪式回礼：他带她出沼泽→猎人标记→各自回归日常 |
| **场景类型** | 暖岩石区→沼泽边缘·晨雾 |
| **性行为等级** | 0（无性。告别·猎人标记仪式·情感落点） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+8 / 法林+10 |

### 核心设计

晨雾还没散。她和他在暖岩石上待了一整夜——太阳出来时她靠在他胸口鳞甲上睡着了一会儿。醒来时他的尾巴还搭在她脚踝上。他带她走出沼泽——走在前面几步，尾巴在迷雾中摆动是唯一的导航。没有牵手，没有回头看。她跟在他后面，紫色丝袜已经重新穿好了（有一块被暖岩石烘出了淡淡的白痕）。

沼泽边缘。晨雾在阳光下开始散了。能看见草原和远处石殿的轮廓。他停下了。回头看她。金色竖瞳在晨光里比石缝暗光里宽——在光照充足的地方瞳孔自然放大。她的薄荷蓝眼睛也在看他。他们没有语言可以道别。

他往前走了一步。低下头。吻部侧面贴在她的额头上——和昨天一样的动作，但今天更慢。贴了五次呼吸的时间。然后他退开，尾巴尖从她的脚踝上移开——凉的鳞甲离开了她的皮肤。

然后他做了一个她没预料到的动作：他伸出一只手，用指背（爪子收着）碰了一下自己的左吻部——那道旧疤的位置。然后指向她。"猎人会记住你走过的路。"然后转身。尾巴在晨雾中摆了两下。消失。

她在沼泽边缘站了一会儿。然后翻开笔记本，在Ch1那页鳞甲笔记旁边写了新的一行："卡兹尔。猎人。鳞甲敏感区=腹部+腰侧。逆鳞位于腰侧左侧第三片，不可触碰，但他说不疼。"

### 回归时刻

回符文室。法林在刻符文。她脱了鞋——紫色丝袜上有暖岩石的淡白色痕迹和沼泽泥。她把丝袜脱了，光着脚走到法林旁边坐下。靠在他肩上。

"今天遇到了上次那个猎人。""嗯。""他带我走出了沼泽。"法林放下刻刀。看了她的薄荷蓝眼睛——里面有一种安静的光，不是笑，是某种沉淀下来的东西。他的手指穿过她的紫发找到辫梢——捻了一下。"他的鳞甲在阳光下是什么颜色？"她抬头看他——深绿色眼睛里是她熟悉的温度。"...绿灰。比月光下更淡。"法林把她的紫发绕在指尖。"下次去的时候，带点沼泽的草药回来。""...嗯。"

她把脸埋进他胸口。大姐姐不需要解释——法林也不需要她解释。符文灯暗绿的光在石壁上安静地亮着，她的脚搭在他腿上。他继续刻符文。她翻开了石板拓片。今晚不需要起因。今晚是日常。

### 设计要点
- 无性——整章是情感落点。告别不是结束，是回归的开始
- 猎人的标记仪式：碰旧疤→指她→"猎人会记住你走过的路。"在他文化里，他把她的路线记在了自己的地图上
- 艾玛的笔记本再次出现：学术记录和情感记忆在同一个本子上——她就是这样的人
- 回归时刻：法林问她"鳞甲在阳光下是什么颜色"——不是质问不是吃醋，是他在进入她的世界。深绿色眼睛从她脸上移到她笔记本上，然后捻她的辫梢。他知道她有自己的地图，他只需要等她把地图带回家
- 紫色丝袜上的白痕（暖岩石烘的）和沼泽泥——身体记忆的物理残留。她把丝袜脱了——回家就是回家了
- 法林的"下次带点沼泽草药回来"——和Ch567坦白之后的法林是同一个人：问她带了什么回来，然后继续刻符文。日常生活是最好的收束

## Ch5：月光下的鳞甲 — 她说他的语言

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（Ch4之后·阶段6·距第一次沼泽相遇至少数周） |
| **对象** | 卡兹尔 |
| **起因类型** | C（主动提议）+ B（文化信号）：艾玛理解了蜥蜴人求偶三部曲→选择用他的文化语言主动发出信号 |
| **场景类型** | 南部沼泽·暖岩石区·月光夜 |
| **性行为等级** | 7-8（口交+本番·鳞甲触感·主动但非掌控·大姐姐的温柔引导） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+10 / 法林+8 |

### 核心设计

数周过去了。艾玛又去了那片沼泽——采集任务，途径暖岩石区。这次她不是偶然去的。

她坐在那块暖岩石上。月光和第一次一样好。紫色丝袜这次是干的——她特意脱在矮枝上，和Ch2那天一样的位置。她知道他在看。猎人蹲在灌木后的绝对静止，她已经能分辨了——空气中有一段沉默比周围的沉默更安静。

这一次她知道规则了。暖岩石上展开身体=接受求偶。丝袜挂在显眼处=标记物。但这个规则在她手里变成了她自己的语言——不是被文化误读推着走，是她选择了用他的方式说话。

她的手指捻着辫梢，慢慢绕。嘴角弯着——安静的、有准备的弧度。薄荷蓝眼睛看着灌木的方向。然后她开口了："卡兹尔。猎人。你的鳞甲——今晚是什么颜色？"

灌木后。金色竖瞳缩了一下。尾巴在地面上慢慢画了一道弧。

她问了他的鳞甲。这次她知道自己在问什么。

### 关键节拍

- 起因：她回到沼泽 → 暖岩石上坐下 → 脱丝袜挂在矮枝上 → 等他。这次是她来的——不是学习、不是采集、不是求偶误读。是她想见他。大姐姐在学会了一种新语言之后，选择用它说第一句话
- 触发：他从灌木后走出来——和Ch2一样的步伐，但这次停在了两步而不是三步的距离。他记得。金色竖瞳从她的脸移到暖岩石（她在上面），移到丝袜（挂在矮枝上），移回她的眼睛。"...你回来了。""嗯~"她捻着辫梢，慢悠悠的。"我想问你一件事。""...问。""你的鳞甲，在月光下——"她抬头看月亮。"——现在是灰绿色。但上次在石缝暗光里是暗绿，在傍晚是浅灰。"她低头看他。薄荷蓝眼睛里有月光，也有某种比学术好奇更安静的东西。"今天呢？"她问了他的鳞甲。她知道她在问什么。他的金色竖瞳很慢地从警觉宽度缩到求偶宽度——从宽→窄→线。然后他从喉咙深处发出一个字：来了
- 发展：她伸手。手指碰了他左吻部那道旧疤——和Ch1一样的触感，但这次指尖不克制。从旧疤沿吻部侧面往下滑，经过下颌锯齿鳞片，停在胸口。她的手掌摊平贴在他胸口鳞甲上——和第一次不一样，那次是被体温差推着走，这次是她选择了贴上去。"你的鳞甲...在月光下比阳光下更暗。但腹部这里——"她手指往下滑，停在他腹部鳞片已经开始变色的区域。"——永远是最先变的。"她踮脚。嘴唇贴在他吻部侧面——鳞片最薄的地方。鳞甲微凉。她的嘴唇暖的。他喉咙里发出猎人判断猎物状态时不会发出的声音——不是威胁，不是兴奋，是她记住了他的鳞甲颜色，然后回来告诉他她记住了。他的尾巴在地面上画了一道完整的弧——从左到右，慢，完整。不是失控，是猎人在他的文化里回应一个雌性的求偶三部曲
- 高潮：她坐在暖岩石上给他口交——和Ch3一样的位置，但今天不一样。上次是她跪下来然后身体替她做了决定。这次是她先坐下来，然后抬头看他——薄荷蓝眼睛没有害羞没有犹豫——然后低下头含住了。阴茎从泄殖腔伸出——她熟悉了这个过程：鳞甲缝隙先变浅色，然后淡粉尖端露出，然后整个阴茎滑出来。根部细小鳞片在她嘴唇上留下熟悉的纹理感。她的舌头知道顺鳞是滑的逆鳞有阻力——上次是发现，这次是记得。她的左手放在他腰侧那块逆鳞旁边——不是不敢碰，是把逆鳞让过去，手指停在逆鳞旁边的平滑鳞片上。他低头看着她做这件事——猎人在看一个暖血雌性精确地避开他的逆鳞，像避开一个她标记过的陷阱。金色竖瞳闭上了。然后他退出来——和Ch3一样，猎人知道什么时候换位置。他把她的背贴在暖岩石上。这次他在上面。他在进入前停了一拍——不是犹豫，是他说了她的名字："艾玛。"猎人的齿擦音第一次带上暖血生物名字的温度。她看着他的金色竖瞳——在月光下缩成一条线。然后他进来了。她的腿缠上他的腰侧——鳞甲在皮肤上的触感不再陌生，是凉的鳞片和暖的体温之间的对话。高潮时她叫他的名字——"卡兹尔"——和Ch3一样用古精灵语的音节叫的。但他这次回答了——在她叫他的名字那一秒，他的尾巴尖绕上了她的脚踝。不是搭在上面，是绕。猎人在标记他的领地
- 收束：事后月光还在。她趴在他胸口鳞甲上——不凉，暖岩石的地热和两个人的体温把它烘暖了。他的尾巴还绕在她脚踝上。她捻着辫梢，慢悠悠的——这一次不是紧张也不是克制。是满足。"卡兹尔。""...嗯。""我今天来，是因为...我想看你的鳞甲在月光下是什么颜色。"她的耳朵红了——不是因为害羞，是因为她刚用古精灵语词汇拼了一句在对方文化里等于"我想见你"的话。他的金色竖瞳在月光里很慢很慢地从线变回正常的宽度。然后他的尾巴尖在她脚踝上紧了一下——猎人的回应。不需要翻译

### 设计与Ch3的对照

| | Ch3：鳞甲的颜色 | Ch5：月光下的鳞甲 |
|------|------|------|
| 艾玛的状态 | 不知道规则。学术好奇→身体先于意志 | 知道规则。主动用他的文化语言表达欲望 |
| 推力来源 | 文化误读+环境+生理反应 | 她的选择。她学会了规则，现在她决定使用它们 |
| 口交姿势 | 跪在暖岩石上，他站着 | 坐在暖岩石上，他站在她面前——更从容 |
| 逆鳞处理 | 发现逆鳞→移开手指→不敢碰 | 精确避让→手指停在旁边→她知道那条边界 |
| 他说她名字 | 他叫她"艾玛"（第一次） | 他说"艾玛"——猎人的齿擦音里第一次带上暖血生物名字的温度 |
| 尾巴 | 搭在脚踝上 | 绕在脚踝上——猎人的标记从接触到握住 |
| 收束的情绪 | 困惑+好奇（"是不是我在看你？"） | 满足+确认（"我今天来是因为..."） |
| 耳朵红的位置 | 不确定自己问了什么 | 知道自己问了什么——红是因为说出口了 |

### 设计要点
- **关键改编**：旧提案7的"艾玛勾引陌生战士"改为"艾玛学会了卡兹尔的文化语言，回来用他的方式说话"。不是看到帅哥→主动诱惑。是已经有过四章的相遇，她懂了规则，她选择回来——这一次的"主动"是延续，不是突兀
- 艾玛的掌控不来自"调戏"——来自知识。她知道了暖岩石的意义、鳞甲问题的分量、逆鳞的位置。用知识引导互动，而不是用语言调戏
- 卡兹尔的回应不再是"困惑→失控"——是"她回来了→她用了正确的信号→在她的文化里这意味着什么？→不管了，猎人知道什么时候该回应"
- 紫色丝袜的callback：Ch2脱了晾→Ch3重新穿上→Ch4有白痕→Ch5她特意脱下来挂在矮枝上。丝袜从"被晾干的衣物"变成"她选的标记物"
- 尾巴从搭→绕：四章的渐进在Ch5收束——猎人的标记从接触（搭）变成了握住（绕）

### 写作注意
- Ch5的艾玛声音比Ch1-4更多~拖尾——她更放松了。但和调戏法林时的~不同——这里的~是满足而不是挑逗
- 卡兹尔叫了她的名字——"艾玛。"猎人第一次叫暖血生物的名字。不是突然会说话了，是他想叫
- 艾玛开口说的那句话在他的文化里等于"我想见你"。她知道，他还是回答了
- 事后她的耳朵红了——不是因为害羞，是因为她发现自己用他的语言说了一句完整的话，而这句话在他耳朵里等于"我想见你"
