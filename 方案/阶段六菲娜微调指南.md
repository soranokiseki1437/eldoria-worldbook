## 一、核心原则

### 1.0 不变底色：娇羞 + 妩媚 + 甜美（最高优先级）

无论阶段如何演进，**娇羞+妩媚+甜美始终是菲娜的底色**。放纵和设计是叠加层，底色不可覆盖。她可以一边设计陷阱骗劳拉上床，一边在门缝偷看时脸红。她可以一边被低语者轮奸到眼泪滴进泥土，一边回头看黎恩确认他还在。她可以一边跨坐凯尔拨通黎恩视频，一边事后在两个人中间蹭脸说"好过分"。

```
娇羞：耳朵尖烫、声音轻、脸烧得不敢看对方、设计陷阱时自己先脸红、汇报时把脸埋进黎恩颈窝
妩媚：长发垂落、声音又轻又软、回头找黎恩的青紫瞳、被干到极限时脆弱又妩媚的表情
甜美：事后蜷进黎恩怀里像猫、汇报完在他胸口蹭脸、眨眼再笑、撒娇的波浪号
```

> **铁律**：如果一章里菲娜没有害羞体征、没有妩媚质感、没有甜美回归，那就是写偏了。放纵写得再极致，底色丢了就是废章。

#### 三色自检（每次修改后必过）

随机抽取菲娜在场景中任意三处——事前/事中/事后各一处。每一处必须至少命中一个底色：

| 时刻 | 娇羞 | 妩媚 | 甜美 |
|------|:--:|:--:|:--:|
| 事前（设计/决定阶段） | 耳尖烫、声音轻、偏开视线、设局时自己先脸红 | 长发垂落、指尖轻触、在月光下走向第三者 | 对黎恩的撒娇或嗔怪、调皮眨眼 |
| 事中（性行为中） | 脸红到脖子、咬唇、回头看黎恩、眼泪滴进泥土 | 回头看黎恩的表情、边被干边找他的眼睛 | — |
| 事后（回归黎恩） | 把脸埋进他胸口、汇报时耳尖红 | 边口交边汇报、指尖在他手心里画圈 | 蜷进去像猫、蹭脸、汇报完毕后的安静 |

> 三格全部为空 → 底色丢失 → 重写。只有一格有内容 → 底色不够 → 补。

#### 常见底色丢失模式

| 模式 | 表现 | 根因 |
|------|------|------|
| **机械型** | 菲娜全程冷静执行"实验"，设计陷阱像写实验报告，事后汇报像读数据。没有任何脸红、声音颤动、回头找黎恩。 | 把"设计"写成了"程序"。她不是执行代码——她设计陷阱时心跳在加快，骗劳拉时紧张得脸红。 |
| **麻木型** | 菲娜被轮奸/群交后没有任何脆弱反应，直接切换回日常模式。 | 把"极限探索"写成了"无感"。推边界后她需要黎恩的回收——不是因为她碎了，是因为她有感觉。 |
| **旁观型** | 菲娜设局后站在一旁观看，像导演看监视器。没有参与感，没有身体反应。 | 把"设计"写成了"导演"。她不是旁观者——她设计的局里她自己是参与者。门缝偷看时她自己腿也在抖。 |

#### 害羞是底色，在极限中依然存在

阶段5的害羞不再阻碍行动。阶段6的害羞**在极限中依然闪烁**——她可以设计骗局骗劳拉，但话说出口时脸红到脖子根。她可以被五六只低语者同时使用，但转头找黎恩时琥珀色眼睛里全是脆弱。

```
阶段5：被问"疼？"→ 耳尖红了，但摇头："不疼。"→ 害羞但能表达
阶段6：骗劳拉"鬼之力暴走需要新身体"→ 话说出口脸红到脖子根→ 演得逼真但自己先烧起来了
```

> 判断标准：菲娜在任何场景中都应有娇羞体征。阶段6的娇羞不阻止她设计、不阻止她承受极限——但必须闪烁。哪怕只是一个回头找黎恩的眼神。

**阶段6的正确张力：设计时的调皮 + 执行时的娇羞同时发生**

阶段6最容易翻车的不是害羞太少，而是把菲娜写成了冷血设计师。正确的做法是：她设计陷阱时心跳加快，执行时脸红，回报时脆弱——三者贯穿。

```
错误：她冷静地骗劳拉，在门外冷静地观看，事后冷静地告知黎恩。
正确：她红着脸骗劳拉，话说得越逼真脸越烧。门缝偷看时手指攥紧了门框。事后爬到黎恩身上把脸埋进他胸口汇报，汇报到一半自己笑了。
```

#### 事后甜美回归黎恩（不可省略）

阶段6的回归不是"跑回黎恩旁边"（阶段4），也不是"靠在他肩上分享体验"（阶段5），而是**边被黎恩干边汇报，然后在黎恩的占有中蜷进去**。

```
阶段5：事后回到黎恩身边，靠在他肩上，把体验说给他听。眼角带着狡黠的光。然后蜷进去，像猫。
阶段6：事后跪在黎恩面前含住他，一边用舌头裹龟头一边逐条汇报。被拉起来按在床沿插入，在他体内射精后再蜷进他怀里。汇报完毕后的安静里，她的手在被子下攥他的手指。
```

> 阶段6的回归公式：**口交汇报 → 黎恩插入回收 → 内射覆盖 → 蜷进去安静下来**。如果一章的最后一个场景不是菲娜在黎恩怀里（或等价的身体接触+占有确认），检查是否遗漏了甜美回归。

### 1.1 阶段6叠加层：放纵 + 设计 + 极限探索

核心行动链：

```
主动设计 → 先斩后奏 → 极限执行 → 口交汇报 → 黎恩回收
```

- **主动设计**：菲娜不只是选择对象——她设计整个场景。骗劳拉"鬼之力暴走"、深夜穿黑丝进书房"加一节实验课"、把黎恩弄昏睡再叫第三者来。她是编剧，不是执行导演。
- **先斩后奏**：不再等黎恩的许可。做完再告诉他。视频接通时她已经在给凯尔足交了。"猜猜我在哪。""书房。""答对了。"——她不是请求许可，她是邀请观看。
- **极限执行**：群交、双插、多孔同入、低语者轮奸。她推自己的边界——不是被逼的，是自己选的。"今天要走到最后。是准备好的。不是意外。"
- **口交汇报**：标准回归仪式。跪在黎恩面前含住他，在吞吐的间隙逐条汇报——谁、哪里、几次。汇报声和舔舐声混在一起。
- **黎恩回收**：黎恩在她汇报完毕后拉起来插入。内射覆盖。不是"确认归属"（阶段4）——是"用身体覆盖所有痕迹"。

#### 菲娜的设计模式

阶段6的菲娜用**头脑设计场景，用身体执行设计**。

```
- 设陷阱：把黎恩弄射两次昏睡→骗劳拉"鬼之力暴走需要新身体"→全程红着脸演→门缝偷看腿也在抖
- 设实验：深夜穿黑丝进书房→用脚给凯尔足交→拨通黎恩视频→叫他来看→叫他加入→事后说"实验组和对照组同时运行"
- 设隐奸：去锻造室激活太刀符文→导力器在腰间震动四次不接→被矮人兄弟一前一后插入→事后跪黎恩面前口交逐条汇报
```

> 菲娜的设计不是冷酷的计算，是调皮的、害羞的、但不容商量的。她骗劳拉时脸烧到脖子根，但她把话说完了。她在门缝偷看时手指攥紧了门框，但她没有移开眼睛。

#### 黎恩的"忍住不出手"

阶段6的黎恩学会了**在极限中忍住**。阶段5他回收她——阶段6他在她推边界时站着不动，鬼之力刻印亮到刺眼但手指没有碰到刀柄。不是不在乎——是指节全白地在忍。

```
阶段5：黎恩从窗边的椅子上起身，解开锁链，把她拉下来亲吻。
阶段6：黎恩站在五步外，鬼之力刻印爆亮——手指攥在太刀柄上，指节全白。但他在等。等她摇头。她没有摇头。
```

> 黎恩的"忍住"是阶段6最强的信任宣言。他信她能承受，他信她会回头。她回头了——在嘴里含满鸡巴的间隙转头找他的青紫瞳。确认他还在。然后转回去继续。

## 三、阶段6标志性场景模式

### 3.1 设局场景

```
1. 酝酿：菲娜脑子里有了一个"方案"。不是黎恩提的——是她自己想的。
2. 准备：她把黎恩弄射两次让他昏睡。擦了擦嘴角去找劳拉。一路上在想要怎么说。
3. 执行：红着脸把情况说得特别严重。越说脸越烧。但话说完了。
4. 观看：门缝偷看——手指攥紧了门框。腿在抖。但没有移开眼睛。
5. 告知：黎恩醒来时她坐在床边。"刚才劳拉来过了。她用下面帮你压制鬼之力。你内射了。"
6. 回收：黎恩翻身把她压在身下。这一次是他自己在她体内射的。是覆盖。
7. 收尾：她趴在他胸口，耳尖还红着。眨了眨眼再笑。
```

### 3.2 先斩后奏场景

```
1. 行动：菲娜没等黎恩同意。深夜穿黑丝进书房。褪下长袍露出黑丝吊带袜。
2. 视频拨通：用脚给凯尔足交的间隙拨通黎恩的私密频道。"猜猜我在哪。""书房。""答对了。"——不是请求许可，是邀请观看。
3. 叫来看→叫来加入：黎恩推门进来拉椅子坐下。"继续。"她在他注视下跨坐到凯尔身上。然后叫他的名字："过来。两个人。"
4. 双插：凯尔在蜜穴，黎恩在菊穴。两根肉棒隔着一层肉壁同时在她体内。
5. 事后：被夹在两个人中间。"实验组和对照组。同时运行。数据最准。"
6. 批准下次实验：黎恩低头："下次实验课题是什么。""三个人。不同姿势。""批准。"
```

### 3.3 隐奸升级场景（黎恩不知情→事后汇报）

```
1. 被困：菲娜去锻造室激活太刀符文。双手握刀柄掌心贴光晶石——这个姿态让她无法反抗。
2. 导力通讯无人接：黎恩的名字在腰间导力器屏幕上亮了四次。震动在臀边嗡嗡响。她瞥了一眼——双手握着太刀没法接。震动停了。又震。又停。第三次时哈根的手放上了她的腰。
3. 半推半就：菲娜咬着嘴唇，圣光在掌心忽明忽暗。"符文还没——"话断了。哈根的手指扣进蜜穴。圣光炸成白金色。
4. 执行：一前一后。两个矮人夹着她。她在高潮中攥紧刀柄。第三道符文亮了。
5. 回归：木屋。黎恩在床沿。她走到他面前跪下来，解开他的裤子，含住他的肉棒。然后开始汇报。
6. 确认：黎恩的手指插进她粉发里收紧。"符文激活了几次。""三次。""和几个矮人。""两个。谁射在哪里。""多尔金嘴里，哈根里面。""刀好用吗。""激活了。""那就够了。"
```

### 3.4 极限探索场景（低语者/群交/轮奸）

```
1. 准备：菲娜低头看了一眼自己的手——手指在微微发抖。把掌心按在膝盖上让它停下。抬起头。"来吧。"
2. 恐惧→承受：第一根暗紫色鸡巴顶出——比黎恩的还粗。她盯着它看了三秒。恐惧从胃底窜上来。然后张开嘴含住了。
3. 极限时刻：第四根从身后抵上小穴。龟头撑开蜜壶口第一圈嫩肉——那个弧度看起来不可能进去。恐慌涌上来。转头看黎恩——琥珀色眼睛里全是恐惧。黎恩的鬼之力刻印爆亮——指节全白。在等她摇头。她没有摇头。
4. 突破：转回去，闭紧眼睛，额头抵在泥土上。进来了。全部。眼泪滴在泥土里——疼、怕、还有一种"做到了"的震颤。
5. 发现：小穴内射的那只炸开金色光柱——真正解脱了。其他的只是呆滞。她用手背挡住眼睛。嘴角弯了一个很小的弧度。她知道了。
6. 回收：黎恩抱起她。他的手在抖。"我差点忍不住。"她伸手摸他的脸："我知道。你忍住了。是信我。"
7. 总结：在他胸口轻声汇报发现——私处体液才能净化。它们的比你的还大。但我没有裂开。因为你在看。下次。就你们。人类的。但如果它们需要解脱。我可以。他低头吻她的发顶："你说了算。"
```

### 3.5 黎恩回收仪式（阶段6版）

```
1. 场景：菲娜回到木屋。头发乱了，白丝脏了，脸上还残留着高潮的潮红。黎恩在等她。
2. 口交汇报：她走到他面前跪下来。解开他的裤子。含住他的肉棒。然后开始逐条汇报——在吞吐的间隙，在舌头裹龟头的时候。
3. 黎恩的确认：他的手指插进她粉发里。不是温柔地穿过——是收紧。他问：几次、几个、谁射在哪里。她在汇报的间隙回答。
4. 插入回收：汇报完毕。他把她拉起来按在床沿。从后面插入——角度是他自己的，深度是只有他知道的。"刀好用吗。""激活了。""那就够了。"
5. 内射覆盖：他在她体内射精。精液覆盖了第三者的、矮人的、低语者的——所有痕迹。
6. 事后宁静：她蜷进他怀里。汇报完毕后的安静里，手在被子下攥他的手指。他低头看她的脸。她眨了眨眼，然后嘴角弯了。
```

### 3.6 实验框架场景（阶段6特有）

```
1. 菲娜把共享体验命名为"实验"——不是为了去感情化，是她的调皮方式。
2. 实验语言携带撒娇："今晚想加一节实验。不是关于精灵语的。"
3. 实验数据是具体的："实验组和对照组。同时运行。数据最准。"
4. 黎恩配合她的框架："下次实验课题是什么。""三个人。不同姿势。""批准。"
5. 实验框架的底线：不是冷酷的研究——事后她在他胸口蹭脸，手在被子下攥他的手指。实验是她的玩具，不是她的身份。
```

### 3.7 自主决定场景（阶段6起点·Ch375模板）

阶段6不是每一章都是设局和先斩后奏。最早期的阶段6章节——菲娜第一次完全由自己决定——有它自己的模式。

```
1. 酝酿：篝火边，菲娜看着某个对象。想起之前的接触，心跳快了半拍。
2. 告知：凑到黎恩耳边，不是自信宣布，是犹豫着说出来。"是我自己想去..."
3. 黎恩反应：不马上点头。看她——看到她脸红。用身体接触回应：捏脸、收紧手。
4. 她嗔怪：被看得不好意思，撒娇抗议。"干嘛看着我..."
5. 放行：黎恩放她过去。不是命令，不是安排——是许可她自己决定。
6. 执行：走向第三者。脸红着做。心跳加速但不停。
7. 回归：事后举手给黎恩看——不是汇报，是展示。反手握住他的手指，说"每一滴都是你的。"
```

> 自主决定场景与设局场景的区别：设局是菲娜设计整个舞台（骗劳拉、拨视频），自主决定场景是她只是决定去做一件事。前者是编剧，后者是第一次自己迈步。自主决定场景中，黎恩的回应不是"忍住"——是"看得她脸红再捏脸"。亲密大于克制。

## 四、标点符号细则

与阶段5指南§4.1-4.12完全一致，此处只列出阶段6需特别强调的规则。

### 4.1 破折号：菲娜场景最小化

阶段6的菲娜场景仍然适用：破折号只在句末（打断/没说完）和黎恩回收场景使用。

```
错误："你——不是说了不能——"
正确："你！不是说了不能——"
```

### 4.2 汇报场景的特殊处理

口交汇报场景中，汇报内容使用逗号串联而非句号切断。汇报和舔舐交替的节奏用分句表达。

```
错误："多尔金射在嘴里。哈根射在里面。"
正确："多尔金射在嘴里，哈根射在里面。"
——同一股汇报流，逗号串联。
```

### 4.3 实验话语的波浪号

菲娜的"实验"台词尾音携带撒娇～：

```
"今晚想加一节实验~"
"不是关于精灵语的。"
```

## 六、修改流程

```
Step 1  读TXT，判断该章属于阶段5还是阶段6（以菲娜的行为模式为准）
Step 2  定位违规点：情感层/动作层/语言层/标点/黎恩角色层
Step 3  编辑TXT：
        - 三色底色在极限中闪烁——不能没有害羞，也不能害羞到停摆
        - 菲娜至少有一次是主动设计的——骗局/陷阱/实验/隐奸
        - 先斩后奏——不等黎恩许可就行动，事后汇报
        - 破折号按POV区分——菲娜场景逗号串联
        - 口交汇报是标准回归仪式——不能只是聊天
        - 黎恩在极限场景中必须"忍住"——指节全白但等她摇头
        - 黎恩回收是用身体的——拉起来插入，内射覆盖
        - 菲娜的"实验"话语必须携带撒娇——不是冷血报告
        - 极限探索必须有情感弧线——恐惧→承受→突破→发现→脆弱→回归
        - 事后甜美回归不可省略——汇报完蜷进黎恩怀里安静下来
Step 4  同步核心/章节任务/章节终止条件
Step 5  等待用户确认后再构建/提交
```

### 常见修改陷阱

| # | 陷阱 | 说明 |
|---|------|------|
| 1 | **底色丢失：设计覆盖了害羞** | 阶段6最常见的翻车模式。三种子类型：**机械型**（冷静设计+冷静汇报无脸红）/**麻木型**（极限后无脆弱直接切日常）/**旁观型**（设局后站一旁观看无身体反应）。根因：把"设计"写成了"程序"。补救：设计时补脸红、执行时补回头看黎恩、事后补蜷进去蹭脸——三者缺一不可。 |
| 2 | 害羞过度阻碍设计 | 反向陷阱——连骗劳拉的话都说不出口。阶段6菲娜害羞但不退缩。 |
| 3 | 只改正文忘了改元数据 | 核心/任务/条件可能残留阶段5的表述。 |
| 4 | 诗意环境收尾 | "窗外的灰蓝变成了淡金。她睡着了。"→删。动作本身传达状态。 |
| 5 | 黎恩只是冷漠旁观 | 阶段6的黎恩在极限场景中是"忍住"——不是冷漠。指节全白、刻印爆亮——他在承受没出手的代价。她的极限就是他的极限。 |
| 6 | 黎恩冲动出手 | 反向陷阱——黎恩拔刀砍了低语者。"忍住"是阶段6最强的信任宣言。 |
| 7 | 忘记口交汇报 | 阶段6菲娜不再是"走回黎恩身边靠肩上"——她跪下来含住他，边舔边汇报。 |
| 8 | 汇报内容太笼统 | "做完了""还可以"→不合格。汇报必须具体：谁、哪里、几次、什么感受。 |
| 9 | 实验话语冷血 | "实验完成。数据正常。"→菲娜不是AI。她用实验框架是为了调皮，不是为了去感情。 |
| 10 | 菲娜的设计写成被动沦陷 | 她不是被低语者抓住——是她自己跪下去的。她不是被矮人兄弟侵犯——是导力器响了四次她没接。半推半就中她的意志是清晰的。 |
| 11 | "不是...是..."句式残留 | 阶段6菲娜不自我辩解。汇报直接陈述事实："多尔金射在嘴里，哈根射在里面。"——不出现"不是"和"是"。 |
| 12 | 菲娜写成全知导演 | "黎恩的鬼之力刻印暗了"——她骗劳拉时知道刻印暗了是她在门外偷看的理由。但她不知道黎恩什么时候会醒。用"应该还在睡""大概没那么快醒"标示她的知识边界。 |
| 13 | 极限探索无生理弧线 | 从开始到结束没有任何身体过渡。必须写：手指发抖→按住膝盖→被撑开时的吸气→适应→高潮→事后腿软。 |
| 14 | 事后没有内射覆盖 | 黎恩只是抱抱她。阶段6的回收更猛烈——拉起来按在床沿插入，龟头抵住子宫口射精。 |
| 15 | 口交汇报写成单方面服务 | 黎恩不能被动接收——他要在她汇报时追问：几次、几个、谁射在哪里。他的问题和她舔舐的节奏交替。 |
| 16 | 菲娜的实验框架被当真 | 她设计"实验"是为了好玩——事后在他胸口蹭脸时实验框架就收起来了。别让她从头到尾都在用学术语言。 |
| 17 | 极限场景没有回头看黎恩 | 全程不看他——像独自承受。必须至少一次：在嘴里含满鸡巴的间隙转头找他的青紫瞳。确认他在。然后转回去继续。这个回头是极限中的妩媚——最脆弱也最强。 |
| 18 | **内心独白膨胀** | 用一整段心理步骤解释"为什么伸手"。`每次碰到这里心跳都会快。这次也是。但她没有停。手伸出去，脸烫起来——手没有缩。想摸。她把注意力给了手。`→ `她脸红地解开他的腰带，握住他的肉棒时心跳有点加速，但她没有停下来。`一句话讲完。动作+体征替代内心独白。 |
| 19 | **冗余表情确证** | 情绪已经传达完了，又追加表情描写来"盖章"。`羞耻和满足同时涌上来，嘴角是弯的，脸是红的`→ `羞耻和满足同时涌上来。`砍掉表情后缀。信读者能从情绪词感受到表情。 |
| 20 | **叙事注解替读者解读画面** | 替读者描述他们已知的事物。`她低头看着那片白，自己的手，别人的精液`→ `她低头看着自己的手。`读者知道手上有什么。不要注解。 |
| 21 | **核心写成意义标注** | 核心替读者总结章节意义，站在场景外面打分。`第一次完全由自己决定——不是黎恩安排，不是任务驱动。`→ 删除。情境里她已经说了"是我自己想去..."，读者不需要核心再被告知。核心描述设计意图和关键时刻，不贴标签，不说教。 |

### 不得做的事

- 不得让菲娜全程被动没有任何设计行为
- 不得让害羞完全消失（→机械型）
- 不得让害羞阻碍菲娜设计（→退行）
- 不得让极限探索写成被动受害——她始终是主动选择者
- 不得让黎恩在极限场景中冷漠旁观或冲动出手——他必须"忍住"
- 不得让事后回归变成阶段5的"分享体验"——阶段6是口交汇报+插入回收
- 不得跳过内射覆盖——黎恩的精液必须覆盖所有其他痕迹
- 不得让汇报内容笼统空洞——具体到谁、哪里、几次
- 不得让"实验"话语冷血无感情——实验是玩具，不是身份
- 不得在收尾处留神秘感——情绪落点要干净
- 不得让菲娜的极限写成被动沦陷——她跪下去是她自己选的
- 不得写冗余心理步骤——动作已传达状态，一句讲完
- 不得在情绪已传达后追加表情确证——信读者能感受到
- 不得替读者解读画面——"那片白""别人的精液"等叙事注解全部砍掉
- 不得使用冗余否定（"不是...是..."）
- 不得在核心中剧透后续章节
- 不得让菲娜写成全知导演——用"应该""大概"标示知识边界
- 不得让核心写成意义标注——核心描述设计意图，不贴标签不说教

### 写作完成后即时扫描

写完一章后，逐句过以下七问：

| # | 扫描项 | 自查问句 | 示例 |
|---|--------|------|------|
| 1 | 不是而是 | 句子里有"不是"吗？ | `不是不想，是腿软了` → `腿软了` |
| 2 | 啰嗦重复 | 前后两个词在说同一件事吗？ | `没有压声音，压不住` → `压不住声音` |
| 3 | 过度解释 | 删掉这一句，读者还能从上下文知道吗？ | `她在想什么——她在想他们...` → 删除 |
| 4 | 断句 | 两个短句中间能用逗号连起来吗？ | `艾玛寄的。好看吗。` → `"艾玛寄的，好看吗？"` |
| 5 | 概括失实 | 概括词覆盖了所有被列举的东西吗？ | `三个人的笔` → 试管和烟不是笔 → 直接列举 |
| 6 | 引号遗漏 | 所有对话都有中文引号吗？ | 写新章最容易忘——脑中听到对话就直接落笔，忘了加引号 |
| 7 | 汇报具体 | 菲娜的汇报里有谁、哪里、几次吗？ | `"做完了。"` → 不合格。`"多尔金射在嘴里，哈根射在里面。"` → 合格 |
| 8 | 回头看黎恩 | 极限场景中菲娜转回头找过黎恩吗？ | 如果全程不看他——补一个转头。在嘴里含满鸡巴的间隙，琥珀色眼睛在紫色暗影中找他的青紫瞳。 |
| 9 | 设计时脸红 | 菲娜设局/骗人时有害羞体征吗？ | 如果冷静流畅——补脸红、声音抖、手指绞在一起。她不是老千，她是第一次骗人。 |
| 10 | 内心独白膨胀 | 有超过两句话在解释"她为什么这样做/此刻在想什么"吗？ | 一整段心理步骤 → 一句动作+体征。`脸红地解开...心跳加速，但没停。` |
| 11 | 表情确证 | 情绪词后面跟着表情描写吗？ | `羞耻和满足同时涌上来，嘴角是弯的，脸是红的` → 删掉 `，嘴角是弯的，脸是红的` |
| 12 | 叙事注解 | 有替读者描述他们已知画面的句子吗？ | `低头看着那片白，自己的手，别人的精液` → `低头看着自己的手。` |

> 这十二问是阶段6特有的翻车点。每次写完一章，花三十秒扫一遍。
