## 二、质量维度定义

每个女性角色的描写从以下6个维度评估和提升：

### 维度1：淫叫/呻吟（NSFW核心）

| 等级 | 标准 | 示例方向 |
|:--:|------|------|
| ★★ 贫乏 | 只有"啊""嗯""哈" | 提升空间大 |
| ★★★ 合格 | 有角色特征的叫声模式 | 劳拉：压抑的低吟→失控的短促叫声 |
| ★★★★ 优秀 | 叫声随场景递进，与性格一致 | 菲娜：从喉间闷哼→压不住的哭腔→事后害羞的沉默 |

**提升要点**：
- 叫声有递进弧线（开始→深入→高潮→余韵，四个阶段的叫声不同）
- 叫声反映性格（劳拉咬嘴唇忍住 vs 奥蕾莉亚不压抑的直接叫）
- 叫声有具体文本，不只写"她叫出声"——写她叫了什么

### 维度2：恐惧表达

| 等级 | 标准 |
|:--:|------|
| ★★ 贫乏 | "身体僵硬""脸色发白" |
| ★★★ 合格 | 有多层次的恐惧反应链：生理反应→心理活动→行为 |
| ★★★★ 优秀 | 恐惧与角色历史/性格结合，有独特的恐惧表达方式 |

**提升要点**：
- 恐惧不只用"僵住"——呼吸变化、指尖温度、视线逃避、声音颤抖
- 恐惧有对象——怕什么具体写出来（怕疼/怕失控/怕被看到/怕被抛弃）
- 恐惧的消退过程同样重要——从害怕到接受的身体信号变化

### 维度3：愤怒表达

| 等级 | 标准 |
|:--:|------|
| ★★ 贫乏 | "瞪了他一眼""脸涨得通红" |
| ★★★ 合格 | 愤怒有触发→升级→爆发的完整链条 |
| ★★★★ 优秀 | 愤怒与角色权力动态结合，是角色塑造的一部分 |

**提升要点**：
- 菲娜铁律可推广：愤怒来自被无视——每个角色的愤怒有不同的"燃点"
- 亚莉莎：被当作小孩 / 劳拉：荣誉被质疑 / 艾玛：研究被轻视
- 愤怒的消退方式也不同（有人需要独处，有人需要被抱住）

### 维度4：语言表达（对话+内心独白）

| 等级 | 标准 |
|:--:|------|
| ★★ 贫乏 | NSFW场景中角色失语，只有叫声没有语言 |
| ★★★ 合格 | NSFW中有角色特征的短句（"等一下""别停""你..."） |
| ★★★★ 优秀 | 语言参与性互动——命令/请求/撒娇/确认——而非被动接受 |

### 维度5：声音描写（非语言声音）

| 等级 | 标准 |
|:--:|------|
| ★★ 贫乏 | 只写"她发出声音" |
| ★★★ 合格 | 有具体的声音描写（呼吸节奏变化、喉音、鼻音、齿间漏出的声音） |
| ★★★★ 优秀 | 声音与身体状态联动，形成声音-身体-情感的闭环 |

### 维度6：动作描写（身体语言）

| 等级 | 标准 |
|:--:|------|
| ★★ 贫乏 | "她抓住床单""她闭上眼睛" |
| ★★★ 合格 | 动作与情感状态一致，有因有果 |
| ★★★★ 优秀 | 动作细节承载角色性格，形成独特的"动作指纹" |

**提升要点**：
- 每个角色有标志性动作（菲娜害羞时把脸埋起来、艾玛思考时捻辫梢、菲拉衣角）
- 性场景中这些标志性动作如何变形
- "身体先于意志"原则（菲娜铁律）按需推广至其他角色

## 四、五阶段工作流

### 阶段一：建立质量基准

```
Step 1.1  选定"金标准"章节作为每个角色的目标参照
          - 菲娜金标准（已有）：Ch160/167/336-338
          - 为每个角色选定1-2章当前最佳章节作为"内基准"
          - 从菲娜的优质章节中提取跨角色通用的描写技法

Step 1.2  为每个角色编写"角色声音卡片"
          - 格式：角色名 → 6维度速写（淫叫模式/恐惧燃点/愤怒表达/
                  语言习惯/声音特征/动作标志）
          - 附带3-5个"应该这样写"的示例片段
          - 附带3个"不该这样写"的反面示例（从当前章节中抽取典型问题）

Step 1.3  建立"跨角色差异化矩阵"
          - 同一情境（如"第一次口交"）下各女性角色的反应对比表
          - 确保每个角色的反应互不雷同，有辨识度
```

### 阶段二：逐章审核与标注（核心阶段，按批次执行）

```
对每个目标章节：
Step 2.1  阅读章节全文（TXT唯一权威源）
Step 2.2  按6维度打分（★~★★★★），记录在追踪表
Step 2.3  标注具体问题位置和类型
Step 2.4  写出修改方向（1-3句/问题），不直接改正文
Step 2.5  完成当前角色的所有章节审核后，进入阶段三
```

**审核工具**：为每个角色维护一个审核追踪Markdown文件：

```markdown
# {角色名} 描写质量审核追踪

## 批次信息：{1/2/3} · 总章节数：{N} · 已审核：{n}/{N}

### Ch{ID}: {名称}
- 日期：{YYYY-MM-DD}
- NSFW：是/否
- 6维评分：淫叫★/恐惧★/愤怒★/语言★/声音★/动作★
- 问题标注：[淫叫]... [语言]...
- 修改方向：{1-3句描述}
- 状态：待修改 / 已修改 / 已复核
```

### 阶段三：逐章修改（按角色批次执行）

```
对每个标注过的章节：
Step 3.1  重新阅读章节全文 + 审核标注
Step 3.2  按修改方向逐处修改（手动，不批量替换）
Step 3.3  修改后自检：
          - 是否符合该角色的"声音卡片"？
          - 是否与其他角色的同类场景有足够差异？
          - 是否违反任何去AI化铁律？
Step 3.4  更新追踪文件状态：→ 已修改
```

**修改原则**：
1. **最小改动原则**：只改描写质量，不改情节结构和性行为内容
2. **角色一致性原则**：修改后的描写必须与角色既有性格一致
3. **不引入新违规**：修改中不新增破折号/否定句式/短句三连等违反铁律的写法

### 阶段四：交叉验证（角色间一致性检查）

```
Step 4.1  同批次角色间的"差异化检查"
          - 抽取同一性行为类型的章节，对比不同角色的描写，确认无雷同
          
Step 4.2  角色内"前后一致性检查"
          - 同一角色在不同阶段的描写是否有合理的演进

Step 4.3  菲娜基准对比
          - 所有修改后的非菲娜章节与菲娜金标准章节进行抽查对比
```

### 阶段五：构建验证与收尾

```
Step 5.1  运行 build_eldoria.py 重新构建JSON
Step 5.2  运行 story_tool.py validate 验证所有章节
Step 5.3  抽查5-10章修改后的章节
Step 5.4  更新 CLAUDE.md：在"角色特征速查"表中增加"声音/反应特征"列
Step 5.5  git commit
```

## 五、质量检查清单（每章）

修改每章时逐项核对：

```checklist
□ [淫叫] 叫声有递进弧线（开始→深入→高潮→余韵），不只用"啊""嗯"
□ [淫叫] 叫声反映角色性格，读完知道是谁在叫
□ [淫叫] 有具体叫声文本，不只写"她叫出声"
□ [恐惧] 恐惧有多层生理信号（呼吸/体温/颤抖/视线），不只有"僵硬"
□ [恐惧] 恐惧有明确对象
□ [恐惧] 恐惧有消退过程
□ [愤怒] 愤怒有触发→升级→爆发的链条
□ [愤怒] 愤怒的燃点与角色性格一致
□ [语言] NSFW中角色会说话，语言参与性互动
□ [语言] 说的话符合角色性格（不混同于其他角色）
□ [声音] 有具体的非语言声音描写（呼吸/喉音/鼻音/齿音）
□ [声音] 声音与身体状态联动
□ [动作] 动作有因有果，与情感状态一致
□ [动作] 角色标志性动作在性场景中有变形/延续
□ [差异化] 与其他角色的同类场景有足够差异
□ [铁律] 不违反去AI化铁律（破折号/否定句式/短句三连/不二字崩等）
```

### 8.1 试运行范围

Batch 1 三个角色各选取代表性NSFW章节，每人1处修改：

| Ch474 | 亚尔缇娜 | 黑丝足交节拍器崩坏 | "一个很小的'啊'从她嘴里漏了出来" | 直接拟声 |

### 8.2 核心教训

1. **每章一处足矣**。找到"由不得自己"的那个瞬间——身体先于意志，声音是自己跑出来的。加多了反而稀释。
2. **禁止通用标签**。"闷哼""低哼""呻吟"三个词全部禁用。每个声音必须是这个角色在这个时刻才会发出的独一无二的声音。
3. **三种声音模式轮换使用**，避免千篇一律：

| 模式 | 写法 | 适用场景 | 示例 |
|------|------|------|------|
| **身体觉察** | 角色自己都没料到的/自己听到了的X | 控制型角色（劳拉、亚莉莎）失控瞬间 | "喉间发出一个她自己都没想到的细小声音" |
| **情感标签** | 委屈的/困惑的/羞恼的X | 角色有明确情绪反应的时刻 | "一个委屈的声音从她喉间漏了出来" |
| **直接拟声** | 很小的X声/一个"啊" | 角色无法归类的原始反应 | "一个很小的'啊'从她嘴里漏了出来" |

4. **角色反应比声音本身更重**。亚莉莎"自己听到了→耳朵尖红透"——傲娇对自己身体的懊恼才是描写的落脚点。劳拉"自己都没想到"——骑士对身体失控的错愕。
5. **短句不三连**。`A。B。C。` 中如果A/B/C都是≤12字的短句，必须用逗号串联。`"喉间发出一个细小的声音，她自己都没想到。"` → `"喉间发出一个她自己都没想到的细小声音。"`

### 8.3 修改时的自检顺序

```
每章 Read 后先判断是否需要改：

【跳过条件】满足任一即跳过，标记"已达标"：
□ 性行为过程中角色发出了≥1处有具体文本的声音（不只是"她叫出声"）
□ 声音有角色特征（换了角色说不通）
□ 声音出现在关键节点（插入/节奏变化/高潮），不是边缘位置

未满足跳过条件 → 进入修改流程：

每章 Edit 后逐条核对：
① [无破折号] 叙事描写中不出现 ——
② [无通用标签] 全文不出现"闷哼""低哼"；"呻吟"仅在对话中可用
③ [无比喻解释] 不写"像...""仿佛..."；声音是什么直接写，不解释为什么
④ [无碎片三连] 句号结尾≤12字不得连续三句
⑤ [声音唯一性] 这个声音换了另一个角色就说不通
⑥ [落脚点在角色] 声音之后有角色的反应（愣住/听到了/耳朵红/皱眉/咬唇）
```

### 8.5 场景分类与描写框架（2026-07-24）

场景按女性角色是"给予方"还是"接受方"分为两大类，描写重点不同。

#### 8.5.1 给予方：口交/手交/足交

女主角用手/嘴/脚主动给予——会产生摩擦声/水声/唾液声。描写重点：**声音+对话**。

| 层 | 内容 | 写法 | 示例 |
|:--|------|------|------|
| **声音** | 摩擦声、水声、唾液声 | 直接写听到的声响 | "手掌上下滑动，能听到皮肤摩擦的湿润声响" |
| **对话** | 按角色×对象组合决定 | 见8.5.3 | — |
| **反应** | 对方的反应 | 呼吸变重、手指收紧、喉音 | — |

审核：有对话+有声音→跳过；缺→加。

#### 8.5.2 接受方：指交/被舔穴/本番/被爱抚

女主角在接受刺激——身体先于意志，快感导致失控。描写重点：**淫叫+骚话**。

| 层 | 内容 | 写法 |
|:--|------|------|
| **淫叫** | 不由自主的声音 | 喉咙漏出/压不住/自己都没注意到的声音 |
| **骚话/骂/娇嗔** | 按角色×对象+事后态度 | 爽的时候叫/说，事后可能不承认 |

**劳拉×艾德里安特例**：过程爽得嗯嗯啊啊叫→事后恼羞成怒不承认。身体是诚实的，嘴事后不认。

审核：有淫叫（≥1处不由自主的声音）→跳过；缺→加。

#### 8.5.3 对话模式——按角色×对象关系

**核心原则**：同一角色对不同对象，对话模式不同。必须结合具体情境和角色人设，**禁止生搬硬套示例**。

| 关系类型 | 角色×对象 | 对话特征 | 方向（仅参考，需结合情境） |
|------|------|------|------|
| **害羞/愿意** | 劳拉×雷恩 | 直接但轻，确认式 | "这样可以吗？""...雷恩。" |
| **害羞/愿意+傲娇** | 亚莉莎×罗恩 | 边说边脸红，嘴硬身体诚实 | "才不是特意为你弄的...""别、别一直盯着看。" |
| **调戏/大姐姐** | 菲娜×其他人 | 从容挑逗，甜中带掌控 | "这里胀这么大吗？""这么喜欢我的脚呀？" |
| **调戏/大姐姐** | 艾玛×法林 | 学术外壳下的甜 | "痒，法林你，嗯~""是痒啦笨蛋~" |

## 九、并行化策略

### 9.1 依赖关系

```
阶段一 ──→ 阶段二+三(批次1) ──→ 阶段二+三(批次2) ──→ 阶段二+三(批次3) ──→ 阶段四 ──→ 阶段五
                │                      │                      │
          ┌─────┼─────┐          ┌─────┼─────┐          ┌─────┼─────┐
          ▼     ▼     ▼          ▼     ▼     ▼          ▼     ▼     ▼
        劳拉  亚莉莎 亚尔缇娜   艾玛  奥蕾莉亚 菲      玲   爱丽榭 菲娜回溯
         │      │      │         │      │      │         │      │      │
         └──────┴──────┘         └──────┴──────┘         └──────┴──────┘
                3路并行                  3路并行                  3路并行
```

- 阶段一必须在阶段二之前（声音卡片是审核的基准）
- 阶段四必须在所有批次完成后（交叉验证需要全量结果）
- **批次之间无硬依赖**——分三批仅为风险管理和迭代优化

### 9.2 按角色分agent

每个女性角色由一个专属agent全权负责——从审核到修改到自检。同一角色的所有章节必须由同一个agent处理以保证角色内一致性。

**为什么必须分批**：
- 批次1完成后可以总结经验教训，优化批次2/3的agent prompt
- 菲娜回溯（批次3）放在最后——等其他角色都改完后对照新标准，确保菲娜仍然明显优于其他人
- 全量并行如果方向偏了，返工成本高

### 9.3 单角色agent工作包

```
Agent-{角色名} 输入：
  1. 该角色的"声音卡片"（阶段一产出）
  2. 分配给该角色的章节文件列表
  3. 6维度质量检查清单（§5）
  4. 去AI化铁律速查（CLAUDE.md §3.3）
  5. 菲娜金标准章节参考（Ch160/167/336-338）
  6. ⛔ 执行铁律（§开头6条）

Agent-{角色名} 执行流程：
  For each 章节 in 分配列表：
    a. Read 章节TXT                    ← 铁律#3：必先Read
    b. 按6维度打分（★~★★★★）
    c. 标注问题位置和类型
    d. 写修改方向（1-3句/问题）
    e. Edit 章节TXT（逐处手动修改）    ← 铁律#1：禁止脚本

  Return: 审核追踪文件 + 修改统计

⛔ 禁止：
  - 不Read直接Edit
  - 使用sed/Python/regex批量处理
  - 跳过自检步骤直接标记"已修改"
  - 为了速度跳过任何章节
```

### 9.4 质量门流程（每个Batch完成后强制执行）

```
不通过标准（任一即不通过）：
  □ 抽查章节中存在★或★★维度（6维度任一未达★★★）
  □ 两个角色的同类场景描写雷同
  □ 修改引入了铁律违规
  □ 角色描写偏离声音卡片
  □ 同一角色前后章节描写风格断裂

不通过处理：
  1. 主agent将问题章节+问题维度列表发回角色agent
  2. 角色agent逐章修正
  3. 主agent重新抽查
  4. 重复直到通过
```
