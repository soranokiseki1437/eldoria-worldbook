## 一、核心原则

### 1.0 不变底色：娇羞 + 妩媚 + 甜美

无论阶段如何演进，**娇羞+妩媚+甜美始终是菲娜的底色**。从容不影响娇羞——她可以一边熟练地含进去，一边耳朵尖红透。

```
娇羞：耳朵尖烫、声音轻、脸烧得不敢看对方、攥紧黎恩的手到指节发白
妩媚：长发垂落、声音又轻又软、指尖轻轻划过、回头看黎恩时的表情既脆弱又妩媚
甜美：事后蜷进黎恩怀里像猫、闷闷地说话、手在被子下攥他的手指
```

> 如果一章里菲娜没有害羞体征、没有妩媚质感、没有甜美回归，那就是写偏了。

#### 害羞是持续状态，不是单点标记

**错误**：找到一处违规→替换为一个害羞表达，然后继续原来的叙事。

**正确**：害羞是**全场景链路**——修改时从头到尾过一遍，确保每个阶段都有对应体征。

```
事前：结巴（"我我我"）、想起黎恩说过的话→脸红、害羞地嗔怪（"你问我我怎么知道...."）
事中：害羞到无法点头/无法回应（"正害羞着呢，哪有心思管他"）、被问疼不疼时用沉默回答（"......"）
事后：脸红红地赶紧跑了、想赶快回到黎恩旁边、把脸埋进毛巾里闷闷地说话
```

> 判断标准：随机点叙事中任意一处菲娜的对话或动作——那一瞬间她应该有娇羞体征。

#### 联系黎恩的锚点式提及

菲娜的主动行为不应凭空出现。她决定帮第三者之前，应追溯到黎恩之前的引导。

```
菲娜看到哈根累到极限→"菲娜想到黎恩前段时间和她说过的话，脸红得像熟透的桃子"→然后才拨通讯
```

事后必须有甜美回归黎恩——哪怕只是一个句子（"菲娜脸红红地赶紧跑了，她现在想赶快回到黎恩旁边"）。

### 1.1 阶段4（跨线）— 叠加层：决心 + 紧张 + 依赖

核心行动链：

```
主动决定 → 紧张执行 → 确认黎恩在 → 才能继续 → 事后回归确认归属
```

- **主动决定**：菲娜自己选择跨线（"我想试试"），开口时有害羞体征
- **紧张执行**：手抖、呼吸碎、眼泪在眼眶里转、攥黎恩的手到指节发白
- **确认黎恩在**：每迈出一步前转头看他、等他点头、向他伸出手。回头看他的表情"既脆弱又妩媚"
- **回归确认**：跨线后回到黎恩怀里，甜美蜷进去

#### 菲娜的害羞抗拒模式

阶段4的菲娜拒绝的方式是**害羞到无法回应**——不是语言上的"不要"，而是身体和反应的退缩。

```
- 害羞到无法点头：乔治等她点头，但她"正害羞着呢，哪有心思管他"
- 被问话时不回答："我想——" "菲娜没有理他"
- 被问疼不疼时沉默："疼？" "......"
- 被问从哪里开始时的害羞嗔怪："你问我我怎么知道...."
```

> 菲娜不理你 = 你要自己判断该不该继续。她沉默 = 在感受而不是拒绝。

### 1.2 阶段5（享受和掌控）— 叠加层：享受 + 掌控

菲娜开始享受共享本身，并在过程中掌控节奏。娇羞+妩媚+甜美底色不变。

## 三、阶段4标志性场景模式

### 3.1 跨线场景（插入事件）

```
1. 约定：菲娜主动说"我想试试" + 黎恩承诺"我全程在"
2. 跨线前：菲娜紧张→找到黎恩的位置→确认他在→深呼吸→开始
3. 关键时刻：菲娜转头看黎恩→黎恩点头→转回去闭眼→向黎恩伸出手
4. 跨线中：黎恩握住她的手→十指扣紧→她攥紧，指甲陷进他手背
5. 跨线后：推开第三者（不内射）→回到黎恩怀里→确认归属
```

> 这个模式是阶段4区别于其他阶段的核心。缺失任何一个环节都是漏洞。

### 3.2 新玩具/新体验场景

```
1. 初见抗拒：躲到黎恩身后/"我不要"/攥袖口
2. 黎恩引导：牵到身边/说"试试，我在"/先摸一下不用放进去
3. 试探：伸一根手指碰→缩回来→回头看黎恩→他点头→再伸手
4. 逐步深入：一档→紧张喘气→攥黎恩的手指节发白→"可以高一点吗"
5. 高潮：埋进黎恩胸口→"太快了——"→事后害羞确认"下次还要你陪"
```

### 3.3 尝试失败场景（未跨过去的线）

```
1. 主动挑战：菲娜说"我想知道能不能做到"
2. 执行前半：前半段顺利（口交吞精做到了）
3. 触及底线：龟头顶到入口→崩溃摇头→发出信号
4. 黎恩救场：全力出手→抱进怀里→"你说了可以才可以，没说就不行"
5. 回归确认：攥着他的衣服哭了很久→"我是还没准备好"→"那就不急"
```

### 3.4 不满→被哄→原谅微弧

```
1. 表达不满：抬头看他，眼里有委屈。"你都没问我。你替我回答了。"
2. 黎恩识别："你生气。"
3. 否认+纠正："...不是生气。是你应该先问我。"（纠正比否认更重要）
4. 黎恩承诺+行动：说"下次我会先问你" + 具体安抚动作（梳理头发、全身按摩）
5. 菲娜给予原谅：在他胸口呼一口气，说"再原谅你一次。"（她主动给，不是他求来的）
```

> 黎恩的安抚必须是**具体动作**（梳理头发、按摩），不能是抽象态度（"他安抚她"）。

### 3.5 NTRS重新占有仪式

```
1. 场景设定：第三者离开后，房间里只剩两人。她的身体还残留着别人的触感。
2. 剥离痕迹：黎恩用鬼之力剥离第三者在她皮肤上的精液痕迹——"取而代之的是他自己的紫色暗影"。
3. 确认她的意识：让她睁眼看他。"高潮时你叫的是谁？""...你。"
4. 从背后插入：用他的精液覆盖第三者残留的湿润——"每一次都顶到凯尔没有碰到的最深处"。
5. 正式宣告：嘴唇贴着她的后颈。"从今天起——每次共享结束，我都会这样。你没有背叛我。你只是在确认——你终究是我的。"
6. 她主动确认归属："我终究是你的。"那语气不含疑问，只有确认。
```

> 重新占有的标点风格：破折号是**重音符号**——`脚步不快不慢——每一步都在告诉她：接下来是我。` 每个破折号落下去都像黎恩的脚步。

### 3.6 "偷笑+眨眼"模式：对黎恩的私密玩笑

当菲娜要把黎恩推向另一个女人时，她的表达不是社交微笑，而是**与黎恩之间的私密互动**。

```
菲娜从他身后探出半个身子，她看了黎恩一眼，偷笑着用手在他背上一推，对奥蕾莉亚眨眨眼说："他只是在想要不要带伞，快去吧。"
  ──看黎恩──  ──偷笑（对黎恩的私密玩笑）──  ──眨眼（调皮但不是讨好）──
```

| 判断标准 | 社交微笑（错误） | 偷笑+眨眼（正确） |
|------|------|------|
| 笑的对象 | 第三者 | 黎恩（偷笑=偷偷地） |
| 笑的性质 | "觉得好玩" | 两人之间的私密默契 |
| 对第三者的互动 | 对着第三者笑 | 眨眼——调皮但不讨好 |
| 第三者反应 | 不觉得意外 | 感到意外——说明菲娜平时不这样 |

## 四、标点符号细则

### 4.1 破折号：按场景和POV区分

| 场景 | 破折号策略 | 示例 |
|------|------|------|
| **菲娜的娇羞/紧张场景** | 最小化。用逗号串联，省略号表示犹豫 | `她生气了，瞪着他，不说话。` |
| **黎恩的占有/仪式场景** | 破折号=重音符号 | `他蹲下来——一只手撑在她耳边的毛皮上。` |
| **对话中的打断** | 保留破折号 | `"如果他没有停——"她没说完。` |
| **对话中的犹豫/口吃** | 保留破折号 | `"震动——呃——导力震动装置。"` |

### 4.2 对话标签与对话内部：逗号 vs 句号

**对话标签**：

| 位置 | 标点 | 示例 |
|------|:--:|------|
| 话未完，标签插入 | `，"` | `"他没有进去，"黎恩说。"但他可以。"` |
| 话完整，标签在后 | `。"` | `"...我知道。"她的声音哑了。` |
| 标签带情绪修饰 | `："` | `她不悦地说："...我知道。"` |

**对话内部逗号串联**：对话内短句之间用逗号，不用句号切断。

| 错误 | 正确 |
|------|------|
| `"没事。你继续。"` | `"没事，你继续。"` |
| `"进来。床冷。"` | `"进来，床冷。"` |
| `"好。明早我来接你。"` | `"好，明早我来接你。"` |

### 4.3 省略号：菲娜的自我谈判

菲娜的犹豫是自我谈判过程：

```
"我还是不想让他们进来...但是我确实有一点点想试试...要不，让低语者插进来..."
  ──否定──────────   ──承认──────   ──提议（声音越来越小）──
```

**四种用法速查**：

| 类型 | 形式 | 示例 | 说明 |
|------|------|------|------|
| 犹豫 | `...` | `"黎恩..."` `"还好...你动"` | 语流中断 |
| 结巴 | `...` + 重复 | `"那个...我我我"` | 念头断成几截 |
| 沉默 | `......` | 被问"疼？"→`"......"` | 六个点。害羞到说不出话 |
| 嗔怪 | `....` | `"你问我我怎么知道...."` | 四个点。声音渐弱到消失 |

> 点数越多，害羞越深：`...`犹豫 → `....`渐弱 → `......`彻底沉默。

### 4.4 长句逗号串联 vs 碎片句

| 错误（碎片） | 正确（逗号串联） |
|------|------|
| `她生气了。瞪着他。不说话。` | `她生气了，瞪着他，不说话。` |
| `一下。两下。节奏不快。` | `一下、两下，节奏不快。` |
| `嘴张开又合上。合上又张开。` | `嘴张了又合，合了又张。` |

> 逗号串联的是**同一股情绪流**中的连续状态变化。顿号（、）用于并列项之间，比逗号更轻。

### 4.5 波浪号~ + "啦"：菲娜的撒娇甜美标记

波浪号表示尾音上扬的轻软感。**只在菲娜的撒娇/甜美时刻使用**。

| 场景 | 不用波浪号 | 用波浪号 |
|------|------|------|
| 事后留宿 | `"今晚。我在这里睡。"` | `"今晚我在这里睡~"` |
| 被插入时的回应 | `"还好。你动。慢一点。"` | `"还好...你动，慢一点~"` |
| 拒绝黎恩来接 | `"不用。"` | `"不用啦黎恩"` |

> "啦"+人名（`"不用啦黎恩"`）— 不加逗号，形成亲昵的呼唤+陈述一体感。"啦"和波浪号择一即可，不同时用。

### 4.6 问句用问号

| 错误 | 正确 |
|------|------|
| `"多尔金呢。"` | `"多尔金呢？"` |
| `"你们什么时候说的——"` | `"你们什么时候说的？"` |

### 4.7 感叹号替代破折号表达惊呼

菲娜的惊呼、喊叫——用感叹号，不用破折号。破折号是语气中断，感叹号是情绪强度。

| 错误 | 正确 |
|------|------|
| `"你——不是说了不能——"` | `"你！不是说了不能——"` |

### 4.8 菲娜慌乱时的连续话语：破折号→逗号

菲娜慌乱中说一串话，中间用逗号串联。破折号只保留在句末——真正的"被打断/没说完"。

| 错误 | 正确 |
|------|------|
| `"你是不是要射了——不能射里面，快拔出来——"` | `"你是不是要射了，不能射里面，快拔出来——"` |

### 4.9 拟声词的标点

拟声词（啪、砰、咚）前用破折号引入，后用逗号接描述。

```
"她抬起手狠狠拍在他后脑勺上——啪，声音很脆。"
  ──动作──  ──破折号引入──  ──逗号接描述──
```

## 六、修改流程

```
Step 1  读TXT，逐条过检查清单
Step 2  定位违规点：情感层/动作层/语言层/标点/黎恩角色层
Step 3  编辑TXT：
        - 害羞是全场景链路——不能只改一个点
        - 破折号按POV区分——菲娜场景逗号串联
        - 对话内部短句用逗号，不用句号切断
        - 菲娜犹豫用省略号，沉默用"......"，撒娇用波浪号
        - 去除比较叙述（"那次她也这样"）
        - 菲娜的主动追溯到黎恩的引导
        - 事后必须有甜美回归黎恩
        - 删诗意环境收尾——动作本身已传达状态
        - 元数据不引用具体台词、不括号举例
        - 检查情绪一致性——愤怒后不突然变温柔
Step 4  同步核心/章节任务/章节终止条件
Step 5  等待用户确认后再构建/提交
```

### 常见修改陷阱

| # | 陷阱 | 说明 |
|---|------|------|
| 1 | 所有微笑用同一个害羞表达替换 | 轮换使用：耳尖发烫、偏开视线、把毛巾按在脸上闷闷地说、脸红到脖子、不敢看他、咬下唇、睫毛颤、攥床单。 |
| 2 | 只改微笑不改场景氛围 | 根因是菲娜被写成了"社交游刃有余"。让她退回害羞节奏——不理人、不回答。 |
| 3 | 去除所有笑意包括对黎恩的 | "偷笑"保留——对象是黎恩。只改对第三者的社交微笑。 |
| 4 | 改完正文忘了改元数据 | 核心/任务/条件可能残留旧表述。 |
| 5 | 诗意环境收尾 | "窗外的灰蓝变成了淡金。她睡着了。"→删。动作本身传达状态。 |
| 6 | 情感矛盾的温存小动作 | 内射后菲娜在生气，不会"在他大腿上画小圈"。检查情绪一致性。 |
| 7 | 元数据括号引用台词 | 占有欲确认不需要`（"具体台词"）`。 |
| 8 | 碎片句合并不彻底 | "嘴张开又合上。合上又张开。"→"嘴张了又合，合了又张。" |
| 9 | 元数据冗长松散 | "菲娜对乔治的控诉是真实的，黎恩也真的打了乔治..." → 用排比句收束："是真的生气""是真的打""是实话""也是真的"。每个短句一个事实，不铺陈。 |

### 不得做的事

- 不得让菲娜在没有确认黎恩的情况下跨线
- 不得让菲娜对第三者微笑（偷笑和眨眼是对黎恩的私密互动，例外）
- 不得在核心中剧透后续章节
- 不得使用冗余否定
- 不得用抽象词替代具体动作
- 菲娜表达不满后不得让她被动接受道歉
- 不得在同一章节中反复使用同一种害羞表达
- 不得让菲娜在叙事中比较自己的表现（"那次也这样""比上次更"）
- 不得让菲娜的主动行为凭空出现——追溯到黎恩的引导
