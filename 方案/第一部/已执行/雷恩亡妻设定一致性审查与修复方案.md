## 二、逐类详细分析

### A. 亡妻名字 — 三个不同名字 🔴致命

这是最核心的矛盾。同一人物在7个章节中被赋予了三个不同的名字：

| 名字 | 使用章节 | 出现形式 |
|------|----------|----------|
| **莉兹** | 第57章 (序章) | 情境正文 + 章节任务 + 终止条件 |
| **艾琳** | 第96章 (试探和暧昧) | 情境正文 + 章节任务 + 终止条件 |
| **莉兹** | 第257章 (跨线) | 情境正文 + 章节任务 + 终止条件 |
| **莉迪亚** | 第338章 (享受和掌控) | 章节终止条件 |
| **莉迪亚** | 第341章 (享受和掌控) | **章节标题名** + 情境正文 + 章节任务 + 终止条件 |
| **莉迪亚** | 第342章 (享受和掌控) | 承接338/341（未直接写出名字但指向莉迪亚） |
| **莉迪亚** | 第362章 (享受和掌控) | 承接338/341弧线 |
| *(无名)* | 第92、94、108、198、285、375、394章 | 仅称"亡妻"，不涉及名字 |

**名字分布图**：
```
第57章 ──→ 莉兹 (Liz) ──→ 面包匠的女儿，瘟疫3天
第96章 ──→ 艾琳 (Eileen) ──→ 赶到太晚
第257章 ─→ 莉兹 (Liz) ──→ 面包匠的女儿（呼应57）
第338章 ─→ 莉迪亚 (Lydia) ──→ 镜湖倒影中对话
第341章 ─→ 莉迪亚 (Lydia) ──→ 章节标题"莉迪亚的名字"
```

**分析**：
- 名字从"莉兹→艾琳→莉迪亚"的演变似乎不是故意的叙事设计，而是写作过程中遗忘了前文设定
- "莉兹"更符合作為"面包匠的女儿"的平民身份
- "莉迪亚"听起来更有贵族气息，与"面包匠的女儿"背景略显不协调
- 但"莉迪亚"已深度嵌入第338-362章的镜湖叙事弧线，且第341章**标题本身就是"莉迪亚的名字"**

### B. 雷恩眼睛颜色 — 三种颜色混用 🔴严重

| 来源 | 颜色描述 |
|------|----------|
| 第52章 (雷恩登场) | **蓝色**的眼睛 |
| 第96章 (晨间仪式) | **蓝灰色**的眼睛在晨光中几乎是透明的 |
| 第338章 (镜湖幻影) | **蓝灰色**的眼睛 |
| 第394章 (接吻即湿) | **深绿色**瞳孔里的月光 |
| 第469章 (告发) | **深绿色**眼睛 |
| **角色设定文件** (CHR03) | **深绿色瞳孔** |

**分析**：
- 角色设定文件（唯一权威源）明确写的是"深绿色瞳孔"
- 早期章节（52/96/338）写蓝色/蓝灰色，后期章节（394/469）写深绿色——可能是中途有人修正过但早期章节未回溯修改
- 第52章作为登场章节，眼睛颜色写错影响最大

### C. 雷恩头发颜色 — 灰白 vs 深棕银丝 🟡中等

| 来源 | 头发描述 |
|------|----------|
| 第92章 (丧妻十二年) | **灰白的头发**在火光里显得比平时更苍老 |
| 第338章 (镜湖幻影) | **灰白短发**垂在额前 |
| 第394章 (接吻即湿) | **深棕色短发**在月光下泛着微光...**灰白短发的侧影**（同一章两句矛盾！） |
| **角色设定文件** (CHR03) | **深棕色短发微卷，夹杂几根银丝** |

**分析**：
- 角色设定写的是"深棕短发+几根银丝"，不是满头灰白
- "灰白头发"让雷恩看起来像60+岁老人，但他才32岁——丧妻之痛可以让他早生华发，但不应是满头灰白
- 角色设定的"夹杂几根银丝"更符合32岁因悲伤早生华发的设定
- 第394章内部自相矛盾尤为明显：同一段情境里先写"深棕色短发"又写"灰白短发"

### D. 亡妻死因 — 在场 vs 赶到太晚 🟡中等

| 来源 | 死因描述 |
|------|----------|
| 第57章 | 瘟疫、高烧、**三天**。雷恩把她抱上床→再也叫不醒。雷恩**全程在场** |
| 第96章 | "放下**那天我赶到得太晚**的事实" — 暗示雷恩**不在场** |
| 第257章 | "她走的那天早上还在笑。说晚上要做炖菜。**当天晚上就**——" 雷恩在场 |
| 角色设定文件 | "因病去世"（笼统，不矛盾） |

**分析**：
- 第57章和第96章的核心矛盾：一个说雷恩陪伴了三天，一个说雷恩"赶到得太晚"
- 考虑到第57章是最详细且最早的版本，"瘟疫三天+在场陪伴"应作为正典
- 第96章的"赶到得太晚"可以理解为"赶到得太晚没能救她"（即使在场也救不了），但措辞确实容易误导

### E. 时间线 — 12年 vs 20年 🟡中等

| 来源 | 时间描述 |
|------|----------|
| 第57/92/93/96/117/257/311/344/446章 | **十二年** |
| 第338章 | "表情是**二十年来**最平静的一次" |
| 第342章 | "嘴角弯着，**二十年来的第一次**" |

**分析**：
- 绝大多数章节（9+章）一致使用"十二年"
- 第338和342章的"二十年"是孤例
- 雷恩32岁，如果妻子去世12年，他20岁结婚；如果20年，他12岁结婚——后者不合逻辑
- 明确是笔误：应为"十二年来"而非"二十年来"

### F. 亡妻外貌 — 仅第338章有描述 🟢低

第338章描述（目前唯一的外貌描述）：
- "深棕色长发编成辫子垂在肩前"
- "浅金色眼睛"
- "白色亚麻裙"

角色设定文件（CHR03）中完全未提及亡妻外貌。建议补充到角色文件。

## 三、修复方案

### 推荐正典设定（统一锚点）

| 属性 | 正典值 | 理由 |
|------|--------|------|
| **名字** | **莉兹** (Liz) | 最早出现(Ch57)、最匹配"面包匠的女儿"平民身份、已在2章中使用 |
| **眼睛** | **深绿色瞳孔** | 角色设定文件权威值，后期章节已在使用 |

| **死因** | **瘟疫，高烧三天，雷恩在场** | Ch57最详细版本，更有情感冲击力 |
| **时间** | **十二年** | 绝大多数章节一致，符合雷恩32岁年龄逻辑 |
| **外貌** | 深棕色长发编辫、浅金色眼睛、白色亚麻裙 | Ch338唯一描述，合理可用 |

### 名字选择的权衡

有两条路：

#### 方案一（推荐✅）：统一为"莉兹"

- 修改：Ch96 艾琳→莉兹，Ch338/341 莉迪亚→莉兹
- 第341章标题从"莉迪亚的名字"→"莉兹的名字"
- 优点：与面包匠女儿身份匹配、早登场早确立、平民感真实
- 缺点：第341章标题需修改，镜湖弧线需全文替换

#### 方案二：统一为"莉迪亚"

- 修改：Ch57 莉兹→莉迪亚，Ch96 艾琳→莉迪亚，Ch257 莉兹→莉迪亚
- 优点：镜湖弧线（4章）不动，第341章标题不动
- 缺点："莉迪亚"是贵族名，与"面包匠的女儿"身份不协调
