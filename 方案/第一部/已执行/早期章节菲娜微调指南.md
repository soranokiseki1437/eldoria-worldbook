## 一、核心原则

### 1.1 阶段1（试探和暧昧）

菲娜面对第三者接触应是：**娇羞 + 抗拒 + 不安**。

她在被动中被推着走。与黎恩的分享是"抱怨 + 寻求情感锚定"。黎恩在场时她才有安全感，黎恩不在场时她会抗拒和不安。

### 1.2 阶段3（渐进接触）

菲娜已积累多次共享经验，但面对**新的行为类型**（第一次口交、第一次双人共享）时紧张和害羞仍然主导。

阶段3的关键变化：
- **娇羞 + 妩媚 + 甜美三者并存**：不再是单纯的害羞抗拒，而是害羞中带有妩媚的主动性，事后确认归属时甜美撒娇
- **从"被享用"到"自己决定在哪停"**：技术熟练了但害羞体征不减
- **主动勾引场景**（如Ch216白丝之夜）：可以保留"调皮/得意/心里酥爽"——这是菲娜按黎恩计划主动勾引第三者，与阶段1被动承受有本质区别
- **黎恩的在场是她行动的前提**：先找他，确认他在，然后才敢继续

## 二、修改检查清单

逐条过，每条都检查：

### 情感层

| # | 检查项 | 错误 | 正确 |
|---|--------|------|------|
| 1 | 菲娜有没有微笑/嘴角弯/觉得好玩？ | "她嘴角弯起来，很小。" | **阶段1-2**：删除，改成害羞体征。**阶段3主动勾引场景**（菲娜按黎恩计划主动勾引）：可保留"得意/调皮"，如Ch216白丝之夜。判断标准：谁发起的？黎恩安排的主动勾引→可保留；被动承受→不可。 |
| 2 | 菲娜有没有对第三者做正面评价？ | "他的手指很轻" | 删除。不写任何正面/中性描述 |

| 6 | **情绪时序对不对？** | 羞耻写在对方开口前 | 预感→愣住→听完后羞耻涌上来。情绪必须在正确的触发点 |

| # | 检查项 | 错误 | 正确 |
|---|--------|------|------|
| 7 | 菲娜有没有对第三者表达不满？ | 站着不动让他碰 | 退半步、瞪眼、躲开——至少一个抗拒动作（阶段1）。阶段3可减少抗拒但增加害羞体征。 |
| 8 | 对话前有没有写情绪状态？ | "菲娜靠在黎恩肩上。" | "菲娜皱着眉头，有点不安地靠在黎恩肩上。" |

### 语言层

| # | 检查项 | 错误 | 正确 |
|---|--------|------|------|
| 13 | 有没有滥用破折号？ | "有点紧张——这个人不用等" | 句号替代。**例外**：对话打断（"我不该——"）、突然意识（"等等——"）保留破折号。 |
| 14 | 标点传达情绪了没？ | "他怎么能这样。我又没让他碰。" | "他怎么能这样**！**我又没让他碰**...**" |
| 15 | 叙述被句号切太碎了没？ | "第一次把脚挪开了。第二次瞪了他一眼。他手缩回去了。" | 逗号串因果："...，...，他才..." |
| 16 | 菲娜的用词是否情绪化？ | "不能画"（规则声明） | "不准画"（情绪化、任性）——体现菲娜的语气而非理性决定 |
| 17 | **对话是否有中文引号？** | `黎恩说: 等我一下。` | `黎恩说："等我一下。"`——所有有声对话须加中文引号 `"..."`。内心独白不加。 |

### 否定句式层（新增）

| # | 检查项 | 错误 | 正确 |
|---|--------|------|------|
| 18 | 有没有"不是X的Y"冗余否定？ | "脸烧起来——不是酒的热" | "脸烧了起来，耳尖烫得自己都感觉到了。"——直接肯定描述 |
| 19 | 有没有"不是A而是B"迂回？ | "不是得意而是认真" | "用认真反击而非得意炫耀"——或更直接的肯定句式 |

> **判断标准**：如果"不是X"的X在前面没有被暗示过（读者没有默认期待它是X），那"不是X"就是冗余否定。比如"脸红了——不是酒的热"前面没说喝酒，读者不会默认是酒的热，所以是冗余。

## 三、情绪时序规则

> 以下模式为参考示例，须根据具体章节的情境和情绪流灵活运用，不可机械套用。

情绪反应必须放在正确的触发点，不能提前也不能延后。

### 标准时序链

```
被暗示有预感 → 愣住 → 第三者摊牌 → 羞耻涌上来 → 手足无措 → 本能看黎恩 → 黎恩挡节奏
```

### 常见错误

| 场景 | 错误写法 | 为什么错 |
|------|---------|---------|
| 第三者刚开口，还没摊牌 | "秘密被看穿的羞耻让她手足无措" | 羞耻提前了——她还没确认对方知道什么 |
| 第三者刚开口 | "她隐隐有点预感，但不知道他要说什么。" | ✅ 正确——有预感但不确定 |

### 不同场景的害羞类型

| 触发源 | 害羞类型 | 典型表现 |
|------|---------|---------|
| 被触碰身体 | 身体羞耻 | 全程闭眼、脸红要哭、指尖发颤、觉得痒/羞耻 |
| 秘密被看穿 | 心理羞耻 | 手足无措、视线不知道该往哪放、完全懵了 |
| 被突然征询意见 | 角色错位羞耻 | "欸？我、我的意见吗？"、愣住才反应过来、耳朵烫 |
| 被越界后告状 | **气愤+委屈复合情绪** | 眼圈红了、委屈得要哭，气愤底下是被冒犯的委屈 |

### 菲娜的情绪层次

菲娜的情绪很少是单一的。以下为参考模式，须根据具体场景灵活调整，不可机械套用：

```
气愤 + 委屈：眼圈红了，委屈得要哭（Ch105）— 被冒犯后向黎恩告状
紧张 + 不安：皱着眉头，有点不安地靠在黎恩肩上（Ch102）— 向黎恩吐槽前
羞耻 + 抗拒：脸红要哭、全程紧闭双眼（Ch103）— 被触碰时
懵逼 + 害羞：完全懵了、本能看黎恩（Ch104）— 被看穿/被问意见时
慌张 + 安静的开心：心跳漏了一拍、不敢看他、有一点开心（Ch106）— 发现黎恩吃醋时
羞耻多于愤怒：耳朵红了、声音有点抖、视线不知道该往哪放（Ch97）— 被抓到偷偷画自己时
害羞 + 大胆提问：问完立刻把脸埋回去、耳朵红透、声音闷在衣服里（Ch118）— 主动问黎恩吃醋后
羞耻 + 被注视：全程闭眼、咬着下唇、黎恩的视线比触碰更烫（Ch140）— 按指示勾引第三者时
教材羞耻 + 微小纠正：被两人注视比被触碰更害羞、轻声纠正后脸烧红（Ch135）— 黎恩教第三者时
执行羞耻 + 锚点确认：闭眼深呼吸才敢碰、全程不敢看对方的脸、先找黎恩的背影确认他在（Ch179/182）— 被安排执行计划时
```

### 阶段3新增模式：娇羞 + 妩媚 + 甜美

菲娜在阶段3与第三者互动时，三种感觉并存：

```
娇羞：耳朵尖烫、脸烧得不敢看对方、声音轻得自己都听不清、说完才意识到自己在分析
妩媚：声音又轻又软像在说悄悄话、长发垂落蹭到手背、指尖轻轻划过、靠近时呼吸拂在锁骨上
甜美：事后蜷进黎恩怀里像猫、蹭胸口、闷闷地说"是你相信我"
```

> 关键判断：妩媚是"做的时候"的感觉，甜美是"做完回到黎恩怀里"的感觉，娇羞贯穿全程。

### "安静的开心"与"觉得好玩"的区别

菲娜可以有正面情绪，关键是表达方式：

| | 错误（觉得好玩） | 正确（安静的开心） |
|---|---|---|
| 面部 | 嘴角弯起来、眼睛亮了、笑了 | 不敢看他、把脸埋起来、没说话 |
| 行为 | 凑近耳边调侃"很可爱"、逗他 | 小心翼翼碰指节、攥紧手指 |
| 对话 | "你的手在握拳。很可爱。" | "你是不是吃醋了"（直接、不绕弯） |
| 情绪底色 | 从容观察、发现秘密的趣味 | 慌张、心跳漏拍、紧张中有一丝暖意 |
| 事后 | 全程带着微笑、是逗他 | 把脸埋进颈窝、声音闷在皮肤上、认真的 |

核心判断标准：**菲娜的开心是安静的、私密的、带着紧张的，不是外显的笑容或调侃。**

> **阶段3例外**：菲娜按黎恩计划主动勾引第三者时（如Ch216白丝之夜），"调皮/得意/心里酥爽"可保留——这是她在执行黎恩的计划，勾引对象是第三者，发现黎恩在窗外吃醋时心里爽是正常的。与阶段1"被推着走"有本质区别。

### 菲娜的许可语气：半推半就，不正式

菲娜对第三者松口/默许时，不应是正式声明（"可以看"），而应是害羞的半推半就：

| | 错误（正式许可） | 正确（害羞松口） |
|---|---|---|
| 措辞 | "可以看。但不能画出来。" | "你爱看就看吧，但是不准画。" |
| 视线 | 侧头看他 | 没有看他，视线落在图纸上 |
| 语气 | 像是在签署协议 | 像是害羞说不出口、半推半就 |
| 用词 | "可以/不能"（规则声明） | "爱看就看/不准"（情绪化、任性） |
| 说完 | 回头加一句评价 | 说完就走，没回头 |

核心判断标准：**菲娜的许可不像是她主动给的——更像是她在害羞中松了口，话从嘴边漏出来的。**

### 菲娜为黎恩做的事：事后确认归属，不从容反问

菲娜按黎恩计划勾引第三者后，对黎恩说的话应是安静的确认归属，不是从容反问：

| | 错误（从容反问） | 正确（害羞确认） |
|---|---|---|
| 对话 | "当然是故意的。好看吗？" | "...是为你穿的。"（埋脸+闷声） |
| 表情 | 仰头看他、嘴角的笑 | 耳尖是粉的、把脸埋进胸口 |
| 事后回味 | 回味那个为黎恩准备的笑 | 把脸埋进他胸口 |

### 菲娜的大胆提问：问完立刻藏起来

菲娜可以问黎恩大胆的问题（"以后还可以再试吗""是吃醋了吗"），但问完必须立刻害羞藏脸。模式：

```
问 → 说完就把脸埋回去，耳朵红透 → 黎恩回答 → 她在他胸口知道了答案
```

这个模式让菲娜既有主动性又不失娇羞——问的时候是认真的，藏的时候是害羞的。

### 时间跨度的真实性

菲娜回味/消化一个重要事件需要时间。不一定要紧接着前一章的当晚。跨几天更自然：
- "黑丝勾引凯尔已经过了几天。这几天她反复想起的，全是黎恩。"

### 第三者的态度变化

第三者不一定永远从容自信。当意识到过火时，态度转变能增加真实感：

```
艾德里安内心："呃，好像玩得太过火了。" → 举起双手，"诚挚地认错"
```

菲娜应该看到这个态度变化再回应："看了一眼诚恳的艾德里安" → 才说"下次再这样就把他踢下去"

## 四、标准改写动作库

> **以下所有库均为参考示例，不可直接机械复制。每条短语都有其适用的具体场景和情绪上下文，须根据当前章节的情境、角色状态和叙事节奏灵活变通使用。**

### 4.1 害羞体征

```
她把脸往他肩上一埋，耳朵尖红了。
她把脸埋进他颈窝，过了一会儿才开口，声音闷闷的。
手不自觉地碰了碰发烫的耳尖。
指尖微微发颤。
停了一下，声音轻下来。
脸红得要哭出来了。
眼圈都红了，委屈得要哭。
全程紧紧闭着眼睛。
耳朵尖烫得自己都感觉到了。
说完才意识到自己在分析，耳朵又烫了。
```

### 4.2 情绪前置（对话前先写）

```
菲娜皱着眉头，有点不安地靠在黎恩肩上。
菲娜没有当场答应。回去后靠着黎恩，把脸往他肩上一埋。
回去的路上菲娜一直没说话。进了木屋，往黎恩肩上一靠，声音闷闷的。
菲娜很慌张地看向黎恩。                           （慌张是早期菲娜的关键情绪词）
她愣了一下。他在吃醋。这个认知让她的心跳漏了一拍。
她没有看他，视线落在图纸上。                       （对第三者松口时，不看他）
```

### 4.3 抗拒动作（对第三者）

```
脚往后退了半步
瞪了他一眼
```

### 4.4 手足无措（秘密被看穿时）

```
视线不知道该往哪放
完全懵了
本能地看向黎恩
```

### 4.5 吐槽+告状（对黎恩抱怨第三者）

```
"他怎么能这样！我又没让他碰..."          （低声吐槽，带着不悦）
"他怎么回事。哪有这样的..."              （懵逼后的抱怨）
"他摸我！"                                （气愤告状，用感叹号）
说完眼圈都红了，委屈得要哭。              （气愤底下的委屈）
"他凭什么不问我？凭什么觉得给我看我就该碰？"（气哭中的质问）
"下次他再这样，你就揍扁他，然后我再揍扁他一次。"（黎恩面前的反击方案，两人一起行动）
```

### 4.5b 对黎恩的直接提问（替代调侃/分析）

菲娜对黎恩说话直接，不绕弯，不调侃：

```
"你是不是吃醋了"              （直接问，替代"你的手在握拳。很可爱。"）
"你躲了？"                    （黎恩的匹配回应）
```

### 4.5c 对第三者的害羞松口（替代正式许可）

菲娜对第三者松口时，话从嘴边漏出来，不像是正式决定：

```
"...你爱看就看吧，但是不准画。"    （半推半就，不看对方眼睛）
"...可以看。但是不能画。"          （正式许可，太从容 — 错误）
说完就走，没回头。                  （松口后不逗留，不等回应）
```

### 4.5d 大胆提问后的立刻害羞（替代从容分析）

## 五、修改流程

```
Step 1  读TXT，逐条过检查清单（26条）
Step 2  定位所有违规点，特别注意情绪时序
Step 3  编辑TXT：
        - 对话统一加中文引号 "..."（内心独白不加）
        - 不得滥用破折号（对话打断"我不该——"和突然意识"等等——"除外）
        - 不得滥用"不是X的Y"冗余否定（"不是酒的热"→直接写"羞的"）
        - 不得滥用"不是A而是B"迂回句式
        - 不得写菲娜对第三者接触的正面/中性评价
Step 4  同步核心/章节任务/章节终止条件
Step 5  等待用户确认后再构建/提交
```

### 不得做的事

- 不得在用户未指示时构建JSON或git commit
- 叙事中不得用破折号（对话打断和突然意识除外）
- 不得让菲娜在阶段1主动发起请求或给许可
- 不得让菲娜微笑/觉得好玩/冷静分析/调侃黎恩（阶段3主动勾引场景除外，如Ch216）
- NTRS场景中不得用"玩"字描述菲娜的行为（"她在里面玩"→"她坐在中间"）
- NTRS场景中菲娜不得对黎恩做"你看"式的得意展示（→改成害羞地寻找黎恩的目光确认他在）
- "安静的开心"（心跳漏拍+不敢看+没有外显笑容）可以保留，与"觉得好玩"有本质区别
- 不得让羞耻等情绪出现在错误的时序点
- 不得使用冗余否定（"不是酒的热"→"羞的"）
- 对话必须有中文引号`"..."`

### 破折号细则

| 场景 | 是否可用 | 示例 |
|------|:--:|------|
| 对话被打断 | ✅ | `"我不该——"菲娜按住他的嘴` |
| 突然意识/转折 | ✅ | `等等——她愣了一下` |
| 叙事连接/解释 | ❌ | `脸烧起来——不是酒的热` → `脸烧了起来。羞的。` |
| 元数据字段（核心/章节任务） | ✅ | 结构性列举可用 |

### 否定句式细则

| 类型 | 判断 | 示例 |
|------|:--:|------|
| 冗余否定（X未被暗示） | ❌ | `在发抖——不是因为冷` → `在发抖。羞的。` |
| 迂回肯定（不是A而是B） | ❌ | `不是得意而是认真` → `用认真反击` |
| 角色对话中的否定 | ✅ | `"不是黎恩。等一下。"` — 这是菲娜在说话，符合口语 |
| 关键区分陈述 | ⚠️ | `"不是演的"` — 口语化表达，可接受 |
| 必要的事实否定 | ✅ | `"暴雨又不是我安排的"` — 反驳黎恩的嫉妒 |

## 六、案例库（新增 v2.1）

### 6.1 Ch200修改案例分析

用户对Ch200（凯尔的再战——从乳到口）做了两处关键改动：

**改动①："口交。" → "口交..."**

| 原 | 改 |
|----|-----|
| `菲娜耳朵尖先红了。口交。她给艾德里安做过一次，被射了满嘴吐了垃圾桶。` | `菲娜耳朵尖先红了。口交...她给艾德里安做过一次，被射了满嘴吐了垃圾桶。` |

**为什么这样改**：句号在"口交"后面太干脆了，像一个陈述句的终结。省略号让"口交"这个词在空气中悬停了一瞬——菲娜听到这个词后迟疑了，想起了上次艾德里安的糟糕经历。省略号承载的是她从"听到"到"行动"之间的犹豫。这不是破折号的解释功能，而是省略号的悬停功能。

> **规则提炼**：菲娜在听到/说出性行为词汇后的迟疑、犹豫、欲言又止，用省略号替代句号。句号=终结断言；省略号=情绪悬停。

**改动②："深蓝眼睛里" → "异色的双瞳里"**

| 原 | 改 |
|----|-----|
| `深蓝眼睛里全是"我刚才经历了什么"` | `异色的双瞳里全是"我刚才经历了什么"` |

**为什么这样改**：凯尔的角色设定是异色瞳（CLAUDE.md明确记载），"深蓝眼睛"是错的。用户注意到了角色特征错误并修正。

> **规则提炼**：修改章节时必须对照CLAUDE.md检查所有出场角色的外貌特征。第三者不是背景板——他们的外貌特征和菲娜/黎恩一样是需要精确维护的设定。

### 6.2 角色特征精确检查（新增）

|------|---------|--------|

### 6.3 核心字段禁剧透（新增）

**核心**、**章节任务**、**章节终止条件**是设计文档字段，不是叙事文本。不得在其中以"为后续...埋下伏笔/做铺垫/直接钩子"形式剧透未来事件。

| 错误（剧透） | 正确（描述本章） |
|------|------|
| "为后续黎恩重新安排乔治埋下直接钩子" | "黎恩在彻夜未眠中做了一个具体的决定" |
| "为第二次低语者做铺垫：菲娜经历了差点失控" | "菲娜经历了差点失控但守住了。黎恩学到了不能丢下她" |
| "为Aldric认出'小不点'埋下伏笔" | "它的眼点闪烁频率和Aldric一模一样，触碰之中有什么在她心里松动了一点点" |
| "为后续事件埋下伏笔" | "拒绝是条件反射，但念头留下来了" |

> **判断标准**：如果一句话的视角在未来（告诉读者"这件事的意义以后会揭晓"），就是剧透。核心应该描述**本章内**发生了什么、角色经历了什么。

### 6.4 碎片句处理（新增）

对话中的碎片短句需要组织成有节奏的完整表达，不能只是罗列：

| 错误（碎片） | 正确（节奏化） |
|------|------|
| `说你。撞。还敢说。撞。` | `"说你。"撞。"还敢说。"又撞。` |
| `不要。哭着推走他。对不起。没有辩解。` | `"不要。"哭着推走他。"对不起。"没有辩解没有但是。` |
| `舒服吗。嗯。想不想别人也进来。` | `"舒服吗。""...嗯。""想不想别人也进来。"` |

> **规则**：①加引号 ②用"又"/"再"等副词串连重复动作 ③保持碎片句的急促感但让读者知道谁在说哪句。

### 6.5 省略号的情感功能（新增）

省略号`...`在中文叙事中有明确的几种情感功能，与破折号不同：

| 功能 | 示例 | 替代 |
|------|------|------|
| 犹豫/迟疑 | `口交...她给艾德里安做过一次` | 不是破折号"口交——"，破折号太快 |
| 欲言又止 | `"...不要。"` | 话到嘴边又缩回去 |
| 声音渐弱 | `"...都怪黎恩。"` | 说完把脸埋起来 |
| 悬停/空白 | `"你刚才..."黎恩没说话。` | 话没说完整，留白 |

> **省略号 vs 破折号**：省略号=迟疑/悬停/渐弱；破折号=打断/突然转折。"口交——她做过一次"是快节奏解释；"口交...她做过一次"是她的迟疑停顿。
