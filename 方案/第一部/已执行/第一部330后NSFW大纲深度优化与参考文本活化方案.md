## 一、 核心痛点诊断：为什么游玩中总是“很快跳过”且“千篇一律”？

在酒馆前端或实际跑团推进过程中，330 章以后的 NSFW 情节普遍存在两大顽疾：**“一晃眼就结束了”** 与 **“换了角色姿势却感觉都差不多”**。深入解构底层大纲，病灶根源在于以下三点：

```
【当前典型单薄结构】
情境 1: 两人独处脱衣/洗漱 ───> 情境 2: 突然插入/套弄并在一句话内直接射精脱力 ───> 情境 3: 环境光影收尾
                                        ▲
                         【信息密度断崖：跳过 80% 心理与感官蓄压】
```

### 1. 单条情境动作跨度过载，导致 LLM 生成“一轮泄洪”
- **现象**：许多章节的 NSFW 核心动作仅占 1 条 bullet（例如 Ch335 第 2 条），却在短短 200 字内塞入了“解开皮绳 ➔ 脚掌贴小腹 ➔ 双足夹住 ➔ 上下套弄 ➔ 射精高潮 ➔ 脱力倒卧”整套流程。
- **后果**：前端模型在读取大纲时，会判定这只是一个“单步事件”，从而在一轮回复中把所有动作快速平铺完毕，玩家根本没有插话、互动或享受推拉拉扯的呼吸空间。

### 2. 严重缺失“声音工程（Acoustic Texture）”
- 大多数章节在亲密接触时，仅有“粗重喘息”、“轻哼”等泛化词汇，缺少：
  - 险境/第三者临场下的**极致气声压抑与窒息式忍耐**；
  - 牙关紧咬、咽口水喉结滚动、破折号截断的断续呻吟；
  - 唾液、爱液、布料丝线挤压摩擦产生的**微观声响**；
  - 贴在耳廓旁、带着微湿热气的短促呢喃。

### 3. 缺乏“受迫体态”与“自欺/心理撕裂”，沦为机械活塞
- 动作千篇一律：足交多为“脚心贴脸→足弓磨茎”，口交多为“含住→吞吐→内射”，本番多为“抱起→穿刺→顶撞”。
- 缺少角色的**重心失衡、无处借力、身体拘束**；缺少“嘴上辩解/迟疑，身体却在高温与摩擦中本能战栗”的**知行错位**；缺少角色性格的专属温度（如艾玛的知性宠溺、亚莉莎的傲娇慌乱、菲娜的狡黠掌控、劳拉的庄重侍奉）。

## 二、 核心重构策略：单薄条目“微创裂变法”

为了兼顾叙事安全与彻底解决痛点，**全案坚决不搞全章推倒重写，统一执行“精准微创裂变”**：

1. **绝对保真地基（70% 既有资产 100% 完整保留，只增不减，零信息删减）**：
   - **零删减死刑线**：严禁自以为是地删除或简写原文任何已有句子、台词伏笔（如角色提及既往事件、剧情承接等关键语句）、人物心理与既有对话；
   - **元数据 100% 保真**：`第三者`、`黎恩知情`（严禁裁剪破折号后的对练观察、事后交代等珍贵细节说明）、`占有欲确认`、`好感影响` 必须完整继承原文已有字句，严禁随意擅改；
   - **起因铺垫与物象收束原样锚定**：前置相遇、交谈铺垫与末尾环境物象收束（如转轴光泽、月光微澜、湿痕风干等闭合锚点）必须一字不漏完整保留，严禁擅自吞并或删去；
   - **坚决禁止通篇洗稿**：未被划为单薄动作的铺垫条目严禁顺带改词、改标点或重写，确保 Git Diff 清晰精准呈现微创切片，严禁把整章重写。
2. **靶向手术切除与裂变（30% 痛点重塑）**：
   - 精准定位把亲密动作一笔带过、导致游戏过快跳过的**那一条单薄 bullet**；
   - 原 bullet 中包含的既有体位、对白与动作信息必须 100% 完整吸收，绝不可丢失；在此基础上原地拆解并扩充裂变为 **2～3 条层次分明的慢推阶梯**：
     * **阶梯 A（边缘解构与试探）**：衣料局部解开、介质试探、测温游走，建立游戏第 1 个推拉气口；
     * **阶梯 B（声学压抑与攻防拉扯）**：第三者临场压迫、贴耳耳语、微言语攻防、身体与理智的知行撕裂，建立游戏第 2 个交互气口；
     * **阶梯 C（临界突破与生理宣泄）**：动作受迫加剧、极细抽气、最真实的生理释放与体温余韵。
3. **技术合规同步**：
   - 相应更新 `总情境数`（与下方实际情境总数严格一致）；
   - 微调 `核心` 摘要，保持无破折号与无古风词。
4. **实体档案严查回检（零设定硬伤）**：
   - 每次大纲撰写与微创裂变完成后、写入文件前，**必须对照 `docs/` 第一部实体档案（`docs/character/` 与 `docs/npc/`）全量检查一遍**：
     * 核验角色外貌数据（发色、瞳色、身形罩杯、专属体香、常驻武器与服装）；
     * 严查出场人物指代与姓名（严禁出现档案库中不存在的虚构角色或错别字，严格对齐正式档案实体）；
     * 核验场域建筑声学结构（石窟、书房隔板盲区、祖地温泉等），彻底排查一切设定冲突与常识错误。
5. **生殖器官自然真实表述（拒绝避讳脱戏·严禁机械误杀）**：
   - **杜绝文雅避讳与别扭代称**：严禁在涉性情境中因避讳洁癖而把原本生动真实的器官描写误杀替换为“肉棱”、“硬物”、“阳具”、“器具”、“那家伙”等出戏代称；此类词汇会严重钝化感官张力，破坏真实感官冲击；
   - **直球自然、多元丰满的感官描写**：大方、自然使用“**肉棒**”、“**鸡巴**”等原生直球名词，但**绝非机械死板地仅限定此二词**；倡导结合具体生理部位与触觉特征进行自然、丰富、具象的刻画（如“粗长滚烫的肉棒”、“发烫挺立的茎身”、“圆钝硕大的龟头”、“嵌在足弓间的柱身”、“渗出前液的顶端冠状沟”、“深色粗硕的巨根”等），让词汇随动作节奏自然流动；
   - **严防审查洁癖与机械一刀切**：审校与微创裂变时必须紧密结合具体语境，既要彻底扫除强行遮掩的避讳词，更要严防机械批处理导致的误杀与词汇单一堆砌，确保 JRPG 与日轻西幻情色原生态的丰富性、动态感与真实触觉冲击。
