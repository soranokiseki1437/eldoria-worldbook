## 一、核心原则

### 1.0 不变底色：娇羞 + 妩媚 + 甜美（最高优先级）

无论阶段如何演进，**娇羞+妩媚+甜美始终是菲娜的底色**。享受和掌控是叠加层，底色不可覆盖。她可以一边主动骑上去掌控节奏，一边耳朵尖红透。她可以一边命令第三者"不准自作主张"，一边事后蜷进黎恩怀里闷闷说话。

```
娇羞：耳朵尖烫、声音轻、脸烧得不敢看对方、被夸时偏开视线、事后把脸埋进黎恩颈窝
妩媚：长发垂落、声音又轻又软、指尖轻轻划过、回头看黎恩时脆弱又妩媚
甜美：事后蜷进黎恩怀里像猫、闷闷地说话、手在被子下攥他的手指、撒娇的波浪号
```

> **铁律**：如果一章里菲娜没有害羞体征、没有妩媚质感、没有甜美回归，那就是写偏了。享受和掌控写得再好，底色丢了就是废章。

#### 三色自检（每次修改后必过）

随机抽取菲娜在场景中任意三处——事前/事中/事后各一处。每一处必须至少命中一个底色：

| 时刻 | 娇羞 | 妩媚 | 甜美 |
|------|:--:|:--:|:--:|
| 事前（决定/准备阶段） | 耳尖烫、声音轻、偏开视线 | 长发垂落、指尖轻触 | 对黎恩的撒娇或嗔怪 |
| 事中（性行为中） | 脸红到脖子、不敢看对方、咬唇 | 回头看黎恩的表情 | — |
| 事后（回归黎恩） | 把脸埋进他胸口 | 指尖在他手心里画圈 | 蜷进去像猫、闷闷说话 |

> 三格全部为空 → 底色丢失 → 重写。只有一格有内容 → 底色不够 → 补。

#### 常见底色丢失模式

| 模式 | 表现 | 根因 |
|------|------|------|
| **放纵型** | 菲娜全程从容主导、享受快感、事后潇洒走人。没有任何脸红、偏头、蜷缩。 | 把"掌控"写成了"老练"。她不是老练——她是脸红着掌控。 |
| **自恋型** | 菲娜站在镜前欣赏自己的身体，数着广场上几个男人为她掉了笔。 | 把"享受被想要"写成了"炫耀自己的吸引力"。享受被想要时应有害羞伴随。 |
| **冷酷型** | 菲娜冷脸命令、施压沉默、走人关门。全程只有掌控，没有妩媚甜美。 | 把"抓包报复"写成了公事公办。她撇嘴之后应有甜美回归黎恩。 |

#### 害羞是底色，不再阻碍行动

阶段4的害羞让菲娜无法回应、无法点头、沉默逃避。阶段5的害羞**依然存在，但不再阻止她行动**。

```
阶段4：被问"疼？"→ "......"（沉默）→ 害羞到无法回应
阶段5：被问"疼？"→ 耳尖红了，但摇头："不疼。"→ 害羞但能表达
```

> 判断标准：菲娜在任何场景中都应有娇羞体征，但她不再因为害羞而停下。她可以脸红着主动，可以耳朵烫着命令。

**阶段5的正确张力：大胆动作 + 撒娇尾音同时发生**

阶段5最容易翻车的不是害羞太少，而是害羞和掌控出现在错误的时序——先害羞，然后切到掌控模式。正确的做法是两者在同一拍上：

```
错误：她张开大腿。然后害羞地说："过来陪陪我。"
正确：她红着脸张开大腿。"过来陪陪我嘛。"
```

"张开大腿"是掌控/暴露，"嘛"是娇羞/撒娇。两者同时——大胆动作被软尾音收住，害羞被动作撑开。张力不在切换中产生，在重叠中产生。

#### 事后甜美回归黎恩（不可省略）

阶段5的回归不是"跑回黎恩旁边"（阶段4模式），而是**与黎恩分享体验并甜美落点**。

```
阶段4：事后脸红红地赶紧跑了，想赶快回到黎恩旁边
阶段5：事后回到黎恩身边，靠在他肩上，把体验说给他听——眼角带着她还不太习惯的、狡黠的光。然后蜷进去，像猫。
```

> 如果一章的最后一个场景不是菲娜在黎恩怀里（或等价的身体接触），检查是否遗漏了甜美回归。

### 1.1 阶段5叠加层：享受 + 掌控

核心行动链：

```
自主决定 → 从容执行 → 享受过程 → 事后回归 → 与黎恩分享
```

- **自主决定**：菲娜自己选择对象、时机、方式。不需要黎恩安排或第三者推动。
- **从容执行**：有害羞体征但不紧张。手不抖了，呼吸不碎了——取而代之的是有节奏的、享受的投入。
- **享受过程**：菲娜开始从共享本身获得快感。"看着一个男人为自己失控是会上瘾的"——这是阶段5的宣言。
- **事后回归**：回到黎恩身边，蜷进去。不是"确认归属"（阶段4的焦虑需求），而是"分享战利品"。
- **与黎恩分享**：她把体验告诉他——细节、感受、评价。黎恩是她的共鸣板，不是她的安全绳。

#### 菲娜的掌控模式

阶段5的菲娜用**行动而非言语**掌控局面。

```
- 主动选择体位：她跨坐上去，自己定节奏
- 设定条件："不能射里面""射哪里"——她说了算
- 事后追责：第二天去找第三者生气、不准自作主张
- 比较评价："虽然比不上你，但是比凯尔和雷恩好多了"——她有权评判
```

> 菲娜的掌控不是冷酷的支配，是妩媚的、害羞的、但不容商量的。她红着脸命令，声音很轻但每个字都清楚。

## 三、阶段5标志性场景模式

### 3.1 自主选择场景

```
1. 酝酿：阶段4积累→菲娜心里有了人选。不需要黎恩安排。
2. 告知：她站到黎恩面前面对面。脸红但眼神不躲。"我想今天。和XX。"
3. 黎恩反应：吃醋但点头。"我不在。我在外面等。"
4. 执行：菲娜自己走向第三者的房间。
5. 回归：事后黎恩在外面等她。拉近，收紧手臂。"他比我还会让你舒服？"
6. 分享：她在他胸口回答。诚实、比较、最终落回黎恩。
```

### 3.2 掌控式性爱场景

```
1. 菲娜主导体位：她跨坐上去，自己定节奏。或她推他胸口调整深度。
2. 设定边界：射精前她捧住他的脸推远——"不能射里面。""射哪里。"
3. 享受快感：她不再咬牙忍耐。叫出声、呜咽、高潮——声音大到她自己都脸红。
4. 事后追责：第二天找到第三者。"不准再自作主张。"声音不高但第三者说了十七遍对不起。
```

### 3.3 远程许可场景（黎恩不在场）

```
1. 被困：外部环境（暴雨/任务）将菲娜与第三者锁在一起。
2. 层层磨薄：第三者进攻、菲娜拒绝、黎恩远程许可——防线在黎恩的许可下一层层松开。
3. 确认黎恩：插入前菲娜坚持视频确认。"我还没得到黎恩的同意。"
4. 执行：得到许可后菲娜享受。黎恩在屏幕那端注视。
5. 次日回收：黎恩推门，第三者识趣锁门。黎恩重新占有——用身体覆盖痕迹。
6. 评价：回去路上菲娜给出排名。"虽然比不上你，但是比XX好多了。"
```

### 3.4 黎恩回收仪式（阶段5版）

```
1. 场景：第三者离开后或次日清晨。她的身体还残留着别人的触感。
2. 回收：黎恩从背后/上面插入——角度是他自己的，深度是只有他知道的。
3. 覆盖：用他的精液覆盖——"比平时更硬"，龟头抵住子宫口。
4. 她在插入瞬间高潮：阶段4是"确认归属"，阶段5是"身体以最直接的方式承认了归属"。
5. 她在他身下叫——连续的，放开的，没有压抑。和共享时不一样：眼睛全程睁着看黎恩。
6. 事后：她蜷在他怀里。给出评价——黎恩永远是第一。
```

### 3.5 吃醋微弧（阶段5版）

```
1. 菲娜吃醋："你知道我会吃醋。""知道。""知道你还选。"
2. 黎恩吃醋："下次，不准自己选人。""你上次说过了。""这次是认真的。"
3. 她在他胸口笑："最吃醋？""最。"
——吃醋是双向的、被承认的、落回幽默的。阶段5的吃醋不是焦虑，是占有欲的日常表达。
```

### 3.6 抓包报复场景（Ch274模板）

```
1. 触发：弯腰/肢体动作→第三者偷看→被抓到。
2. 害羞→不满：先自己脸红，随即意识到他在偷看。不满升起——上次也是，这次又是。
3. 不满翻面：偷看也就罢了，还不敢承认。每次装着一副规矩的样子——指控是具体的、指向伪善的，不是抽象感慨。
4. 抓包：转身、双手交叠、冷脸质问。语言简洁——"你刚才在看哪里？"
5. 施压：沉默盯着他，盯到他冒汗。不提后果，后果在沉默里自己长大。
6. 提条件：条件内容留白——"还没想好。等我想好了，不管你愿不愿意，你都得做。"空白支票比指定条款有张力。
7. 收尾：走人。走廊里撇了撇嘴——活该。两个字收掉全部情绪。
8. 晚上告知黎恩→被安抚→气消了。干净落点，不留神秘感。
```

## 四、标点符号细则

### 4.1 破折号：按场景和POV区分

| 场景 | 破折号策略 | 示例 |
|------|------|------|
| **菲娜的害羞/掌控场景** | 最小化。用逗号串联，省略号表示犹豫 | `她生气了，瞪着他，不说话。` |
| **黎恩的回收/占有场景** | 破折号=重音符号 | `他蹲下来——一只手撑在她耳边的毛皮上。` |
| **对话中的打断** | 保留破折号 | `"如果他没有停——"她没说完。` |
| **菲娜的因果自白** | 破折号连接因果 | `"他让我很舒服——是因为你知道怎么碰我。"` |

### 4.2 对话标签与对话内部：逗号 vs 句号

| 位置 | 标点 | 示例 |
|------|:--:|------|
| 话未完，标签插入 | `，"` | `"他没有进去，"黎恩说。"但他可以。"` |
| 话完整，标签在后 | `。"` | `"...我知道。"她的声音哑了。` |
| 标签带情绪修饰 | `："` | `她不悦地说："...我知道。"` |

**对话内部逗号串联**：对话内短句之间用逗号，不用句号切断。

| 错误 | 正确 |
|------|------|
| `"没事。你继续。"` | `"没事，你继续。"` |
| `"进来。床冷。"` | `"进来，床冷。"` |

### 4.3 省略号：菲娜的自我谈判（阶段5减少）

阶段5的菲娜不再需要漫长的自我谈判。省略号使用频率降低。

| 类型 | 形式 | 阶段5使用 | 说明 |
|------|------|:--:|------|
| 犹豫 | `...` | 保留 | 语流中断，但比阶段4少 |
| 结巴 | `...` + 重复 | 减少 | 阶段5菲娜说话更完整 |
| 沉默 | `......` | 极少 | 阶段5她不再用沉默代替回答 |
| 嗔怪 | `....` | 保留 | 撒娇时声音渐弱 |

### 4.4 长句逗号串联 vs 碎片句

逗号串联的是**同一股情绪流/思维流/动作流**中的连续状态变化。不是所有句号都要改逗号——场景切换、人物切换、动作节拍切换时句号保留。

**基础碎片合并**：

| 错误（碎片） | 正确（逗号串联） |
|------|------|
| `她生气了。瞪着他。不说话。` | `她生气了，瞪着他，不说话。` |
| `一下。两下。节奏不快。` | `一下、两下，节奏不快。` |

**身体感知 + 生理反应（同一股情绪流）**：

| 错误（切断） | 正确（串联） | 规则 |
|------|------|------|
| `意识到姿势在他眼里是什么样子。热度从锁骨涌上耳尖。` | `意识到姿势在他眼里是什么样子，热度从锁骨涌上耳尖。` | 认知→身体反应，不间断 |
| `听到导力器那边传来声音。耳尖红了。` | `听到导力器那边传来声音，耳尖红了。` | 同上 |

**观察 + 推理（同一股思维流）**：

| 错误（切断） | 正确（串联） |
|------|------|
| `他在躲她的视线。那就是刚才确实在偷看。` | `他在躲她的视线，那就是刚才确实在偷看。` |

**动作 + 身体姿态（同一个连续动作）**：

| 错误（切断） | 正确（串联） |
|------|------|
| `她转过身面对他。双手交叠在胸前。` | `她转过身面对他，双手交叠在胸前。` |

**表情 + 目光/声音（同一个冷脸/害羞姿态）**：

| 错误（切断） | 正确（串联） |
|------|------|
| `菲娜没笑。琥珀色眼睛盯着他。` | `菲娜没笑，琥珀色眼睛盯着他。` |
| `她捡起笔站起来。没看他。耳尖还是红的。` | `她捡起笔站起来。没看他，耳尖还是红的。` |

**动作 + 延续（同一个过程）**：

| 错误（切断） | 正确（串联） |
|------|------|
| `菲娜看着他。沉默了很长一会儿。` | `菲娜看着他，沉默了很长一会儿。` |

> **判断标准**：如果两个句子描述的是同一个人在同一瞬间的连续状态（感知→反应、观察→推理、动作→姿态、表情→目光、动作→延续），逗号串联。如果是场景切换、人物切换、或前后两个独立动作节拍，句号保留。

### 4.5 波浪号~ + "啦"：菲娜的撒娇甜美标记

波浪号表示尾音上扬的轻软感。**只在菲娜的撒娇/甜美时刻使用**。

| 场景 | 不用波浪号 | 用波浪号 |
|------|------|------|
| 事后留宿 | `"今晚。我在这里睡。"` | `"今晚我在这里睡~"` |
| 拒绝黎恩来接 | `"不用。"` | `"不用啦黎恩"` |

> "啦"+人名（`"不用啦黎恩"`）— 不加逗号，形成亲昵的呼唤+陈述一体感。

### 4.6 问句用问号

| 错误 | 正确 |
|------|------|
| `"多尔金呢。"` | `"多尔金呢？"` |
| `"你知道我现在在做什么吗。"` | `"你知道我现在在做什么吗？"` |

### 4.7 感叹号替代破折号表达惊呼

| 错误 | 正确 |
|------|------|
| `"你——不是说了不能——"` | `"你！不是说了不能——"` |

### 4.8 菲娜场景的连续话语：破折号→逗号

菲娜的连续话语中——无论是慌乱时的喊叫还是冷脸时的质问——中间用逗号串联。破折号只保留在句末（真正的"被打断/没说完"）或黎恩的回收场景。

| 错误 | 正确 | 场景 |
|------|------|------|
| `"你是不是要射了——不能射里面，快拔出来——"` | `"你是不是要射了，不能射里面，快拔出来——"` | 慌乱 |
| `"上次在贮藏室我就说过——不准再自作主张。偷看也算。"` | `"上次在贮藏室我就说过，不准再自作主张，偷看也算。"` | 冷脸质问 |
| `这次没滚远——他弯腰去捡的时候...` | `这次没滚远，他弯腰去捡的时候...` | 叙述承接 |

> 菲娜场景中，破折号是中断符——只有在真正被打断、被吞掉、或语流骤然停止时才用。其他情况一律逗号。

### 4.9 拟声词的标点

```
"她抬起手狠狠拍在他后脑勺上——啪，声音很脆。"
  ──动作──  ──破折号引入──  ──逗号接描述──
```

### 4.10 撇嘴：不满翻面后的收尾表情

撇嘴 = 嘴角往下轻撇，一瞬即逝。携带的情绪：不满刚消 + 得意刚来 + 不屑残留。

| 场景 | 撇嘴 | 嘴角弯 |
|------|------|------|
| 情绪 | 活该/解气/不服 | 甜美/得意/撒娇 |
| 用法 | 动作完成后（"撇了撇嘴，活该"）或说话时（"撇着嘴说"） | 对黎恩的私密甜笑、事后蜷在他怀里的弧度 |

> 撇嘴是阶段5的新表情——菲娜不再只是害羞或甜美，她可以不屑。但这种不屑持续不超过一秒，随即被其他情绪覆盖。

### 4.11 内心独白：具体指控 > 抽象感慨

菲娜的不满必须指向具体行为，不是抽象感慨。

| 错误（抽象） | 正确（具体） |
|------|------|
| `被一个弯腰就搞成这样的男人，到底在紧张什么` | `每次装着一副规矩的样子，结果做的事一次比一次过分` |

> 抽象的内心独白让菲娜听起来像旁观者。具体的指控让她是当事人——她在控诉一个她认识的人，不是在感慨人性。

### 4.12 收尾落点：干净 > 神秘

阶段5的情绪落点要直接。不要让黎恩问"你在想什么"而她笑而不答——那是阶段4的暧昧。阶段5她气消了就是消了，被安抚了就是安抚了。

| 错误（留神秘感） | 正确（干净落点） |
|------|------|
| `你在想什么。她没回答。但嘴角那个弧度还在` | `黎恩安抚了一下菲娜，菲娜憋着的气也消了` |

## 五、阶段差异速查

| 维度 | 阶段4（跨线） | 阶段5（享受和掌控） |
|------|------|------|
| **叠加层** | 决心+紧张+依赖 | **享受+掌控** |
| **主动性** | 菲娜自己决定跨线，但需要黎恩在场 | 菲娜自己选择对象/时机/方式，可独立行动 |
| **黎恩位置** | 在房间内，视线范围内 | 可远程/事后回收。他在或不在，她都能做 |
| **害羞模式** | 全场景链路：结巴→沉默不理人→跑回黎恩 | **底色不阻碍**：脸红着主动，耳尖烫着命令 |
| **跨线确认** | 转头看黎恩→黎恩点头→转回去闭眼 | 视频确认黎恩同意即可，或事后告知 |
| **事后模式** | 跑回黎恩怀里确认归属 | 回到黎恩身边**分享体验**——细节、感受、排名 |
| **微笑规则** | 对第三者不笑 | 可以有掌控性调笑（支配姿态），社交微笑仍禁止 |
| **省略号密度** | 高——大量犹豫/结巴/沉默 | 中等——犹豫保留，沉默显著减少 |
| **黎恩角色** | 确认者/救场者 | **回收者/享受者**：他享受她的共享，事后用身体覆盖 |
| **核心情绪** | 紧张但信任 | **享受且掌控** |

## 六、修改流程

```
Step 1  读TXT，判断该章属于阶段4还是阶段5（以菲娜的行为模式为准）
Step 2  定位违规点：情感层/动作层/语言层/标点/黎恩角色层
Step 3  编辑TXT：
        - 害羞是底色不阻碍——不能没有害羞，也不能害羞到停摆
        - 菲娜至少有一个环节是她定的
        - 破折号按POV区分——菲娜场景逗号串联
        - 对话内部短句用逗号，不用句号切断
        - 阶段5省略号减少——"......"沉默只在极罕见的时刻出现
        - 事后必须有与黎恩的分享和回收
        - 黎恩的回收是用身体的——不能只是聊天
        - 菲娜可以有评价性比较（"比XX好"），但不能有过程比较（"和上次一样"）
        - 删诗意环境收尾——动作本身已传达状态
        - 检查情绪一致性——享受和掌控是底色，羞耻是底色，两者不矛盾
Step 4  同步核心/章节任务/章节终止条件
Step 5  等待用户确认后再构建/提交
```

### 常见修改陷阱

| # | 陷阱 | 说明 |
|---|------|------|
| 1 | **底色丢失：娇羞妩媚甜美被掌控覆盖** | 最常见的阶段5翻车模式。三种子类型：**放纵型**（全程从容享受无害羞）/**自恋型**（欣赏自己的身体、数男人掉了多少笔）/**冷酷型**（冷脸命令走人关门无妩媚甜美）。根因：把"享受+掌控"写成了"老练+放纵/炫耀/公事公办"。补救：事前补害羞体征、事中补妩媚画面、事后补甜美蜷缩在黎恩怀里——三者缺一不可。 |
| 2 | 害羞过度阻碍行动 | 反向陷阱——把阶段5写回阶段4。菲娜不再因为害羞而停下。 |
| 4 | 只改正文忘了改元数据 | 核心/任务/条件可能残留阶段4的表述。 |
| 5 | 诗意环境收尾 | "窗外的灰蓝变成了淡金。她睡着了。"→删。动作本身传达状态。 |
| 6 | 黎恩只是旁观者 | 阶段5的黎恩是参与者——回收是身体的，兴奋是真实的。 |
| 7 | 忘记事后分享 | 阶段5菲娜不再"赶紧跑回黎恩旁边"——她走回来，靠在他肩上，把体验说给他听。 |
| 8 | 碎片句合并不彻底 | "嘴张开又合上。合上又张开。"→"嘴张了又合，合了又张。" |
| 9 | 元数据冗长松散 | 用排比句收束。每个短句一个事实，不铺陈。 |
| 10 | 菲娜的享受写成被动沦陷 | 她享受是因为她在掌控——不是被征服，是主动沉浸。 |
| 11 | "不是...是..."句式残留 | 阶段5菲娜不自我辩解。不满直接指向对方行为："偷看也就罢了，还不敢承认"——不出现"不是"和"是"。 |
| 12 | 冗余心理步骤 | "盯着屏幕上的数据，没在看数字"——"盯着"已经传达了。删掉解释性半句。 |
| 13 | 收尾留神秘感 | 黎恩"你在想什么"→她没回答但嘴角弧度还在 → 阶段4的暧昧。阶段5收尾直接：安抚→气消了。干净落点。 |
| 14 | 条件内容太具体 | "以后弯腰时不准移开视线"→太具体。留白更好："还没想好，等我想好了你都得做"——空白支票比指定条款有张力。 |
| 15 | 内心独白用抽象感慨 | "被一个弯腰就搞成这样的男人"→旁观者语气。改为具体指控："每次装着一副规矩的样子，做的事一次比一次过分。" |
| 16 | 啰嗦重复（同一信息说两遍） | "高潮来的时候她没有压声音，压不住"→"压不住"已包含"没有压"。改为"高潮来的时候她压不住声音。" |
| 17 | 过度解释（读者已知的信息） | "她在想什么——她在想他们看到她时的样子"→上下文已明。删除整句。 |
| 18 | 啰嗦视觉描述（动作堆砌） | "看了她一眼，又看了裙子一眼"→一眼就够。"黎恩进门停了一步。新裙子。" |
| 19 | 断句（碎片句未合并） | "艾玛寄的。好看吗。"→"艾玛寄的，好看吗？"逗号串联，加问号。 |
| 20 | 概括失实（强行上位词） | "三个人的笔都掉了"→凯尔掉的是试管不是笔，艾德里安是烟没点着。直接列举具体事物，不强行概括。 |
| 21 | 菲娜写成全知导演 | "一半是因为黎恩在门外"→她不知道黎恩到了没有，只知道"应该快到门外了"。设计隐奸游戏时她是在估算时机，不是在监控画面。用"应该""大概"标示她的知识边界。 |

### 不得做的事

- 不得让菲娜全程被动没有任何掌控行为
- 不得让害羞完全消失
- 不得让害羞阻碍菲娜行动（退回阶段4模式）
- 不得在核心中剧透后续章节
- 不得使用冗余否定（"不是...是..."）
- 不得用抽象感慨代替具体指控
- 不得用抽象词替代具体动作
- 不得让菲娜进行过程比较（"和上次一样""比上次更"）
- 不得让黎恩只是被动观看——他必须回收
- 不得让事后回归变成阶段4的"确认归属"焦虑——改为"分享体验"
- 不得让菲娜的享受变成被征服——她始终是掌控者
- 不得在收尾处留神秘感——情绪落点要干净
- 不得把条件内容写死——空白支票比指定条款有张力
- 不得写冗余心理步骤——动作已传达状态，删掉解释性半句
- 不得用上位词强行概括不同事物——直接列举，不造假
- 不得堆砌视觉动作——看一眼就够，不写"看了一眼又看了一眼"

### 写作完成后即时扫描

写完一章后，逐句过以下五问：

| # | 扫描项 | 自查问句 | 示例 |
|---|--------|------|------|
| 1 | 不是而是 | 句子里有"不是"吗？ | `不是不想，是腿软了` → `腿软了` |
| 2 | 啰嗦重复 | 前后两个词在说同一件事吗？ | `没有压声音，压不住` → `压不住声音` |
| 3 | 过度解释 | 删掉这一句，读者还能从上下文知道吗？ | `她在想什么——她在想他们...` → 删除 |
| 4 | 断句 | 两个短句中间能用逗号连起来吗？ | `艾玛寄的。好看吗。` → `"艾玛寄的，好看吗？"` |
| 5 | 概括失实 | 概括词覆盖了所有被列举的东西吗？ | `三个人的笔` → 试管和烟不是笔 → 直接列举 |
| 6 | 引号遗漏 | 所有对话都有中文引号吗？ | 写新章最容易忘——脑中听到对话就直接落笔，忘了加引号。写完后grep `："` 确认每处对话标签后都有引号。 |
| 7 | 菲娜全知 | 菲娜的判断里用了"在""到了"还是"应该""大概"？ | 她不是导演看着监视器。设计隐奸时她只知道约好的时间点，不知道黎恩是否准时到。用"应该快到"而非"在"。 |
