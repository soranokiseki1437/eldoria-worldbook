## 一、 执行机制

当用户要求继续推进第一部审读时：

1. **读取看板**：查阅 [`第一部大纲读者审读_总进度看板.md`](第一部大纲读者审读_总进度看板.md)，锁定首个处于 `⏳ 待执行` 的断点批次；
2. **定位大纲**：根据批次章节区间，读取 `docs/story/` 下对应的 20 篇 `.TXT` 文件；
3. 自由探索章节跳过；
4. **档案核对与逻辑审读**：对照 `docs/` 设定档案与本指南审查准则，在 IDE 内对其余主线、支线及 NSFW 章节进行审读；
   - **前文脉络与伏笔检索铁律**：审读中凡遇到跨章节的情节指涉、未明前因或角色心理伏笔时，**严禁凭空主观断言“缺乏前因/逻辑断层”**，必须首先检索 `docs/story/` 前文对应章节，核实是否为前文已埋下的伏笔或呼应。若前文已有严密铺垫，属于合规呼应，予以保留；
5. **生成建议方案**：将有修改意见的章节写入 `方案/第一部/读者审读建议_批次XX_ChAAA-ChBBB.md`；
6. **更新看板**：将看板中对应批次标记为 `✅ 已完成` 并更新成果链接与新断点。

## 二、 审读核心准则

### 1. 结构与大纲定位
* **大纲属性**：所有 `.TXT` 章节均为结构化情境大纲。审读仅针对逻辑漏洞、人设偏差与情节断层提出修改建议，无需逐条重写每个具体情境，严禁给出“为xx埋下伏笔”等解释；
* **精简原则**：无修改意见的合格章节绝对不写入方案，全篇仅保留需要修改的章节。**严禁在方案文档头部罗列“合格免修章节”或“自由探索跳过”**（审读免修与跳过记录仅在聊天汇报中口头提及，方案文档本体必须100%与模板保持一致，保持纯粹干净）；**严禁在修改建议中编写“全力保护/决定保留/完整保护”等合格内容废话**（修改建议只写具体问题对应的修改动作与改动内容，严禁复述和赞赏决定保留的合格情节）；
* 自由探索章节直接跳过不审；
* 占有欲确认等字段可以留空。

### 2. docs 设定档案核对体系
审读时以 `docs/` 设定档案为第一基准，按以下顺序对照：
1. **人物性格档案（`docs/character/`）**：核对角色性格神韵、台词声线、身心羁绊与行为逻辑；
2. **阶段系统（`docs/chapter/_阶段系统.TXT`）**：核对章节所属阶段、当前关系的推进界限与行为等级（注：阶段系统专门用于管理和约束第三者 NTR/NTS 接触深度与行为递进；黎恩与菲娜正牌伴侣间的纯爱 NSFW 互动以及噩梦/心魔潜意识投射不受此阶段限制）；
3. **生物与魔兽档案（`docs/creature/` 与 `docs/npc/`）**：核对外貌生理、攻击方式、弱点与消散特性；
4. **场景与建筑档案（`docs/location/`）**：核对空间结构、距离与私密性；
5. **魔法与能量体系（`docs/magic/`）**：核对圣光、鬼之力与腐化的相互作用机制。

### 3. 题材属性与 NSFW 直白语言定锚（严禁过度洁癖误判）
* **题材属性与情趣动因**：本作属于**绿帽向/NTS背德情趣成人西幻作品**。黎恩与菲娜基于绝对信任与爱意设立了“背德情趣共享与安全试探”（`_背德与越界心理.TXT`）。黎恩主动安排、默许或试探菲娜与他人的接触，属于核心情趣约定与心理试探；
* **直白语言与台词规范**：成人情爱情境必须使用直白、具有动作抓力与真实刺激感的成人词汇与口语对白，只要符合角色当下性格与粗粝或放浪情境，完全成立；`lexicon.md` 杜绝的是中式修真与明清艳情黑话，绝非禁止直白直接的成人描写；
* **角色真实对白保真**：生动对白，属于成人作品核心张力，必须完整保留。

### 4. 剧情逻辑与动机构建审查

#### 亲密与 NSFW 章节审查（叙事动力学拷问）
* **动机构建铁律（严禁无由发情与机械发车）**：
  - 严禁出现缺乏前置铺垫、脱离角色心智与人设、或无端陷入亲密关系的机械发车；
  - 角色切入亲密氛围，必须具备扎实的戏剧动力学支撑，严格归属于以下两类合法动因之一：
    1. **现场客观诱发与感官引信（外部火星点燃）**：
       - **物理空间阻隔与偶发契机**：依托封闭地形、环境避险、身体失衡或非故意的物理触碰引发距离骤缩；
       - **形体魅力与感官视觉冲击**：特定体态曲线、意外的衣衫不整、体温或体香对理智产生瞬间冲击；
       - **逼仄私密与特定氛围催化**：独处空间、封闭压迫感或外部环境声光对情绪的发酵；
       - **既有压力或生理诉求的具象引爆**：角色即便身负长期生理需求或心理压抑，亦绝不可凭空爆发，必须由具体的偶发事件或感官火星作为临界点火器；
       - **亲密关系的生理惯性与身体记忆**：处于关系深化阶段时，既往越界经历形成的身体记忆在特定互动下被本能唤醒；
    2. **主观前置筹划与深层心理诉求（内部动机驱动）**：
       - **正配情感试探与背德情趣编排**：基于深层信任建立的主权确认、情趣共谋与安全边界探索；
       - **心结解构、尊严代偿与主动报备**：为化解伴侣特定隐秘心结、实现心理代偿或抚平失衡情绪而展开的理性权衡与主动选择。
  - **判定基准**：凡未具备上述动力学引信支撑、缺乏心理与物理递进便突兀展开亲密互动的章节，一律定性为动机构建重大缺陷，必须增补完备的前因脉络。
* **逻辑审读三原则**：
  - **契机自洽**：行为发生的时间节点必须具备不可替代的现场契机；
  - **人设保真**：各方言行举止必须与其阶层背景、行事智商及性格基底高度吻合；
  - **心理闭环**：正配伴侣的心智逻辑必须自洽，心理层面的试探、默许、接纳与事后回收必须具备清晰的情感桥梁。
* **物理空间与动线闭环**：
  - 严格核验现场空间的声学隔离、视野遮蔽与同伴活动动线，杜绝众目睽睽下的真空穿帮；
  - 亲密接触必须具备眼神、呼吸节奏与肢体试探等层层递进的微动作过渡，杜绝突兀跳跃。

#### 常规剧情与大事件审查
* **核心承诺兑现**：核心字段列明的情节必须在情境列表中落实，杜绝货不对板；
* **事件过程完整**：团队战斗与重要事件须具备完整的战术分工、中枢配合与战后收束，杜绝快进跳过；
* **Show, Don't Tell**：严禁旁白定性说明角色心意，通过具体微动作呈现。

### 5. 文风、语病与词汇保真专项审查

* **口语对白质感保真（严禁道德过度净化）**：
  - 角色在亲密或特定情境中符合其性格声线的生动、粗粝或放浪口语对白，属于成人文学的核心张力，严禁借审读之名擅自删改或净化为生硬的书面语；
  - 审读修改仅针对确实存在语法语病、人设违和或违规词汇的对白；凡符合角色当下心智与情境氛围的台词，一律完整保留。
* **情感温存质感保真（严禁概念化与公文化替换）**：
  - 严禁将描写体表温存、深情抚慰与亲密依恋的具象词汇，机械替换为疏离、冷漠的公文化或概念化辞藻；
  - 伴侣间的情感特质与亲密神髓必须保持原有的温度与触感，杜绝去情感化的扁平替代。
* **代词泛滥治理（本名正位铁律）**：
  - 旁白叙事必须严格遵循本名正位准则，杜绝以第三人称代词作为泛滥主语；
  - 尤其在双人或多角色互动的场景中，严禁连续使用模糊代词造成主语混淆；凡存在指代不明或语流松散处，必须全面回归实体本名。
* **彻底根除元叙事开篇与事件标签式过渡**：
  - 各情境开端必须具象交代时间节点、物理空间、光影感官与当下角色的即时微动作；
  - 严禁使用上帝视角总结式的事件标签、事件后缀或跨时空概括短语作为段落开篇，必须依托当下的物理时空切片自然切入。
* **彻底拔除旁白定性批注与判断性断语**：
  - 严禁旁白下场充当解说员进行定性说明、自问自答或以解释性断语对角色的动作意图打补丁；
  - 角色的心理涟漪与行为意图，必须通过身体动作切片、微表情、体表生理反应与对白交锋自然交代。
* **语病治理与文风优雅定锚**：
  - 严禁在正文叙述中使用脱离 JRPG 西幻轻小说格调的市井低俗词汇，体位与肢体交互应以具象动作分镜与优雅修辞呈现；
  - 凡涉及跨章节的情节指涉与心理前因，必须交代扎实清晰的情境脉络，杜绝语意悬空与逻辑断层。
