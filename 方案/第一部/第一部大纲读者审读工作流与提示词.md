## 一、 执行机制

当用户要求继续推进第一部审读时：

1. **读取看板**：查阅 [`第一部大纲读者审读_总进度看板.md`](第一部大纲读者审读_总进度看板.md)，锁定首个处于 `⏳ 待执行` 的断点批次；
2. **定位大纲**：根据批次章节区间，读取 `docs/story/` 下对应的 20 篇 `.TXT` 文件；
3. 自由探索章节跳过；
4. **档案核对与逻辑审读**：对照 `docs/` 设定档案与本指南审查准则，在 IDE 内对其余主线、支线及 NSFW 章节进行审读；
   - **前文脉络与伏笔检索铁律**：审读中凡遇到角色提及“上次的事”、“之前承诺”、“未明过节/道歉/心结”等跨章指涉时，**严禁凭空主观断言“缺乏前因/逻辑断层”**，必须首先检索 `docs/story/` 前文对应章节，核实是否为前文已埋下的情节呼应。若前文已有严密铺垫，属于合格且优秀的呼应，予以保护；
5. **生成建议方案**：将有修改意见的章节写入 `方案/第一部/读者审读建议_批次XX_ChAAA-ChBBB.md`；
6. **更新看板**：将看板中对应批次标记为 `✅ 已完成` 并更新成果链接与新断点。

## 二、 审读核心准则

### 1. 结构与大纲定位
* **大纲属性**：所有 `.TXT` 章节均为结构化情境大纲。审读仅针对逻辑漏洞、人设偏差与情节断层提出修改建议，无需逐条重写每个具体情境，严禁给出“为xx埋下伏笔”等解释；
* **精简原则**：无修改意见的合格章节不写入方案，全篇仅保留需要修改的章节；
* 自由探索章节跳过；
* 占有欲确认等字段可以留空。

### 2. docs 设定档案核对体系
审读时以 `docs/` 设定档案为第一基准，按以下顺序对照：
1. **人物性格档案（`docs/character/`）**：核对角色性格神韵、台词声线、身心羁绊与行为逻辑；
2. **阶段系统（`docs/chapter/_阶段系统.TXT`）**：核对章节所属阶段、当前关系的推进界限与行为等级（注：阶段系统专门用于管理和约束第三者 NTR/NTS 接触深度与行为递进；黎恩与菲娜正牌伴侣间的纯爱 NSFW 互动以及噩梦/心魔潜意识投射不受此阶段限制）；
3. **生物与魔兽档案（`docs/creature/` 与 `docs/npc/`）**：核对外貌生理、攻击方式、弱点与消散特性；
4. **场景与建筑档案（`docs/location/`）**：核对空间结构、距离与私密性；
5. **魔法与能量体系（`docs/magic/`）**：核对圣光、鬼之力与腐化的相互作用机制。

### 3. 题材属性与 NSFW 直白语言定锚（严禁过度洁癖误判）
* **题材属性与情趣动因**：本作属于**绿帽向/NTS背德情趣成人西幻作品**。黎恩与菲娜基于绝对信任与爱意设立了“背德情趣共享与安全试探”（`_背德与越界心理.TXT`）。黎恩主动安排、默许或试探菲娜与他人的接触，属于核心情趣约定与心理试探；
* **直白语言与台词规范**：成人情爱情境必须使用直白、具有动作抓力与真实刺激感的成人词汇与口语对白，只要符合角色当下性格与粗粝或放浪情境，完全成立；`lexicon.md` 杜绝的是中式修真与明清艳情黑话，绝非禁止直白直接的成人描写；
* **角色真实对白保真**：生动对白，属于成人作品核心张力，必须完整保留。

### 4. 剧情逻辑与动机构建审查

#### NSFW 章节审查
* **开头场景**：人物当前状态与所处环境，空间私密性与同伴动线；
* **事件起因与动机**：剧情走向接触的前置动因、情感积累与心理逻辑；
* **动作过渡与微反应**：前置情感升温、眼神、呼吸与微动作过渡，杜绝无铺垫突兀发车；初次结合需具备生理阻滞与深情安抚层次；
* **词汇规范**：严格执行 [`lexicon.md`](file:///home/nanhu2/comfyui/世界书/.agents/rules/lexicon.md)。

#### 常规剧情与大事件审查
* **核心承诺兑现**：核心字段列明的情节必须在情境列表中落实，杜绝货不对板；
* **事件过程完整**：团队战斗与重要事件须具备完整的战术分工、中枢配合与战后收束，杜绝快进跳过；
* **Show, Don't Tell**：严禁旁白定性说明角色心意，通过具体微动作呈现。
