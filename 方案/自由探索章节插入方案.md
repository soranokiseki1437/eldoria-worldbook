### 3.2 地点真实性规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **锻炉在营地远处，营地听不到** | 矮人三兄弟的工坊不在营地内，声音传不到营地。若提及锻造相关，只能以全知叙事视角描述"矮人小屋那边"正在发生什么，绝不能写"传来""方向飘来"等暗示声音/气味到达营地的表述。乔治的工坊在营地内但偏导力器和图纸研究，不以锻造为主。 |
| 2 | **不遍历所有地点，但随机提多个可选地点** | 禁止每章bullet 2遍历"训练场有木剑声→厨房有炊烟→图书室有人翻书→锻炉在响→溪边有人在洗东西"。有些地方就该空着，该安静。但也不要只提一个地点——每章随机提及2-4个适合该时段的地点，让玩家感觉有选择余地，增加自由度和随机性。 |
| 3 | **镜湖日常禁用** | 镜湖的特定作用是映出死去之人的倒影。日常自由探索章节禁止出现镜湖。仅在伴随怪物/低语者线索时可用。 |
| 3 | **不是每个地方都恰好有人** | 营地不是所有角落同时被使用。允许训练场空无一人、图书室黑着灯、篝火边座椅全空、厨房灶台冷着。安静和空旷本身就是一种氛围。 |

### 3.3 环境元素多样化

避免每章重复"厨房/训练场/图书室/锻炉"四件套。以下元素根据时间段和场景随机选用，**不是每次都要出现**：

| 类别 | 元素池 | 使用原则 |
|------|------|------|
| **天气与活动提示** | 适合晒被子散步；泡温泉的好日子；适合去森林探险但窝在家睡觉也不错；下雨了适合在家打牌但出去看雨也别有风味；阴天适合在家整理东西不过出去吹吹阴风也不错；大太阳热死了容易出汗适合泡在水里或者干脆躺着不动 | 有叙事暗示但不锁定剧情走向。随机出现，每次选不同的，根据章节的实际天气和时间段匹配。 |
| **森林动物** | 森林龟趴在石缝晒太阳；星叶蝶停在座椅扶手上翅膀缓缓开合；银流鱼在浅滩石缝间穿行鳞片闪荧光；啄木鸟在树干上断续敲击；松鼠叼着坚果跳过树枝 | 动物是活的背景，不问人类的事。每次选1-2种。 |
| **宴会与集会** | 最近腐化清理了很多/同盟有进展/打猎收获丰富/营地建设有了新进展，感觉晚上可以办个宴会，可能得讨论一下；今天好像得开个会，商量一下接下来的计划 | 宴会/开会是提议不是决定。办不办、谁来、吃什么都不锁定。偶尔出现（≤20%章节）。 |
| **营地维护** | 最近营地里什么东西好像要修，营地自己能修好吗要不要拜托矮人；某间木屋的门轴该上油了；篝火边的座椅有一把松了腿；建房子的材料堆在营地边上有些日子了 | 提示但不锁定。谁去修、修不修、什么时候修都不写死。偶尔出现（≤25%章节）。 |
| **日常劳作** | 吃火锅（谁去备料呢）；打猎（今天谁有兴致去森林里转转）；采药（森林里草药正是季节）；种菜（营地后面那块地该翻土了）；种花（星彩花的种子谁收着了） | 劳作是邀请不是任务。不写谁在做，只写"可以做"。每次选1种。 |
| **人际动态提示** | 哪里好像有人在说话，是有什么事情吗；今天谁有什么事情好像要找谁；今天好像没看到谁，是在忙什么；篝火边今天多坐了一个人还是少坐了一个人 | 暗示社交动态但不锁定对话内容或结果。是氛围不是剧本。偶尔出现（≤30%章节）。 |
| **巡逻与守卫** | 今天是个巡逻的好日子，轮到谁了呢；哨塔上值夜的人换了班；北线巡逻队回来时带了几根奇怪的羽毛 | 巡逻是营地日常，但轮班和发现不锁定角色。 |
| **种族与外部势力** | 蜥蜴人那边最近好像有什么消息；狼人领地的满月快到了；矮人小屋那边今天特别安静（或者特别吵）；低语林地边缘的符文最近闪得比平时频繁 | 提醒世界比营地更大。管不管取决于角色。偶尔出现（≤20%章节）。 |
| **远方异响** | 森林深处好像有什么声音；山洞方向传来低沉的共鸣；地底偶尔有微弱的震动 | 暗示但不强制。管不管看心情。偶尔出现（≤25%章节）。 |
| **独特地点** | 银流河（石阶水流+银流鱼+影光菇）；银塔（符文微光+两百年守夜人）；林间空地（花田石台+星彩花）；温泉（天然热水+蒸汽）；矮人小屋（锻造声+酒壶——全知叙事，不写声音传来营地）；山洞（石壁滴水+导力器）；密林深处（追踪路线+啄木鸟）；蜥蜴祖地（鳞片与符文）；商道（仓库货箱+车轮辙印） | 每章随机提2-4个适合该时段的地点，不锁定某一个。镜湖日常禁用（仅限怪物线索）。从设定文档中选取真实存在的地点。 |
