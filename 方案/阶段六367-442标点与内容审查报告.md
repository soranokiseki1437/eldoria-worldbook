## 三、标点符号修改重点

### 3.1 破折号规则执行

按指南§4.1，菲娜场景中的叙述性破折号全部改为逗号串联。黎恩回收/占有场景的破折号保留作为重音符号。对话中的打断保留破折号。

**典型修改**（批次C/D各约32/55处）：
```
改前：黎恩快回来了——踩线的快感从脊椎窜上来
改后：黎恩快回来了，踩线的快感从脊椎窜上来

改前：高潮来得又快又密——第一次还没退第二波就推上来了
改后：高潮来得又快又密，第一次还没退第二波就推上来了
```

### 3.2 碎片句合并

按指南§4.2，同一情绪流/动作流中的碎片句用逗号串联。

**典型修改**：
```
改前：她开始动。不快。
改后：她开始动，不快，

改前：雷恩喝醉了。真的喝多了。
改后：雷恩喝醉了，真的喝多了。
```

### 3.3 问句补问号

**典型修改**：
```
改前："你要试吗。" → 改后："你要试吗？"
改前："符文激活了几次。" → 改后："符文激活了几次？"
改前："谁说只能一次的。" → 改后："谁说只能一次的？"
```

### 3.4 对话标点修正

```
改前："好喝。"他说。 → 改后："好喝，"他说。
改前："不要。"她说。 → 改后："不要，"她说。
```

## 四、去AI化清理重点

### 4.1 删除"不是...是..."句式（~15处）

```
改前：没有凯尔只有他 → 改后：只剩她和他
改前：你不是不行。是参照物不对。 → 改后：你没问题，参照物不对。
改前：没有拒绝。没有点头。只是张开了嘴。 → 改后：张开了嘴。
改前：不是关于精灵语的 → 改后：跟精灵语无关
改前：符文不是符号是意志的结晶 → 改后：符文是意志的结晶，符号只是它的形状
```

### 4.2 叙事注解删除（~18处）

叙事注解是阶段6最高频的去AI化问题——替读者解读他们已知的画面。

```
改前：她低头看着那片白，自己的手，别人的精液
改后：她低头看着自己的手。

改前：作为一个从不需要别人帮忙的人，奥蕾莉亚懂这句话的重量。
改后：她没有回答。温泉的咕嘟声填满了沉默。

改前：是在确认一个等了太久的答案。
改后：删除

改前：两个字。是她的决定
改后：删除
```

### 4.3 内心独白压缩（~5处）

```
改前：还挺舒服的。她在含鸡巴的空隙里冒出了这个念头
改后：还挺舒服的，然后脸红了。

改前：她哭是因为这两个最温柔的男人愿意再次为她变成野兽。清醒地。自愿地。
改后：她又哭了，眼泪淌在脸颊上。
```

### 4.4 核心意义标注删除（~12处）

按要求§6陷阱#21，核心不写"第一次由自己决定""不是黎恩安排"等说教标签。

Ch426/427/429/433/434/435/436/437/438/439/440/441/442的核心字段和占有欲确认中的意义标注均已清理。

### 4.5 表情确证删除（~4处）

```
改前：羞耻和满足同时涌上来，嘴角是弯的，脸是红的
改后：羞耻和满足同时涌上来。

改前：（删除"那是她决定重要实验参数时的表情"）
```
