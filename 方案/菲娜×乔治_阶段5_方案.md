## 五、写作铁律（逐条对照，违反即重写句子）

### 5.1 破折号使用规则

破折号只允许三种场景。其余任何一个破折号出现，不修标点，重写整个句子。

**允许：**

| 场景 | 示例 | 说明 |
|:--|:--|:--|
| 标题分隔符 | `工坊的午后——再来一次` | 前半段和后半段之间的连接 |
| 对话被打断 | `"你怎么——"` | 话说一半被截断 |
| 插入语 | `惩罚之后，乔治在工坊躲了好几天` | 插入语拆成独立句或逗号前移 |

插入语重写示范：`被惩罚之后——黎恩一拳、菲娜巴掌、横抱带走——乔治在工坊躲了好几天` → `黎恩一拳、菲娜巴掌、横抱带走。惩罚之后的几天，乔治在工坊躲着没出来。`

**禁止场景与重写方法：**

| 违规类型 | 错误示范 | 重写方法 |
|:--|:--|:--|
| 后置解释 | X，Y理由 | 理由前置：删掉"X"，直接从Y起句 |
| 后置描写 | 细节堆在破折号后 | 另起独立句，或逗号串联 |
| 戏剧停顿 | 动作接破折号再接描写 | 拆成两个独立句，或逗号合并 |
| 后置判断 | 陈述接破折号接评价 | 评价另起一句。两句独立的重量大于一句带破折号 |

检验方法：删掉"X"和破折号，只看"Y"。如果Y是完整句子，则原句的破折号就是冗余的。

### 5.2 画圈禁令

"手指在皮肤上画圈"是AI最爱的亲密动作模板——事后在胸口画圈、沉默时在手背上画圈、安抚时在后背上画圈，全是cliché。

**禁止场景**：
- 手指在胸口/手背/锁骨/后背画圈（亲密后的标配填充动作）
- 拇指在手背上慢慢画了一个圈（沉默时的万能填充）

**替代方向**：写具体的、只属于这个角色的动作。菲娜手指无意识地蜷了又张开。乔治手指在导力器外壳上摩挲。黎恩拇指按在她后颈上不动，就是按着。

**明确允许**：舌尖在乳晕/龟头/阴蒂上画圈——那是具体的口交技法，不是cliché手势填充。

### 5.3 句子节奏规则

一个段落内，句子长度必须有明显起伏。长句提供密度，短句提供重量。两者轮流出现。

```
✗ 全是短句：她没抽手。她抬头看他。他耳朵红了。她心跳很快。他说不出话。
✓ 长短交替：她没抽手，抬头看他。他耳朵红透了，眼神却没躲，嘴唇动了动没发出声音。她感觉到自己的心跳比表情诚实。
```

**具体约束：**
- 禁止连续三个短句排列。短句定义：≤12字、无逗号、单主谓结构
- 每个短句的下一句必须≥20字
- 两个相关联的短动作合并为一个中长句：`她蹲下。她捡起发绳。` → `她蹲下捡发绳`
- 动作链用逗号串联，不拆句号：`他接过笔。他放下。他把她拉起来。` → `他接过笔放下，把她从地上一把拉起来`

### 5.3 叙事视角规则

禁止高维视角。不从故事外部俯视时间流逝，一切叙述落在角色的感知里。

```
✗ 本番之后没几天，菲娜去工坊取修好的导力器。
✓ 菲娜去工坊取修好的导力器。上次她在这里引导过他，已经过了好几天，两个人见面时谁也不提。
```

```
✗ Ch270视频直播的第二天。菲娜路过工坊。
✓ 视频直播的第二天。菲娜路过工坊。
```

章节编号（Ch###）只能出现在位置字段、分析段落和优先级表中。核心、回归时刻等叙事字段禁止使用。

### 5.4 迂回否定禁令

凡是要陈述一件事，直接说它是什么。不先说它不是什么。

```
✗ 他在学习她，不是评判她。
✓ 他在学习她。

✗ 她不是在安抚——她是在重新建立规则。
✓ 她在重新建立规则。安抚不会有这个重量。

✗ 不是欲望，是恐惧。
✓ 恐惧。比欲望深得多。
```

例外只保留两种：角色对话中的自然否定（`"你的导力器不是昨天才修过"`）和文学对比（`是同一个人。又不是同一个人。`）。

### 5.5 对话写作规则

- 人物不说完句话。吞字、犹豫、把后半截交给动作
- 不用"我知道了""他知道""嗯"做单字回应。用身体反应或更完整的表达替代
- 每段对话后至少跟一句描写（动作、表情、身体反应、环境），禁止连续堆对话行
- 迂回否定禁令同样适用于分析性字段（功能、驱动力、反应、黎恩角色）：直接说是什么

**对话标点规则：**

| 标点 | 含义 | 示例 | 误用 |
|------|------|------|------|
| `。` | 陈述落地、冷淡、克制 | `"我没笑。"` | 真问句用句号→冷冰冰的质问 |
| `？` | 真问题、调侃 | `"你笑什么？"` | — |
| `！` | 情绪上扬：愤怒/羞恼/激动 | `"你明明笑了！"` | 情绪高涨时用句号→压平了 |
| `~` | 傲娇、拖尾、撒娇 | `"滚啊~"` `"乖~"` | — |
| `...` | 气息渐弱、犹豫 | `"等...等一下"` | 被外部打断用`——` |

**回归时刻的"被接住"原则：** 菲娜从第三者那里回来后——尤其是被撩起来又没释放、或者情绪有大起伏的时候——她不需要和黎恩先演一场对抗（捶胸口/抓领子/推拒）。此刻她需要被接住。黎恩懂她的身体，不需要她先"挣扎一下再接受"。直接写他给她什么，她的身体怎么回应。

### 5.6 乔治的关键特征

棕色短发、不戴眼镜、社交腼腆技术自信、写字画图纸的手指。口头禅"可以吗"在阶段四后逐渐减少。

### 5.7 菲娜的视角与人物指纹

摄影机模型确定对准谁。菲娜在乔治面前偏主导，但害羞体征贯穿全场景：事前结巴、事中沉默不理人、事后跑回黎恩怀里蹭胸口。

**新增方案必须逐条确认以下10条人物指纹**（缺一条补一句）：

1. **琥珀色眼睛先弯再笑** — 专属表情。压缩为"她笑了"=丢失顺序
2. **动作之后的延迟害羞** — 先行动再脸红。脸红放动作前面=那不是菲娜

## 七、2026-07-23 工作记录与经验总结

### ### 7.2 反复犯错的根本原因

**问题1：修复只改标点，不重建句子结构。** 用户指出破折号滥用后，我只把"——"替换成逗号或句号，句子的信息组织方式没变。正确的做法是拆掉"X——Y"的两段式，重新决定信息出现的顺序：把Y的内容前置，或分拆为独立句，或改用语法连接词。

**问题2：分析性字段被当成"豁免区"。** "功能""驱动力""菲娜反应""黎恩角色"这些字段我潜意识里归类为"元数据"而非散文，因此对里面的"不是而是"和破折号滥用放松了标准。用户明确指出：这些字段同样是读给人听的文字，规则一刀切。

**问题3：逐条打地鼠，从不做全量扫描。** 每次用户指出一个具体问题，我只修那一处。修完后从不运行全局grep验证是否还有其他残留。结果就是同样的模式在不同的方案里反复出现，用户需要反复指出。

**问题4：写完不复核。** 本日多次出现"刚写完就违反了自己刚写的规则"的情况。最典型的一次：修改第五节规则文字时，顺手在规则散文里加了一个破折号。写完一段文字后没有对照五条铁律逐条过一遍。

### 7.3 正确的修改流程

以后修改任何方案文字，按以下顺序执行：

```
1. 写完一段
2. grep 扫描：'——' '不是' 'Ch\d' '吗。' '呢。"' '？"' '！"'
3. 手动扫读对话：有没有单字/两字回答+句号？（`"糊的。"` `"嗯。"`）→ 扩充或加动作
4. 手动扫读对话：有没有连续Q&A堆砌无穿插？→ 插入动作/表情/环境
5. 发现违规 → 重写句子结构，不修标点
6. 再扫描确认零残留
7. 继续下一段
```

短句检查不在grep范围内，需要在步骤2手动扫读：一个句号一个句号地数。如果连续三个句子都不超过12字且无逗号，用逗号合并或拉长中间句。

### 7.4 方案标题命名规律

已有章节的标题格式为 `具体场景/意象/时刻——核心事件/动态`：

- `临界边缘——蹭穴与口交`（状态——行为）
- `工坊的午后——乔治的第一次`（时间地点——事件）
- `贮藏室的意外——门锁坏了的隐奸`（触发条件——事件类型）
- `挂断之后——反正都做过了`（时刻——心理独白）

方案标题应参照此格式。本轮修复的两个标题：
- `深夜——图纸是借口` → `半夜敲门——图纸是借口`（"深夜"太泛，"半夜敲门"是具体动作）
- `图纸下——他重新问了可以吗` → `覆上她的手背——他重新问了可以吗`（"图纸下"太模糊，"覆上她的手背"是身体动作）
- `他的床——关了灯之后` → `乔治的房间——关了灯之后`（"他的床"过于聚焦，"乔治的房间"是完整空间）

### 7.5 方案编号原则

- 所有方案统一使用 `S{阶段号}-{序号}` 格式，如 S3-1、S4-3、S8-4
- 阶段内方案按时间顺序排列，但编号跳跃（如S4-5、S4-6、S4-7、S5-5）是允许的——已删除的方案编号永久空缺，不重新分配
- 旧编号（1A/1B/2A/2B/3A/3B/3C）是两套方案合并时遗留的，已全部清理

### 7.6 字段职责说明

| 字段 | 定位 | 写作要点 |
|:--|:--|:--|
| 核心 | 叙事散文，章节正文的蓝本 | 五条铁律全量适用，最严格标准 |
| 回归时刻 | 叙事散文，菲娜回到黎恩身边 | 同上。不可省略，不可写成"不需要单独回归" |
| 功能 | 说明本章在弧线中的作用 | 可以引用方案编号（S4-6等），但仍需遵守破折号和迂回否定禁令 |
| 乔治驱动力 | 分析乔治的动机 | 直接说是什么，不说不"是"什么 |
| 菲娜反应 | 分析菲娜的情感变化 | 同上 |
| 黎恩角色 | 分析黎恩在事件中的位置 | 同上。黎恩是有血肉的人，描述他的文字本身也应该有血肉 |
| 位置/类型/好感影响 | 纯元数据 | 可以使用编号和简写 |

### 7.7 对话写作自查清单

写完任何对话后，逐条检查：

1. 有没有独立的 `"嗯。"` / `"好。"` / `"行。"` / `"对。"` / `"我知道。"` 作为一句完整的对白？→ 替换为更长的话，或附加动作描写
2. 有没有连续三行及以上纯对话（中间没有动作/表情/环境穿插）？→ 插入至少一句描写
3. 对话中的角色用词是否符合其性格？（黎恩话少但每句有重量、菲娜害羞但不冷、乔治结巴但不怯）
4. 如果角色在性爱中说话，声音是否带着喘息/断句/黏腻感？→ 在对话前或后加半句身体状态描写
