### ⚠️ 法林语言风格纠正（2026-06-30）

**根因**：法林角色设定（`docs/npc/法林.TXT`）中**无"结巴"特征**。草案沿用了已有章节中法林在性场景的临时紧张反应，错误地将其固化为固定说话方式。

**法林真实的语言特征**：
| 特征 | 说明 |
|------|------|
| 礼貌措辞 | "请""谢谢""麻烦你了""应该的"——多尔金曾说你他妈能不能少说请 |
| 陈述语气 | 讨论正事时语气平稳、认真、不躲闪——像陈述事实 |
| 耳朵红 | 害羞/紧张时的身体反应，但不影响说话流畅度 |

**已在草案中修复**：230.3中法林的对话从碎字改回正常措辞（"请问…你指的是""自己解决。只能这样。""我还好。大哥和二哥运动量大，需要得更多。"）。章节任务和一致性检查表同步更新。

### ⚠️ 破折号(——)超标

草案情境中使用了大量破折号作为轻停顿（每bullet 3-5处），而规则要求**目标0处**。TXT创建时必须逐条替换：

| 草案写法（❌） | 修改方向（✅） |
|------|------|
| "石板在最底层——膝盖跪地，屁股翘起来" | "石板在最底层。膝盖跪地，屁股翘起来" |

| "不是哈根那种紧张的急促，是稳的" | "稳的，和哈根那种紧张的急促完全不同" |
| "深棕色小眼睛钉在她脸上——不是惊慌，是确认" | "深棕色小眼睛钉在她脸上。那是确认。不是惊慌。" → 更准确："深棕色小眼睛钉在她脸上。确认来的人是谁。不慌。" |
| "多尔金射完后第一件事不是喘气——是从旁边" | "多尔金射完没有先喘气。他从旁边架子上拿了..." |
| "不是推——是扶" | "没推。扶着。" |

**修复策略**：正式创建TXT时，用句号/逗号替代所有破折号。保留0处。思维断裂处(极少)用句号分割独立句。

### ⚠️ "不是X是Y"句式

草案中多处使用了此禁止句式。TXT创建时必须改为肯定句：

| 草案（❌） | 修改方向（✅） |
|------|------|
| "不是害羞，是不理解" | "那是真正的困惑——他听不懂这个词" → 再改："他听不懂这个词。脸上是真正的困惑。" |
| "不是哈根那种紧张的急促，是稳的" | "稳的。和哈根那种紧张的急促不同。" → 或直接："稳的。像打铁时的锤击频率。" |
| "不是惊慌，是确认" | "确认来的人是谁。不慌。" |
| "不是陈述，是提醒" | "提醒的语气。和平时不同的语调。" |
| "不是推——是扶" | "没推。扶着。" |

### ⚠️ "真正的"强化词检查

规则禁止"是X。纯粹的/完全的/真正的X"冗余自强化。草案中"真正的困惑"需检查是否构成冗余。"真正的学者"同理。

**TXT创建时替换**："真正的困惑"→"脸上是不理解" / "真正的学者"→删除"真正的"，"平稳得像个学者在找资料"已足够。
