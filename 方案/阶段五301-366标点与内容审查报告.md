## 三、标点符号修改重点

### 3.1 破折号规则执行

按指南§4.1，菲娜场景中的叙述性破折号全部改为逗号串联。黎恩回收/占有场景的破折号保留作为重音符号。对话中的打断保留破折号。

**典型修改**：
```
改前：菲娜尝了一口皱了皱眉——这味道和上次不一样
改后：菲娜尝了一口，皱了皱眉，这味道和上次不一样
```

### 3.2 碎片句合并

按指南§4.4，同一情绪流/动作流/思维流中的碎片句用逗号串联。

**典型修改**：
```
改前：她生气了。瞪着他。不说话。
改后：她生气了，瞪着他，不说话。

改前：一下。两下。节奏不快。
改后：一下、两下，节奏不快。
```

### 3.3 问句补问号

按指南§4.6，疑问句末尾补全问号。

**典型修改**：
```
改前："多尔金呢。"
改后："多尔金呢？"

改前："你知道我现在在做什么吗。"
改后："你知道我现在在做什么吗？"
```

### 3.4 去AI化清理

按指南§6常见陷阱#11，删除"不是...是..."冗余否定句式。阶段5菲娜不自我辩解，不满直接指向对方行为。

**典型修改**：
```
改前：和命令无关，是她的腿自己软了
改后：腿自己软了

改前：那不是哽咽，呜咽从牙缝里漏出来
改后：呜咽从牙缝里漏出来
```
