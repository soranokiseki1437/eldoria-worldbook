## 〇、扩展原则

1. **纯爱内核NTRS**：共享时刻 ⇄ 回归时刻。艾玛的心始终在法林。身体的共享是信任的延伸，不是背叛。
2. **身体先于意志**：艾玛的反应顺序是 身体回应 → 意识到 → 做决定。先红耳朵，再决定接受或推开。
3. **大姐姐的张力开关**：掌控 → 失去掌控 → 被接住。权力反转是艾玛场景的张力核心。
4. **因果链，非事件链**：每个节拍必须"因此"而非"然后"。每个性行为节拍前面必须有情绪/身体原因。
5. **场景独立**：每章独立，不依赖"上次做了X"来驱动。起因 → 触发 → 发展 → 收束四段完整。
6. **艾玛的声音不可变**：甜软声线 + 主动调戏 + 问句多于陈述句 + ~拖尾 + 身体出卖。捻辫梢是情绪刻度尺。

### 提案1：月光下的古老契约——月语者的沉默与馈赠

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段5中后段） |
| **对象** | 月语者（狼人部族精神领袖） |
| **起因类型** | D：月语者的孤独与岁月打破了艾玛的预期 |
| **场景类型** | 西北山谷·月光岩·深夜 |
| **性行为等级** | 5-6（手交+口交为主） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+12 / 法林+8 |

**核心设计**：

艾玛去西北山谷记录月光百合生长周期。傍晚在月光岩上遇到月语者——偏瘦的灰黑身形、断了半截的犬齿、颈间那串骨珠（每一颗代表一个离世的族人）。月语者说话慢而沉，每个字都在喉咙里转一圈才出来。他看她的眼神格外长：近乎金色的眼睛里有某种在太古石板上读到过但从未在活人眼里见过的东西——**时间**。

他看出了她对知识的渴望，但给出了她没预料到的东西：他对她说了一句狼人部族用来在月光下纪念死者的古老语言。她的耳朵先红了。被看见了。

**关键节拍**：
- 起因：艾玛在月光岩上遇到月语者 → 她问了骨珠（学术本能） → 他一个一个说出了那些名字，每个名字后面都有一句不重复的话。"你问了，所以我说了。大多数人不问。"
- 触发：月光升起。月语者的眼睛泛起淡蓝荧光——月瞳开启。"在看你的影子。你的影子...很亮。和她的很像。"说的是他的伴侣
- 发展：她伸手碰了他颈间骨珠，指尖停在最旧的那颗上。他的喉结动了一下——一百多年了，没有人碰过那颗。她踮脚，嘴唇很轻地贴在他的额头上
- 高潮：她跪在月光岩上给他口交。他在她嘴里射的时候发出从胸腔深处碾出来的低音，像月光本身在叹息
- 收束：事后他坐在石头上。"你的影子会很长。比她长。"回符文室她问法林："人的影子有多长？"法林放下刻刀。"很长。""...嗯。"

**差异化**：
- 首次艾玛×月语者——性行为是古老仪式/情感馈赠的延续
- 艾玛不调戏——大姐姐模式让位给倾听者和给予者
- 回归时刻：她带回来的是近似智慧的东西

### 提案2：胶质包裹中的边界溶解——腐化史莱姆的全身沉浸

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段5中后段） |
| **对象** | 腐化史莱姆（水精灵腐化态·半透明暗紫胶质） |
| **起因类型** | 怪物遭遇+学术好奇：观察水精灵腐化过程→被史莱姆包裹 |
| **场景类型** | 银流河或镜湖·浅水区·夜晚/月光 |
| **性行为等级** | 7-8（胶质包裹·全身同时刺激·麻痹毒素） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+8 / 法林+10 |

**核心设计**：

腐化史莱姆是水精灵被腐化污染后形成的半透明暗紫胶质，无固定形状。与腐化藤共享麻痹毒素，但体验完全不同：**藤蔓是线状缠绕（被束缚），史莱姆是面状包裹（被溶解）**。胶质在热源集中的地方自动汇集——乳房、大腿内侧、蜜穴口——跟随宿主脉搏同步蠕动。

艾玛在镜湖边研究水精灵腐化过程的物理性质变化。一只史莱姆从浅水区浮出——她本可以后退，圣光符文在手边。但学术好奇心比恐惧快了半拍。然后胶质接触了她的脚踝。

**关键节拍**：
- 起因：镜湖边采集样本 → 史莱姆从水中撑起人形轮廓 → 她没有退，蹲下来想近距离观察 → 胶质触到手指，凉→热
- 触发：胶质从手指沿手臂蔓延——像被温热的半液态丝绸一层层裹住。麻痹毒素让力气慢慢稀释。胶质在热源处更密更厚。紫色丝袜在胶质里变了形
- 发展：全身被暖胶裹住——麻痹让皮肤失去边界。胶质在蜜穴口、阴蒂、乳尖同时汇集，暗紫胶质有脉冲感地微微蠕动——节奏和脉搏同步。甜喘从胶质空隙间漏出来，闷闷的
- 高潮：全身同时到达——蜜穴、阴蒂、乳尖在同一瞬间被胶质脉冲推过临界。胶质变深紫然后随消退变淡。她在胶质里弓起腰。史莱姆不停——高潮被拉成叠浪
- 解救：右手蠕动了很久够到腰间符文石。圣光激活，胶质瞬间凝固成石灰色。她从胶质里滚出来跪在浅水区喘气，然后捡了一块凝固碎片放样本袋。标签写完看自己的字，耳朵红了
- 收束：回符文室。法林用拇指擦掉她脸上的胶质碎片，手指很暖，和胶质完全不同。"我今天做了一次不太成功的野外采集。""样本有用吗？""有用的~"她停了一下。"下次你陪我去~"

**差异化**：
- 胶质包裹是"面状沉浸"——全身被温热半液态胶质裹住，非线状缠绕
- 胶质热源汇集+脉搏同步蠕动+全身同时到达——无意志的精准
- 半主动（本可退但选择观察）
- 自己圣光脱困
- 事后捡样本→学术本能自动重启→看到字才害羞

### 提案3：暗紫残影的包围——低语者遇袭

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段5末） |

| **起因类型** | 怪物遭遇：在腐化边缘废墟被低语者包围袭击 |

| **黎恩知情** | 否 |

**核心设计**：

她从废墟出来时被包围了——七八个暗紫色人形轮廓从石缝和枯树后同时浮现。绝对沉默。没有警告，没有声音。只有细长手指——触感滚烫——同时伸向她。

低语者是腐化精灵的残影，不是魔兽。它们在触碰她的时候，她感受到的是200年被压抑后的、在圣光元素刺激下的集体躁动。这不让她感觉更好。

**关键节拍**：
- 起因：艾玛独自去腐化边缘废墟采集古老符文石 → 触动遗跡残余圣光 → 圣光波动扩散 → 周围半休眠低语者全部被激活 → 从废墟出来时暗紫人形从四面八方浮现。"...这么多。"

- 发展：多双手同时在扯衣服、触碰身体。没有配合。八年十年二十年都没碰过活物的残影在集体躁动。衬衣被撕开。丝袜从大腿根撕裂——一只低语者的手指穿过茂密阴毛。另一只含住乳尖。暗紫半透明胶质的温热覆裹，不是嘴唇的柔软。她叫了出来，真实的、从喉咙挤出来的叫。她叫了法林的名字，没有回音——低语者不会回应。第一根暗紫色半透明阴茎进入了，滚烫。第二根在嘴里，第三根在手里
- 持续：轮番。不像矮人兄弟有节奏、有默契，这是残影的集体释放。每根暗紫阴茎都滚烫，和冰冷外表相反。她的身体反应（蜜液、喘息、高潮）和恐惧并行，互不否认。低语者射精后有些会自行消散。只有守护者能通过性行为净化低语者——它的消散是能量自然耗尽的结果，在圣光元素残余的刺激下加速解体成金色粒子。新的低语者补上来。她没数有多少个。只记得那晚的沉默从头到尾没有一声
- 收束：黎明的圣光救了她的命。晨光中腐化能量衰退，残影一个接一个退回阴影和石缝。她在碎石地上坐了很久，衬衣撕了，丝袜只剩残片，身上全是滚烫触感留下的淤红。站起来时腿在抖。耳朵不红。薄荷蓝眼睛里有某种以前没有的东西。是知道了。回符文室。法林还在睡，她没叫醒他。洗了很久。光着身子钻进他被窝，冰凉皮肤贴着他后背。"艾玛？""...做噩梦了。""什么噩梦？""...记不清了。"他把她的手握在自己手心里。她在他手心里一直在抖，后来才停

**差异化**：
- 首次艾玛×低语者遭遇——真实的遇袭
- 低语者是"多个"残影的集体躁动。绝对沉默×多人触感=独特恐怖

### 提案4：观察者的囚笼——低语者研究失控

| 维度 | 内容 |
|------|------|

但符文束缚阵的导力频率和低语者体内的腐化能量产生了她没预料到的共振——符文在持续接触中缓慢衰减。这是她没有算到的变量。

- 触发：符文束缚阵导力频率与腐化能量共振→符文缓慢衰减。她发现时最后一道符文已暗到只剩微光，然后灭了。"...共振频率和预估的不一样——"她抬头。低语者已经在看她了。眼部两点暗光在半暗里亮着。绝对沉默。它往前走了一步。她的手移向紧急触发器，但触发器需要圣光注入，而束缚阵的共振已经干扰了圣光回路。这是她没设计的故障模式

- 高潮：它进入了，和废墟那晚一样滚烫。她叫了法林的名字，和废墟那晚一样。但这次她的声音是锚。她在绝对沉默中到达高潮，身体反应和情绪分离。低语者射精了，滚烫精液在她体内溢出。然后它的形体开始不稳。只有守护者能通过性行为净化低语者——它的消散是因为腐化能量在射精释能后跌破了维持聚合的临界值。金色粒子从暗紫轮廓中渗出，200年的残影，在她体内耗尽了最后的能量。她看着它在她眼前化为金色光柱，消散

- 首次艾玛×低语者遇袭后的主动研究——从被动遭遇转向主动面对
- 研究发生在遇袭数周后，有时间处理创伤。研究是应对机制。多重安全措施到位。失控是共振频率计算错误

- 回归时刻的关键转折：主动告诉法林那晚的事
- 菲娜不出场——这里不需要菲娜，只需要法林

### 提案6：野外帐篷——寒冷中的独处

- 第二天路上的手指小动作——不需要说话的情感确认

- 高潮：节奏放缓，是微醺松弛。她在多尔金身上时叫了法林的名字，要他过来。法林过来握住她的手。哈根在她视线里，他今天没说脏话。艾玛伸手碰哈根的脸。"你今天好安静。""在想词。"他停了。"...没找到。""那你做给我看~"他做了。结束后四个人挤在祖厅的兽皮垫上。艾玛枕着法林手臂，脚搭在多尔金腿上。哈根的鼾声在背景里
- 收束：第二天早餐。哈根的勺子碰碗没停，十七次。他在哼矮人古歌。多尔金给她盛的炖肉比别人多。法林左手在桌下握住她的手指。"我昨晚...说了很多奇怪的话吗？""没有。"法林看着她。"你说的大多是平时没说出口的。"她的耳朵红了，嘴角是弯的。"那以后少喝点~""嗯。""但不用完全少。"

**差异化**：
- 艾玛全程清醒能 consent——微醺松弛，酒精的作用是降低她的自我审查，不是剥夺意识
- 艾玛微醺，松弛但不失控
- 兄弟们看到的是"不跟自己谈判的艾玛"——更诚实，但不失掌控
- "你说的大多是平时没说出口的"——法林一句话收束

### 提案11：安静的夜晚——不需要起因

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch6xx（战争结束后） |
| **对象** | 法林 |
| **起因类型** | 纯爱·日常——没有起因，不需要起因 |
| **场景类型** | 符文室·日常·慢节奏 |
| **性行为等级** | 5-6（轻柔亲密） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+8 / 法林+8 |

**核心设计**：

战争结束了。石殿安静了。这天晚上没有特别的起因——没有任务、没有醉酒、没有委托。符文灯暗绿的光在石壁上安静地亮着，她趴在兽皮垫上看石板拓片，脚搭在他腿上。他的手指在给她按摩小腿——手指知道每一个她舒服的点，从来没忘过。

然后她说了句"法林~"，把脚从他腿上收回来，翻了个身。他看着她的薄荷蓝眼睛——里面没有调戏、没有任务、没有"今天要试试什么"。只是安静地看着他。她把脚踝送到他手边。"继续~"

他从她的脚踝开始往上亲。紫色丝袜不是被扯掉的——是一寸一寸褪下来的。他的嘴唇跟在手指后面：脚踝骨、小腿内侧、膝盖窝。他亲到大腿内侧时，她手里的石板拓片滑到了兽皮垫上——放下了。战争前做爱总有某种紧迫感：时间不够、明天要出任务、还有人在等锻造室的门被敲响。现在什么都没有了。只有他嘴唇的温度、符文灯暗绿的光、和她越来越慢的呼吸。

这就是一切结束之后该有的性爱：不激烈、不新奇、不冒险。两个人在一起很久之后，做爱像说话一样自然——不用想下一句该说什么，身体自己知道怎么接。

**关键节拍**：
- 起因：没有起因。晚饭后，符文室的日常。她翻拓片，他磨刻刀。她把脚搭在他腿上——不是勾引，是这个姿势已经成为他们之间的默认设置了
- 触发：他按摩的手法太熟了——手指沿着她小腿内侧的弧度，力度刚好压到酸胀但不疼。她说了句"法林~"，不是叫名字——是叫他继续，往上的意思。他把她的脚踝托起来，嘴唇贴在踝骨上。然后是第一个吻
- 发展：他从脚踝往上，一路亲一路褪丝袜。不急——不是因为克制，是因为他喜欢这个过程。紫色的丝袜一寸一寸往下卷，他的嘴唇跟在露出来的皮肤上：脚踝骨凸起的弧度、小腿内侧最薄的那片皮肤、膝盖窝——他亲到膝盖窝时她的呼吸碎了半拍，他停了一秒，她的手指穿过他的棕发往下按了一下。继续。亲到大腿内侧时，她手里的石板拓片滑到了兽皮垫上。书可以等。现在不等了
- 高潮：他在她里面，动作很慢——不是因为累，是因为没有理由快。她的腿缠着他的腰，脚踝搭在他后腰上——紫色丝袜还挂在一只脚上，半褪不褪的。她看着他的深绿色眼睛，高潮时叫了他的名字："法林。"不是逐音节拖长的"法~林~"，是完整的、平稳的、两个字里面什么都有。他在她体内射的时候额头抵着她的额头，呼吸混在一起。战争结束了。明天的任务不是出战斗，是继续刻守护符文
- 收束：事后趴在他胸口，手指在他左掌心慢慢画——那里刻着她的名字（一枚小小的、已经褪色过很多次的符文，每次褪了他就重刻一遍）。"你明天要刻什么？""守护。""你每天都在刻守护。""因为是给你的。"她没说话，把脸埋进他胸口。大姐姐在一切结束之后，终于可以完完全全松下来了。符文灯暗绿的光在石壁上安静地亮着。和每晚一样

**差异化**：
- 唯一纯日常向——没有起因、没有第三者、没有隐奸、没有任务
- 时间感：慢，不赶。每一拍都被拉长但不是拖沓——是两个人终于不用在缝隙里偷时间了
- 法林全程主导身体节奏——从按摩到亲吻到进入，他知道她每一个舒服的点。不是第一次探索的谨慎，是长久相处后的默契
- 紫色丝袜半挂在脚上——不是被急切地扯掉，是褪到一半就顾不上继续褪了
- 掌心名字符文在日常中出现——不在高潮中，在事后手指漫无目的地画的时候。守护已经是每天的事

### 提案12：手给我——护理第一夜

### 提案13：还疼吗——恢复中的第一次越界

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（提案12之后几天） |
| **对象** | 法林 |
| **起因类型** | B：护理→身体靠近→从换药滑向第一次亲密 |

| **好感影响** | 艾玛+8 / 法林+10 |

**核心设计**：

几天后，伤口在愈合，不再渗液，边缘开始收干。艾玛每晚来换药已成惯例。今晚拆开绷带时伤口不再是湿的，愈合开始了。两个人同时看着那道正在变成疤痕的伤口，然后同时抬头，然后同时发现对方也在看。换药→唇贴在疤痕边缘→亲手腕内侧、掌心、每根手指指尖。姿势呼应：跪着换药→跪着口交。法林的"我觉得好得很"——矮人工匠第一次学会了说不是符文的句子。

### 提案16：他喝醉了，我们去锻造室——法林意识缺席中的默契

| **对象** | 多尔金 + 哈根（法林在祖厅醉酒睡着） |
| **起因类型** | 法林意识缺席：法林醉酒睡着→艾玛与兄弟去了锻造室→"他在隔壁但他不知道" |

| **黎恩知情** | 否 |
| **好感影响** | 艾玛+10 / 多尔金+8 / 哈根+8 / 法林+8（事后知情） |

**核心设计**：

矮人烈酒。法林酒量三兄弟里最差的，不到两杯就在祖厅长凳上睡着了，呼吸均匀，蜷着身子。艾玛把他的头移到兽皮垫上，给他盖了条毯子，在额头亲了一下。然后多尔金站起来，巨掌在她肩上放了一下，往锻造室的方向偏了一下头。她看了看法林，睡得很沉。然后跟多尔金去了锻造室。哈根已经在里面了，他在调熔炉，手在抖。他知道法林在隔壁睡着了。

**设计要点**：
- 法林在祖厅睡，三人去锻造室。隔着一道石门——法林在隔壁不知道
- "他在但他不知道"的第四种状态——"他在但他不知道"的独特状态
- 三个人的默契是为了不吵醒他。反向的亲密
- 事后约定告知，日常告知

### 提案17：她回来的时候他在睡——法林累倒后的接住

**核心设计**：

- 她给他们身体，他们给她接住
- 法林通过纸条接住她，兄弟通过身体接住她
