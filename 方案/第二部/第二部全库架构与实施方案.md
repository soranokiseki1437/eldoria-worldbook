# docs2 第二部草案全库整理与扩展架构方案

本文档为 `docs2/`（第二部草案）的系统性整理与重构方案。
根据用户的五大确认决策：
1. **内容尺度**：保持 NSFW 能力，角色卡保留三围与私密数据，为后续情感与隐秘背德情节提供支撑；
2. **地点体系**：新建 `docs2/location/`，建筑与空间物理格局必须为私密、隐秘（隐x/背德）提供天然死角与物理掩护，但在文本中仅纯物象描写或微妙暗示；
3. **生物体系**：新建 `docs2/creature/`，涵盖残区影牙兽残余、暗影实验畸变体及五族生物生态；
4. **角色与NPC划界**：将已确立正配与第二部核心男主的 NPC（罗恩、法林、加尔、朱利安）移入 `character/` 核心角色库；剩余 NPC 重新编排解决编号重叠；
5. **背景溯源**：彻底清除艾德里安与雷恩身上的“帝国”残留文字，厘清维里迪亚王国历史与帝国位面关系。
