# 第二部：文风与世界观基调指南

> **定位**：供作者与编写智能体参考的基调指导文件。与第一部写作参考完全隔离，专用于指导《世界书》第二部（维里迪亚王国篇）之篇章创作与台词润色。

---

## 一、核心基调与精神风貌

1. **宏观风格定调**：
   - **正统西幻中世纪封建社会** + **Falcom 轨迹系列（英雄传说）JRPG 正统王道与暗流交织风格**。
   - 展现中世纪封建城邦、骑士教条、教会教权、世俗王权与底层平民/行商的生动社会百态。
   - 继承轨迹系列对“日常烟火气与宏大政治阴谋交织”、“角色微动作与含蓄深沉台词”的叙事质感。

2. **严禁武侠/仙侠/修真词汇（红线词库）**：
   - 维里迪亚王国属于纯正的西方中世纪背景，绝对禁止使用任何东方仙侠、修真、江湖武侠、小资古风修辞。
   - **词汇对照与置换规范表**：
     | 严禁词汇（东方古风/仙侠） | 规范替换词汇（西幻中世纪/轨迹质感） | 语境说明 |
     | :--- | :--- | :--- |
     | 罡风、狂飙 | 荒野冷风、峡谷强风、刺骨寒风 | 描写山谷与关隘风候 |
     | 演武场、演兵场 | 骑士训练场、要塞大操场、跑马校场 | 军事与训练场所 |
     | 地宫、秘阁、暗牢 | 地下密库、石质地窖、拱顶墓室、石牢 | 地底与密室建筑 |
     | 绿河原、黑水泽、狼啸谷 | 维里迪亚平原、暗影沼泽、狼人隐谷 | 自然地理与野外命名 |
     | 集镇、商肆、脚店 | 驿镇、聚落、半木结构旅馆、商铺 | 聚落与商业设施 |
     | 江湖、武林、宗门 | 王国各地、教廷、骑士团、行会、学社 | 势力与社会组织 |
     | 打坐、吐纳、周天、真元 | 冥想、祷告、调整呼吸、凝神、圣光共鸣 | 心理与专注状态 |
     | 大能、高人、尊者 | 主教、大团长、资深学者、隐士、导师 | 人物身份与尊称 |

3. **台词与口吻规范**：
   - 封建阶层礼貌与严谨性：圣殿骑士对话严肃、重誓约、恪守骑士信条；王室教会人员语调和缓、深不可测、言辞间带有神学与政治双关；
   - 粗粝与市井质感：驿镇马夫、雇佣兵、酒馆侍从言语通俗、直接、带有麦酒与麦饼的烟火气；
   - 轨迹角色特色：黎恩沉稳且富有责任感，劳拉凛冽而真挚，菲灵动敏锐，艾玛温柔知性，马奇亚斯严谨务实。

## 二、世界观绝缘铁律：王国绝对零导力（Zero Orbal Tech）

1. **绝对绝缘原则**：
   - **维里迪亚王国（以及整片大陆原住民）在技术史上从未发现导力，全境绝对零导力**。
   - 王国的一切日常运转均建立在传统中世纪物理手段之上：
     - **照明**：鲸油灯、牛油蜡烛、松脂火把、石灶火光；王室与高级教廷仅使用天然发光矿石（如微光水精石）或日光百合符文；
     - **热力与能源**：干柴壁炉、木炭火盆、地热温泉；
     - **机械与动力**：水车、风车磨坊、滑轮组、发条绞盘、纯铁匠锻造；
     - **交通与运输**：四轮载重马车、轻型双轮双马篷车、驮马、步战行军；
     - **远距通讯**：警报信标塔、信鸽、王家快马骑信使（信使链）。

2. **外来导力者的行为边界**：
   - 导力器（战术导力器 ARCUS、导力灯、导力通讯器）仅属于黎恩、劳拉、菲、艾玛、马奇亚斯等从埃雷波尼亚帝国穿过时空裂隙来到此界的外来者；
   - **隐蔽与冲击法则**：
     - 在维里迪亚王国腹地（王都、城镇、酒馆、军营），VII班成员与调查人员**严禁公开炫示导力器具**，必须以斗篷、皮质包裹伪装，避免引发教会将之视为“异端黑巫术”或引发圣殿的武力觊觎；
     - 原住民如果偶然目睹导力通讯或便携导力发光，其认知反应必然是：“那是哪种稀有的古代遗物还是未知的炼金异械？”，绝不可习以为常地直呼“导力”。

## 三、命名规范与美学

1. **字数与节奏控制**：
   - 地点名与建筑名严格控制在 **2 ~ 5 个汉字**；
   - 严禁生硬、累赘的复合词（如“埃斯特雷亚家族旧领遗址”、“暗影低语之幽深沼泽”）；
   - 推荐结构：
     - [特色地貌/人文前缀] + [核心实体词]：如 `法尔肯驿镇`、`维里迪亚关隘`、`圣泉大浴堂`、`黑野猪酒馆`、`暗影地窟`。

2. **音律与西幻质感**：
   - 采用标准西欧封建译名音调（法尔肯 Falken, 维里迪亚 Viridia, 艾斯特雷亚 Astrea, 克莱门特 Clement, 阿达尔伯特 Adalbert）；
   - 保持字面画面感与厚重历史感。
