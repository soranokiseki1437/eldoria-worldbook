# 前十幕大调查规划与十维审查矩阵体系

> **工作区定位**：`方案/第二部/主线与世界扩充方案/前十幕大调查工作区/`
> **核心任务**：对第二部前十幕（第一幕至第十幕，共 34 个阶段详规与 10 个幕大纲接口文件）展开地毯式、深细度核查。
> **核查基准**：严格对照 `docs2/` 实体设定库（角色、NPC、地点、生物、世界观）、母案集群（00~06号母案）、文风法典（`viridia-writer`、`writing-guards.md`、`lexicon.md`）以及后置剧情接口（第十一幕至第十四幕）。
> **本次原则**：**本次不修改实际剧情与方案文件，只做全量穿透分析、建立对账表册并出具总结报告与增删改建议**。

## 一、 审查十维核心诊断矩阵（User Core Checklist）

本次调查严格针对用户指定的十个核心维度展开地毯式扫描，每一幕、每一阶段均须对齐以下矩阵：

| 维度编号 | 诊断维度 | 核心核查定义与判别标准 | 典型事故表现（红线） |
| :---: | :--- | :--- | :--- |
| **DIM-01** | **人物动机缺失/不合理/违背人设 (OOC)** | 角色的言行举止是否严格符合 `docs2/character/` 与 `docs2/npc/` 的性格基调、身心羁绊与行为动因。 | 艾德里安浪子假面与复仇决意失衡；雷恩克制与坚守初心被写成软弱；黎恩失去温和幽默变成哑剧木头人；朱利安被写成政治巨婴或阴谋老叟；菲娜守护者底色崩塌。 |
| **DIM-02** | **剧情逻辑硬伤与物理因果断裂** | 事件发生是否具备充分的物理前提、技术合理性与前后因果咬合。 | 零导力环境下未屏蔽外溢；重伤员未经历生理恢复期立刻生龙活虎；缺乏物理掩护的潜入成功；没有交通工具短时间跨越数十公里。 |
| **DIM-03** | **地点/人物凭空捏造与未建档** | 文本中出现的地理据点、建筑构件、次要人物是否在 `docs2/location/`、`docs2/character/`、`docs2/npc/` 中合法建档并有据可循。 | 随意生造未建档的村落、城镇、哨所、客栈、酒馆；使用第一部或异世界未定义的虚构地点；出现未定义姓名的临时 NPC 抢戏。 |
| **DIM-04** | **前后逻辑矛盾与状态机撕裂** | 跨幕之间对证物归属、角色伤情、武器耐久、外部政治态势的交接是否存在冲突或自相矛盾。 | 这一幕武器折断，下一幕无端自愈或凭空拔出；证物在A处保管却由B在C处突然掏出；前幕达成协议后幕突然当成没发生。 |
| **DIM-05** | **认知突增或认知倒退** | 角色对外部世界、政治黑幕、对方秘密的情报获取是否有合理的消息来源与推理链条；是否发生莫名遗忘。 | 前一秒不知教会阴谋，后一秒直接说出克莱门特三十年前计划；此前已经摸清的关防暗道，后文突然表现得像初次听闻。 |
| **DIM-06** | **开天眼 (全知全能视角)** | 角色在没有斥候、密信、目击或侦察的前提下，直接知道千里之外发生的变故或敌方密谋。 | 黎恩在大本营突然知道王都某条小巷的埋伏；朱利安在深宫未接信报却直接知晓林中同伴的最新伤情。 |
| **DIM-07** | **人物短时间两地分身 (时空折叠)** | 角色在严格的时空日历与 170 公里物理尺度下，移动时间是否符合交通工具速度限制；是否存在瞬移。 | 刚在法尔肯喝茶，当晚出现在王都；大部队在王都激战，次日清晨全员在大本营喝汤。 |
| **DIM-08** | **人物单薄与逻辑牵强 (工具人化)** | 次要人物、反派与平民是否沦为推动剧情的提线木偶；事件推进是否依托生硬巧合而非角色内在动力。 | 平民无条件奉献牺牲却无情感支撑；反派无动机突然自爆破绽；主角团靠降智巧合脱险。 |
| **DIM-09** | **反派认知跳跃或反派降智** | 克莱门特三世、阿达尔伯特、达米安、莫尔茨、维克托等反派的情报网络与应对逻辑是否老辣严密。 | 执掌教会三十年的枢机主教轻易被拙劣谎言蒙骗；大团长毫无城府沦为单纯莽夫；审问官达米安频繁无能狂怒送人头。 |
| **DIM-10** | **剧透、出戏、文风与基准冲突** | 叙事是否出现打破第四面墙的元评论、未来预告；是否存在古风仙侠、世俗军队降阶词；是否违规混入色情文本。 | 旁白出现“在后续剧情中”、“正如读者所料”；主线方案中违规混入大段露骨肉体描写与低俗恶趣味桥段（如违背王道宏篇史诗定位）。 |

## 二、 调查执行程序与阶段划分

1. **第一阶段：设定基准与时空基准建立**（输出 `01_全量设定卡基准白名单与地理时空总表.md`）
   - 提取 `docs2/` 全部 95 张实体卡的核心要素，建立唯一合法白名单。
   - 建立 170 公里地理尺度与 68 周时空日历对照轴。
2. **第二阶段：前十幕分段深度穿透调查**（输出 `02` 至 `06` 调研笔记）
   - 第一幕至第二幕（阶段 1~7）：破冰、建交、生活流展开。
   - 第三幕至第四幕（阶段 8~14）：行商南下、大门水毒、商道许可、两族结盟。
   - 第五幕至第六幕（阶段 15~21）：四路巡礼、铁证起获、冬歇庆典、商路定锚。
   - 第七幕至第八幕（阶段 22~28）：王都商行、市井生活流、白鹿大溃败、断剑被俘。
   - 第九幕至第十幕（阶段 29~34）：绝境流亡、重剑重铸、暗河逆流、死牢测绘。
3. **第三阶段：跨幕全局状态机与反派智商逻辑专项审查**（输出 `07_跨幕时空线_物理状态机与反派认知读条审查.md`）
   - 审查 10 大物理证物传递链。
   - 审查劳拉 60 天重伤恢复期与雷恩 120 天水牢承压极限。
   - 审查达米安、阿达尔伯特、克莱门特三世情报边界。
4. **第四阶段：全景硬伤诊断与增删建议方案**（输出 `08` 与 `09` 方案）
   - 归纳总结前十幕所有缺陷清单。
   - 出具具体的删除建议（去糟粕、去OOC、去文风污染）与新增剧情点建议（补足逻辑链、增强情感厚度）。
5. **第五阶段：前十幕大调查总结报告**（输出 `前十幕大调查总结报告.md`）
   - 面向用户的最终全景交付报告。
