## 二、 阶段剧情推进

### 1. 界标对峙：奥蕾莉亚单手挥剑劈断帅旗
* **路线**：第九幕·阶段三十 / 边境对峙与强者现身
* **主要人物**：卢卡斯, 黎恩, 菲, 督战官, 奥蕾莉亚
* **核心意图**：圣殿三队重装铁骑踩着晨霜薄冰逼近大门大理石界标，督战官叫嚣强行越界搜查；危急关头奥蕾莉亚单身手持阿卡迪亚巨剑步出晨雾，霸气震慑全场，战马惊嘶百骑退缩。
* **时序情境推进**（共 7 条）：
  - 1. 破晓严霜覆满峡谷，维里迪亚大门沉重的生铁吊闸门带着绞盘摩擦声升起；三队全副武装的圣殿重装铁骑踩着晨霜薄冰奔涌而出，战马厚重的覆铁马铠反射冰冷晨光，马蹄铁敲击石板商道激起沉闷轰鸣，深黄烟尘弥漫谷道。
  - 2. 大门以北数百米峭壁岩松阴影下，黎恩与菲隐蔽在乱石凹槽中；黎恩平稳调整战术望远镜焦距测算编制：三队共七十二骑，全员配备生铁重骑枪与阔剑，排头八人携折叠轻弩；菲快速在皮纸上标绘其行进角度，确认其锋芒正向北方森林延伸。
  - 3. 骑队进抵古老大理石界石南侧，少壮派白鹰队长卢卡斯勒马示意全队整队；督战官策马上前粗暴扬起血红火漆搜捕公文，指着界石叫嚣大团长密令在此，全队无需顾忌边线，强行越界搜查。
  - 4. 排头重骑平端五米长生铁骑枪，战马厚重铁蹄已然抬起悬空即将踏过分界线；北侧山道浓白晨雾中，突然传出清脆坚实的战靴踏石声，步调从容有力。
  - 5. 浓雾向两侧翻卷散开，奥蕾莉亚身着深蓝修身制服、外罩深紫色长披风缓步现身；银灰长发垂腰，右手随意搭在单手托握的常人难举巨型重剑“阿卡迪亚”剑柄上，剑首暗金狮首徽记在晨光下泛着沉静威严的冷芒。
  - 6. 没有多余的动作，只是那双紫眸微抬扫过骑兵方阵，沉重如山岳般的顶级强者气势瞬间笼罩谷道；排头战马充血惊嘶猛然人立，后方数十匹战马本能抗尖桩木栅刺驱赶连连倒退，整齐阵型顿时骚动混乱连连后撤。
  - 7. 谷道强劲山风掠过界石，奥蕾莉亚左耳金狮耳坠在晨风中轻轻晃动后静止下垂，整片峡谷里的嘈杂声在这一瞬完全安静下来。

### 2. 一剑之威：花岗岩大道砸出深裂沟
* **路线**：第九幕·阶段三十 / 巨剑重斩断旗与界石深沟立威
* **主要人物**：奥蕾莉亚, 督战官, 卢卡斯, 黎恩
* **核心意图**：督战官蛮横下令六骑冲锋越界，奥蕾莉亚单手挥动阿卡迪亚巨剑斩出纯粹重斩风压，凌空截断白鹰帅旗、轰开十二米坚石深裂沟，单手插剑宣告越界者斩，立下绝对停滞线。
* **时序情境推进**（共 8 条）：
  - 1. 督战官勒紧缰绳稳住惊马，拔出镀银长剑展露公文厉声呵斥，索要搜查权并威吓格杀勿论；卢卡斯凭借敏锐直觉感知奥蕾莉亚剑势厚重难测，策马挡在督战官身前急促劝阻不可轻进。
  - 2. 奥蕾莉亚右手微动，阿卡迪亚厚实剑尖轻触花岗岩石板，沉闷金石钝鸣震得众人脚底发麻；她冷淡嗤笑教令公文与枯草无异，界石以北三百年绝非铁蹄所能践踏。
  - 3. 督战官暴怒推开卢卡斯，挥剑严令排头六骑平挺长枪全速冲锋强行过界；战马覆钢马蹄悍然踏落在大理石界标平齐的石板接缝上。
  - 4. 眨眼之间奥蕾莉亚脚下一步踏稳，右臂手腕瞬间发力，常人双手难举的阿卡迪亚巨剑呼啸出鞘，在半空化作一道耀眼的暗金圆弧。
  - 5. 绝无半点导力光弧与异邦法术，纯粹依凭肉身爆发与巅峰重斩技巧；宽厚剑脊撕裂高压空气掀起暴风般的风压真空风刃，刺耳破空声撕碎峡谷晨雾。
  - 6. 狂暴风刃在半空横扫，四米高处的圣殿白鹰帅旗旗杆应声碎为木屑，厚重战旗翻滚坠落尘埃；余波下压轰落大道正中，花岗岩石板向两侧翻卷碎裂。
  - 7. 浓烈石尘中一条深半米、宽三十厘米、横贯大道达十二米的深裂沟清晰出现；奥蕾莉亚反手插剑于深沟北侧石缝，双手轻搭剑首，冷冽宣告：“越界者——断旗即尔等下场！”
  - 8. 卢卡斯神色凝重举起覆甲右手下达全队止步命令，整条商贸大道陷入好一阵子安静，只有一粒被剑风崩飞的花岗岩碎石滚入深沟深处，发出轻脆的咔嗒声。

### 3. 营帐算盘：圣殿大团长认怂架起木栅封路
* **路线**：第九幕·阶段三十 / 主帐谋算与尖桩木栅封路
* **主要人物**：阿达尔伯特, 达米安, 卢卡斯, 圣殿信使
* **核心意图**：界标深沟与断旗急报传回要塞主帐，阿达尔伯特审视断木剑痕，判定北境有蛮荒隐世强者，断然拒绝为教廷当炮灰；签署戒严告令架设尖刺木栅扎营封锁道路只守不攻，卢卡斯驻守前沿信念动摇。
* **时序情境推进**（共 7 条）：
  - 1. 暮色降临，圣殿要塞顶层主帐内牛油烛火摇曳；信使跪呈断裂旗杆木茬与界石深沟拓印图纸。
  - 2. 阿达尔伯特手掌反复摩挲平滑的红衫木断裂面与石裂拓印，眉头拧紧沉声定性：单手挥巨剑风压断木裂石者，乃北方森林避世不出的顶尖隐世强者，各大修会无人能及。
  - 3. 达米安掀帘而入面色阴鸷，厉声主张调派异端死士与重型床弩连夜压境放火烧林；阿达尔伯特拿起生铁剪烛小刀咔嚓剪断烛芯，语调冷硬：圣殿铁骑是守备主力，绝不给教廷当送死的干柴。
  - 4. 阿达尔伯特签署大门防务戒严告令，以严查逃犯为名全面封锁大门主驿道；巡防队连夜推来覆铁木栅与带倒刺尖刺木栅，在界标以南两百米筑起连绵布帐。
  - 5. 圣殿防务严密扎实却全无进攻意图，将搜查脏活推脱给教廷暗探；达米安咬牙调动暗部斥候展开隐蔽盯梢，两大阵营裂痕进一步激化。
  - 6. 卢卡斯受命留守前沿帐营，深夜独自按剑巡视石堑边缘，回想白鹿驿馆遭遇的黑酸战兽与十四年前雷恩案，内心坚守的骑士誓约深感触动。
  - 7. 第一道防骑木栅横木上系着一根用于辨识界线的褪色红亚麻布条，夜半刺骨山风穿过狭窄谷道，布条在黑暗中被撕扯得笔直，发出短促的啪啪抽打声。

### 4. 马厩草堆：提米吹响小木笛暗号与菲接头
* **路线**：第九幕·阶段三十 / 水牢暗信与小木笛接头
* **主要人物**：雷恩, 瓦尔特·巴恩斯, 提米, 菲, 莫尔茨
* **核心意图**：水牢雷恩获悉前线大捷沉稳蓄力；大门马厩深处守备队长幼孙提米吹响白桦木小短笛与菲接头，摸清石砌泄洪暗渠巡查空档。
* **时序情境推进**（共 6 条）：
  - 1. 坚硬黑石水牢深处换班对话传入暗潭，巴恩斯将北方界石一剑断旗轰裂、大团长下令戒严不敢进森林的消息告知雷恩；刺骨暗河水中负重三十公斤的雷恩嘴角扬起，沉着蓄力。
  - 2. 典狱长莫尔茨前线吃瘪面色阴沉，恶狠狠吐掉烟斗残灰，下令在第七号水牢外层生铁吊门上额外加挂两道浸油重锁，水牢防备森严。
  - 3. 维里迪亚大门下层防雨重装马厩内，五岁的小提米在四轮大车与干草垛死角躲着，小手紧抓祖父削制的白桦木小短笛。
  - 4. 菲倒挂在马厩顶棚粗木阴影中，确认巡查空档后模仿夜鸟发出两短一长低鸣；草堆里的小提米鼓起腮帮子，拿起小短笛吹出短促清脆的木管笛音回应。
  - 5. 菲飘然落地塞给孩子一块干净黑麦饼，摸清大门古代石砌泄洪暗渠出口的巡防交接空档，完成情报接头。

### 5. 地窖油灯：劳拉退烧绘制重铸大剑草图
* **路线**：第九幕·阶段三十 / 伤势好转与重铸大剑草图
* **主要人物**：劳拉, 黎恩, 菲娜, 艾玛, 乔治
* **核心意图**：劳拉高烧彻底退去稳步下床，与黎恩菲娜研讨防酸大剑重心配重与黑酸特性；艾玛结合卢恩图谱确立导酸微槽重铸方案，绘制羊皮图纸，明确断刃寻回目标。
* **时序情境推进**（共 6 条）：
  - 1. 艾玛用陶锅煨热野山菌麦糊，菲娜轻柔扶起劳拉；高烧彻底退去的剑士面色红润，站直身躯缓步行走，步履沉稳有力。
  - 2. 花岗岩石台上大剑残柄整齐安放；劳拉指尖抚过断面焦黑发脆的金属晶格，剖析生化强酸会顺着金属孔隙造成内部分子坏死脆断，单靠硬度无法抗衡。
  - 3. 艾玛展开干燥古羊皮纸用炭笔勾勒：在星银基底上开凿两道对称弧形“导酸微槽”分流酸液，并由矮人工匠使用银刻针雕出防酸卢恩。
  - 4. 黎恩用细油石替劳拉打磨残柄断口毛刺，劳拉指出重剑若求不折当取前半截断刃的秘金精纯钢芯，重铸方案彻底清晰。
  - 5. 乔治从工具包取出生牛皮尺仔细复核剑脊受力配重，众人围坐油灯下商量，重创在此转化为重铸好剑的契机。
  - 6. 大橡木桶顶盖平铺的亚麻布图纸上巨剑草图清晰可见，一截熄灭的栎木炭条斜搁空白处，地窖通风石缝漏入的山风吹散细微炭灰，在布纹间留下深黑痕迹。

### 6. 深夜商议：敲定菲走泄洪暗渠北上取回断刃
* **路线**：第九幕·阶段三十 / 领民猎道联络与暗渠潜行商定
* **主要人物**：艾德里安, 老吉尔, 朱利安, 菲, 劳拉, 黎恩, 菲娜, 奥蕾莉亚
* **核心意图**：艾德里安以染血铜印集结领民绘制暗道避开巡哨；全员商议，定下菲潜入石砌泄洪暗渠寻回白鹿驿馆断刃的行动，交由阶段三十一承接。
* **时序情境推进**（共 7 条）：
  - 1. 深夜酒庄后坡草棚内老吉尔引来周边七村老农与青年猎户，艾德里安拿出刻有双剑鹫鹰与葡萄藤纹样的染血黄铜印信，领民热泪盈眶誓死追随。
  - 2. 艾德里安快步上前扶起老领民，托付山间猎道巡护；青年猎户在泥地上划出穿梭峭壁、直通大门暗渠外围的羊肠泥泞小道。
  - 3. 地窖整备台前全员齐聚推演局势：前方大门被奥蕾莉亚强悍重斩震慑，阿达尔伯特闭门坚守不攻，为小队赢得隐秘行动窗口。
  - 4. 劳拉轻抚大剑残柄转向菲：“前半截断刃遗留在白鹿驿馆废墟残柱下，那是重铸不可或缺的筋骨；拜托你了”；菲利落系紧双刃短刀点头答应。
  - 5. 艾德里安摊开猎户暗道图，结合提米提供的泄洪暗渠巡防空档敲定路线：菲只身潜入暗渠北上，利用猎道折返白鹿河畔取回断刃送往大本营锻炉。
  - 6. 菲披上防雨深灰斗篷走进夜色，黎恩与菲娜站在地窖石阶目送，彼此眼神里满是信任与默契。
  - 7. 大门以北一公里大理石界石前，横贯大道的十二米巨剑深裂沟在晨雾中非常清晰，一滴积聚整夜的冰凉草露顺着切平断面滑落，在苍白基座上啪的一声轻柔碎开。
