## 二、 逐章详尽剧情演进（共 10 章）

### 第 86 章：工坊街深处的游丝之音
* **阶段/路线**：第三幕·阶段九 / 工坊街偶遇与初识科林
* **主要人物**：玲, 艾玛, 科林
* **核心意图**：玲与艾玛漫步工坊街，偶遇“白鸽与游丝”钟表铺，初见纯良邻家少年科林，引入核心关键配角。
* **时序情境推进**：
  - 1. **漫步工坊街**：午后阳光洒在下城工坊街青石板上，两旁传来锉刀细削铜件与风箱呼呼的声响；玲与艾玛手挽手闲逛，寻找修车用的特种拉簧。
  - 2. **清脆擒纵声**：玲敏锐的耳朵在嘈杂市井声中捕捉到极其微小、极其精准的规律性滴答声；寻声推开街角一家名为“白鸽与游丝”的狭窄小店，门框上方挂着的黄铜风铃发出清澈脆响。
  - 3. **初见少年**：店内靠窗的长木工作台前，年仅18岁、身穿浅灰帆布围裙的少年科林正戴着单眼放大镜，用鹿皮镊子极其轻柔地挑起一根细如发丝的钢质游丝；听见开门声，少年慌忙抬头，耳尖微红，手忙脚乱地用围裙擦手。
  - 4. **纯净第一印象**：少年有些结巴地向两位气质非凡的客人打招呼；玲金色的眸子扫过工作台上摆放的数十枚纯机械齿轮，露出了感兴趣的笑意。

### 第 87 章：非导力发条与机巧切磋
* **阶段/路线**：第三幕·阶段九 / 纯机械切磋与学术折服
* **主要人物**：玲, 科林, 艾玛
* **核心意图**：玲与科林的技术较量，惊叹于纯机械游丝校准的天赋；科林腼腆展现微型八音盒。
* **时序情境推进**：
  - 1. **游丝校准较量**：玲随手拿起一枚有偏差的摆轮擒纵器指出摆角不足；科林没有争辩，而是闭上双眼，仅将摆轮贴在耳边听了两秒振动，用细铜针在擒纵叉上极微地拨动了千分之一厘。
  - 2. **纯粹手艺震撼**：玲将零件放回测试架，惊异地发现没有任何测量仪表辅助下，摆轮的周期误差居然降到了零！向来自负天才的导力少女第一次对本土少年的手艺流露出由衷赞许。
  - 3. **展示微型八音盒**：见客人懂行，科林腼腆地拉开最底层的木抽屉，捧出一只仅有半个手掌大、由纯铜黄铜发条驱动的微型八音盒；轻轻拧动发条，清脆悠扬如林间清泉般的音律在小店内流淌开来。
  - 4. **初心袒露**：科林低声解释，这是他在照顾隔壁生病孩童时制作的，希望清脆的琴音能赶走噩梦；艾玛眼中泛起动容的温柔。

### 第 88 章：两双纯净的薄荷蓝眼眸
* **阶段/路线**：第三幕·阶段九 / 艾玛与科林的姐弟羁绊
* **主要人物**：艾玛, 科林, 玲
* **核心意图**：艾玛与科林的长谈，发现相同的瞳色；科林弹奏《晨曦森林》，姐弟般温润羁绊确立。
* **时序情境推进**：
  - 1. **摘下放大镜的长谈**：科林取下单眼目镜，艾玛端坐在木椅上与其温和交谈；当少年抬起澄澈的面庞时，艾玛不禁微微愣神。
  - 2. **相同的薄荷蓝**：少年的眼眸与艾玛几乎如出一辙——那是澄澈纯净、毫无杂质的薄荷蓝，透着对世间万物的温柔善意；科林被温婉知性的大姐姐注视着，脸颊再次泛起红晕。
  - 3. **晨曦森林之曲**：科林换上特制的带凹槽音筒，转动八音盒，演奏出王都古老的民谣《晨曦森林》；艾玛轻声随着节律低声吟唱，两人的声音与音律在小铺中和谐交融。
  - 4. **羁绊缔结**：艾玛温柔地揉了揉少年的浅发，从行囊中取出一小包埃雷波尼亚带来的清甜草药糖赠给科林，少年如获至宝般郑重收好，姐弟般的温润信任油然而生。

### 第 89 章：白榆货栈的工匠采购

* **主要人物**：黎恩, 科林, 乔治
* **核心意图**：黎恩前往工坊街为货栈重篷车采购拉簧，帮瘦削的科林扛运老铸铁台钻，结下工匠之谊。
* **时序情境推进**：
  - 1. **采购重拉簧**：黎恩受乔治所托来到“白鸽与游丝”铺挑选高韧度防酸拉簧；科林热情迎上前，为黎恩挑选出淬火最均匀的四副高碳钢拉簧。
  - 2. **老台钻困局**：铺子后院角落堆着一台刚自码头运来的两百磅旧铸铁手摇台钻，科林与年迈的店主正犯愁无法将其抬入狭窄的里屋工坊。
  - 3. **黎恩神力相助**：黎恩卷起袖子，微笑道“我来帮把手吧”；只见黎恩沉腰跨步，双手稳稳扣住铸铁台钻底座，浑身肌肉隆起，举重若轻地单人将沉重的铁家伙平稳抱起，步履稳健地移入里屋安装在厚木操作台上，分毫不差。
  - 4. **折服与敬重**：科林与老店主看得目瞪口呆，连连道谢；黎恩微笑着拍了拍手上的铁锈，向科林传授了两招加固夹头防松脱的杠杆小窍门，少年敬佩得两眼放光。

* **时序情境推进**：
  - 1. **路过货栈送件**：黄昏时分，科林抱着装有精修机芯的木盒送货路过白榆货栈，在大门前探头张望；正巧遇上在院内劈柴整备的黎恩。
  - 2. **回赠防锈特用油**：黎恩将一小瓶大本营特制的纯矿物无酸防锈机油递给科林：“这个比鲸油更耐挥发，用来润滑游丝轴尖很合用。”科林惊喜万分。

* **时序情境推进**：
  - 1. **深入地下二层涵洞**：哈根带着乔治与法林换上厚牛皮防水高筒靴，深入白榆货栈下方的下水道次级排污拱道。
  - 2. **矮人粗豪古调**：地底暗流湍急，回音空旷；哈根扯开粗嗓门哼着两百年前矮人矿坑的古老民歌，音波在石券间震荡，哈根通过回音在耳膜上的振动敏锐判断空间跨度。

### 第 94 章：工坊街夜市的旧书摊

* **主要人物**：艾玛, 科林, 玲
* **核心意图**：艾玛与科林在夜市地摊搜寻古老发条图纸，交流机械与古代符文共鸣。
* **时序情境推进**：
  - 1. **下城夜市灯火**：下城石桥两侧点起一盏盏马灯，形成热闹的旧货与夜市地摊；艾玛与玲受科林之邀一同走访旧书地摊。
