### 第 76 章：宏伟石门与王都下城晨雾
* **阶段/路线**：第三幕·阶段八 / 王都初至与入城检验
* **主要人物**：艾德里安, 黎恩, 菲娜, 亚莉莎, 雷恩
* **核心意图**：商队双马重篷车抵达王都南外门，公秤处火耗称重交税，租下下城临河“白榆货栈”，确立立足点。
* **时序情境推进**：
  - 1. **晨雾石门**：薄雾笼罩的清晨，商队四轮重篷车沿石板商贸大道缓缓驶抵王都南门；青黑玄武岩城门高达二十米，生铁吊栅门悬于上方，城堞迎风飘扬着双头狮旗与圣殿白鹰战旗。
  - 2. **公秤处火耗**：艾德里安递交北方商会通行文牒；公秤处文官将商队携带的粗银条放在青铜巨秤上称量折算，克扣“铸造火耗”兑换为三袋沉甸甸的王国紫铜便士与旧银克朗；亚莉莎暗中在羊皮纸记录火耗损耗比率。
  - 3. **租下白榆货栈**：在迷迭香商行暗线中介下，艾德里安以三十枚银克朗租下下城区临运河的一处石造旧货栈——门牌铭刻着斑驳的“白榆”，内设宽敞仓房、卸货码头与两层带壁炉的木筋起居阁楼。
  - 4. **驻扎落脚**：两辆马车驶入院内，沉重的生铁插销合拢；全员踏入散发着干燥麦草与老松木香气的大堂，正式在王都扎下第一处坚实驻点。

### 第 77 章：曲折石板窄巷的炊烟
* **阶段/路线**：第三幕·阶段八 / 货栈整备与市井安顿
* **主要人物**：黎恩, 菲娜, 爱丽榭, 法林, 劳拉
* **核心意图**：全员分工整备货栈；黎恩与法林加固仓房大门，菲娜与爱丽榭清理起居阁楼，展现温馨安稳的日常生活流。
* **时序情境推进**：
  - 1. **分工打扫**：菲娜与爱丽榭打来井水，擦洗二层阁楼的实木窗框与床铺，将干燥的麦秸新床褥铺整一新；阁楼小窗推开，正对下城错落有致的青石板屋顶与缕缕炊烟。
  - 2. **仓房木工加固**：黎恩脱去外套，身着粗布衬衫与矮人工匠法林一起检修一层货仓；法林挥动木槌更换开裂的地龙骨，黎恩运劲稳稳扶住沉重的立柱，二人合力为大门加装双重熟铁抱箍与暗栓。
  - 3. **生火煮汤**：厨房石壁炉生起无烟栎木炭火，爱丽榭将腌肉、干鹰嘴豆与切碎的洋葱倒入大陶锅熬煮浓汤，空气中弥漫开浓郁温暖的食物香气。
  - 4. **傍晚围坐**：劳拉将擦拭干净的长木凳搬到餐桌旁，众人围坐喝着滚烫的面包菜汤，下城石板路传来远方巡更木梆声，商队完成首日安顿。

### 第 78 章：河畔白榆货栈的清点

* **主要人物**：亚莉莎, 艾德里安, 乔治, 菲
* **核心意图**：亚莉莎梳理莱恩福尔特复式账册，艾德里安向北方行会递交第一批货物报关单，建立合法行商屏障。
* **时序情境推进**：
  - 1. **货物清点分类**：货仓内码放着掩护用的北地灰松鼠皮、风干酪块与粗亚麻布匹；乔治仔细检查装有隐蔽物料的防潮夹层箱，确保铅封与皮革外壳万无一失。
  - 2. **复式记账法展露**：亚莉莎在算盘与鹅毛笔前运笔如飞，运用现代复式记账法将货物的进价、折旧、王都关税火耗与损耗折算列得清清楚楚，账目严丝合缝；艾德里安赞叹连连，称此账册足以令王都最挑剔的公秤税官哑口无言。
  - 3. **行会文牒初审**：艾德里安将报关单送交下城行会办事所，公办人员见账目清晰详尽、附带北方正规商会印牌，顺利盖下初审红戳。
  - 4. **防务踩点**：菲轻巧翻上货栈屋脊，将周边三个街区的巡逻路线与建筑屋顶死角制成手绘简图，交由货栈留存。

* **时序情境推进**：
  - 1. **集市晨景**：清晨的下城集市熙熙攘攘，叫卖声、石板推车骨碌碌的车轮声交织成片；菲与劳拉提着柳条编筐漫步于杂货摊位之间。
  - 2. **货币称量折算**：在面粉铺前，老店主用铜制小天平称量几枚磨损严重的紫铜便士，嘴里嘟囔着“边缘剪边的破钱要多贴两枚”；劳拉认真观察市井交易规矩，递上完好的新版铜币，顺利购得半袋筛净的上等黑麦粉。

### 第 80 章：白榆货栈门前的车马堵塞
* **阶段/路线**：第三幕·阶段八 / 街头排险与初遇卢卡斯
* **主要人物**：黎恩, 卢卡斯, 雷恩, 乔治
* **核心意图**：运河码头运粮货车断轴堵路，黎恩手持垫铁迅速排险，先锋骑兵队长卢卡斯巡防初次识荆。
* **时序情境推进**：
  - 1. **狭道堵塞**：白榆货栈门前狭窄的运河石桥口，一辆满载谷物的笨重双轮运粮车突然发生车轴脱榫，生铁抱箍断裂，侧翻的大车将道路彻底堵死，两端车马滞留喧哗。
  - 2. **卢卡斯严正巡防**：白鹰队长卢卡斯率领四骑先锋骑兵巡逻至此；面对手足无措的贫苦车夫，巡骑副官欲拔剑强行推车入河清障，卢卡斯厉声喝止：“退下！骑士之剑不向平民示威，下马协助抬车！”
  - 3. **黎恩纯熟排险**：黎恩当时正与乔治在门前修整篷车，见状手提一根厚重的熟铁撬棍与垫木快步上前；黎恩低声叮嘱车夫稳住车把，借力沉腰踏步，撬棍精准卡入车底承重死穴，单臂发力生生将沉重粮车撬起十余公分！乔治顺势推入厚木方，黎恩手持生铁锤两记精准敲击，迅速归正脱落车轴并敲入备用木楔，仅数息便解除了危机。
  - 4. **心照不宣之礼**：运粮车顺利移开道路复通；卢卡斯惊异于眼前年轻工匠举重若轻的力道与沉稳气度，下马向黎恩抚胸致礼：“好身手，好眼力。白鹰先锋骑兵队长卢卡斯，多谢阁下解围。”黎恩收起铁锤，平静回以工匠礼：“分内之事，骑士大人过奖。”
