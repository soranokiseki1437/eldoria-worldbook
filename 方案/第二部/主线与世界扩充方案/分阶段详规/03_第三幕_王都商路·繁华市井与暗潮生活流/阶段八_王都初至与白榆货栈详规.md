## 二、 逐章详尽剧情演进（第 76 ~ 85 章）

### 第 76 章：青黑石门——白榆落脚
* **阶段/路线**：第三幕·阶段八 / 王都初至与入城安顿
* **主要人物**：艾德里安, 黎恩, 菲娜, 亚莉莎, 雷恩, 爱丽榭, 法林
* **核心意图**：双马重篷车抵达王都南外门，公秤处火耗结算兑换紫铜便士与旧银克朗，租下下城临河双层石木“白榆货栈”，全员分工修缮大门、生火煮汤，在王都扎下坚实立足点。
* **时序情境推进**（共 7 条）：
  - 1. 晨雾笼罩的清晨，商队四轮重篷车沿石板商贸大道缓缓驶抵王都南门；二十米高的青黑玄武岩城门券下，生铁吊栅门高悬，双头狮旗与圣殿白鹰战旗在晨风中翻卷。
  - 2. 艾德里安递交北方商会通行文牒；公秤处文官将商队携带的粗银条置于青铜大天平上称量折算，克扣“铸造火耗”，兑换为三袋沉甸甸的王国紫铜便士与磨损旧银克朗，亚莉莎暗中在羊皮纸记录火耗损耗比率。
  - 3. 在迷迭香商行暗线中介下，艾德里安以三十枚旧银克朗租下下城临运河的一处石造旧货栈——门牌斑驳铭刻着“白榆”，内设宽敞仓房、卸货码头与两层带壁炉的木筋起居阁楼。
  - 4. 两辆重篷车驶入货栈院内，沉重的生铁插销合拢；全员踏入散发着干燥麦草与老松木香气的大堂，正式在王都扎下第一处坚实驻点。
  - 5. 菲娜与爱丽榭打来清冽井水，擦洗二层阁楼的实木窗框与床铺，将干燥的麦秸新床褥铺整一新；阁楼小窗推开，正对下城错落有致的青石板屋顶与缕缕炊烟。
  - 6. 黎恩身着粗布衬衫与矮人工匠法林合力检修一层货仓；法林挥动木槌更换开裂的地龙骨，黎恩运劲稳稳托住立柱，二人为大门加装双重熟铁抱箍与暗栓。
  - 7. 厨房石壁炉生起无烟栎木炭火，爱丽榭将腌肉、干鹰嘴豆与洋葱倒入陶锅熬煮浓汤；众人围坐长凳喝着热汤，下城石板路传来远方巡更木梆声，壁炉余烬在暗夜中散发着微红暖光。

### 第 77 章：剪边紫铜——复式清账
* **阶段/路线**：第三幕·阶段八 / 商业复式记账与市井货币生活流
* **主要人物**：亚莉莎, 艾德里安, 乔治, 菲, 劳拉, 菲娜, 爱丽榭
* **核心意图**：亚莉莎梳理莱恩福尔特现代复式账册对接行会初审，菲屋脊测绘防务简图，同伴深入下城集市采购口粮，体验剪边破钱称重与市井温情。
* **时序情境推进**（共 7 条）：
  - 1. 货仓内整齐码放着北地灰松鼠皮、风干酪块与粗亚麻布匹；乔治仔细检查装有隐蔽物料的防潮夹层箱，确认铅封与皮革外壳严密完好。
  - 2. 亚莉莎伏案疾书，凭借莱恩福尔特家族严谨的财务训练，运用现代复式记账法绘制借贷平衡图谱，将货物进价、折旧与王都火耗列得严丝合缝；艾德里安赞叹此账册足以令挑剔税官无从挑刺。
  - 3. 艾德里安将报关单送交下城行会公署办事所，公办人员见账目清晰详尽、附带北方正规商会印牌，顺利盖下初审红戳。
  - 4. 菲轻巧翻上货栈屋脊，伏在烟囱后将周边三个街区的巡逻路线与建筑屋顶死角制成手绘简图，交由货栈留存。
  - 5. 清晨下城集市熙熙攘攘，叫卖声与石板推车车轴骨碌碌声此起彼伏；菲与劳拉提着柳条编筐漫步于杂货摊位之间采购口粮。
  - 6. 在面粉铺前，老店主用黄铜小天平称量几枚磨损严重的紫铜便士，嘟囔着剪边损耗需贴补两枚；劳拉认真辨识市井交易规矩，递上足值新版铜币，顺利买下半袋精细黑麦粉。
  - 7. 菲挑选带泥防风草与新鲜胡萝卜，菲娜与爱丽榭挑选烹调用的麝香草束；热情的面包大婶赠送了两块刚出炉的肉桂软饼，少女们在街心石喷泉旁分食，水珠滴落在长满斑驳青苔的石盆边缘。

### 第 79 章：断轴狭道——飞锤排险
* **阶段/路线**：第三幕·阶段八 / 货栈前运粮车断轴与初识卢卡斯
* **主要人物**：黎恩, 卢卡斯, 乔治, 雷恩
* **核心意图**：货栈门前运河石桥发生运粮车脱轴翻覆狭道堵塞，卢卡斯严正巡骑禁止扰民，黎恩单臂撬车纯熟换楔，两人因工匠之技初次结缘。
* **时序情境推进**（共 6 条）：
  - 1. 白榆货栈门前狭窄的运河石桥口，一辆满载谷物的笨重双轮运粮车突然发生车轴脱榫，生铁抱箍断裂侧翻，将狭窄桥道彻底堵死，两端车马滞留喧哗。
  - 2. 白鹰先锋骑兵队长卢卡斯身着银白胸甲、率四骑巡防小队行经至此；副官欲拔剑强行推车入河清障，卢卡斯厉声喝止：“退下！骑士之剑不向平民示威，下马协助抬车！”
  - 3. 黎恩提着厚重熟铁撬棍与垫木自货栈快步走出，低声叮嘱车夫稳住车把；黎恩压低重心踏步，撬棍精准卡入车底承重死穴，单臂发力硬生生将数千磅大车撬起十余公分。
  - 4. 乔治顺势推入厚木方支垫，黎恩挥动生铁锤两记精准敲击，迅速归正脱榫车轴并嵌紧备用硬木榫头，仅数息便使重车稳稳着地。
  - 5. 运粮车移开道路复通，车夫感激涕零；卢卡斯惊异于眼前粗布工匠举重若轻的力道与沉稳气度，下马抚胸郑重致谢：“好身手，好眼力。白鹰先锋骑兵队长卢卡斯，多谢阁下解围。”
  - 6. 黎恩收起铁锤，平静回以工匠礼：“分内之事，骑士大人过奖。”巡骑队伍踏步离去，桥头石板上留下一道深深的铁撬划痕。

### 第 80 章：临河铁砧——暗渠听石
* **阶段/路线**：第三幕·阶段八 / 工匠冶金考察与地下暗渠主拱勘测
* **主要人物**：乔治, 法林, 哈根, 黎恩
* **核心意图**：工匠组走访老铁匠铺评估本土封建冶金，哈根深入地下排污涵洞敲石听音勘测两百年罗曼石券主拱受力，手绘暗渠力学草图。
* **时序情境推进**（共 7 条）：
  - 1. 沿运河下游步入打铁作坊区，铁砧铿锵与煤烟弥漫；法林与乔治走进一家挂着风车铁砧招牌的老铁匠铺，采买本土褐煤与粗铁矿渣样本，评估封建传统风箱的锻造温度与铁质韧性。
  - 2. 货栈后院工棚内，黎恩协助法林与乔治，利用传统炭火将篷车磨损的刹车铁皮与拉簧重新回火热锻，打磨得严丝合缝。
  - 3. 大本营随行建筑大师哈根叼着陶土烟斗，身穿油渍皮马甲，领着弟弟法林与乔治换上防水长靴，踏入白榆货栈下方的地下排污涵洞入口。
  - 4. 幽深阴冷的地下主涵洞内两壁皆为罗曼式花岗岩拱券，暗渠渗水滴答；哈根大口灌着黑啤哼着矮人古调，手持八磅锻铁地质锤连续敲击主拱肋梁数十处结合石。
  - 5. 哈根侧耳倾听岩石传递的回响，精准指点：“主拱吃重在上方第七级悬挑石，两百年前修这渠的人在拱顶偷了料，用了劣质生铁销钉代替铆固！”
  - 6. 哈根就着微弱马灯在黄牛皮纸上飞快勾勒出暗渠与上方要塞悬崖承重主拱的力学草图，准确标出两处结构致命弱点。
  - 7. 乔治协助核对图纸尺寸并收纳扣紧铁盒，地底暗渠的浑浊水流在石壁下方无声打着旋涡。

### 第 81 章：公署刁难——法理交锋
* **阶段/路线**：第三幕·阶段八 / 行会公署受阻与法理商战筹谋
* **主要人物**：艾德里安, 亚莉莎, 玛格丽特, 教会税官
* **核心意图**：艾德里安办理商队长期居留文牒，遭遇教会代理税官无理刁难索贿，亚莉莎援引法典条款据理力争，确立商战突破口。
* **时序情境推进**（共 5 条）：
  - 1. 艾德里安与亚莉莎前往中城区行会公署大厅，申请为期两个月的商队长期居留与批发贸易执照。
  - 2. 当值的教廷特派监督税官面带傲慢冷笑，将申请卷宗摔在柜台上，蛮横勒令北方商货必须缴纳三倍惩罚性防邪税，且必须出具晨光大教堂驻防司铎亲笔签署的圣洁担保书。
  - 3. 亚莉莎从容上前，当场调出《王国自由贸易公约》法典原本与北方商会互免协定条款，逐条指出教会单方面设立额外捐税系越权违宪；迷迭香商行暗线引荐的行会老书记官亦适时介入调解。
  - 4. 税官冷汗浸透领口哑口无言，悻悻收回卷宗，勒令五周后复核；艾德里安与亚莉莎明确反派在商路上的全面卡脖子意图，商议通过结交中立贵族彻底穿透审批壁垒。
  - 5. 暮色洒满行会公署门前的青石台阶，公署铜钟敲响下班沉鸣，鸽群扑棱着翅膀掠过雕花石栏。

### 第 82 章：战斧裂疤——暗室警讯
* **阶段/路线**：第三幕·阶段八 / 街角辨识旧仇与货栈闭门戒备升级
* **主要人物**：雷恩, 劳拉, 黎恩, 菲娜, 艾德里安
* **核心意图**：雷恩在要塞悬崖街角远眺认出要塞典狱长莫尔茨，手腕放逐火印剧痛克制，货栈闭门长谈全面调整戒备等级。
* **时序情境推进**（共 7 条）：
  - 1. 黄昏时分，雷恩与劳拉在要塞悬崖底部的石阶排查撤退路线；夕阳如血，将要塞森严的高墙染成深红。
  - 2. 在石造酒肆门前，雷恩脚步猛然顿住——视线穿过巷道阴影，一名身高近两米的魁梧骑士大步踏上石阶；此人身披带有生铁倒刺的碎颅重铠，左脸横贯战斧撕裂疤痕，眼神如秃鹫般阴鸷嗜血。
  - 3. 雷恩右手死死按住左手腕处的衣服，指节发白——十四年前暴雨中被烧红铁烙烙下流放烙印的耻辱剧痛再次苏醒，当年亲手执刑将老骑士们推入死牢的正是眼前这个要塞典狱长莫尔茨！
  - 4. 劳拉敏锐察觉异样，不动声色踏前一步用斗篷遮挡视线，手掌轻轻按在雷恩紧绷的臂膀上稳住其杀意；雷恩闭目敛住杀意，二人悄然隐退。
