## 二、 逐章详尽剧情演进（共 10 章）

### 第 106 章：白鸽与游丝的离别赠礼
* **阶段/路线**：第三幕·阶段十一 / 工坊街告别与八音盒赠礼
* **主要人物**：黎恩, 艾玛, 科林
* **核心意图**：黎恩与艾玛前往工坊街向科林道别，科林赠予小巧纯铜风铃八音盒：“愿琴声保佑大家平安”，埋下照亮至暗时刻的永恒微光。
* **时序情境推进**：
  - 1. **晨曦中的道别**：商队拔营前夕，黎恩与艾玛再次推开“白鸽与游丝”钟表铺的木门，门顶铜铃发出熟悉的清响；科林从工作台后快步迎出。
  - 2. **少年依依不舍**：得知商队即将启程远赴平原大道，少年薄荷蓝的眼眸中满是不舍；科林从内室郑重捧出一个铺着红丝绒的红木小匣。
  - 3. **纯铜风铃八音盒出世**：匣内是一只巴掌大小、以王国纯紫铜精细打磨而成的微型八音盒；外壳雕刻着展翅的白鸽，顶部装有一枚小巧的风铃铛。拧动发条，清脆宛如晨露坠落绿叶的空灵琴音悠悠回荡。
  - 4. **真挚祝福**：科林低着头，声音带着少年人特有的腼腆与真诚：“黎恩先生，艾玛小姐……这是我调试了整整半个月的机芯。无论遇到什么风雨，只要听到这个声音，就一定能平安回来。”艾玛动容地将少年轻轻搂在怀中，黎恩郑重接过木匣收入行囊贴身暗格。

### 第 107 章：王都商栈暗线的全面托付
* **阶段/路线**：第三幕·阶段十一 / 白榆货栈托付与商会常态化
* **主要人物**：亚莉莎, 艾德里安, 玛格丽特
* **核心意图**：亚莉莎与玛格丽特夫人完成账目交接，托付商栈老主管维持白榆货栈日常运营，留存王都隐秘退路。
* **时序情境推进**：
  - 1. **账目交割**：白榆货栈二层办公室内，亚莉莎将整理完备的货栈全套账册、仓储租赁契约与剩余的一袋王国旧银克朗移交给迷迭香商行指派的可靠老主管。
  - 2. **常态化经营指令**：艾德里安叮嘱老主管：“对外继续以普通北地毛皮和干酪货栈正常接单开工，按时缴纳市井税款，切勿显露任何异样。”
  - 3. **玛格丽特夫人的暗线承诺**：玛格丽特夫人饮了一小口红茶，沉着保证：“放心，这处运河码头商栈已在商会名下彻底合法化；一旦前线有变，这里随时是可以容纳三十人隐蔽集结的地下安全屋。”
  - 4. **退路闭环**：全员确认王都联络暗记与信鸽交接密码，完成了后勤退路的绝对闭环。

### 第 108 章：哈根绘制的暗渠总草图
* **阶段/路线**：第三幕·阶段十一 / 暗渠草图封存与地底伏笔锁定
* **主要人物**：哈根, 乔治, 法林
* **核心意图**：哈根将手绘的下水暗渠主拱受力图存入货栈地砖暗格，留作日后战略后手，呼应第七幕劫狱与第九幕关闸。
* **时序情境推进**：
  - 1. **暗渠图纸终稿**：矮人建筑大师哈根将连日来敲石听音勘测出的成果，绘制在一张加厚防水黄牛皮纸上；图上用红黑双色墨水详尽标示出王都下水总渠、要塞悬崖承重主拱、以及两处生铁吊栓减配的脆弱结合点。
  - 2. **加固密封筒**：法林取出一只铅锡合金密封圆筒，将图纸卷好推入筒内，并在螺纹接口涂抹防水松脂拧死。
  - 3. **货栈地砖暗格封存**：乔治掀开货栈仓房最内角的一块重型花岗岩铺地石板，将密封筒放入干燥石缝暗槽中，重新覆上石板并以灰浆做旧，表面与普通地面毫无二致。
  - 4. **哈根的豪迈自信**：哈根拍了拍手上的石灰，叼着陶土烟斗咧嘴一笑：“这可是老哈根给这帮王都伪善神棍留下的‘命门’；总有一天，咱们会回来亲手把它撬开！”

### 第 109 章：卢卡斯巡骑在长街尽头的注视
* **阶段/路线**：第三幕·阶段十一 / 商队启程与卢卡斯石桥送行
* **主要人物**：黎恩, 卢卡斯, 菲娜, 雷恩
* **核心意图**：商队四轮重篷车缓缓驶出下城，卢卡斯在石桥上勒马抚胸目送车队，正直骑士之谊定格。
* **时序情境推进**：
  - 1. **篷车起步驶入长街**：清晨薄雾中，两辆换装新拉簧、覆着厚油布帆布的双马重篷车骨碌碌碾过湿润石板路，缓缓驶向下城外围。
  - 2. **石桥上的银白骑影**：行至下城横跨运河的拱形大石桥前，一骑身披银白胸甲、腰跨长剑的挺拔骑士正勒马独立于桥头——正是白鹰先锋骑兵队长卢卡斯。
  - 3. **骑士的真诚告解**：卢卡斯翻身下马，缓步走到坐在前车车辕上的黎恩身侧，目光坦荡：“听说你们要赶往平原大道送货……近日王都戒备森严，暗流涌动。先生身手不凡，亦是心怀仁义之人，路上务必多加小心。”
  - 4. **抚胸致意**：黎恩跳下车辕，微笑着向卢卡斯点头：“队长恪尽职守庇护平民，亦请多珍重。”卢卡斯右手握拳按在左胸白鹰徽记上，行正规先锋骑士大礼；两队交错而过，战马铁蹄在石桥上踏出坚实回响。

### 第 110 章：王都北门的最后巡检

* **主要人物**：艾德里安, 守门骑士, 黎恩
* **核心意图**：守门骑士核对紫蜡通关文牒，沉重的生铁吊栅门轰然抬起，商队顺利出城。
* **时序情境推进**：
  - 1. **抵达成城垣北门**：王都北城门青黑雄伟，两排全副武装的要塞重装守卫按剑伫立，城门通道落着十米高的生铁重齿吊栅门。
  - 2. **文牒递验**：艾德里安从容递上大理院盖章、滴有皇家紫火漆的通关特许状；当值骑士队长拿起放大镜仔细查验火漆上的双头狮纹章与墨迹防伪线。

  - 4. **驶向荒野平原**：重篷车缓缓驶过幽暗的城门洞券，车轮压过厚实的护城河木吊桥，彻底踏上城外辽阔的平原大地。

### 第 111 章：秋末平原大道的金色草浪
* **阶段/路线**：第三幕·阶段十一 / 平原大道疾驰与壮阔生活流
* **主要人物**：全员（菲娜, 黎恩, 菲, 劳拉, 爱丽榭, 亚莉莎）

* **时序情境推进**：
  - 1. **平原壮阔天地**：平原大道宽阔平整，两侧是无边无际呈波浪般起伏的金黄色深秋草浪；天空高远碧蓝，极目远眺令人胸怀大畅。
  - 2. **车顶放哨与清风**：菲身姿轻盈地坐在篷车帆布顶棚最高处，迎着秋风惬意地张开双臂，任由碎发在风中飞扬；亚莉莎掀开车窗布帘，深深呼吸着干燥麦草与野菊的清香。

  - 2. **领主车驾云集**：驿馆外围停靠着数辆装饰着亨里克边境伯领地金鹰徽记与平原大领主纹章的豪华四轮马车，近卫卫士在门前肃立。

  - 4. **会晤前夕**：同情王室的年轻侍从热情引领主角团入驻二层上席包厢，大驿馆内人声鼎沸、酒香四溢。

### 第 114 章：行驿入驻与各方就位
* **阶段/路线**：第三幕·阶段十一 / 行驿入驻与各方暗中就位

* **核心意图**：同情王室的年轻侍从引领商队驶入大驿馆后院马厩，主角团入驻二层包厢休整，亨里克边境伯近卫暗中示意。
* **时序情境推进**：
  - 1. **后院马厩安置与防务检查**：同情王室的年轻侍从快步迎出，神色警惕而恭敬，熟练地指引两辆重装篷车转入后院隐蔽的干草棚停放，卸下战马缰绳精心喂草饮水。
