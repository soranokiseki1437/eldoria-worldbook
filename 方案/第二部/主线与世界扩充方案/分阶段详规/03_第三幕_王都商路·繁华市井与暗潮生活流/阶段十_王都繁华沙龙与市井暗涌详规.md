## 二、 阶段剧情演进

### 1. 羊皮复账——圣泉洗尘
* **阶段/路线**：第三幕·阶段十 / 名媛沙龙复式记账与大浴堂生活流
* **主要人物**：亚莉莎, 爱丽榭, 劳拉, 菲娜, 玛格丽特
* **核心意图**：亚莉莎在金鸢尾沙龙展露莱恩福尔特复式记账法折服贵妇，赢得大理院法官夫人支持；清晨女伴们前往罗曼式圣泉大浴堂洗尘，生活流舒缓放松。
* **时序情境推进**（共 6 条）：
  - 1. 通过迷迭香商行引荐，亚莉莎身着优雅收腰长裙与爱丽榭步入金鸢尾沙龙二层大厅，水晶吊灯下茶香弥漫，几位女伯爵正为领地货栈烂账发愁。
  - 2. 亚莉莎现场运用莱恩福尔特复式记账法将借贷分栏、坏账剥离与仓储周转率逐一拆解，条理分明的现代财务思维令在场贵妇与文官大受震撼。
  - 3. 大理院首席法官瓦卢瓦伯爵的夫人对亚莉莎大为赏识，当场允诺在商会文牒审批中提供背书，打通了上层文官壁垒。
  - 4. 隔日清晨微凉，爱丽榭、劳拉与菲娜一同前往中城区著名的罗曼式“圣泉大浴堂”，厚重花岗岩列柱间弥漫着温暖的地热矿物蒸气。
  - 5. 换上白亚麻浴袍，劳拉踏入温热宽阔的青石大池舒展长剑肌肉；菲娜轻淋泉水打趣黎恩老好人日常，爱丽榭以木梳轻梳长发双颊微红。
  - 6. 洗净一路泥泞颠簸，少女们在更衣室品尝特供的冰镇甜羊奶，石室铜灯投射出一道柔和的晨曦光斑。

### 2. 暗渠水文——沙池战阵
* **阶段/路线**：第三幕·阶段十 / 运河平底船测绘与十字竞技场密探
* **主要人物**：菲, 亚尔缇娜, 雷恩, 朱利安
* **核心意图**：菲与亚尔缇娜乘平底旧木船无声测绘运河水文盲井，雷恩与朱利安披斗篷暗访竞技场观摩白鹰铁骑操演，评估禁卫战力。
* **时序情境推进**（共 6 条）：
  - 1. 菲在老码头用十枚紫铜便士租下一艘平底旧木船，划桨载着亚尔缇娜顺着下城窄运河无声漂流，战术壳在船底启动极低能耗回声测绘模块记录吃水深度。
  - 2. 菲凭借昔日直觉指出四处官方水图未注明的隐蔽排水口盲井坐标标注流速水压，面对迎面划来的巡防哨船，菲顺手捏碎面包屑喂鸭从容避过。
  - 3. 朱利安与雷恩身披粗呢斗篷步入王都“十字竞技场”高层阴影看台，开阔沙池中卢卡斯正率领数百名白鹰先锋铁骑进行长枪刺杀与重盾阵操演。
  - 4. 骑士们动作划一、吼声如雷，展现出极高的封建正规铁骑战术素养；雷恩凝视冲锋战阵向朱利安低声评估，确认白鹰先锋队纪律严明未遭黑血腐化。
  - 5. 朱利安握紧看台石栏，沉声立誓终将当着全军之面洗刷雷恩冤屈，让白鹰之誓重新归于正义。
  - 6. 操演号角声在黄沙沙池上空久久回荡，看台石缝间一截枯黄的杂草在秋风中微微晃动。

### 3. 飞石破鞭——草垛心誓
* **阶段/路线**：第三幕·阶段十 / 击退教会恶吏与草料棚点拨初心
* **主要人物**：科林, 黎恩, 菲娜
* **核心意图**：异端审问厅恶吏强闯钟表铺抢夺零件挥鞭打人，科林舍身护老，黎恩暗掷碎石击飞皮鞭解围；草料棚旁科林倾诉对杀戮机械的痛苦，黎恩温言点拨工匠之誓。
* **时序情境推进**（共 5 条）：
  - 1. 正午两名黑袍异端税吏闯入“白鸽与游丝”钟表铺强夺零件推搡老店主倒地，18岁的科林毫不犹豫张开双臂死死护在老人身前据理抗争。
  - 2. 恶吏恼羞成怒扬起带铁刺的生牛皮短鞭狠狠抽向少年面颊；街角暗处的黎恩指尖一弹，一枚不起眼的碎石裹挟破空锐气呼啸飞出，精准击碎鞭扣并震脱恶吏手腕打得脱臼，恶吏狼狈逃窜。
  - 3. 傍晚科林红着眼圈来到白榆货栈草料棚旁，坐在干燥的草垛上看着满手老茧机油，声音发颤向黎恩倾诉要塞征调工匠造铁兽杀人、自己不愿让发条用于杀戮的迷茫与痛苦。
  - 4. 黎恩放下手中的刨刀与少年并肩独坐，目光深邃而和缓地开导：齿轮错在掠夺的执念，只要手中拧动的发条依然为了带来欢笑琴音，工匠之心便从未玷污，守护这份初心本身就是极具勇气的战斗。
  - 5. 科林抹去泪水坚定立誓绝不替杀戮奏响音符，夕阳将草垛镀上温暖淡金，残木刨花在地面静静散落。

### 4. 晨曦清音——紫蜡通牒
* **阶段/路线**：第三幕·阶段十 / 八音盒清音抚慰与通关特许状核准
* **主要人物**：科林, 黎恩, 菲娜, 艾德里安, 亚莉莎, 玛格丽特
* **核心意图**：科林在避难所为失语孤儿拧动八音盒，清澈琴声唤回女孩微笑展现人性微光；公秤处联合会审终期届满，主审官浇铸紫火漆重印通商特许状，全境合法地位到手。
* **时序情境推进**（共 6 条）：
  - 1. 下城避难所石阶前聚集着边境逃难来的流民，七岁失语小女孩整日蜷缩在角落发抖；科林蹲在女孩面前，轻轻拧动三圈小纯铜八音盒发条。
  - 2. 叮咚清澈的《晨曦森林》在破败石阶前悠悠流淌，小女孩呆滞的双眼渐渐泛起神采，伸出小手触碰旋转的小铜摆轮，眼角滑落眼泪第一次露出了微笑。
  - 3. 街对角驻足的黎恩与菲娜久久凝视这一幕，菲娜挽紧黎恩臂弯低语只要还有科林这样的孩子未来就绝不会陷落，黎恩握紧身旁之人的手，目光如磐石。
  - 4. 五周审批窗口期届满，在瓦卢瓦伯爵公署批文与亚莉莎严谨账目支撑下，教廷代理税官再无借口阻拦。
  - 5. 公秤处大厅内，主审官取出一卷加厚羊皮纸《王国全境商贸特许执照》，在末端浇上滚烫的皇家紫火漆，重重压下双头狮与公秤重型青铜印章。
  - 6. 盖好印章的羊皮卷轴在案上徐徐收卷，融化的紫火漆边缘迅速冷却凝固成坚硬的晶体轮廓。

### 5. 平原白鸽——暗格铅封
* **阶段/路线**：第三幕·阶段十 / 白鹿会盟密令与连夜战备整备
* **主要人物**：艾德里安, 朱利安, 黎恩, 雷恩, 亚莉莎, 乔治, 菲
* **核心意图**：系深蓝丝绳白鸽带来朱利安密信，五大反教廷领主齐聚白鹿大驿馆举行大会盟；全员连夜检修马车底盘、四大物理铁证双层铅封锁入暗槽，整装待发。
* **时序情境推进**（共 6 条）：
  - 1. 一只系着皇家暗号深蓝丝绳的白鸽自平原方向飞落白榆货栈二层窗台；艾德里安拆解密信，确认亨里克边境伯等五位反教廷平原大公领主已赴平原大道中段【白鹿大驿馆】举行大会盟。
  - 2. 雷恩战火重燃，黎恩与艾德里安当机立断定于次日清晨商队拔营出发，全员拉响最高战备。
  - 3. 货栈后院灯火通明，乔治与法林用新采购的高碳钢拉簧为两辆重篷车更换减震底盘，加固生铁轮毂。
  - 4. 亚莉莎与菲将四大物理铁证（工匠主齿轮、十四人名册、洗钱账本、主教密令）分别装入双层防震铅盒，深锁入篷车底板夹层暗槽。
  - 5. 爱丽榭与菲娜为每人打包配发三日份高热量脱水肉干与创伤药膏，战马嚼子与蹄铁抹上防冻油脂，全员佩剑入鞘包裹严实。
  - 6. 东方天际泛起极淡的灰白晨光，后院炭盆的火苗渐渐熄灭，两辆四轮重篷车在晨霜中整装静立。
