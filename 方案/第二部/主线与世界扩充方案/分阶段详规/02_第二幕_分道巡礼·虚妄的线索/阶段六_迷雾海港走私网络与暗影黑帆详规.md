## 二、 逐章详尽剧情演进（第 58 ~ 67 章）

### 第 58 章：咸涩海雾——骨牌暗航
* **阶段/路线**：第二幕·阶段六 / 南方海港深入与酒馆暗线踩点
* **主要人物**：黎恩, 菲娜, 乔治, 玛格丽特
* **核心意图**：调查组抵达浓雾笼罩的迷雾海港，踩点破旧栈桥与鱼市；在木筋酒馆品尝烤鳕鱼，暗中观察海盗掷骨牌赌便士，摸清午夜黑帆走私航线。
* **时序情境推进**（共 6 条）：
  - 1. 浓稠咸湿的海雾笼罩南方海港小镇，破旧木栈桥下暗流涌动，生锈铁锚与腐朽缆绳浸泡在浑浊海水里。
  - 2. 黎恩与菲娜身披灰呢短斗篷，以北方商会护卫与药草采购员身份与乔治会合，步入玛格丽特夫人联络的码头木筋酒馆。
  - 3. 粗栎木长桌上摆着两盘焦香烤鳕鱼与泛着微酸的本地淡麦酒，三人轻声交谈，目光借着煤油灯昏黄视线投向酒馆角落。
  - 4. 几名满身刺青的海盗水手围坐在木桶前掷骨牌赌便士，言语间咒骂着午夜涨潮时必须赶往深水锚地装运“教会专供黑铅箱”。
  - 5. 乔治从袖口滑出炭笔，在粗麻餐巾角上勾画出双桅黑帆快船的吃水深度与靠泊泊位，确立突袭渗透坐标。
  - 6. 外面码头传来海浪拍击防波堤的沉闷钝响，窗外海风吹动木窗铁搭扣发出规律轻响。

### 第 60 章：滩涂毒斑——渔村啼声
* **阶段/路线**：第二幕·阶段六 / 炼金毒水取证与参战动因升华
* **主要人物**：菲娜, 黎恩
* **核心意图**：退潮潜入芦苇滩化验炼金毒渣，暗访下游渔村救治黑斑咳喘孤儿，目睹教廷罪恶，菲娜与黎恩参战动因升华至生态自然天命守护。
* **时序情境推进**（共 6 条）：
  - 1. 午夜退潮，两人踩着滑腻的黑泥潜入芦苇滩涂深处；排水暗渠外滩淤泥泛着刺目的紫黑油光，周围数公顷红树林枯焦腐烂。
  - 2. 菲娜戴皮手套取水样盛入试管，试剂触碰水样立刻泛起剧烈气泡与硫磺恶臭，确凿证实走私船定期在深海暗流倾倒高浓度炼金废渣。
  - 3. 穿过泥泞小道暗访下游受害贫民渔村，低矮草棚内传来撕心裂肺的幼童咳喘声；数名孤儿面生青黑斑纹，高烧蜷缩在发霉草垫上。
  - 4. 菲娜素手轻抚孩童滚烫额头，极度克制地引渡微量纯净温润圣光舒缓毒素侵蚀，黎恩以随身清泉润湿亚麻布为孩子们擦拭额头。
  - 5. 菲娜收回手掌，眼神由温柔化作决绝如寒冰；黎恩握紧佩刀刀柄，两人在草棚外海风中无声立下彻底斩断黑幕的誓言。
  - 6. 远处潮水拍打岸边碎贝壳泛起细碎白沫，湿咸海风卷动草帘，在夜色中静静起落。

### 第 62 章：黑帆深舱——碳化心木
* **阶段/路线**：第二幕·阶段六 / 码头潜入与生态核心铁证起获
* **主要人物**：黎恩, 菲娜, 乔治
* **核心意图**：码头潜行无声放倒巡哨，乔治破拆双桅黑帆快船底舱铁锁，在铅封重箱中起获三十一年前自森林掠夺之心木树枯萎碳化残根生态铁证。
* **时序情境推进**（共 7 条）：
  - 1. 暴风雨前夕海潮猛涨，双桅黑帆快船在码头剧烈起伏；菲娜以微声石声东击西引开栈桥守卫，黎恩瞬步欺身以刀鞘敲晕两名暗哨。
  - 2. 三人轻捷滑入漆黑阴冷的底舱，积水淹至小腿，空气中充斥着腐烂海藻与机油铁锈的呛鼻气味。
  - 3. 乔治取出破拆撬棍与特制铜钳，旋开固定在龙骨深处的双重重型生铁门锁。
  - 4. 暗舱深处固定着一只沉重铅封大木箱，撬开铅条掀开厚木盖，里面赫然盛放着半截通体焦黑碳化的古老树根，残存脉络散发微弱腐化异能。
  - 5. 菲娜素手触碰碳化根系，320年精灵守护者的古老血脉骤起轰鸣，确认正是三十一年前教廷暗部自 Eldoria 森林心木母树盗伐、用于机兽充能的枯萎残根。
  - 6. 乔治迅速以绝缘牛皮与铅板将残根严密封箱，彻底阻隔暗影异能外泄。
  - 7. 底舱生锈排水孔的水流滴入舱底，发出单调而沉重的滴答声，随着舱门合拢归于黑暗。

### 第 63 章：暗夜破栈——洗钱密卷
* **阶段/路线**：第二幕·阶段六 / 突袭走私货栈与经济黑幕起获
* **主要人物**：黎恩, 菲娜, 乔治, 玛格丽特
* **核心意图**：突袭芦苇荡走私货栈，黎恩鞘击制敌，菲娜屏障格挡暗弩，乔治破拆密室，起获教廷黑市洗钱账本与受贿贵族往来密卷第三重铁证。
* **时序情境推进**（共 7 条）：
  - 1. 暴雨倾盆，潮水漫过芦苇荡深处货栈吊桥；数十名教廷私雇武装水手严密把守，两排黑铁重木箱正被吊索装车。
  - 2. 黎恩低姿滑步踏碎泥泞，太刀未曾出刃，刀鞘与剑柄化作连环重击利落震碎当面强敌锁骨与护腕，敌手长刀脱手跌落。
  - 3. 暗处死士扣动淬毒排弩偷袭，菲娜撑起半月形无光圣光护盾将毒矢尽数震飞。
  - 4. 乔治抡动铸铁大锤轰然砸开货栈密室生铁夹壁，露出藏匿其间的秘密暗格。
  - 5. 夹壁暗格中滚落三卷浸蜡防水牛皮纸大账册与数十封火漆密信，详实记录了罗曼商行洗钱网络与平原大贵族按季分肥的受贿清单。
  - 6. 玛格丽特夫人迅速将账册归入行会防水箱，与乔治合力将其抬出密室。
  - 7. 货栈油灯被风雨吹灭，焦糊灯芯在黑暗中散出青烟，屋檐雨水成串坠入泥地。

### 第 64 章：案头杀令——晨雾回车
* **阶段/路线**：第二幕·阶段六 / 反派警报拉响、物资回流与阶段六收官
* **主要人物**：黎恩, 菲娜, 乔治, 玛格丽特（异端审问厅视角：达米安）
* **核心意图**：达米安案头汇总三线败局冷酷签署封杀令；调查组将残根与账本混装运粮篷车，水网大道安全返回法尔肯前哨，阶段六圆满收束。
* **时序情境推进**（共 6 条）：
  - 1. 异端审问厅暗室内烛火昏暗，达米安审阅海港货栈被端与修道院失守的急报，眼神冷酷如毒蛇，大笔一挥签署针对北方商队的全境格杀令。
  - 2. 拂晓海雾渐退，乔治将密封铅箱与账本深埋于运粮四轮重车的干麦草与面粉袋暗格中，伪装严丝合缝。
  - 3. 玛格丽特夫人递给黎恩一份河谷商道备用通行副牌，低声叮嘱法尔肯近日恐生商战变故。
  - 4. 黎恩扬起马鞭，两辆运粮大车碾过湿漉漉的石板大道，菲娜并坐车辕回望逐渐隐入浓雾的咸腥海港。
  - 5. 铁轮穿过林荫道上的泥坑，车辙向着东北方河谷蜿蜒延伸，商队安全踏上归途。
  - 6. 林鸟拍动湿润羽翼掠过枝头，晨曦悄然爬上车顶帆布，将一层微金光芒洒向远方。
