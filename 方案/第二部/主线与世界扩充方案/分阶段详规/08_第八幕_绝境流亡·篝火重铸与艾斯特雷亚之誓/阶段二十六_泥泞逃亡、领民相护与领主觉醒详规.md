## 二、 阶段剧情推进

### 1. 避难地窖：在废弃酒庄安顿重伤同伴
* **路线**：第五幕·阶段十七 / 泥泞隐蔽与旧领遗民相认
* **主要人物**：黎恩, 菲娜, 艾德里安, 朱利安, 劳拉, 菲, 吉尔
* **核心意图**：主角团撤抵艾斯特雷亚旧领荒废半地下酒庄建立避难防线，安置高烧劳拉与负伤朱利安，藏好四大铁证铅盒；破晓巡查时与留守十九年的忠仆吉尔相遇，出示白鸢尾刺剑主仆相认，获悉圣殿铁骑与异端审问官封锁大搜捕。
* **时序情境推进**（共 7 条）：
  - 1. 深秋冷雨连绵，黎恩背着高烧昏迷的劳拉，在艾德里安指引下避开巡哨穿过枯木林，进入半山坡长满黑苔的石造酒庄；两扇浸透雨水的厚重橡木地窖门合拢，粗铁栓落槽的沉闷声响将外面的风雨隔绝在外。
  - 2. 穿过两侧高大的发酵橡木桶长廊，黎恩小心翼翼地把劳拉抱进深处的起居暗室，平放在铺有干草与旧羊毛褥的木板床上；菲娜拧干温水亚麻布，轻柔擦拭劳拉额头的冷汗与唇角血迹；艾玛则为朱利安被刺穿的左肩清创敷药。
  - 3. 艾德里安把四大铁证铅盒稳妥放进发酵槽内侧的花岗岩暗格中，盖上干燥油布；乔治检查全员ARCUS战术导力器的皮革遮蔽套，确认没有半点导力光弧溢出；黎恩在通往地窖的石阶拐角拉起细麻绳连接倒扣的空陶杯，设下零导力物理预警。
  - 4. 破晓时分薄雾弥漫，艾德里安佩戴家传刺剑，与黎恩、菲悄无声息地自地窖暗道巡查地面农庄；十九年前焚毁的工坊只剩下断壁残垣，漫坡老葡萄藤在乱石堆中交错蔓生，下风向一处半塌干草棚石缝间隐约升起一缕细微柴烟。
  - 5. 菲反握短刃悄悄绕到草棚后方戒备，草堆后一名身穿破旧羊皮袄、手拿缺口柴刀的花白头发农夫正瑟瑟发抖；艾德里安拉住菲的手臂缓步上前，亮出佩剑护手上雕刻的白鸢尾家族徽记。
  - 6. 留守十九年的忠仆吉尔颤抖着抚摸剑身纹路，认出艾德里安与前任伯爵非常相像的琥珀色眼睛，眼泛泪光地跪在地上哽咽：“少爷……您真的活着回来了……”；吉尔急促告知，圣殿铁骑与教廷黑袍审问官已经封锁各处路口，四处搜捕通缉画像上的人。
  - 7. 萧瑟山风掠过山坡，一片被霜打透的干枯老葡萄叶从发黑的藤蔓上脱落，在半空中转了几个圈，最后落在吉尔沾满泥浆的破旧牛皮草鞋旁。

### 2. 握紧断剑：劳拉退烧想通了重剑的意义
* **路线**：第五幕·阶段十七 / 劳拉苏醒与大剑沉思
* **主要人物**：劳拉, 黎恩, 菲娜, 艾玛
* **核心意图**：劳拉自高烧中苏醒，面对折断大剑与身体创痛坦然反思；与黎恩深谈八叶流借力技巧与“以重剑为盾”的守护心境，心结自然解开。
* **时序情境推进**（共 5 条）：
  - 1. 午后微光透过地窖石缝照进来，劳拉高烧稍退苏醒，伸手摸索床沿，指尖准确握住了那截裹着干涸血痂与破损缠皮的大剑残柄。
  - 2. 艾玛端来温热的退烧草药汤，菲娜轻抚其后背帮她喝下；黑酸冲击带来的阵痛令劳拉面色微白，但琥珀色眼睛清澈坚定，坦诚讲出自身剑技在硬碰未知生化强酸时过于刚硬容易受损的问题，没有一句怨言。
  - 3. 黎恩坐在木凳上，温和地讲起八叶流顺势借力、卸去重压的体悟；劳拉摸着残剑护手上的蓝纹徽记，轻声说道：“以前我总把重剑当成斩倒敌人的利刃，但在白鹿桥前，这把剑成了保护大家的盾牌；剑想要不被折断，得先明白到底是为了守护什么而握剑”，解开了心中长久的纠结。
  - 4. 菲娜拿着温湿毛巾细致地为劳拉包扎固定肋骨伤处，劳拉把大剑残柄横放在膝盖上，合上双眼平稳呼吸，呼吸声在安静的地窖里显得格外平稳沉着。
  - 5. 木板床旁的粗木墩上，盛放退烧草药的粗陶碗已经喝空，碗底挂着几缕深绿色的苦涩药渣，一滴深褐药汁沿着粗糙碗沿缓缓滑落，渗入干燥木墩的裂缝里。

### 3. 水牢深处：巴恩斯啐了莫尔茨一口血沫
* **路线**：第五幕·阶段十七 / 水牢对话与硬汉骨气
* **主要人物**：雷恩, 瓦尔特·巴恩斯, 戈德弗里, 莫尔茨
* **核心意图**：视线转向圣殿要塞底层第七号黑铁水牢；雷恩身负三十公斤重枷被囚于冰冷暗河死水中，与老副团长戈德弗里、守备队长巴恩斯互相支持；典狱长莫尔茨逼供碰壁，守备队长吐出血沫嘲笑展现硬汉骨气。
* **时序情境推进**（共 5 条）：
  - 1. 圣殿要塞黑石地下三十米的第七号水牢里，冰凉的暗河水没过大腿；雷恩双臂被生铁链条吊在湿滑岩壁上，三十公斤重的生铁连体手颈重枷卡住脖颈与手腕，雷恩闭目靠着晨光流呼吸法调匀气息抵御冰冷池水。
  - 2. 深水对面的粗铁栅栏里，十四年前被夺去佩剑的老副团长戈德弗里与刚被押进来的守备队长瓦尔特·巴恩斯并肩坐在石台上；巴恩斯嘴角挂着血痕，右脸上横亘的旧伤在昏暗火把下拉得很长，望着雷恩挺拔的身板，露出守备队长特有的刚硬神色。
  - 3. 要塞典狱长莫尔茨穿着沉重胸甲走在湿木栈道上，咬着粗陶烟斗居高临下吐出烟雾，逼问同伴去向；巴恩斯扶着岩壁挺起胸膛，一口带血的唾沫猛地啐在莫尔茨靴子上的生铁马刺上，沙哑粗粝地嘲笑：“莫尔茨，你给大团长当了十四年看门犬，老子当年跟着雷恩长官抗命放走平民的时候，你连马镫都还没踩稳呢！”
  - 4. 莫尔茨脸色铁青，冷哼一声转身走开，沉重的生铁门重重合上锁死；死寂的水潭边，雷恩与戈德弗里隔着铁栏互相对视，眼神平静如铁。
  - 5. 空旷安静的水潭上方，控制囚笼的粗铁链微微晃动，一滴冰冷的岩顶水珠嗒的一声落在泛着油光的死水水面上。

### 4. 搜查逼近：领民堆起臭鱼假坟掩护大家
* **路线**：第五幕·阶段十七 / 搜捕逼近与假坟掩护
* **主要人物**：达米安, 菲, 吉尔, 黎恩, 艾德里安, 菲娜
* **核心意图**：达米安率异端审问厅斥候下乡推行残酷搜捕，火把逼近酒庄；吉尔率领民堆假坟泼硫磺死鱼胆汁吓退猎犬，黎恩与艾德里安叠起两米半空橡木桶挡住暗室，巧妙避开第一波拉网搜查。
* **时序情境推进**（共 7 条）：
  - 1. 异端审问厅执行官达米安身披黑斗篷、佩细剑，策马带队冲进周边村落，拿出盖着火漆印的公文宣称谁敢窝藏就抓谁；几支沥青火把被点燃，浓黑的烟柱在暮色下升起，直奔半山酒庄而来。
  - 2. 菲轻巧地爬上酒庄外围三层楼高的大栎木树冠顶端，透过黄铜望远镜看着敌方三头猎犬的动静与骑兵搜查路线，快步跳下跑回地窖报信。
  - 3. 接到警报的吉尔迅速叫来山坳里仅剩的几位村民，连夜推独轮车在酒庄背阴坡挖土堆起五座插着歪斜松木十字架的假坟，泼上熬煮发酵的死鱼胆汁与硫磺粉，假装成病死者的埋葬坑。
  - 4. 黎恩与艾德里安在地窖合力搬动几十只高大的空橡木桶，在暗室门前层层码成厚实的弧形木桶墙，桶壁抹上酸败陈酒渣掩盖挪动痕迹；木桶匠在走廊叮叮当当敲击铁箍假装检修旧桶，每隔一阵子响起的木槌声，正好给暗室里的菲娜替劳拉换药提供了安全的掩护。
  - 5. 搜捕骑兵牵着猎犬强行冲进酒庄后坡，刚靠近假坟就被刺鼻的恶臭熏得连连干呕，猎犬被硫磺与腐败气味刺激得呜呜叫着往后缩；骑兵害怕沾上怪病，骂骂咧咧地用布捂着鼻子随便拿长枪捅了捅草堆，就急忙退了出去。
  - 6. 菲娜与菲在石阶拐角确认搜捕骑兵已经走远，黎恩与艾德里安靠在木桶阴影里相视一笑，暗室里的大家总算松了口气。
  - 7. 新挖开的潮湿假坟堆顶上，松木十字架歪歪斜斜插在烂泥里，一滴浑浊雨水顺着木刺滑落，滴进散发着硫磺味的泥水坑中。

### 5. 忠仆挨打：艾德里安接下染血的黄铜印章
* **路线**：第五幕·阶段十七 / 忠仆受刑与领主责任觉醒
* **主要人物**：达米安, 吉尔, 艾德里安, 黎恩, 菲娜, 爱丽榭
* **核心意图**：达米安去而复返突袭外院，皮鞭拷打吉尔打断腿骨，忠仆宁死不招；艾德里安暗处目睹深受震撼，敌退抢救老仆接过十九年染血黄铜领地印信，立下守护誓言，领主责任全面觉醒。
