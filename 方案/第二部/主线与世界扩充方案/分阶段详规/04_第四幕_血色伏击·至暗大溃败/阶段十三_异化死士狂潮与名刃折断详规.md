### 第 126 章：破门狂潮与骨刺死士
* **阶段/路线**：第四幕·阶段十三 / 玄关破门与正门遭遇战
* **主要人物**：劳拉, 黎恩, 菲, 艾德里安
* **核心意图**：外门遭重型撞木与战兽轰然破开，暗影忏悔者骨刺突击，大厅混战爆发，黎恩与菲游击牵制掩护平民彻底避入地窖通道。
* **时序情境推进**：
  - 1. **轰鸣破门与碎石横飞**：战兽巨爪与包铁撞木重击之下，大驿馆两扇厚重橡木外门伴随生铁绞盘的断裂悲鸣轰然倒塌；湿冷的暴风雨混合着恶臭的黑血气味倒灌涌入，碎石灰尘弥漫玄关。
  - 2. **骨刺掠空与桌垒阻击**：十余名双目被麻布缝死、手指化为三十厘米角质骨刺的暗影忏悔者如鬼魅般贴地爬行跃入；劳拉双手大剑平斩扫出沉重风压，刚猛剑风直接将冲在最前的两名死士震退数米，狠狠撞在倒翻的栎木长桌掩体上。
  - 3. **战术牵引与护送撤离**：菲在半空翻转抛出钢丝牵引索，反手双短刃切断两名扑向侍应的死士手腕筋腱；艾德里安与朱利安一左一右拔出佩剑，大声喝令吓瘫的马夫与行商仆役低头贴墙撤入后厨厚石地窖通道；黎恩沉腰滑步切入玄关中轴，太刀刀鞘自下而上挑飞刺向平民背部的骨刺。
  - 4. **石阶碎骨收束**：一名被震碎臂骨的暗影忏悔者在地上抽搐，黑血从破损的亚麻绷带渗透至青石板台阶；狂风将暴雨雨水吹进门廊，石阶上的黑血在泥水中泛起令人作呕的彩油光晕。

### 第 127 章：回廊之困与仁慈枷锁
* **阶段/路线**：第四幕·阶段十三 / 室内近战与道义苦战
* **主要人物**：雷恩, 黎恩, 劳拉, 圣殿年轻巡骑
* **核心意图**：二层环形回廊与底层通道窄道交锋，圣殿年轻巡骑受蒙骗杀入；主角团恪守承诺仅以剑脊击打与刀鞘格挡卸除武装，在道义枷锁下陷入苦战。
* **时序情境推进**：
  - 1. **年轻巡骑涌入回廊**：随着外门失守，二十余名身穿圣殿白鹰胸甲的年轻巡骑在先锋骑兵队长官喝令下拔剑冲入底层回廊；他们面容稚嫩，眼中满是对“盗取圣物叛逆”的狂热敌意，精钢长剑在逼仄通道内交织成密不透风的剑网。
  - 2. **剑脊制敌的艰难格挡**：雷恩反握长剑，在昏暗狭窄的回廊转角处以纯正的圣殿剑术化解突刺；他恪守道义诺言，每一次挥剑皆翻转剑身，以宽厚的剑脊狠狠抽击年轻骑兵的手腕与胫骨，击落长剑却绝不伤及对方咽喉要害。
  - 3. **道义枷锁下的战术受制**：狭窄地形极大限制了大开大合的战技施展；劳拉同样压制大剑锋芒，以坚实的剑鞘横扫逼退三人；然而年轻巡骑前赴后继，主角团为了不伤及人命处处留手，战术走位被死死压制在后厅狭长走道内，同伴体力在剧烈肉搏中飞速消耗。
  - 4. **长剑跌落鸣响收束**：一名被黎恩太刀刀背敲中右腕的年轻巡骑脱力跪地，制式精钢长剑当啷一声砸在石板上滑入墙角阴影；年轻人的粗重喘息与回廊外狂暴的雷声在幽暗中回荡。

### 第 128 章：黑血狂骑的暴虐重斧
* **阶段/路线**：第四幕·阶段十三 / 狂暴死士重压
* **主要人物**：达米安, 破誓黑血狂骑, 劳拉, 雷恩
* **核心意图**：达米安投入破誓黑血狂骑，体格膨胀的狂暴死士挥舞浸透黑血的双手巨斧撕裂栎木掩体，伤口黑粘液自愈，大厅防线被层层压制。
* **时序情境推进**：
  - 1. **重斧劈裂掩体**：沉重的重靴踏碎门槛，三名身高超过两米的破誓黑血狂骑踏入大厅；他们肌肉如树根般虬结隆起，皮下黑血如粗缆剧烈搏动，双手挥舞着沉重达数十磅的破甲战斧，一击便将乔治立起的五厘米厚栎木桌垒齐齐劈成木屑碎片。
  - 2. **非人自愈与恐怖抗性**：雷恩挺剑疾刺，精钢剑尖精准贯穿一名狂骑的左肩骨缝；然而狂骑不仅毫无痛感狂吼反扑，伤口处更是迅速涌出大量黏稠的黑色粘液，瞬间封堵创口止血，反手巨斧带起呼啸狂风将雷恩震退数步。
  - 3. **劳拉硬撼重斧**：劳拉大步上前接应，星银百锻双手大剑自下而上撩起一道刚烈弧光，正面架住两柄重斧的合力重劈；两把精钢兵刃剧烈撞击，金铁交鸣声震耳欲聋，大厅吊顶的石灰碎屑如雨落下。
  - 4. **斧刃木刺定格收束**：狂骑战斧斧刃深深卡在断裂的栎木立柱上，黑血顺着生锈斧柄滴滴答答坠落在燃烧的木屑余烬上；空气中弥漫开硫磺与烧焦兽皮般的刺鼻臭气。

### 第 129 章：毒雾弥漫与圣光界壁
* **阶段/路线**：第四幕·阶段十三 / 强酸危机与超自然防火墙
* **主要人物**：菲娜, 黎恩, 乔治, 暗影忏悔者
* **核心意图**：忏悔者濒死自爆释放强酸黑雾与腐蚀血雨，空气灼烧；菲娜以短杖微引克制圣光撑开净化微光，与黎恩一同疏导地窖换气口阻断酸雾，两人战力被深度牵制。
* **时序情境推进**：
  - 1. **忏悔者疯狂自爆**：被挑飞跌落的两名暗影忏悔者喉咙发出怪异嘶鸣，胸腔黑血剧烈发热膨胀，轰然爆裂成漫天腐蚀性强酸血雨；飞溅的黑液落在地毯和橡木柱上，立即腾起大团刺鼻窒息的滚滚浓烟，木质结构以肉眼可见的速度焦黑碳化。
  - 2. **菲娜撑开净化微光**：眼见毒雾顺着通风道向后厨地窖涌去，菲娜双手紧握银质短杖，美眸微凝，极其克制地引出一道澄澈温润的金色圣光结界；光幕如半透明薄纱般护住地窖入口与大厅中段，死死挡住强酸毒雾的侵蚀，黑烟在圣光触碰下发出嗤嗤净化脆响。
  - 3. **黎恩断后与封堵气孔**：黎恩反手挥刀斩断垂落的厚羊毛挂毯，乔治迅速上前将挂毯浸泡冷水，二人配合死死堵住地窖上方外泄的通风石缝；菲娜脸色因持续维持高强度净化而泛起苍白，黎恩一边横刀戒备扑来的死士，一边在激战间隙侧身扶住菲娜的腰肢，传递掌心的温热支持。
  - 4. **湿布水汽蒸腾收束**：浸湿的厚毛毯在强酸烟雾边缘不断冒出白汽，滴落在石板上的水滴与毒液反应，结成一层泛着灰白泡沫的黏稠胶质，地窖内隐约传来仆役们压抑的微弱抽泣。
