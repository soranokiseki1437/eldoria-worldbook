### 第 181 章：深渊集结与盲泉水文推演
* **阶段/路线**：第六幕·阶段十八 / 特遣组集结与暗河长廊前哨
* **主要人物**：凯尔, 玲, 亚尔缇娜, 加尔, 罗恩, 黎恩
* **核心意图**：特遣队于艾斯特雷亚酒庄地下深窖与太古石殿入口完成整备交接，黎恩叮嘱安全，凯尔依据古籍笔记推演暗河水流流向与盲泉落差，全员登船入暗河。
* **时序情境推进**：
  - 1. **石窖裂口与地底冷风**：艾斯特雷亚酒庄半地下石砌酒窖尽头，加尔与罗恩合力撬开掩盖太古十七通道入口的厚重花岗岩磨盘；磨盘移开的瞬间，一股混杂着潮湿水汽与极寒石粉的强劲穿堂风自幽黑裂谷中狂涌而出，将壁炉投射在石壁上的暖光吹得剧烈摇曳；黎恩将两套包覆厚实生牛皮外壳的防水行囊逐一递给加尔与亚尔缇娜，目光沉稳地嘱咐众人地底盲区潜渡以稳为先。
  - 2. **学者手册与便携短镰**：通道入口的干燥条石旁，凯尔仔细扣好斜挎牛皮包的铜扣，自包内抽出浸油牛皮包裹的冷光晶石提灯与厚重羊皮封面的《太古封印语辞典》手稿；玲单手将缩小轻量化的符文黑镰稳稳卡入后背皮革卡槽，紫发双马尾在冷风中扬起细微弧度，少女挑起秀眉调侃凯尔“可别走两步就被地底石笋绊倒哭鼻子”；凯尔推了推滑落的镜架，神色严肃地摊开水文便签，指出上游地下落差极可能达到上百米。
  - 3. **折叠木舟与野兽嗅探**：加尔与罗恩在太古石殿（`LOC_D2_05`）暗河岸边组装好两艘吃水极浅的硬木拼接折叠舟；两名战士踩入冰凉齐膝的河水中固定木栓，罗恩蹲在湿漉漉的黑色卵石滩上抽动鼻翼，辨识着逆流漂来的水汽味道；亚尔缇娜指尖轻按光剑战术外壳的被动声纳旋钮，闭目倾听河道深处的超声波反射，确认主水道目前通畅无大面积塌方。
  - 4. **缆绳松脱入激流收束**：粗麻缆绳自粗粝的玄武岩石桩上滑脱散开，折叠木舟轻微一震切入奔腾咆哮的幽黑激流；船桨拨开冰冷刺骨的浪花，翻卷而起的白色泡沫在石殿湿润岩壁蓝绿地衣的微光中转瞬即逝，木舟随着水声彻底没入幽深的暗河回廊。

### 第 182 章：逆水潜渡与玄武岩裂谷
* **阶段/路线**：第六幕·阶段十八 / 盲泉逆流与地底管网前测
* **主要人物**：加尔, 亚尔缇娜, 凯尔, 玲
* **核心意图**：小队乘折叠舟在极度逼仄的地下裂谷中逆流而上，加尔展现高超控船技巧，亚尔缇娜无声绘制水文截面，凯尔与玲比对地下声学回响。
* **时序情境推进**：
  - 1. **裂谷狭逼与激流扑面**：航行深入五百米后，暗河两岸的玄武岩长廊急剧收缩为宽度不足四米的垂直深槽；上方十余米高的穹顶密布着倒垂如枪林的尖锐钟乳石，冰冷刺骨的凝结水滴暴雨般砸落在众人的油布斗篷上；暗河水面下暗礁林立，逆向回旋的湍流猛烈拍打着木舟侧舷，发出沉闷的撞击声。
  - 2. **短篙破浪与特务测绘**：加尔赤足稳稳踩在船头湿滑的龙骨横梁上，双手翻飞操持一根两米半长的铁木短篙；蜥蜴人凭借脚掌角质层与蹼状结构精准吃住湿石，短篙每一次点在暗礁上都借力化去剧烈颠簸，推着木舟在狭窄浪峰间逆流切进；后座的亚尔缇娜神情冷澈，指尖顺着战术外壳侧面的刻度滑移，以微弱的冷光晶石为照，在羊皮纸上分毫不差地标出水深与暗礁坐标。
  - 3. **回声变奏与学者断言**：随着航程逆行进抵盲泉中段，水声在狭长管状石壁间激荡出令人耳鸣的低沉嗡响；玲用手肘顶了顶紧紧抓着船舷的凯尔，凯尔扯开嗓子迎着水声大喊指出——前方岩壁反射的回音频率由尖锐转为宽厚，说明岩层质地已由天然喀斯特溶洞转为人工开凿的玄武岩粗石壁，距离圣殿要塞地底排洪外壁已不足三公里。
  - 4. **篙尖顿石带水珠收束**：加尔手中的铁木短篙猛地向下一顿，包铁的篙尖稳稳咬死河床下一块突兀的青黑巨石；短篙带起一串清脆冰凉的水珠，在半空中划过一道弧线落在船头干燥木板上，迅速渗入深褐色的木纹缝隙。

### 第 183 章：盲目伏影与酸蚀油膜

* **时序情境推进**：

  - 2. **野兽警兆与狼息压抑**：率先跳下浅滩的罗恩脊背猛然绷紧成一张硬弓，喉咙深处压抑着极低促的呼噜声；狼人战士俯下身躯，前爪探入湿润冰凉的砂砾中捻了捻，随后抬起头朝向黑暗深处抽动鼻翼；他压低声音警告四周有大型冷血爬虫滑过泥沼的腥气，水潭底下隐藏着至少三股沉重且异样的脉搏跳动。
  - 3. **死寂环伺与铁鳞盲兽**：滩涂上游浑浊的水面下，数道半米宽的深水波纹正悄然逆水聚拢；伴随着粗糙鳞片刮擦湿石的刺耳沙沙声，三头体长超过四米、通体覆盖着惨白骨质鳞甲的庞大巨蜥自溶洞阴影中缓缓爬出；巨蜥头部眼目早已彻底退化为深深凹坑，但两侧细密的侧线感知孔正随着空气中呼吸的震颤剧烈开合，血盆大口里不断垂挂下泛着微泡的浑浊黏涎。
  - 4. **腐泡破裂带浊圈收束**：深潭边角一处凹陷的泥坑里，一枚拳头大小的黑色气泡自淤泥深处咕嘟翻出；气泡在水面上啪的一声轻响爆开，带起一圈泛着暗红油膜的浑浊涟漪，缓缓荡开在死寂的石滩边缘。
