# 第二部晨光大陆西幻风土与生活细节设定方案

> 这篇方案专门用来把第二部里那些带着中式古代水利、修仙和野路子山寨味道的词改掉，换成大家熟悉的日式 RPG 剑与魔法轻小说的样子。晨光大陆是个正儿八经的西幻世界，没有导力，大家平时过的就是朴素的中世纪生活。方案里不讲大道理，也不用生硬的大词和典雅古风词，全用大白话把世界观、生活小物件和剧情改法讲清楚，读起来轻松有趣，写正文时也清爽好懂。

---

## 一、 晨光大陆到底是个什么样的西幻世界

### 1. 纯正的剑与魔法日式轻小说世界
本土世界叫晨光大陆，这里有古老的晨光大森林、封建骑士团、小酒馆和热腾腾的面包。维里迪亚王国是大陆上的封建王国，北边紧挨着精灵守护的大森林，走出森林南边十五公里就是王国的维里迪亚大门。大家平时赶着大马车，喝黑麦肉汤和热苹果酒，到了晚上就在壁炉里烧松木柴取暖。

### 2. 完全没有导力的中世纪日常
晨光大陆本土完全没有导力这种东西。黎恩他们随身带的战术导力器都用厚牛皮套紧紧包着，不能露出一丝光弧，免得被当地人当成奇怪的妖术。人们平时生活全靠人力、马车、水车、石炭、蜡烛和油灯，打起仗来也是实打实的冷兵器硬碰硬。

### 3. 城堡和地下迷宫的实在构造
西幻城堡和地下迷宫，从来不会有什么中式古代的排沙洞或者青铜大绞盘。现实和轻小说里的正经城堡，地底下都是实打实的石头下水道、暴雨时排水用的泄洪暗渠、地下排污沟，还有地牢里的通风暗井。

### 4. 让人觉得温暖的小物件
乡下孩子挂在脖子上的小木笛、路边小酒馆里的双耳锡杯、大马车走在石板路上的马蹄声，都要有日式 RPG 那种温暖清新的生活味道。

## 二、 几个别扭物象的大白话改动

### 1. 别再吹鸟哨子了，换成乡村孩子最喜欢吹的手工小木笛
* **原来的写法为什么很怪**：
  原稿里提米动不动就吹木雕哨子，写成百灵鸟哨、云雀长鸣、尖锐哨声穿透山谷，听上去就像武侠小说里打暗号或者猎人吹鸟哨，特别刺耳，把温馨的异世界生活感全给破坏了。
* **正经剑与魔法轻小说里怎么写**：
  在日式西幻轻小说和 RPG 游戏里，乡下小孩或者小牧童最喜欢带的，通常都是大人随手削出来的小木笛。
  巴恩斯队长是个粗线条的中年骑士，平时在大门哨所值班，闲下来的时候就用干燥的白桦木，给自己的小孙子提米削了一只圆圆短短的小木笛。
  提米平时就把这只小木笛挂在脖子上当玩具玩，第三幕爱丽榭救了提米之后，还特意用结实的深绿防湿皮绳帮他重新编了挂绳。
* **声音和画面的改法**：
  彻底删掉尖锐鸟叫和哨声长鸣，改成小孩子鼓起腮帮子，吹出一串清脆欢快、不成调子却特别可爱的小木笛声。
  到了第十二幕全书大结局，车队北上回森林的时候，提米站在大门石头高台上，用力吹响这只小木笛，清脆悠扬的笛声在晨风和山谷里飘开，车窗里的爱丽榭和菲娜笑着挥手，这才是最地道的日式轻小说大团圆画面。

### 2. 删掉莫名其妙的排沙，换成正经的地下排水道和泄洪暗渠
* **为什么排沙非常不合理**：
  原稿里写了大量的排沙涵洞、排沙总渠、排沙盲井、排沙水坝，这完全是把古代中原治水防泥沙那一套生搬硬套进来了。西幻城堡建在石头峡谷里，要塞地牢建在地下溶洞里，平时只需要排走暴雨积水、生活脏水或者山洪，根本不需要排泥沙。轻小说读者看到排沙肯定会觉得特别出戏。
* **改换成真正的西幻地下工程**：
  1. **维里迪亚大门底下**：改成**石砌泄洪暗渠**或者**地下泄水道**。这是当年为了防止雨季暴雨山洪把大门冲垮而修的石头涵洞，水浅的时候只到小腿肚子，正好可以让人弯着腰涉水穿过去。
  2. **圣殿要塞地牢底下**：改成**要塞排污暗道**和**地基排水盲井**。用来排走地牢脏水和暴雨积水，管子很粗，连着外面的地下暗河。
  3. **暗河深处的古代水闸**：改成**太古蓄洪分水闸**。用来调节地下暗河的水位，挡住脏水回流。
  4. **王都地下水网**：改成**王都地下蓄洪排污总闸**。

### 3. 别用青铜做大绞盘了，城堡大门用结结实实的生铁齿轮
* **为什么青铜绞盘很别扭**：
  原稿里动不动就写青铜传动绞盘、青铜导槽，让人联想到古代中原的青铜器。但在中世纪西幻里，升降几吨重的铁闸门，用的全都是黑沉沉的生铁齿轮和铁链；只有精密的小钟表、小发条才会用黄铜。
* **大白话材质规范**：
  - 大门水闸和升降机构：一律写成**生铁齿轮绞盘**，大齿轮咬在一起，带着粗铁链转动；
  - 水下暗锁和插销：写成**生铁插销和粗铁连杆**；
  - 机关里的小齿轮和发条：写成**黄铜发条机括**；
  - 古代遗迹里看不懂的机械：写成**太古合金构件**。

### 4. 别写草莽味十足的封关锁山，换成骑士团正规的戒严和封路
* **为什么封关锁山不对味**：
  原稿里的封关锁山令、封山锁关、封山扎营，带着浓浓的山寨占山为王或者修仙封山的味道。圣殿骑士团是正儿八经的封建武装修会，他们调动兵力走的是正规命令。
* **大白话规范**：
  - 文书名称写成：**大门防务戒严告令**或者**主道通行禁令**；
  - 防务动作写成：在大门南边的商道上推来带铁皮的尖桩木栅和木栅栏，派巡防骑兵封锁道路，关上大门铁闸，封锁道路只守不攻。彻底不提封山两个字。

## 三、 全十二幕剧情大白话改动走势

### 1. 第三幕：大门封路，走石砌泄洪暗渠逃生
* 达米安把维里迪亚大门死死关上，还想放火烧贫民窟。菲娜和爱丽榭用森林草药熬汤救活小提米，巴恩斯认出雷恩之后，下定决心放大家走。
* 巴恩斯带大家去的不是什么排沙涵洞，而是大门悬崖底下的**古代石砌泄洪暗渠**。巴恩斯和手下卫士一起用力压下**生铁齿轮绞盘**的长柄，齿轮咬合发出沉重的声响，把生铁水闸吊起来。大家赶着大马车，踩着冰凉的浅水穿过山体暗渠，顺利跑到外面的河谷碎石滩。
* 菲娜救活提米之后，爱丽榭拿出结实的深绿防湿皮绳，给提米脖子上挂着的**白桦木小短笛**重新编好了结实的挂绳，提米乖巧地向大家道谢。

### 2. 第七幕：大门防线对峙，提米吹小木笛接头
* 水牢里的巴恩斯用铁链敲打石壁，给隔壁的雷恩传递消息，讲的是要塞地下泄洪暗道的换班空档，不是排沙通道。
* 要塞大团长阿达尔伯特被奥蕾莉亚一剑劈断帅旗震慑住，签发的是**大门防务戒严告令**，在大路两边拉起带尖刺的尖刺木栅，严令大家守好防区，闭门坚守不攻。
* 在阶段二十二中，菲去马厩草堆找提米。提米躲在干草后面，拿起爱丽榭编了挂绳的**白桦木小短笛，轻轻吹出两短一长清脆的笛声**当暗号。菲听出是小木笛的声音，跳下来和提米碰头，摸清楚了大门泄洪暗渠出口的守备空档。
* 在阶段二十三中，菲借着小木笛指引的路线，顺着大门的**古代石砌泄洪暗渠**一路往北潜行，顺利回到白鹿驿馆废墟去捡大剑断刃。

### 3. 第八幕至第九幕：暗河潜水与死牢救人
* 第八幕大家在千米地下暗河潜水，遇到的是古代矮人留下的**太古蓄洪分水闸**。凯尔和玲解开的是黄铜水银发条机关，把水闸稳住，防止暗河水暴涨。
* 亚尔缇娜顺着要塞地底两米多宽的**生铁排污管道**往上爬，在图纸上精确画出负四层地牢的排水管网和**地基沉淀盲井**的结构，找出了那堵被水泡酥了的黑石薄弱墙面。
* 第九幕大家冲进死牢，蜥蜴人加尔潜进冰水里，一刀砍断水牢水闸的铁销子。哈根摇动生铁总绞盘，升起大铁笼，把巴恩斯、戈德弗里和十四位资深骑士全都平平安安救了出来。

### 4. 第十一幕：王都全城水网排毒
* 教会在王都水井里倒暗影毒液，埃德蒙国王把祖传图纸送出来。凯尔和玲在酒馆地下室看懂图纸，大家一起打开王都地下的**太古蓄洪排污总闸**，引来山里的干净泉水，把整座城市的下水道冲洗得干干净净。

### 5. 第十二幕：大结局北归巡礼的温情收尾
* 审判结束后，商队大马车一路往北回大本营。
* 到了维里迪亚大门前，几吨重的生铁吊闸门被铁链高高吊起，再也不关上了，商队和旅人可以自由走动。巴恩斯穿戴得整整齐齐，站在大路边向马车行礼。
* 大门右边几米高的岩石高台上，小提米趴在石头边上，脖子上挂着爱丽榭编的深绿皮绳，小手抓着磨得光滑的**白桦木小短笛**，鼓起小脸蛋用力吹响，一串清脆欢快的小笛声在晨风和山谷里飘开。车窗里的爱丽榭和菲娜笑着挥手告别，马车缓缓开进葱郁温暖的晨光大森林，达成日式轻小说最舒心温暖的圆满结局。
