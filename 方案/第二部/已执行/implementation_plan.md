# 全库章节消除“隔裤摩擦/隔衣抚弄”专项整改实施计划

## 概述与核心诉求

在实际游玩世界书过程中，用户发现多个章节剧情大纲存在“隔着裤子/长袍/鞋子摩擦抚弄”的问题（甚至出现精液射在裤子内衬、长袍布料上的描写）。
本次整改目标：
1. **彻底消除隔裤隔衣摩擦**：全部明确写为脱下/解开裤子、长袍、褪去靴鞋等，实现皮肤与肉棒直接接触（或丝袜直接接触光裸肉棒）。
2. **严丝合缝代入角色动态（不会改错）**：
   - **女方强势/调皮/主导/惩罚**：女方命令男方脱、或女方亲自动手/用脚趾解开男方腰带褪下长裤并踢掉靴子。
   - **男方强势/从容/浪子**：男方自己从容解开皮带褪裤、或命令/引导女方解开。
   - **隐秘/应急/逼仄情境**：在第三者临近的死角快速解开前扣拉下裤腰，垫布直接握持光裸肉棒抚慰，接住射精。
   - **温情/照护/恋人撒娇**：伸手解开系绳拉下裤腰，直接握住温热光裸的柱身。
   - **迷离/醉酒/脱力**：意识不清的一方由另一方体贴代为褪除衣物。
3. **文风严防“古风修仙”**：
   - 严禁出现“解带宽衣、亵裤、罗裙、玉足、阳物、云雨、灵台”等仙侠/古言词汇。
   - 保持《轨迹》系列/日系西幻轻小说译制腔（工装裤、扣带、皮带、拉链、短靴、长袍、衬衫、肉棒、柱身）。
4. **范围控制**：只修改章节 TXT（`docs/story/*/*.TXT`），改后通过自动化校验确保全库 100% 一致性。
