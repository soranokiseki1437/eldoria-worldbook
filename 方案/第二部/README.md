## 核心管理原则

1. **绝对隔离原则**：
   - 第一部属于营地时期（Eldoria森林 13×10km 舞台），重心在于微创精修与碎片化修复；
   - 第二部属于雾帷消散后宏观大陆时期（维里迪亚王国 170km 舞台），重心在于多线政治叙事与空间舞台调度。两者的写作经验、人设状态与技术规则严禁混为一谈。

2. **王国零导力原则（Zero Orbal Tech）**：
   - 维里迪亚王国全境无导力。王国原住民使用油灯、烛火、石炭与马车。导力器仅属于帝国穿界者且须保持伪装。

3. **地点卡纯物理物象化铁律**：
   - `docs2/location/` 下的词条卡仅提供空间尺寸、材质、声光掩蔽与常态功能；所有剧情走向、伏笔与冲突只记录于本指导目录中。
