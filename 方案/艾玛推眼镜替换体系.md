# 艾玛"推眼镜→辫子"替换体系

## 根源
艾玛角色设定："魔女身份已公开，不再需要眼镜伪装" — 眼镜是伪装工具，已无存在必要。

## 新手势体系：李子色长辫

艾玛的辫子是她的"构建自我"——整洁、学术、受控。触摸/调整辫子=处理信息。解辫=交付。

## 对照表

| 原动作 | 新动作 | 含义 |
|--------|--------|------|
| 推了一次眼镜 | 手指轻触辫尾 | 思考/注意到什么 |
| 推了推眼镜 / 推眼镜 | 手指顺着辫子滑下来 / 指尖捻了捻辫梢 | 处理信息/缓冲 |
| 推了两次眼镜 | 手指穿过辫子，从发根梳到发尾 | 做决定 |
| 推了第三次眼镜 / 推了三次眼镜 | 攥住辫梢，指节收紧 | 紧张到极限但不退缩 |
| 摘下眼镜（放在桌上） | 解开发辫（让紫色长发散落） | 完全交付/坦诚 |
| 戴上眼镜 / 把眼镜戴回去 | 重新编好辫子 | 恢复冷静/回到学术框架 |
| 镜片反光（遮住眼睛） | 睫毛低垂 / 辫子垂落遮住侧脸 | 隐藏情绪 |
| 眼镜后 / 镜片后（观察） | 睫毛下 / 发丝间（抬起眼看） | 评估/观察 |
| 没有镜片遮挡 | 散发披肩 | 温柔/卸下防备 |
| 把眼镜放在... | 解下辫梢的光晶石发绳 | 准备交付 |
| 推了推不存在的眼镜 | 手指碰到散落的发丝后收回 | 习惯性动作落空 |

## 写法示例

旧: "艾玛推了推眼镜，薄荷蓝瞳从镜片后安静地看着他。"
新: "艾玛指尖捻了捻辫梢，薄荷蓝瞳从发丝间安静地看着他。"

旧: "她摘下眼镜放在工作台上——这是她的交付信号。"
新: "她解开发辫让紫色长发散落肩上——这是她的交付信号。"

旧: "推了推眼镜。推了第二次。第三次。笔放下。然后站了起来。"
新: "手指碰到辫梢。穿过发丝。攥住了辫尾。笔放下。然后站了起来。"

旧: "艾玛连推了三次眼镜。"
新: "艾玛的手指把辫梢攥了三次。"

旧: "推了推不存在的眼镜——推到鼻梁，没有镜框——笑了。"
新: "手指习惯性去碰辫梢——辫子是散开的，指尖落了空。笑了。"
