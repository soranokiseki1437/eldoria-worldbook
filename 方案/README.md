## 分部管理核心原则

1. **时空与状态隔离**：
   - 第一部属于营地时期、终局前后的既有长篇体系，重心在于文本精修、台词润色与去机械化；
   - 第二部属于雾帷消散后的宏观大陆新世界，重心在于王国大陆舞台拓宽、新政治阵营博弈与新章节大纲开拓。
2. **世界观法则隔离**：
   - 第一部舞台完全局限于 Eldoria 森林（13km×10km）；
   - 第二部舞台扩展为三大圈层（森林大本营、维里迪亚王国全境、帝国东部边境），严格遵循“维里迪亚王国绝无导力”的世界观铁律。
3. **地点卡纯物象化铁律**：
   - `docs2/location/` 下的地点卡仅描写客观物理空间、材质、声光与死角掩护，严禁直接包含剧情走向或角色剧透；具体的剧情推进与情节构思统一收纳于 `方案/第二部/` 中。
