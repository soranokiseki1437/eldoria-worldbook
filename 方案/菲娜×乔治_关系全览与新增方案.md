## 二、关系演变的核心轴线

### 2.1 菲娜的变化

```
被动害羞执行 → 主动引导者 → 规则制定者 → 隐奸设计者 → 主动亲吻者 → 完全自主走向他 → 恶作剧式道具化 → 见证他成为营地支柱
```

### 2.2 乔治的变化

```
偷看被抓的胆小鬼 → 被动参与者 → 反客为主的口交者 → 笨拙的第一次本番 → 认真学习的伴侣 → 失控的索取者 → 被惩罚的反省者 → 主动抚摸接吻的发起者 → 拘束偏好被发现的"变态" → 被菲娜主动亲吻的幸运儿 → 被菲娜完全自主走向的回报对象 → 三人常驻之一 → 连接两个世界的工程师
```

### 2.3 五个关键转折点

1. **Ch241（乔治的唇）**：乔治首次主动。他反推倒她，为她口交，吻了她，说"这么好吃"。
2. **Ch262（工坊午后）**：首次本番。菲娜全程引导，她对黎恩说"因为乔治比她更不会"。
3. **Ch365（老实人的另一面）**：乔治首次不请自来的主动。他覆上她的手背，吻她，插入了她。
4. **Ch408（帽檐下的轻吻）**：菲娜首次纯情感主动亲吻。从性到情，转折在这一吻。
5. **Ch599（裂隙的频率）**：乔治的技术巅峰。菲娜站在他身后，听他的导力通讯穿过裂隙，把两个世界连在了一起。

### 2.4 反复出现的核心意象

- **手足无措**：乔治被打动时忘了手里在做什么（Ch241, 262, 300, 314, 576...）
- **摸后脑勺**：乔治的标志性不安动作（贯穿全书）
- **"像修导力装置一样"**：乔治的工程思维渗透到性行为中
- **拘束姿势**：从Ch355（创伤）到Ch381（调情）的镜像复现
- **黎恩的注视/视频**：三角结构中黎恩始终是锚点

## 五、写作铁律（逐条对照，违反即重写句子）

### 5.1 破折号使用规则

破折号只允许三种场景。其余任何一个破折号出现，不修标点，重写整个句子。

**允许：**

| 场景 | 示例 | 说明 |
|:--|:--|:--|
| 标题分隔符 | `工坊的午后——再来一次` | 前半段和后半段之间的连接 |
| 对话被打断 | `"你怎么——"` | 话说一半被截断 |
| 插入语 | `惩罚之后，乔治在工坊躲了好几天` | 插入语拆成独立句或逗号前移 |

插入语重写示范：`被惩罚之后——黎恩一拳、菲娜巴掌、横抱带走——乔治在工坊躲了好几天` → `黎恩一拳、菲娜巴掌、横抱带走。惩罚之后的几天，乔治在工坊躲着没出来。`

**禁止场景与重写方法：**

| 违规类型 | 错误示范 | 重写方法 |
|:--|:--|:--|
| 后置解释 | X，Y理由 | 理由前置：删掉"X"，直接从Y起句 |
| 后置描写 | 细节堆在破折号后 | 另起独立句，或逗号串联 |
| 戏剧停顿 | 动作接破折号再接描写 | 拆成两个独立句，或逗号合并 |
| 后置判断 | 陈述接破折号接评价 | 评价另起一句。两句独立的重量大于一句带破折号 |

检验方法：删掉"X"和破折号，只看"Y"。如果Y是完整句子，则原句的破折号就是冗余的。

### 5.2 画圈禁令

"手指在皮肤上画圈"是AI最爱的亲密动作模板——事后在胸口画圈、沉默时在手背上画圈、安抚时在后背上画圈，全是cliché。

**禁止场景**：
- 手指在胸口/手背/锁骨/后背画圈（亲密后的标配填充动作）
- 拇指在手背上慢慢画了一个圈（沉默时的万能填充）

**替代方向**：写具体的、只属于这个角色的动作。菲娜手指无意识地蜷了又张开。乔治手指在导力器外壳上摩挲。黎恩拇指按在她后颈上不动，就是按着。

**明确允许**：舌尖在乳晕/龟头/阴蒂上画圈——那是具体的口交技法，不是cliché手势填充。

### 5.3 句子节奏规则

一个段落内，句子长度必须有明显起伏。长句提供密度，短句提供重量。两者轮流出现。

```
✗ 全是短句：她没抽手。她抬头看他。他耳朵红了。她心跳很快。他说不出话。
✓ 长短交替：她没抽手，抬头看他。他耳朵红透了，眼神却没躲，嘴唇动了动没发出声音。她感觉到自己的心跳比表情诚实。
```

**具体约束：**
- 禁止连续三个短句排列。短句定义：≤12字、无逗号、单主谓结构
- 每个短句的下一句必须≥20字
- 两个相关联的短动作合并为一个中长句：`她蹲下。她捡起发绳。` → `她蹲下捡发绳`
- 动作链用逗号串联，不拆句号：`他接过笔。他放下。他把她拉起来。` → `他接过笔放下，把她从地上一把拉起来`

### 5.3 叙事视角规则

禁止高维视角。不从故事外部俯视时间流逝，一切叙述落在角色的感知里。

```
✗ 第一次本番之后没几天，菲娜去工坊取修好的导力器。
✓ 菲娜去工坊取修好的导力器。上一次她在这里引导他完成了第一次，已经过了好几天，两个人见面时谁也不提。
```

```
✗ Ch270视频直播的第二天。菲娜路过工坊。
✓ 视频直播的第二天。菲娜路过工坊。
```

章节编号（Ch###）只能出现在位置字段、分析段落和优先级表中。核心、回归时刻等叙事字段禁止使用。

### 5.4 迂回否定禁令

凡是要陈述一件事，直接说它是什么。不先说它不是什么。

```
✗ 他在学习她，不是评判她。
✓ 他在学习她。

✗ 她不是在安抚——她是在重新建立规则。
✓ 她在重新建立规则。安抚不会有这个重量。

✗ 不是欲望，是恐惧。
✓ 恐惧。比欲望深得多。
```

例外只保留两种：角色对话中的自然否定（`"你的导力器不是昨天才修过"`）和文学对比（`是同一个人。又不是同一个人。`）。

### 5.5 对话写作规则

- 人物不说完句话。吞字、犹豫、把后半截交给动作
- 不用"我知道了""他知道""嗯"做单字回应。用身体反应或更完整的表达替代
- 每段对话后至少跟一句描写（动作、表情、身体反应、环境），禁止连续堆对话行
- 迂回否定禁令同样适用于分析性字段（功能、驱动力、反应、黎恩角色）：直接说是什么

### 5.6 乔治的关键特征

棕色短发、不戴眼镜、社交腼腆技术自信、写字画图纸的手指。口头禅"可以吗"在阶段四后逐渐减少，S5-4重新出现。

### 5.7 菲娜的视角与人物指纹

摄影机模型确定对准谁。菲娜在乔治面前偏主导，但害羞体征贯穿全场景：事前结巴、事中沉默不理人、事后跑回黎恩怀里蹭胸口。

**新增方案必须逐条确认以下10条人物指纹**（缺一条补一句）：

1. **琥珀色眼睛先弯再笑** — 专属表情。压缩为"她笑了"=丢失顺序
2. **动作之后的延迟害羞** — 先行动再脸红。脸红放动作前面=那不是菲娜
3. **捂嘴/指缝看人/藏脸** — 害羞时的特有肢体语言
4. **害羞后紧接确定的眼神/动作** — 害羞从不以退缩结束
5. **高潮退去后的蹭脸/鼻尖蹭枕头/猫一样小动作** — 淫荡和可爱不互斥
6. **声音发抖/变轻的心理原因** — 只说"声音发抖"=原因被抹平
7. **从床单/手臂/指缝里抬起一只眼看人** — 害羞+好奇的混合表情
8. **会脸红，永远会** — 320岁在黎恩面前永远有少女的一面
9. **笑必须有动因** — 每次笑之前必须有读者能识别的触发。禁止"她笑了"单独成句
10. **事后甜美回归黎恩** — 哪怕只是一个句子：把脸埋进他胸口、蜷在他怀里蹭脸、手指攥他背后的衣料

**菲娜在乔治面前的特征补充**：

- 害羞体征贯穿全场景：事前结巴（"我我我"）、事中沉默不理人（"......"）、事后跑回黎恩怀里
- 阶段四跨线时：每迈出一步前转头看黎恩→确认→才继续
- 阶段五享受时：说浪话时耳朵尖红、攥黎恩的手到指节发白。高潮后蹭脸/鼻尖蹭枕头
- 阶段六放纵时：主动找乔治但耳朵还是一碰就红
- 阶段八后日谈：娇羞回归+成熟妩媚，叠加了所有经历的沉淀，非少女时代的复刻

### 5.8 黎恩是锚点

菲娜与乔治的任何进展最终都要回到菲娜与黎恩的关系中确认。回归时刻不可省略。

**黎恩的血肉感——他不是一个冷静的旁观者。** 他的反应必须有物理表现：

| 反应层面 | 具体写法 | 禁止 |
|---------|---------|------|
| 声带 | "声带是紧的""声音降了半度""从胸腔里传出来" | "他冷静地说""他淡淡地说" |
| 心跳 | "心跳比平时快了整整一拍""透过肋骨传过来" | 不写心跳变化 |
| 手 | "手指捏她后颈""攥她的手指到指节发白""帮她重新扣扣子" | 手部无动作，只写"他看着" |
| 胸腔 | "胸腔震了一下""笑是被她的笑牵出来的" | 只写"他笑了" |
| 笑 | 每次笑必须有触发（被逗到/释放紧张/看着事情按预期发生） | 无触发突然笑 |
| 吃醋 | 不直说，藏在动作里：收紧手臂、拽她到腿上、扣子扣得比平时慢 | "他吃醋了""他说他不高兴" |
| 占有 | 藏在日常动作中：手指穿过她发丝的时候停留、帮她整理扣错的扣子、下巴搁在她头顶 | "他重新占有了她"（概述代替描写） |

**黎恩的对话法则**：话少但每句有重量。不直接说"我爱你""我吃醋了""你做得很好"。这些情感从动作里渗出来——拽她到腿上、手指捏她后颈、帮她扣扣子扣得很慢、"下次给他带点咖啡豆"。他的沉默不是冷漠，是信息在身体里跑了一圈还没找到合适的词。声带会紧，心跳会快，手会抖——这些替代了他没说的话。

**参考章节**：Ch155/158/311-313 — 黎恩的反应充满物理细节，从"胸腔震了一下"到"心脏跳得比想象中快"。

### 7.2 反复犯错的根本原因

**问题1：修复只改标点，不重建句子结构。** 用户指出破折号滥用后，我只把"——"替换成逗号或句号，句子的信息组织方式没变。正确的做法是拆掉"X——Y"的两段式，重新决定信息出现的顺序：把Y的内容前置，或分拆为独立句，或改用语法连接词。

**问题2：分析性字段被当成"豁免区"。** "功能""驱动力""菲娜反应""黎恩角色"这些字段我潜意识里归类为"元数据"而非散文，因此对里面的"不是而是"和破折号滥用放松了标准。用户明确指出：这些字段同样是读给人听的文字，规则一刀切。

**问题3：逐条打地鼠，从不做全量扫描。** 每次用户指出一个具体问题，我只修那一处。修完后从不运行全局grep验证是否还有其他残留。结果就是同样的模式在不同的方案里反复出现，用户需要反复指出。

**问题4：写完不复核。** 本日多次出现"刚写完就违反了自己刚写的规则"的情况。最典型的一次：修改第五节规则文字时，顺手在规则散文里加了一个破折号。写完一段文字后没有对照五条铁律逐条过一遍。

### 7.3 正确的修改流程

以后修改任何方案文字，按以下顺序执行：

```
1. 写完一段
2. grep 扫描该段：'——' '不是' 'Ch\d' '。"'  '。"'
3. 发现违规 → 重写句子结构，不修标点
4. 再扫描确认零残留
5. 继续下一段
```

短句检查不在grep范围内，需要在步骤2手动扫读：一个句号一个句号地数。如果连续三个句子都不超过12字且无逗号，用逗号合并或拉长中间句。

### 7.4 方案标题命名规律

已有章节的标题格式为 `具体场景/意象/时刻——核心事件/动态`：

- `贮藏室的意外——门锁坏了的隐奸`（触发条件——事件类型）
