## 〇、扩展原则

1. **纯爱内核NTRS**：共享时刻 ⇄ 回归时刻。艾玛的心始终在法林。身体的共享是信任的延伸，不是背叛。
2. **身体先于意志**：艾玛的反应顺序是 身体回应 → 意识到 → 做决定。先红耳朵，再决定接受或推开。
3. **大姐姐的张力开关**：掌控 → 失去掌控 → 被接住。权力反转是艾玛场景的张力核心。
4. **因果链，非事件链**：每个节拍必须"因此"而非"然后"。每个性行为节拍前面必须有情绪/身体原因。
5. **场景独立**：每章独立，不依赖"上次做了X"来驱动。起因 → 触发 → 发展 → 收束四段完整。

## 一、艾玛人设核心（写作技法摘要）

> **来源**：`艾玛专属_去机械化和碎片化叙述经验.txt` · `艾玛×蜥蜴人_沼泽猎人方案（仅人设与技法，非剧情）`

### 1.1 艾玛的声音配方

**核心公式**：甜软的声线 + 主动调戏 + 问句多于陈述句 + ~拖尾 + 身体出卖。

- **~ 甜度标记**：跟在名字/嘛/呀/乖后面；逐音节~（"法~林~"）= 最高甜度
- **问句默认句式**：调戏用问句让对方参与，陈述句是旁观。"好不好？""喜欢吗？""这么喜欢呀？"
- **名字是情感最小单位**："法林"→"法林~"→"法~林~"→"法林先生~"，叫法本身就是情感刻度
- **句式比例**：日常调戏 问句70%/陈述句20%/感叹句10%；学术思考 陈述句90%/问句10%
- **词汇表**：呀/嘛/哦/啦/好不好/乖/讨厌（完整句子+暖甜语调）。禁用：臭家伙/坏蛋/二字讨厌~/三字句号（嗯。好。对。）

### 1.2 身体永远先出卖她

艾玛主动调戏时也会害羞——耳朵红、捻辫梢加速。头脑在调戏，耳朵在投降——两层同时发生。

**捻辫梢情绪词典**：
- 从容调戏：慢慢绕，一圈比一圈慢
- 调戏中的害羞：绕得快起来了——自己没注意到加速
- 紧张：指尖在发抖
- 心动：手指停了，辫梢停在指尖不动
- 决定：辫梢从指尖滑落，没再去捻
- 被看穿：手抬到一半想去碰辫子，硬生生压住
- 害羞到极致：把辫梢咬在嘴里，自己没发现
- 满足：指尖沿辫子纹路慢慢滑下去
- 被攻陷：辫子散开了
- 生气：不碰辫子。手指摆在桌上或垂在身侧

规则：同一章内捻辫梢不出现超过三次；每次含义不同；不配破折号解释。

### 1.3 不自知的魅惑力

艾玛的性感是别人发现的，不是她自己说的。写他人（男性角色/生物的视线流动），不写"她很性感"。"好看。不止好看。"——让角色把后面的话咽回去。艾玛自己不知道丝袜好看——她只是穿了。是别人的视线替她发现的。

### 1.4 好奇心驱动的行动

艾玛的好奇心不是"她很好奇"——是身体已经动了，脑子还没跟上。好奇心 = 动作在先，意识在后。被弹开/被烫到/被发现了 → 才反应过来。

### 1.5 学术精准是本色

艾玛的学术措辞不是"掩饰"——她就是这样的人。暖的艾玛和学术的艾玛是同一个人。学术语言只在艾玛真正在思考时写。真掩饰用身体反应（耳朵红、捻辫梢抖）。

### 1.6 被服务时的声音节奏

指导（"这里..."）→ 甜喘（"嗯嗯~"）→ 夸奖（"乖~"）→ 叫名字（"法林~"）。循环交错。艾玛被服务时不是不出声——她会说、会叫、会夸。"乖~"是大姐姐被服务时的最高评价。事后暖甜抱怨："你好讨厌啊，射满了都..."

### 1.7 大姐姐气质

照顾别人时：动作比语言多，语言是甜的问句。"要不要我帮你？"——给选择权。

被照顾时：先愣一拍（不习惯被反向照顾）→ 肩膀先松 → 手指松 → 呼吸松 → 声音更轻更软 → 被照顾到某个点 → 把脸埋起来。大姐姐在这一刻变成女孩。

### 1.8 情绪直接写不绕弯

不写"她很纠结"——写多层序列：认出→停顿→托底→选择，每步一句。害羞时写"耳朵红了，嘴角还弯着"——害羞和甜同时存在。生气时~消失、问句变陈述句、名字变全名——甜味下线是艾玛生气的标志。

## 二、月语者与怪物设定摘要

> **来源**：`docs/npc/狼人月语者.TXT` · `docs/creature/低语者.TXT` · `docs/creature/腐化藤.TXT` · `docs/creature/腐化史莱姆.TXT` · `docs/creature/狼人.TXT`

### 2.1 月语者（狼人部族精神领袖）

- **身份**：Eldoria最后狼人部落的精神领袖和口传史诗守护者。雄性，年龄相当于人类六十岁以上
- **外貌**：常态约185cm，偏瘦但站姿如百年老树不倒。灰黑毛发夹杂大片银白，口鼻部和下颌银灰色。绯红色眼睛——比年轻狼人更淡，近乎金色，月光下泛起淡蓝荧光（"月瞳"）。右耳有一处缺口（被影牙兽咬掉）。犬齿有一颗断了半截。兽皮和粗布拼成的长袍，肩部缝月亮纹章。颈间挂骨珠——每一颗代表一个离世的部落成员
- **性格**：说话慢而沉——每个字都在喉咙里转一圈才出来，但不犹豫。带着"我见过太多所以不急着评价"的从容。对人类的态度是观察。"你身上有鬼。不是坏的鬼。"
- **月语能力**：能在月光下看到"影子"——过去和未来的残影。月语不是魔法——是狼人与月亮之间的古老契约。"月亮不说话。但月光有形状。你看久了就会认。"
- **背景**：出生在北方深林，影牙降临时正值壮年。带着幸存者从北方深林一路南迁，路上失去伴侣和两个幼崽。现在每天傍晚站在山谷石壁上对着北方深林方向站很久

### 2.2 低语者（腐化精灵残影）

- **本质**：200年前精灵王国陷落时未能解脱的先祖灵魂被腐化扭曲后的形态。介于生与死、精灵与幽魂之间——早已不是真正的"活物"
- **外貌**：暗紫色人形，轮廓模糊像被水浸湿的墨水画。没有面部细节——只有眼部两点暗光。手指细长，关节不明显。触感滚烫，与外表的冰冷暗色反差
- **阴茎**：约19cm，暗紫色半透明——与身体同样介于虚实之间。偏长偏直，龟头轮廓模糊但尺寸明显
- **行为**：绝对沉默——从不发出任何语言或声音。这种沉默是最显著的特征——比任何威胁都更让人毛骨悚然。不主动攻击但会本能地靠近圣光和生命之力。被200年囚禁压抑后出现集体躁动
- **消灭方式**：物理手段可击散形体但不彻底——残存腐化能量数日或数周后会重新聚合复活。只有圣光才能彻底净化解脱。守护者私处体液净化是误打误撞——射精时圣光浓度峰值+低语者丧失抵抗力→顺势消散。**只有守护者（Seraphina）能通过性行为净化低语者**

### 2.3 腐化史莱姆（水精灵腐化态）

- **本质**：原为银流河或镜湖中透明水之精灵，被腐化污染后变为半透明暗紫色胶质
- **形态**：没有固定形状——静止时是一滩，移动时撑起人形或触手状
- **行为**：本能包裹靠近猎物。胶质接触皮肤释放麻痹毒素使人逐渐失去力气但意识清醒。过程持续数小时吸取生命能量
- **弱点**：圣光照射使胶质瞬间凝固变脆一击即碎。离开腐化区域超一小时脱水化为粉末
- **触感特征**：胶质在热源集中处自动汇集——乳房、大腿内侧、蜜穴口——跟随宿主脉搏同步蠕动

### 2.4 腐化藤（掠食藤蔓）

- **本质**：原生藤蔓被腐化扭曲后的掠食植物
- **形态**：暗紫色粗壮藤蔓，表面有倒刺含麻痹毒素。尖端触须探索周围寻找热源
- **行为**：平时半休眠在地面或枯树上。感知生命体靠近时三秒内进入攻击状态——缠绕绞杀并注入毒素。根系未毁则无限再生
- **弱点**：圣光可直接烧毁藤蔓但根系可能存活。切断根部最有效——需挖到地下半米。火攻可行但不推荐（释放有毒烟雾）

### 提案1：月光下的古老契约——月语者的沉默与馈赠

他看出了她对知识的渴望，但给出了她没预料到的东西：他对她说了一句狼人部族用来在月光下纪念死者的古老语言。她的耳朵先红了。被看见了。

- 首次艾玛×月语者——性行为是古老仪式/情感馈赠的延续
- 艾玛不调戏——大姐姐模式让位给倾听者和给予者

### 提案2：胶质包裹中的边界溶解——腐化史莱姆的全身沉浸

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段5中后段） |
| **对象** | 腐化史莱姆（水精灵腐化态·半透明暗紫胶质） |
| **起因类型** | 怪物遭遇+学术好奇：观察水精灵腐化过程→被史莱姆包裹 |
| **场景类型** | 银流河或镜湖·浅水区·夜晚/月光 |
| **性行为等级** | 7-8（胶质包裹·全身同时刺激·麻痹毒素） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+8 / 法林+10 |

**核心设计**：

腐化史莱姆是水精灵被腐化污染后形成的半透明暗紫胶质，无固定形状。与腐化藤共享麻痹毒素，但体验完全不同：**藤蔓是线状缠绕（被束缚），史莱姆是面状包裹（被溶解）**。胶质在热源集中的地方自动汇集——乳房、大腿内侧、蜜穴口——跟随宿主脉搏同步蠕动。

艾玛在镜湖边研究水精灵腐化过程的物理性质变化。一只史莱姆从浅水区浮出——她本可以后退，圣光符文在手边。但学术好奇心比恐惧快了半拍。然后胶质接触了她的脚踝。

**关键节拍**：
- 起因：镜湖边采集样本 → 史莱姆从水中撑起人形轮廓 → 她没有退，蹲下来想近距离观察 → 胶质触到手指，凉→热
- 触发：胶质从手指沿手臂蔓延——像被温热的半液态丝绸一层层裹住。麻痹毒素让力气慢慢稀释。胶质在热源处更密更厚。紫色丝袜在胶质里变了形
- 发展：全身被暖胶裹住——麻痹让皮肤失去边界。胶质在蜜穴口、阴蒂、乳尖同时汇集，暗紫胶质有脉冲感地微微蠕动——节奏和脉搏同步。甜喘从胶质空隙间漏出来，闷闷的
- 高潮：全身同时到达——蜜穴、阴蒂、乳尖在同一瞬间被胶质脉冲推过临界。胶质变深紫然后随消退变淡。她在胶质里弓起腰。史莱姆不停——高潮被拉成叠浪
- 解救：右手蠕动了很久够到腰间符文石。圣光激活，胶质瞬间凝固成石灰色。她从胶质里滚出来跪在浅水区喘气，然后捡了一块凝固碎片放样本袋。标签写完看自己的字，耳朵红了
- 收束：回符文室。法林用拇指擦掉她脸上的胶质碎片，手指很暖，和胶质完全不同。"我今天做了一次不太成功的野外采集。""样本有用吗？""有用的~"她停了一下。"下次你陪我去~"

**差异化**：
- 胶质包裹是"面状沉浸"——全身被温热半液态胶质裹住，非线状缠绕
- 胶质热源汇集+脉搏同步蠕动+全身同时到达——无意志的精准
- 半主动（本可退但选择观察）
- 自己圣光脱困
- 事后捡样本→学术本能自动重启→看到字才害羞

**写作注意**：
- 胶质触感关键词：温热半液态、丝绸质地、脉搏同步、暗紫随刺激变深→消退变淡
- 麻痹≠昏迷。意识全程清醒，身体感觉被放大——皮肤边界溶解的独特体验
- 艾玛的学术脑在麻痹中也断续运转：观察→记录→但被快感打断→继续观察→又被高潮冲散
- 自己脱困是关键——能动性不归零。挣扎够到符文石的过程是意志力的体现
- 事后捡样本：不是"哈哈好刺激"也不是"太可怕了"——是学术本能自动重启，标签写完才脸红。这是艾玛

### 提案3：暗紫残影的包围——低语者遇袭

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段5末） |
| **对象** | 低语者（多个·腐化精灵残影） |
| **起因类型** | 怪物遭遇：在腐化边缘废墟被低语者包围袭击 |
| **场景类型** | 腐化边缘·精灵废墟·夜晚 |
| **性行为等级** | 8-9（多个低语者·轮番·无法反抗） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+6 / 法林+12 |

**核心设计**：

低语者是腐化精灵的残影——暗紫色半透明人形，绝对沉默，19cm暗紫半透明阴茎。艾玛在腐化边缘的精灵废墟采集符文石样本时，触动了遗迹中残存的圣光元素——波动激活了周围所有处于半休眠状态的残影。

她从废墟出来时被包围了——七八个暗紫色人形轮廓从石缝和枯树后同时浮现。绝对沉默。没有警告，没有声音。只有细长手指——触感滚烫——同时伸向她。

低语者是腐化精灵的残影，不是魔兽。它们在触碰她的时候，她感受到的是200年被压抑后的、在圣光元素刺激下的集体躁动。这不让她感觉更好。

**关键节拍**：
- 起因：艾玛独自去腐化边缘废墟采集古老符文石 → 触动遗迹残余圣光 → 圣光波动扩散 → 周围半休眠低语者全部被激活 → 从废墟出来时暗紫人形从四面八方浮现。"...这么多。"
- 触发：没能跑掉。第一个低语者的手指扣住手腕——滚烫。第二个、第三个。暗紫半透明的手从背后、身侧、前方同时伸过来。被拉倒在地，紫色丝袜在碎石上划破，辫子散了。整个过程中，**绝对沉默**
- 发展：多双手同时在扯衣服、触碰身体。没有配合。八年十年二十年都没碰过活物的残影在集体躁动。衬衣被撕开。丝袜从大腿根撕裂——一只低语者的手指穿过茂密阴毛。另一只含住乳尖。暗紫半透明胶质的温热覆裹，不是嘴唇的柔软。她叫了出来，真实的、从喉咙挤出来的叫。她叫了法林的名字，没有回音——低语者不会回应。第一根暗紫色半透明阴茎进入了，滚烫。第二根在嘴里，第三根在手里
- 持续：轮番。不像矮人兄弟有节奏、有默契，这是残影的集体释放。每根暗紫阴茎都滚烫，和冰冷外表相反。她的身体反应（蜜液、喘息、高潮）和恐惧并行，互不否认。低语者射精后有些会自行消散——只有守护者能通过性行为净化低语者，它的消散是能量自然耗尽的结果，在圣光元素残余的刺激下加速解体成金色粒子。新的低语者补上来。她没数有多少个。只记得那晚的沉默从头到尾没有一声
- 收束：黎明的圣光救了她的命。晨光中腐化能量衰退，残影一个接一个退回阴影和石缝。她在碎石地上坐了很久，衬衣撕了，丝袜只剩残片，身上全是滚烫触感留下的淤红。站起来时腿在抖。耳朵不红。薄荷蓝眼睛里有某种以前没有的东西。是知道了。回符文室。法林还在睡，她没叫醒他。洗了很久。光着身子钻进他被窝，冰凉皮肤贴着他后背。"艾玛？""...做噩梦了。""什么噩梦？""...记不清了。"他把她的手握在自己手心里。她在他手心里一直在抖，后来才停

**差异化**：
- 首次艾玛×低语者遭遇——真实的遇袭
- 低语者是"多个"残影的集体躁动。绝对沉默×多人触感=独特恐怖
- 身体反应和恐惧并行，互不否认
- 艾玛没有告诉法林实情，独自承受
- 低语者消散≠净化——艾玛不能净化低语者。消散是能量自然耗尽+圣光残留催化

**写作注意**：
- 低语者的绝对沉默是恐怖核心——从头到尾没有一个音节。叙事中用"没有回音""没人回应""沉默"反复标记
- 艾玛叫法林名字→没有回音——这个瞬间的绝望比任何描写都重
- 身体反应和恐惧并行：不写"虽然害怕但是湿了"——写蜜液和恐惧同时发生，互不解释互不否定
- 事后艾玛的状态：耳朵不红（不是害羞，是冲击过大后的空白），薄荷蓝眼睛里有"知道了"——不是具体知道了什么，是知道了世界有这一面
- 回归时刻：不说。独自洗了很久。钻进他被窝时不说话，是冷的皮肤贴上去。法林问，她说"做噩梦了""记不清了"——不是撒谎，是无法用语言承载。他在她手心里一直在抖——然后才停。法林什么都没说，只是握着

### 提案4：观察者的囚笼——低语者研究失控

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段6初） |
| **对象** | 低语者（单个·被符文阵困住的残影） |
| **起因类型** | 学术研究→意外失控：符文束缚阵共振衰减→低语者脱困 |
| **场景类型** | 石殿隔离间·符文灯光·多重安全措施 |
| **性行为等级** | 7-8（单个低语者·研究中途意外失控） |
| **黎恩知情** | 是（营地知道她在做低语者行为研究） |
| **好感影响** | 艾玛+8 / 法林+10 |

**核心设计**：

数周过去了。艾玛没有让那晚的沉默成为终点，她用学术回应了恐惧。"正因为怕，所以要理解。"这是真实的创伤处理机制：可控的、有安全措施的、有人知道她在哪的暴露。

她搭建了符文束缚阵来研究低语者的行为模式：能量波动周期、触感温度变化、对圣光元素的距离反应。一个低语者被符文阵困在石殿隔离间。她不是一个人——营地知道她的研究项目，法林知道她今晚在隔离间，安全信号每半小时发一次。多重束缚阵、紧急圣光触发器、定时检查。她做了所有对的事。

但符文束缚阵的导力频率和低语者体内的腐化能量产生了她没预料到的共振——符文在持续接触中缓慢衰减。这是她没有算到的变量。

当她发现最后一道符文暗到只剩微光时——它灭了。低语者走向她。绝对沉默。

**关键节拍**：
- 起因：数周后的常规研究夜 → 记录腐化能量与圣光距离衰减曲线 → 完全沉浸在数据中。安全措施全部到位：多重束缚阵、紧急触发器、定时信号。但共振频率是她没算到的变量
- 触发：符文束缚阵导力频率与腐化能量共振→符文缓慢衰减。她发现时最后一道符文已暗到只剩微光，然后灭了。"...共振频率和预估的不一样——"她抬头。低语者已经在看她了。眼部两点暗光在半暗里亮着。绝对沉默。它往前走了一步。她的手移向紧急触发器，但触发器需要圣光注入，而束缚阵的共振已经干扰了圣光回路。这是她没设计的故障模式
- 发展：只有一个低语者。它是慢慢来的。她后背贴着石壁，路径被挡住了。细长手指触碰她的脸，滚烫。和废墟那晚一样的触感。但这次只有一个。她的恐惧和废墟那晚不同——被淹没的恐惧换成了另一种："我做了所有安全措施但共振频率算错了"的恐惧。这恐惧里有愤怒，对自己的。然后它的手指顺着锁骨往下滑。乳尖硬了，蜜液开始分泌，身体反应和她脑内的自我指责同时发生。身体记得废墟那晚的触感，神经系统的条件反射
- 高潮：它进入了，和废墟那晚一样滚烫。她叫了法林的名字，和废墟那晚一样。但这次她的声音是锚。她在绝对沉默中到达高潮，身体反应和情绪分离。低语者射精了，滚烫精液在她体内溢出。然后它的形体开始不稳。只有守护者能通过性行为净化低语者——它的消散是因为腐化能量在射精释能后跌破了维持聚合的临界值。金色粒子从暗紫轮廓中渗出，200年的残影，在她体内耗尽了最后的能量。她看着它在她眼前化为金色光柱，消散
- 收束：独自坐在隔离间石地上。安全信号灯在闪，她没按，但它自己到了定时。笔记本最后一页画着束缚阵频率曲线，歪歪扭扭，她画到一半笔掉了。合上笔记本。去了法林的符文室。他抬头看到她的表情，薄荷蓝眼睛里有光但不是笑，放下刻刀。她在他旁边坐下，把头靠在他肩上。沉默很久。"我今天知道了两件事。""什么？""低语者的束缚阵...频率不能和腐化能量同频。"她停了一下。"还有一件事。""嗯？""废墟那天晚上的事...我可以告诉你了。"

**差异化**：
- 首次艾玛×低语者遇袭后的主动研究——从被动遭遇转向主动面对
- 研究发生在遇袭数周后，有时间处理创伤。研究是应对机制。多重安全措施到位。失控是共振频率计算错误
- 低语者消散=能量耗尽。艾玛见证了它
- 回归时刻的关键转折：主动告诉法林那晚的事
- 菲娜不出场——这里不需要菲娜，只需要法林

**写作注意**：
- 安全措施的逐一描写（多重束缚阵、紧急触发器、定时信号）——建立"她做了所有对的事"的前提。然后共振频率算错——不是她蠢，是她遇到了未知变量
- 恐惧的第二形态："被淹没的恐惧"→"我算错了的恐惧"。后者有愤怒（对自己的），比前者更复杂
- "身体记得"：废墟那晚→身体条件反射→乳尖硬了/蜜液分泌→和她脑内的自我指责同时发生。神经系统有自己的记忆，不经过意志
- 消散时刻的目睹：低语者化为金色光柱——被囚禁200年的残影，射精后能量跌破临界值。她在场但这不是她的力量——是自然规律。见证者是她的角色
- 回归时刻的"两件事"：第一件是学术（频率不同频），第二件是情感（我现在能告诉你了）。两件事一起说——艾玛的学术和情感是一体的

### 提案5：触手拘束中的身体诚实——腐化藤的麻痹与释放

| 维度 | 内容 |
|------|------|
| **暂定ID** | Ch4xx（阶段6初） |
| **对象** | 腐化藤（暗紫色掠食藤蔓·倒刺+麻痹毒素） |
| **起因类型** | 怪物遭遇：野外采集时被腐化藤缠绕→麻痹毒素→身体先于意志的极端版 |
| **场景类型** | 密林·腐化边缘·野外 |
| **性行为等级** | 8-9（多藤蔓·触手·拘束·多重刺激） |
| **黎恩知情** | 否 |
| **好感影响** | 艾玛+8 / 法林+10 |

**核心设计**：

腐化藤是原生藤蔓被腐化扭曲后的掠食植物。艾玛去采集腐化藤样本做研究——做了防护但藤蔓根系比她预估的深了半米。蹲下来挖样本时，三条藤蔓从不同方向同时缠上来。麻痹毒素渗入，四肢逐渐无力但意识清醒。这是"身体先于意志"的极端版：大脑在反抗，身体在接受，两者同时发生互不矛盾。

**关键节拍**：
- 起因：独自去腐化边缘采集样本 → 挖样本时三条藤蔓从地下窜出 → 倒刺划破紫色丝袜 → 麻痹毒素渗入
- 触发：圣光符文石从麻木指尖滑落 → 第四条更细的藤蔓带着尖端触须沿小腿内侧往上探索
- 发展：触须本能寻找热源——蜜液渗透丝袜在触须尖拉出湿痕。"...湿了。"说完才意识到，耳朵烧起来。更多藤蔓加入——缠绕乳房、分开大腿。呼吸碎成被麻痹迟缓后的深喘
- 高潮：在触须刺激下到达——麻痹让快感被拉长，像水下的声音。藤蔓不知道"够了"——继续吸收
- 解救：法林和多尔金找到了她——她出发前说了采集地点，时间过了还没回来。多尔金用大锤砸碎根系。法林把她从残骸里抱出来——手指攥着他的衣襟攥得很紧
- 收束：符文室。法林给她擦划痕。"麻痹毒素...应该和圣光元素做一次交叉反应..."停了。"明天再说。"她把手覆在他手上，手指还不能完全握紧，但够了

**差异化**：
- 麻痹毒素剥夺行动力但意识完好——"身体先于意志"的极端版
- 藤蔓多点同时刺激——独特的触手身体体验
- 法林赶来救她，把她从藤蔓残骸中抱出来
- 事后先学术→自己喊停——艾玛学会了暂停

**写作注意**：
- 藤蔓是植物——不是触手怪有策略。触须寻找热源是本能，不是意图。写藤蔓时用"触须""缠绕""倒刺"，不用拟人化动词（"它决定""它想"）
- 麻痹≠无力。是渐变过程：手指麻木→手腕→前臂→肩膀→全身。意识全程清醒，能看见、能听见、能感受，就是动不了
- "身体先于意志"的极端版：大脑说"这是掠食植物"，身体说"但触须在阴蒂上"。两者同时发生，互不矛盾。不是"身体背叛"——背叛需要选择，身体没有选择
- 法林来救：他看到她的状态——圣光符文石掉在地上（够不到）、丝袜破了、辫子散了、触须还在蠕动。然后多尔金砸碎根系。他从残骸中把她抱出来——"手指攥着他的衣襟攥得很紧"——麻痹还没消退，这是她能做的唯一动作
- 事后在符文室：她先启动学术脑（交叉反应）→然后自己喊停（"明天再说"）。学会了暂停——提案5的收束是成长
