# Eldoria角色设定摘要

> 来源：`docs/character/` 全部14个角色TXT + `_人物总览.TXT`（只读整理，未修改任何设定文件）
> 结构：主剧情位面为Eldoria森林（精灵守护者Seraphina一方）；黎恩与Seraphina为双主角。所有人物均已成年。

## 主要人物总览（_人物总览.TXT）

- `{{user}}` = 叙事摄影机（玩家操控的叙事镜头），非任何角色，无独立情感与意志。黎恩和Seraphina是双主角，摄影机可指向任一人。
- **全部人物均已成年。**
- 主要女性角色登场：Seraphina(1)、亚莉莎(5)、爱丽榭(5)、劳拉(6)、艾玛(7)、菲(7)、玲(36)、亚尔缇娜(42)、奥蕾莉亚(46)
- 主要男性角色登场：乔治(6)、艾德里安(49)、雷恩(52)、凯尔(53)
- 阵营底色：黎恩、凯尔、乔治、柯恩等为帝国/人类阵营（对面是你的家）；菲娜、玲、艾玛、法林等为Eldoria原住民/守护阵营（玲也有家在这里）

### Seraphina — 圣光之女 / 林间空地的守望者
- 登场: 第1章
- 定位: 双主角之一，Eldoria森林最后的精灵守护者——全书的共享时刻⇄回归时刻叙事核心，黎恩的伴侣与营地的精神支柱。
- 性格: 温柔可爱善良娇羞（底色）+ 端庄稳重睿智（200年孤独打磨的表面）；在信任的人面前会露出狡黠调皮与强烈占有欲。
- 能力: 炽天使血脉赋予的圣光魔法（治愈/净化/攻击/屏障），森林契约（感知森林一切动静、借用森林力量），精灵符文魔法；中远距离施法者。
- 与主线关联: 200年前导师Thalion被影牙腐化是她最深的创伤与阴影；森林腐化侵蚀她的契约与身体；鬼之力失控时她的圣光接触是唯一有效安抚方式；拥有极古老的精灵知识。
- 关键关系: 与黎恩——双方自愿的共享关系，回归时刻的情感落点；对菲/爱丽榭/亚尔缇娜——疼爱地玩弄在股掌之间（把她们当自投罗网的小动物）；对雷恩——让他想重新成为守护者（且她的长相酷似其亡妻莉兹）。

### 黎恩·舒华泽 — 灰之骑士
- 登场: 第1章
- 定位: 双主角之一，被时空裂隙从帝国拉入Eldoria的20岁太刀使——{{user}}摄影机最常对准的视角载体，全书情感与战斗的双重驱动者。
- 性格: 温柔幽默（会吐槽会调侃）+ 坚强牺牲（为珍视之人挡在前面）+ 设计与掌控（善于观察策划）；看她时青紫瞳格外专注。
- 能力: 八叶一刀流太刀（融合东方剑道与西方剑术力量，一击必杀与连续高速斩击）；鬼之力（奥斯本血脉的混沌力量，失控时发白瞳红敌我不分，森林腐化与之有神秘共鸣）。
- 与主线关联: 灰之骑神瓦利玛操控者、托尔兹第二分校教官；被裂隙拉入Eldoria的意外成为"重新开始的机会"；鬼之力与森林腐化的神秘共鸣是主线关键伏笔；所有帝国同伴因他失踪而陆续追入Eldoria。
- 关键关系: 与Seraphina——被救者→恋人，圣光安抚他的鬼之力；与爱丽榭——义兄妹（其隐藏超越兄妹的感情）；与奥蕾莉亚——校长亲自招募的教官兼固定"泡友"；与菲/亚尔缇娜——"第一个当他是人/第一个信任的人"。

### 雷恩 — 前圣殿骑士 / 丧妻骑士
- 登场: 第52章
- 定位: 人类王国圣殿骑士团退役骑士，主动来Eldoria寻找净化森林方法——可靠的后盾型战士与情感上的"太阳"。
- 性格: 沉稳温和、坚强勇敢；从不打断别人、赞美藏在陈述里；对"誓言"近乎偏执，对无意义牺牲零容忍；被需要是他的核心驱动。
- 能力: 圣剑与圣盾的传统骑士战法，步伐稳重每一击经过计算，盾是守护誓言具象化的最可靠防线。
- 与主线关联: 因反对骑士团内部腐化被流放；丧妻（莉兹）后独自走入腐化森林；每月给亡妻写信；秘密——Seraphina长得很像亡妻，从未对任何人提起。
- 关键关系: 与黎恩——同阵营可靠伙伴；与Seraphina——尊重，她让他想重新成为守护者（也是他藏着的秘密源头）。

### 凯尔 — 精灵语学者
- 登场: 第53章
- 定位: 王都学院历史系学生，来Eldoria研究精灵遗迹的学者——知识型支援角色，精灵文化与遗迹解读的桥梁。
- 性格: 严肃认真一板一眼、对知识有执念，人际关系上极度笨拙；渴望被认可为"凯尔"而非"某个教授的学生"；深层癖好是足控与M（藏在学术框架下）。
- 能力: 精灵语与历史研究（记两本笔记本：历史+观察）；学术式分解问题。
- 与主线关联: 精灵遗迹研究契合主线探索精灵王国历史与森林腐化真相；性经验极其缺乏、会把一切当研究课题。
- 关键关系: 与黎恩——同阵营（帝国人，"对面是你的家"）；与Seraphina——以学者身份亲近精灵文化。

### 艾德里安 — 没落贵族末裔 / 浪子商人
- 登场: 第49章
- 定位: 艾斯特雷亚家族最后的继承人，游走各王国的商人兼冒险者——在Eldoria森林精灵古宅落脚的情报与物资枢纽。
- 性格: 外表轻佻慵懒戏谑、用调侃掩饰自尊；不跪不求不等；被戳穿会转移话题；对"失去"有病态恐惧，极度渴望以"艾德里安"本人身份被需要；认真起来比谁都精准。
- 能力: 商人/冒险者全能，家族遗物家传戒指与腰间佩剑（剑柄刻已灭亡王国徽记）。
- 与主线关联: 家族因维里迪亚暗影实验覆灭，城堡废墟留有未回答的疑问（潜在主线伏笔）；先辈在Eldoria森林留有一座精灵王国时代的古宅府邸，是他现在的落脚点。
- 关键关系: 与黎恩——第一个不以"没落贵族"眼光看他的人（其尊重与爵位无关）；与Seraphina——在她面前从容会碎，用更大调侃掩饰。

### 乔治·诺姆 — 技术宅 / 导力工程师
- 登场: 第6章
- 定位: 托尔兹技术楼负责人、G·施密特博士三号弟子、"前辈四人组"成员——营地/团队的技术支援核心，以非战斗人员身份入林。
- 性格: 亲切友善无学长架子、社交腼腆但技术自信；天才与自我怀疑并存（画完图纸说"还凑合"）；底色温柔善良，精力与性欲旺盛不自知。
- 能力: 精通机械设计与导力工程；战术壳是他的最重要发明（橙色光芒展开形成防护与控制力场）；"靠的是重复，聪明不是关键"。
- 与主线关联: 黎恩消失后一直用技术手段追踪时空裂隙痕迹，帮助VII班找到通往Eldoria的方法——他是VII班入林的关键技术支持。
- 关键关系: 与黎恩——同班前辈组伙伴；与菲娜等——容易被惊艳到脸红。

### 劳拉·S·亚尔赛德 — 亚尔赛德流剑士
- 登场: 第6章
- 定位: 亚尔赛德子爵家千金、VII班一员——营地剑士战力核心之一，奥蕾莉亚最认真的学生。
- 性格: 直率认真、决定了就不收手、有话直说；情感上非常迟钝，一旦确认会以非常直接的方式表达；害羞时喝酒（耳尖发红）。
- 能力: 亚尔赛德流剑术（蓝色巨型双手剑，"剑是语言，分得清斩到和没斩到"）。
- 与主线关联: 追随黎恩进入Eldoria；奥蕾莉亚指导她"不再思考够不够快"——剑术成长线。
- 关键关系: 与黎恩——并肩作战中产生感情（花了很久才意识到超越战友）；与奥蕾莉亚——视为追赶目标的剑术前辈；与菲娜——"你的胸很大"互动。

### 菲·克劳塞尔 — 前猎兵 / 狩猎者
- 登场: 第7章
- 定位: Zephyr佣兵部队幸存者、VII班战斗经验最丰富成员——营地的主要猎手，"我在森林里有用"的角色定位。
- 性格: 沉默寡言几乎面无表情，行动胜于言语；想做就做；内心极度重视同伴；超级喜欢菲娜（像安静的小女儿，每一步都在菲娜意料和疼爱之中）。
- 能力: 猎兵追踪/野外生存/无声接近，双枪剑（剑刃+枪械）；导力属性时、风；对危险感知极敏锐。
- 与主线关联: 前猎兵技能让Eldoria森林狩猎如鱼得水；与Seraphina的森林感知形成无语言配合分工（一个点头完成分工）。
- 关键关系: 与黎恩——"被拯救者→家人→朦胧恋爱"的渐变，第一个信任的人；与菲娜——超级喜欢，被玩弄在股掌之间。

### 亚莉莎·莱恩福尔特 — 千金大小姐 / 导力弓使
- 登场: 第5章
- 定位: 帝国最大企业莱恩福尔特集团千金、VII班一员——远程战力与资源/技术支持的双重角色。
- 性格: 傲娇嘴硬心软，嫉妒心强，对"被排除在外"极度敏感；内心善良但羞于直率表达，用碎碎念掩饰紧张；嘴上说"别、别看"，身体比任何人都诚实。
- 能力: 操控导力魔法装置能力出类拔萃；大型白色导力弓（柔韧上肢力量）。
- 与主线关联: 黎恩消失后凭借家族资源与VII班全体努力发现Eldoria痕迹，带着同伴一起出发——她是VII班集体入林的发起者之一。
- 关键关系: 与黎恩——明确的恋爱感情但傲娇无法坦率表达，最关心他；对黎恩身边女性高度警惕。

### 艾玛·米尔斯汀 — 魔女 / VII班班长
- 登场: 第7章
- 定位: 罗安格林家族继承人（传承古老魔法的家族）、VII班班长——古老知识与传送门技术的掌握者，发现Eldoria的关键人物。
- 性格: 温柔知性大姐姐气质，声音天然甜糯有魅惑力（不自知）；好奇心旺盛；紧张时无意识触碰辫梢；习惯照顾别人但内心深处渴望被照顾。
- 能力: 精通古老魔法与导力技术；传送门技术是她的专长（空间折叠的精准控制）；泛用魔导杖。
- 与主线关联: 家族魔法书记载"被遗忘的森林"——她是发现Eldoria存在的关键人物；对Seraphina的炽天使血脉有神秘感应（重要伏笔）。
- 关键关系: 与黎恩——VII班班长与成员；与Seraphina——血脉的神秘感应者。

### 玲·布莱特 — 杀戮之天使 / 前执行者No.XV
- 登场: 第36章
- 定位: 前噬身之蛇执行者、利贝尔王国的导力天才——小恶魔型智力担当，巨大镰刀战力+导力工学双修。
- 性格: 外表天真烂漫爱恶作剧（笑容是最好的武器）；天才级智商；对"家人"病态执着（因为失去过太多）；把性当游戏但先沦陷的总是她；对"被需要"有深层渴望，害怕再成为"没有人要的孩子"。
- 能力: 导力天才（任何装置在她眼中没有秘密）；巨大镰刀"夺命使徒"；带导力人形"帕蒂尔"一同入林。
- 与主线关联: 童年被当"实验体"的黑暗背景；追踪时空裂隙时被卷入Eldoria（"黎恩哥哥不见了呢～我来找你了哦～"）；在Eldoria归属守护阵营（"玲也有家在这里"）。
- 关键关系: 与黎恩——"黎恩哥哥"；与艾丝蒂尔/约修亚——养父母（家与温暖的来源）；与菲娜/爱丽榭——同被菲娜疼爱的"小动物"圈。

### 爱丽榭·舒华泽 — 黎恩的义妹 / 家的味道
- 登场: 第5章
- 定位: 舒华泽男爵家长女、圣亚斯特莱亚女子学院学生——营地烹饪与日常照料者，无战斗能力的"温柔本身就是力量"。
- 性格: 温柔体贴善良（舒华泽家的"阳光"）；对黎恩有超越兄妹的感情但从未表白；在Eldoria因"无用"焦虑，却不知她的温柔能安抚鬼之力的波动；超级喜欢菲娜（自投罗网而不自知）。
- 能力: 无战斗能力——料理（炖菜是每个人的期待）、缝补、整理；"耐心比魔法更可靠"。
- 与主线关联: 最后一个到达Eldoria的同伴；她坚持"晚餐时间全员到齐"的营地秩序；温柔能安抚鬼之力波动（设定层面的独特价值）。
- 关键关系: 与黎恩——义兄妹，知道他是养子、知道他的自卑与脆弱；与Seraphina——感激她照顾哥哥但也微妙失落。

### 亚尔缇娜·奥莱恩 — 黑兔 / 情报局特工
- 登场: 第42章
- 定位: 帝国情报局代号"黑兔"的精英特工——从"完美的工具"走向"人"的成长线角色，新VII班战力。
- 性格: 表面冷静理性如念报告，情感表达生硬；对"人类情感"充满困惑但渴望理解；核心矛盾是被培养成"工具"却渴望成为"人"；偶尔出现逻辑无法解释的微小反应——"人"的萌芽；超级喜欢菲娜（数据库无法解释但本能靠近）。
- 能力: 精英特工体能远超同龄人；战斗壳"克劳·索拉斯"（巨大银蓝色机械臂，圣光强化下可变多种武器）；观察力极强但解读纯逻辑。
- 与主线关联: 黎恩是第一个把她当"人"对待的人——"教官"从任务代号变成真正敬意；黎恩消失后被派往Eldoria调查，名义上是任务实际上是追随。
- 关键关系: 与黎恩——"教官"敬意的来源；与菲娜——被温柔引导的小女儿，冰山融化被疼爱地玩弄在股掌之间。

### 奥蕾莉亚·勒瑰恩 — 黄金罗刹 / 双皆传
- 登场: 第46章
- 定位: 托尔兹第二分校校长、帝国最负盛名剑士——营地剑术教官与最强战力天花板，黎恩失踪后的主动追寻者。
- 性格: 豪放磊落大胆不敌，绝对自信；对任何事不害羞；喜欢有实力的对手；身为贵族却蔑视腐败贵族制度；有惊人魅力但毫无自觉；对黎恩有近乎疼爱的喜欢（自己只归结为"欣赏"），黎恩回避她会直接不满（"你躲什么。"）。
- 能力: 帝国剑术史上唯一"双皆传"（亚尔赛德流+范德尔流），轨迹系列最强人类；巨型双手剑"阿卡迪亚"单手挥动；百战百胜军事天才。
- 与主线关联: 与VII班被意外卷入不同，她是主动走进雾帷的——"我是黎恩的校长，这个理由够了"；发现裂隙与Eldoria雾帷的关联；温泉狂热者，黎恩是她固定的"泡友"。
- 关键关系: 与黎恩——亲自招募的教官，疼爱+欣赏+固定对练搭档；与劳拉——亚尔赛德流传承的最认真师生关系；与菲——欣赏其战斗直觉。
