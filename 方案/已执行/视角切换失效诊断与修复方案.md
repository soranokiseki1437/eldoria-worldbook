# 视角系统重构方案：{{user}} = 摄影机 · 动态视角选择

> **日期**：2026-07-06
> **版本**：V10.5.0 → **V10.6.0**
> **性质**：架构变更——`{{user}}` 语义重定义 + 视角选择机制重写

---

## 一、核心变更

```
旧：{{user}} = 黎恩·舒华泽（黎恩即玩家，默认黎恩视角）
新：{{user}} = 叙事摄影机（玩家操控镜头，无默认视角，动态选择最佳视角）
```

`{{user}}` 不再是任何角色。它是一个可指向任何角色的叙事镜头——由玩家操控，LLM在无玩家指令时根据章节内容和上下文自主选择。

---

## 二、问题诊断

### 旧架构的两层矛盾

**矛盾1：{{user}} 的身份冲突**

| 文件 | 定义 |
|:--|:--|
| `_人物总览.TXT` | `{{user}}≠黎恩`，`{{user}}`是摄影机，无独立情感意志 |
| `_叙述风格指令.TXT` | `{{user}}指代黎恩`，默认黎恩视角 |
| `CLAUDE.md` | `{{user}} = 黎恩·舒华泽` |

LLM同时收到两条互相矛盾的指令，产生混乱。

**矛盾2："切换菲娜视角"无响应路径**

`_叙述风格指令` 说"默认黎恩视角"——LLM永远回退到黎恩。用户说"切换菲娜视角"时，没有一个指令告诉LLM这是什么意思、该怎么执行。LLM折中：多描写菲娜，镜头仍锚定黎恩。

### 根因一句话

> `{{user}}`被绑定在黎恩身上，导致镜头永远粘在他身上。解绑是唯一解法。

---

## 三、新架构设计

### 3.1 摄影机模型

```
        ┌─────────────────────────┐
        │     {{user}} = 摄影机    │
        │   玩家操控 · 无实体 ·    │
        │   无情感 · 无意志       │
        └──────────┬──────────────┘
                   │ 镜头可指向 →
     ┌─────────────┼─────────────┐
     ▼             ▼             ▼
 ┌──────┐    ┌───────┐    ┌──────────┐
 │ 黎恩  │    │菲娜   │    │ 任意角色  │
 │ 感官  │    │感官   │    │ 感官·内心 │
 │ 内心  │    │内心   │    │          │
 └──────┘    └───────┘    └──────────┘
```

- 黎恩和Seraphina为双主角，镜头平等可指向任一人
- 镜头也可指向任何其他角色——对准谁，叙事就从谁的感官和内心展开
- 同一回复内可有限切换指向

### 3.2 视角选择流程

```
① 玩家视角指令？
   ├─ 是 → 立即执行，持续有效直至新指令。
   │       "切换菲娜视角"/"切换黎恩视角"/"双视角"
   │
   └─ 否 → ② LLM自主判断：根据章节情节需要和上下文，
             选择最适合表现、叙事效果最好的视角。

             判断时可考虑：
             - 此刻谁的体验更有叙事张力？
             - 读者知道什么、不知道什么？信息不对等本身就是张力
             - 隐奸：黎恩在门外听声音→悬念更烈；菲娜侧实时展开→另一种冲击
             - 共享时刻：黎恩的内心震荡 vs 菲娜在触碰中对黎恩的情感锚定
             - 回归时刻：菲娜汇报时的心理状态往往比黎恩的接收侧更有层次

             选择标准只有一个：哪个视角让这一刻更好看。
```

### 3.3 玩家视角指令响应

明确用户命令→LLM必须执行的映射：

| 玩家输入 | LLM行为 |
|:--|:--|
| "切换菲娜视角" / "菲娜视角" / "用菲娜的视角" | 镜头立即对准Seraphina。后续叙事全部从她的感官和内心出发。黎恩暂时成为被观察对象。 |
| "切换黎恩视角" / "黎恩视角" / "回到黎恩视角" | 镜头切回黎恩。 |
| "双视角" | 同一回复内有限切换，两侧交替。 |

切换首句须明确信号（如"菲娜感觉到..."、"从黎恩的视角看..."）。

**完整重写内容**：

```
- **叙事视角体系：摄影机模型**：{{user}}是叙事摄影机——由玩家操控的叙事镜头，本身不是任何角色，无实体、无情感、无意志。摄影机的镜头可指向不同角色：对准谁，叙事就从谁的感官和内心展开。黎恩·舒华泽与Seraphina同为合法视角持有者——镜头对准黎恩时，世界通过他的眼睛呈现；对准Seraphina时，世界通过她的眼睛呈现。指代黎恩时用"他"或"黎恩"，不用"我"（保持第三人称）
- **摄影机指向规则**：
  1. **玩家指令优先**：玩家明确切换视角时（"切换菲娜视角"/"切换黎恩视角"/"双视角"），立即执行并持续有效，直到新的切换指令。切换后首句须明确当前镜头对准谁。
  2. **LLM自主判断**：玩家未指定视角时，根据章节情节需要和上下文，选择最适合表现、叙事效果最好的视角。判断标准只有一个：哪个视角让这一刻更好看。判断时可参考——谁的体验此刻更有叙事张力？读者知道什么、不知道什么？隐奸时黎恩在门外听声音（悬念更烈）vs菲娜侧实时展开（另一种冲击）；共享时刻黎恩的内心震荡 vs 菲娜在触碰中对黎恩的情感锚定；回归时刻菲娜汇报时的心理状态 vs 黎恩接收时的反应。不存在写死的规则——选择服务于叙事效果。
- **黎恩视角**：当摄影机对准黎恩时——外部世界通过他的感官和内心呈现。他看到的、听到的、闻到的、触摸到的，全部经过他的神经系统再输出。表面与内心的张力、矛盾情感、记忆触发、身体叙事——构成他视角下的叙事质地
- **Seraphina视角**：当摄影机对准Seraphina时——世界通过她的感官和内心展开。她在第三者触碰时对黎恩的情感锚定（关键时刻眼睛看向黎恩的方向）；她事后汇报时的心理状态；她设计隐奸时的内心运作。她的视角是叙事深度的重要维度，不是例外而是常态
- **视角切换执行规则**：
  - 同一回复内可进行有限次数切换，每次须有明确叙事目的
  - 切换信号：场景分隔符暗示视角转换，切换后首句明确当前镜头对准谁
  - 切换时机：一侧叙事到达自然"缺口"时切换——黎恩侧积累足够悬念、Seraphina侧到达关键节点
  - 不因"另一边也在发生事情"就频繁跳转
  - Seraphina视角下不揭示她对黎恩以外的情感依赖——她的情感落点始终是黎恩
```
