## 重写铁律（必读）

> 以下三条是本次审计过程中发现的跨章节通病，重写时必须逐条遵守。

### 铁律一：条件3 = 纯收束信号，非剧情延续

条件3回答"这一章结束之后发生了什么"。**不是**"这一章里还剩什么在继续"。

| 正确方式 | 关键词 | 示例 |
|:--|:--|:--|
| **时间推进**（倾向最大） | 入夜/次日/几天后/晨光/暮色/夜深 | "两人走回营地时晨光完全铺开了，银流河上游的瀑布水声从远处传来薄雾已散尽。" |
| **场景收束** | 离开场景/回营地/回木屋/熄灯/收拾工具 | "铜锅在篝火上咕嘟着，野莓的酸甜味在营地空气里散开，爱丽榭把切好的柠檬片放进锅里。" |
| **情感沉淀** | 安静/沉思/入睡/呼吸平复 | "书房灯熄了，战术终端屏幕上的两条校准曲线在暗光中重叠着，艾玛把解开的辫子重新编好时窗外已是星光满天。" |

三种方式可组合使用（场景收束+时间推进、情感沉淀+时间推进等）。时间推进可常用。

| 错误（=剧情延续） | 正确（=纯收束） |
|:--|:--|
| "亚尔缇娜还在搅拌每一圈的角度都相同" | "铜锅在篝火上咕嘟着…两个人并排站在锅前的剪影被午后阳光拉长在石板地面上" |
| "哈根继续蹲在地上画矿车轨道" | "天色已近黄昏，哈根继续蹲在地上画矿车轨道"（加上时间推进） |
| "菲把巡逻报告交给了下一班"（有新动作） | "两人走回营地时阳光重新穿过树冠落在地面上" |

**判断标准**：读一遍条件3，问"这一章之后时间往前走了吗？场景关上了吗？人物沉淀了吗？"——三个问题至少答一个"是"。

### 铁律二：禁止否定迂回句式

不写"不是X是Y""没有X只是Y""并非X而是Y"。直接写肯定句。

| ❌ 禁止 | ✅ 正确 |
|:--|:--|
| "用手心的温度揉。不是砸。" | "用手心的温度慢慢转圈揉。" |
| "不是剑术流派，是纯粹的实战本能" | "猎兵靠的是纯粹的实战本能" |
| "不是被动承受，是用整个身体接住" | "用整个身体接住对方的力" |
| "不是安全。是有东西不让影牙兽靠近" | "有东西不让影牙兽靠近。更危险的东西。" |
| "不是问句" | "是一个陈述" / 直接省略 |
| "不是凯尔那种古文字研究。是能在武器上刻出火球的那种。" | "能在武器上刻出火球的那种。和凯尔教的古文字不一样。" |
| "不是特意为你改的。是之前做实验剩下的" | "之前做实验的时候顺手改的" |

**铁律**：读一遍情境和核心，grep `不是|没有.*只是|而非`，逐条改为肯定句。

### 铁律三：情境/核心/章节任务/条件3中禁止破折号

破折号(——)仅在**名称**字段中允许（作为前后半段的分隔符）。其余四个字段——情境、核心、章节任务、章节终止条件——**0容忍**。

| ❌ 破折号 | ✅ 替换 |
|:--|:--|
| "菲的耳朵转了半圈——舒服" | "菲的耳朵转了半圈" |
| "她的沉默承载了观察——她用耳朵捕捉一切" | "她的沉默承载了观察，她用耳朵捕捉一切" |
| "符文——不是符号，是意志的结晶" | "符文是意志的结晶"（同时修复否定） |
| "星叶蝶落在枪剑上——艾玛说它只落在信任的东西上" | "星叶蝶落在枪剑上，艾玛说它只落在信任的东西上" |

**替代优先级**：句号 `.` > 逗号 `,` > 直接续接。
