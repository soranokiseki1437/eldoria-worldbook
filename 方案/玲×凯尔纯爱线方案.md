## 一、路线设计总纲

### 1.1 核心动态

```
凯尔 → 玲：一直当妹妹宠，什么都包容，从没把她当"女孩子"看
玲 → 凯尔：喜欢这个大哥哥，所有逗他玩。恶作剧没反馈（因为他包容），
          色色暗示他接收不到（因为他根本没往那方面想）
          → 生闷气 → 点燃斗志 → 穿黑丝 → 凯尔终于破防
```

### 1.2 情感递进弧

| 阶段 | 玲的状态 | 凯尔的状态 | 核心转折 |
|------|---------|-----------|---------|
| Stage 2前期 | 恶作剧→成人暗示，挫败 | 教育她懂礼貌，摸头让她别着凉 | 玲发现"黑丝"是钥匙 |
| Stage 2后期 | 穿黑丝试探，得逞 | 目光被脚吸引，脸红，赶她出去 | 凯尔第一次对玲有性反应 |
| Stage 3前期 | 牵手脸红（为什么是我脸红）| 自然牵着，提醒别踩便便 | 玲意识到自己对凯尔的感情不是游戏 |
| Stage 3中期 | 坐腿上、展示身体、不再伪装 | 勃起、脚崇拜→口交、失控 | 凯尔第一次把玲当"女人" |
| Stage 3后期 | 足交→口交，主动给予 | 接受、沉迷、回应 | 双向欲望确认 |
| Stage 4 | 告白→接吻→插入 | 确认感情，温柔郑重 | 玲的"游戏"终于变成真的 |

### 1.3 与现有玲章节的关系

玲现有章节（均与黎恩）：
- ch112 挑逗和接受：玲开始恶作剧针对凯尔（**本路线的起点**）
- ch133 渐进接触：玲情感崩溃，菲娜治愈（玲讲凯尔推眼镜次数→玲在观察凯尔）
- ch135-136 渐进接触：玲给黎恩口交/足交（玲把性当"游戏"的实验阶段）
- ch263 享受和掌控：玲向菲娜坦白过去（情感成熟）
- ch264 享受和掌控：玲与黎恩本番，"游戏"外壳破裂

本路线插入在 ch112 之后，与玲×黎恩线平行发展。玲对凯尔的感情是"真的"，对黎恩的性游戏是"实验"——两条线在情感质地上的区分正是本路线的叙事价值。

#### NEW A1：玲的恶作剧——没人上当的烦恼

**情境概要**：

#### NEW A2：玲的疑问——黑丝的真相

**章节任务**: 玲问菲娜为什么凯尔会脸红，菲娜尴尬但不撒谎地说是黑色袜子，玲秒懂是黑丝并获得了攻略凯尔的关键情报。

**章节终止条件**: 
1. 玲晃到菲娜旁边安静五秒后问凯尔为什么在菲娜面前脸红。
