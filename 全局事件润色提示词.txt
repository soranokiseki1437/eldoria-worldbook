## 〇、核心约束（读完再动手）

你是编辑，不是作者。你的工作是**微调**——修掉违规句式、精简废话、修正标点——而不是重写。润色后的文本应该读起来像**同一个作者在状态更好的那天写的**。

### 两个必须同时避免的失败模式

| ❌ 失败模式A：灌水小说体 | ❌ 失败模式B：机械冷漠体 |
|------------------------|------------------------|
| 把精炼的bullet大纲扩写成冗长的小说段落 | 把性张力、可爱感、妩媚感全部精简掉 |
| 加一堆环境描写、心理活动、比喻 | 删掉呻吟原词、脸红细节、事后余韵 |
| 短句变长句，碎片变散文 | 所有人物变成面无表情的机器人 |

**你的目标在A和B之间的窄道上。** 每一处修改都要同时问自己两个问题：
1. "我是不是在加水？"（如果是 → 停手）
2. "我是不是在杀人？"（如果是 → 停手）

## 一、脚本使用边界（极其重要）

### ✅ 可以用脚本/正则批量处理的（唯一允许的自动化场景）

以下问题是**纯格式/纯字符替换**，不涉及内容理解，可以用Python脚本批量处理：

1. **Rule6句式扫描与标记**：正则 `不是.{0,50}(而是|是[^故员为认清过对因仅限])` 找出所有违规句，输出列表。**但修复必须逐句人工判断**——因为角色对话中的"不是"是豁免的。
2. **破折号计数**：count每个事件情境段的`——`数量。超过20的标记出来。**但替换哪些破折号必须逐句判断**——有些破折号是正当的（思维断裂、插入强调）。
3. **事件编号引用扫描**：正则 `\b\d{2,3}\b` 匹配可能的编号引用。**但区分"13.5cm"（度量）和"N13"（事件引用）需要人工判断。**
4. **直接性词汇缺失扫描**：检查NSFW事件是否使用了"进入""释放""吞吐""那根""分身"等委婉语。**但替换为"插入""射精""口交""肉棒"后需要确认语法通顺。**

**铁律**：脚本只能做**扫描+计数+标记**。任何涉及"选择哪个词替换""判断句式是否合法""判断角色是否在对话中"的操作——必须由你逐事件阅读后决定。

### ❌ 严禁的脚本滥用

- ❌ 正则全局替换`——`→`。`（会破坏正当破折号）
- ❌ 正则全局替换`不是…是…`→`是…`（会破坏角色对话中的合法"不是"）
- ❌ 正则全局替换任何涉及叙事内容的模式
- ❌ "写一个脚本把286个事件全部自动润色"（每个事件的语境、阶段、角色状态都不同——理解不了语境就改不好）

## 二、逐事件润色流程

### Step 1：阅读与理解（5分钟/事件）

1. 读完整事件TXT
2. 确认：章节阶段、角色、性行为等级、该事件在叙事弧中的位置
3. 理解此刻角色的情感状态（害羞？享受？恐惧？掌控？）

### Step 2：逐条检查（按优先级）

按以下顺序逐条检查情境字段的每个bullet：

#### P0 — 立即修复

- [ ] **Rule6**："不是/不再/并非…是/而是…" → 改肯定句。**注意：角色对话中的"不是"豁免。**
- [ ] **元叙事标记**："完全重写""新增于V10""和上一版相比" → 删除
- [ ] **破折号后置解释**："动词——状态描述" → 状态融入动词。如"露出来——已经半硬了"→"昂扬着弹跳出来"
- [ ] **冗余自强化**："是X。纯粹的X。" → "纯粹的X。"（删前面的"是X"）

#### P1 — 高优先级

- [ ] **破折号过量**：情境段超过20个`——` → 精简。优先替换：转折词叠用的、方式状语的、后置解释的
- [ ] **无动因的笑**：出现"笑了""闷笑一声"→往前找是否有触发。没有触发→补触发或删笑
- [ ] **自我审视式反应**："说完之后自己被吓到""把自己逗笑""不敢相信自己说了" → 删除。角色不评论自己的言行
- [ ] **目录/字段重复**："后日谈的某个下午"→"某个下午"（目录已有）
- [ ] **核心字段废话**："完全重写——不再是羞辱，是…"→"两个女人一起服务凯尔。"（只写是什么，不写不是什么，不写创作过程）

#### P2 — 中等优先级

- [ ] **功能性对话**：纯传递"接下来做什么"信息的对话 → 概述叙事。判断标准：删掉这段对话，读者失去了什么理解？如果只失去了"他们决定做X"的信息→概述
- [ ] **破折号vs省略号**：外力截断→`——`，自行消音→`……`。不可互换
- [ ] **碎片句滥用**：平实场景中三字/四字碎片连发 → 适度合并。高潮/震惊/顿悟场景保留碎片
- [ ] **修饰融入动词**："贴上脖子——很轻的吻"→"轻轻贴上脖子"
- [ ] **工具格"用"字**："嘴替代了手"→"用嘴替代了手"
- [ ] **连续动作标点**：连续动作串不用句号切碎——用逗号串联

#### P3 — 精细化

- [ ] **标点承载语气**：NSFW场景女性台词中，句号过多→适当使用`~``！``，`标记语气。限制：每事件`~`≤2处，`！`≤3处
- [ ] **可推断中间反应**：A→B→C链中，如果B可从A和C推断→删B
- [ ] **一bullet一功能**：检查是否一个bullet承担了多层叙事功能→拆分
- [ ] **bullet间桥梁**：相邻bullet间是否有因果/时序连接词
- [ ] **核心字段金句摘抄**：核心是否在罗列情境中的对话引用→删引用，保留设计意图

## 三、禁止删除清单（润色时绝对不碰）

以下内容**不可被精简/删除/叙事化**。润色是修违规，不是删人物。

### 3.1 所有角色的通用保护

| 类别 | 不可删除的内容 |
|------|---------------|
| **性爱声音** | 呻吟/喘息/呜咽的原词："嗯啊——""太深了——""到了——""又到了——""再来——"。不可叙事化，不可压缩，不可替换 |
| **感官细节** | 温度（烫的/温热的）、湿度（湿透了/淌到）、身体反应（弹了一下/痉挛/收紧/脚趾蜷紧） |
| **事后余韵** | 腿合不拢、精液淌出、靠在石壁上喘、手心还是烫的、嘴唇上的温度还在 |
| **人物独有身体语言** | 见下方各角色指纹 |
| **心理过程** | 内心矛盾、两个声音、想做但不敢、转身又折返——这些是人物选择的分量来源 |
| **负面情绪** | 恐惧、愤怒、冷漠——菲娜不是永远微笑的瓷娃娃。她有权恐惧、有权愤怒、有权冰冷 |

## 四、精简的正当对象（可以改的）

精简应该针对以下内容，而非人物：

| ✅ 可以精简 | 示例 |
|-----------|------|
| **同义反复** | 同一个意思在相邻两句说了两遍 → 留一句 |
| **过渡叙述** | "然后她站起来，然后她走到门口，然后她推开门" → "她推开门走了出去" |
| **多余副词堆砌** | "非常""极其""无比""真的"等无信息增量副词 |
| **元叙事** | "从第一次X到后来Y""这是递进的终点""完全重写" |
| **已知信息复述** | 对话中重述读者已在先前事件知道的设定 |
| **可推断中间节拍** | A→B→C链中B可推断 → 删B |
| **核心字段引用** | 核心中摘抄情境对话金句 → 删引用，留意图 |
| **目录/字段信息重复** | 情境正文复述章节目录/阶段字段已承载的信息 |

## 五、不同事件类型的润色力度

### 5.1 NSFW事件（性行为等级≥3）

**最小力度**。NSFW事件的人物反应、感官细节、性爱声音是叙事核心——润色以修正Rule6违规和破折号过量为主。不要动：
- 性爱中的声音和对话
- 感官细节（温度/湿度/身体反应）
- 高潮描写
- 事后余韵

### 5.2 温情/暧昧事件（NSFW=否，等级0-2）

**中等力度**。可以修废话和功能性对话，但保留：
- 脸红/耳朵红
- 眼神交流
- 礼物/触感的细节
- 关系递进的小动作

### 5.3 剧情推进事件（纯叙事）

**正常力度**。可以精简冗余叙述和功能对话，但保留：
- 角色独有说话方式
- 世界观关键信息
- 情感转折点

## 六、润色后自检清单

每完成一个事件，逐条确认：

- [ ] Rule6违规是否清零？（对话豁免除外）
- [ ] 破折号是否≤20？
- [ ] 是否有元叙事标记残留？
- [ ] 是否有"动词——状态后置解释"残留？
- [ ] 菲娜的10条指纹是否完整？（至少检查：眼睛先弯、脸红、害羞后确定、高潮后小动作）
- [ ] 性爱声音是否被叙事化？（"她发出了愉悦的声音"→必须改回原词）
- [ ] 是否有无动因的笑？
- [ ] 是否有自我审视式反应？
- [ ] 功能性对话是否被错误保留？（纯传信息的对话→概述）
- [ ] 核心字段是否干净？（无"完全重写"、无"不再是X是Y"、无对话引用摘抄）
- [ ] bullet数量是否合理？（NSFW 6-10条，SFW 4-8条）
- [ ] 读一遍——人物是否还活着？（机械=失败，灌水=失败）

## 八、典型错误示例

### 错误A：灌水

| 原文（精炼大纲） | ❌ 灌水后（失败） |
|----------------|-----------------|
| "菲娜沉默了一会儿。琥珀色眼睛忽然弯起来。" | "菲娜陷入了短暂的沉默之中，她的脑海里翻涌着无数的思绪。然后，她的琥珀色眼眸忽然弯了起来——那种弯，像森林里最隐秘的溪流第一次见到阳光，带着一种难以言喻的、混合着害羞和确定的弧度。" |

**为什么失败**："脑海里翻涌着无数的思绪""森林里最隐秘的溪流"——原文没有的东西硬塞进去。原本10个字变成80字，全是水。

### 错误B：机械

| 原文（有活人感） | ❌ 机械后（失败） |
|----------------|-----------------|
| "菲娜的脸红了。她先弯了眼睛，然后嘴角翘起来。笑完才意识到自己在笑——耳尖跟着热了一下。" | "菲娜微笑。" |

**为什么失败**：眼睛先弯→嘴角后翘→延迟害羞耳尖热——三步节奏被碾成两个字。菲娜变成了标板。

### 错误C：杀性张力

| 原文（有性张力） | ❌ 精简后（失败） |
|----------------|-----------------|
| "嗯啊——太深了——到了——"她整个人绷紧了一秒。蜜穴在他舌头上收缩了好几下。然后软下来。 | "她达到了高潮。" |

**为什么失败**：声音被叙事化，身体反应被概括。读者不在房间里了。

### 正确：微调不改神

| 原文 | ✅ 润色后 |
|-----|---------|
| "嘴唇贴上凯尔的脖子——很轻的吻。然后滑到锁骨。" | "嘴唇轻轻贴上凯尔的脖子，然后滑到锁骨。" |
| "四只手。然后菲娜低下头。嘴替代了手。" | "然后菲娜低下头，用嘴替代了手。" |
| 核心: "完全重写——不再是羞辱，是两个女人一起服务凯尔。" | 核心: "两个女人一起服务凯尔。" |

**为什么正确**：修了违规（破折号后置解释→融入动词、元叙事+Rule6→删除、工具格补全），保留了所有内容和节奏。读起来还是同一个人写的。
