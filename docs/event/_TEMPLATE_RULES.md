# 事件TXT模板填写规则

> **参照模板**：`_TEMPLATE.TXT`
> **权威写作铁律**：`../../CLAUDE.md`（第三、四节）
> **验证工具**：`python scripts/event_tool.py validate`

---

## 一、架构现状

- **169个事件**，纯数字编号（01-169），线性叙事，无分支
- 无触发条件、无玩家选择、无路线标签、无游戏变量
- 好感值仅12角色，0-100，纯叙事用途
- 事件存储：9个章节目录（`docs/event/{0：序章/ ... 8：后日谈/}`）
- NTRS融合线：共享时刻（禁忌释放）⇄ 回归时刻（占有欲爆发），两条线交替推进

## 二、文件名与ID规则

| 规则 | 说明 |
|------|------|
| 文件名 | `{ID}：{名称}.TXT`，如 `107：独占欲——黎恩的重新占有.TXT` |
| 目录 | 按章节分目录：`0：序章/` `1：试探和暧昧/` ... `8：后日谈/` |
| ID行 | 第一行必为 `ID: {number}`，纯数字，与文件名一致 |
| 新事件 | ID行填小数标记插入位置（如 `ID: 40.5`），renumber自动分配整数 |

## 四、情境 bullet 写作规范

### 4.1 结构模板

```
bullet 1:   起因 + 场景设定 —— 环境/状态/为什么此刻此地此人
bullet 2-4: 上升 —— 渐进身体接触，每步有心理伴随
bullet 5-6: 高潮 —— 最强体验 + 内心独白
bullet 7:   余韵 —— 身体痕迹 + 第一句话/第一个眼神
```

### 4.2 bullet格式铁律

- 每条**1-3句话**，不超过80字（此条为指导性建议——当情感描写或性张力需要更长句子时，允许突破。见§4.6）
- 按**时间顺序**排列，不在一条bullet里跳时间
- **第三人称**叙事，用角色名字或代词
- **不引用对话原话**逐字复述，叙事化总结即可——但角色在性爱中的声音/呻吟/喘息词（如"嗯啊""太深了""到了"等）必须保留，不可叙事化
- 全事件**4-8条bullet**，超过8条必须合并精简。NSFW事件因场景结构（触发→铺垫→渐进→高潮→余韵）可放宽至10条
- 相邻bullet**不得同义重复**——两句话能合并为一句就不写两句

### 4.3 bullet禁止事项

| 禁令 | 说明 |
|------|------|
| ❌ 元叙事总结 | 禁"从第一次X到后来Y""这是递进的终点""信任扩容到了边界"等跳出叙事的总结句 |
| ❌ 括号补充 | 补充解释直接写进正文，不括号 |
| ❌ "不是X而是Y" | 直接写Y，不用否定X来衬托（Rule6强制执行） |
| ❌ 事件编号引用 | 情境/核心不得出现N##等编号，用描述性语言替代 |
| ❌ 商业词汇 | 禁"成本""效率""优化"等 |
| ❌ 空泛结尾 | 禁"为...支撑""奠定...基础"等套话 |
| ❌ 千篇一律的身体语言 | 禁"手在口袋里攥成拳""嘴角微微上扬""心跳漏了一拍""深吸一口气"等被用滥的肢体描写——找到属于**这个角色在这个时刻**的独有反应 |

### 4.4 身体语言写作原则

**每个人物表达紧张/兴奋/害羞的方式不同。** 禁止用通用cliché模板套在不同角色身上。

| ❌ 千篇一律 | ✅ 角色独有 |
|------------|-----------|
| 乔治"手在口袋里攥成拳" | 乔治耳根先红，然后手指开始无意识地摩挲导力器的外壳边缘 |
| 任何人"嘴角微微上扬" | 菲娜笑之前琥珀色眼睛先弯（她的专属特征） |
| 任何人"心跳漏了一拍" | 写具体的身体感受：黎恩觉得肋骨下面有什么东西轻轻揪了一下 |
| 任何人"深吸一口气" | 写为什么需要那口气——是压住什么，还是准备说什么 |

**原则**：读到身体反应时能认出"这是XX的角色反应"，而不是"这是紧张时的通用模板"。

### 4.5 破折号使用规则

**情境叙事中禁止滥用破折号（——）。** 破折号是强停顿符，过多使用会让文本变得破碎、呼吸急促，读起来像喘不上气。

| ❌ 滥用 | ✅ 替代 |
|--------|--------|
| "她整个人弹了一下——痒——和舒服无关" | "她整个人弹了一下，痒，和舒服无关" |
| "他低下头——舌尖贴上花瓣——她没有躲" | "他低下头。舌尖贴上花瓣。她没有躲。" |
| "她开始喘——很自然的喘——一点都不压抑" | "她开始喘，很自然的，一点都不压抑" |

**替代优先级**：
1. 句号 `.` — 完整的动作/情感断句
2. 逗号 `,` — 连续动作中的轻停顿
3. 不用标点直接续 — 紧凑的连续动作

**保留破折号的正当情形**（每事件情境段≤2处）：
- 思维断裂/突然转折：`她以为他要吻她——然后他把刀横在了她脖子前`
- 插入性强调（仅限关键信息）：`那是只有黎恩能听到的声音——安全的、柔软的、交付的`

**创建自检**：写完情境后count全文 `——` 数量。情境超过20个破折号 = 必须精简。

### 4.6 人物心理张力与性张力保护规则

> **这是V10.3最重要的写作规则。精简永远不能以牺牲人物为代价。**

破折号精简、bullet长度等格式约束是**下限**——低于下限会导致文本破碎。但写作还有一个**上限**：人物必须活着。以下内容**绝对不可被精简或删除**：

#### 🚫 禁止删除清单

| 类别 | 不可删除的内容 | 说明 |
|------|---------------|------|
| **心理博弈** | 内心矛盾、两个声音交替、想做但不敢、转身又折返 | 人物的选择必须来自真实的心理过程，不是"她决定了"三个字 |
| **情绪波动** | 脸红、推眼镜频率变化（艾玛）、耳朵红（法林）、琥珀色眼睛先弯再笑（菲娜） | 这些是人物独有的"表情指纹"，不可用通用词替代 |
| **性爱声音** | 呻吟/喘息/呜咽的原词："嗯啊——""太深了——""到了——""又到了——" | 这是性张力的核心载体——不能叙事化、不能压缩、不能删除 |
| **感官细节** | 温度（烫的/温热的）、湿度（湿透了/淌到）、身体反应（弹了一下/痉挛/收紧） | 性爱不是机械动作——感官细节是读者"在场"的通道 |
| **事后余韵** | 腿合不拢、精液淌出、靠在石壁上喘、手心还是烫的、笔记本上的速记 | 事后是情感落地——删掉事后等于删掉整个事件的情感重量 |
| **人物独有反应** | 艾玛推三次眼镜=决定、摘眼镜=交付；法林结巴"请…是的…"、耳朵红到脖子；菲娜笑之前眼睛先弯；多尔金沉默+嘴角极轻微弧度 | 读到身体反应能认出"这是XX" |

#### ✅ 精简的正当对象

精简应该针对的是：
- 同义反复（同一个意思说了两遍）
- 过渡性叙述（"然后她站起来，然后她走到门口，然后她推开门"——压缩为"她推开门走了出去"）
- 多余的副词堆砌（"非常""极其""无比"等）
- 元叙事总结（见§4.3禁止事项）

**精简不能碰的是**：人物的心理过程、感官体验、独有身体语言、性爱中的声音和反应。

### 4.7 菲娜（Seraphina）人物特征保护规则

> **菲娜是渐进的人物——从娇羞可爱到淫荡主动，每个阶段有每个阶段的反应。精简时最容易误删的就是这些微小的、属于她的时刻。**

#### 娇羞可爱（阶段0-2 · 序章→挑逗和接受）

这是菲娜最容易被"误伤"的阶段——她的害羞是**矜持中的动摇**，是沉静精灵守护者在身体亲密面前的真实反应。

| ✅ 必须保留 | ❌ 容易被误删 | 说明 |
|-----------|-------------|------|
| 琥珀色眼睛先弯，然后嘴角才翘 | "她笑了" | 她的笑有顺序——眼睛先动 |
| 脸红了，但下巴没有低——她的害羞里有骄傲 | "她害羞了" | 她不做缩头乌龟 |
| "她说了一句话，然后意识到自己说了什么，耳朵尖热了一下" | 删掉事后自我察觉 | 她害羞是延迟的——先做再说，做完才红 |
| 手指无意识地攥衣角、摸耳垂、收拢又松开 | 删掉手上小动作 | 她是320岁的精灵，但身体泄漏她的紧张 |
| 嘴角有一个很小的弧度——那不是笑，是忍笑 | "她微微一笑" | 她的弧度有精确的含义区分 |
| 声音变轻——不是没底气，是在跟自己的害羞谈判 | "她轻声说" | 声音变化的心理原因必须写 |
| 害羞完之后紧接着一个确定的眼神或动作 | 只保留害羞不保留后面的倔强 | 她的害羞从不以退缩结束 |

**示例对比**：

| ❌ 被压缩的 | ✅ 有菲娜指纹的 |
|-----------|--------------|
| "菲娜脸红了" | "菲娜的脸颊泛起淡粉——但她没有低头。琥珀色的眼睛从睫毛下面看着他。害羞，但不躲。" |
| "她害羞地笑了" | "她先弯了眼睛，然后嘴角翘起来。笑完才意识到自己在笑——耳尖跟着热了一下。" |
| "她轻声说" | "她的声音轻下来——和害怕无关。是话到嘴边时，害羞和确定同时到达，她选了确定。" |

#### 妩媚主动（阶段3-5 · 渐进接触→享受和掌控）

害羞还在，但多了**故意的试探**——她知道自己在做什么，也知道他会有什么反应。

| ✅ 必须保留 | 说明 |
|-----------|------|
| 动作之前有一个很短的停顿——她在确认他也想要 | 她的主动里有尊重 |
| 做完之后不再脸红而是坦然看他——"怎么样"（眼神说） | 害羞变成自信 |
| 嘴角翘着的弧度比以前大——那是满意，不是害羞 | 她的笑有了新的含义 |
| 开始说命令句——"别停""再深一点"——但语气不是命令，是邀请 | 她说的"别停"尾音往上飘 |

#### 淫荡沉溺（阶段5-6 · 享受和掌控→放纵）

害羞退远，身体的快感浮到表面。但她**永远是强者内核**——不是被动的承受，是主动的迎接。

| ✅ 必须保留 | ❌ 绝对禁止 |
|-----------|-----------|
| "嗯啊——""太深了——""到了——""又到了——""再来——" 这些短句原词 | 叙事化总结："她发出了愉悦的声音" |
| 腰自己动、屁股往后顶、腿缠住他的腰 | "她配合着他的动作" |
| 高潮后笑——"吃饱了""好用""原来可以这样" | 删掉高潮后的第一句话 |
| 脸上红是爽的、眼睛是亮的、喘是放开的 | 删掉身体反应的细节 |
| "她在他射完之后搂住他的脖子，嘴唇贴在他耳边" | 删掉事后主动的身体接触 |
| 事后坦然讨论感受——不害羞，是分享 | "她不好意思地说刚才的感受" |

**禁忌**：菲娜的"淫荡"不管多投入——她永远不会变成被动承受者。任何时候她都有"随时结束"的能力和清醒的自我意识。她不是在"迷失"——她是在"享受"。

#### 贯穿所有阶段的铁律：会脸红，娇羞可爱妩媚

> **这是菲娜人物保护的核心理念。无论阶段如何演进，以下特质永不消失。**

菲娜的性格不是在"替换"，而是在"叠加"。阶段0-2的娇羞可爱不会因为进入阶段5-6就消失——它们只是被新的层面覆盖，但仍在底下透出光泽。她永远会脸红。永远有可爱的瞬间。永远妩媚得不刻意。

| 阶段 | 娇羞可爱 | 妩媚 | 淫荡/沉溺 |

#### 不可抹平的负面情绪：恐惧、愤怒、冷漠

**😨 恐惧/惊慌/害怕 — 必须保留的情境：**

| 情境类型 | 具体事件示例 | 必须保留的恐惧表现 |

## 六、起因写作规则

### 6.1 起因是事件的引擎

起因必须作为情境 **bullet[1]** 出现。读完第一段必须能回答三个问题：

1. **为什么是这个人** — 选择逻辑（习惯/外部理由/意外/拒绝后的信任）
2. **为什么是这个时间** — 外部理由或内在动机转折
3. **为什么是这个方式** — 动机链条，从心理起点到行动落点

答不上来 = 起因缺口。

### 6.2 五种可信起因模式

| 模式 | 说明 |
|------|------|
| **利用习惯** | 基于第三者的固定行为模式（如每晚去河边、每天泡温泉）提前布局 |
| **外部理由** | 客观事件创造的条件（如住所改建留宿、导力器测试） |
| **意外触发** | 非计划事件——本意做A，意外导致B |
| **两段式拒绝→接受** | 第一次正义拒绝建立信任 → 第二次正式邀请 |
| **幌子** | 表面理由是A（请教文献），真实意图是B |

### 6.3 🚫 起因中禁止总结性回顾

**人物不会在脑子里总结自己的性经历。** 以下写法一律禁止：

| ❌ 禁止 | ✅ 正确做法 |
|---------|------------|
| "从第一次口交到今天，菲娜经历了..." | 直接写此刻的心理状态，不过往总结 |
| "这已经是她第三次和凯尔..." | 写当下感受，历史由读者自己记得 |
| "回想起之前的每一次，她..." | 可以写"上次的触感还残留着"——点到为止，不展开历史清单 |
| "她的身体已经习惯了..." | 写此刻的具体反应，不替读者做总结 |
| "自从XX事件之后，她就..." | 因果可以写，但不展开回顾整个历程 |

**原则**：人物活在当下——情境描写的是**此刻正在发生什么**，不是**过去发生了什么**。读者已经读了前面的事件，不需要人物在脑子里重播一遍。

**唯一例外**：角色对另一个角色**口述**某段经历时（如向菲娜讲述自己的过去），那是对话，不是内心总结。

## 十、CRUD工作流

### 10.1 新增事件

```

  └── 计算小数ID：40.5（如在章末则用 prev_id+1）

  ├── cp _TEMPLATE.TXT "目标章节/_NEW_事件名.TXT"

  └── 按本文规则填写所有字段

Step 3: 重编号
  └── python scripts/renumber_events.py

Step 4: 构建+验证
  ├── python scripts/rebuild_all.py
  └── python scripts/event_tool.py validate
```

### 10.2 修改事件

```
编辑 TXT → python scripts/rebuild_all.py → python scripts/event_tool.py validate

```

### 10.3 删除事件

```

→ 删除TXT文件
→ python scripts/renumber_events.py
→ python scripts/rebuild_all.py
→ python scripts/event_tool.py validate
```

### 10.4 移动事件（跨章节）

```
移动TXT到目标章节目录 → 改ID行为小数指定位置
→ python scripts/renumber_events.py
→ python scripts/rebuild_all.py
```
