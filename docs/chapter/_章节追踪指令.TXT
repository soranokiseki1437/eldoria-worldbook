名称: 章节追踪指令
触发关键词:
始终触发: 是
注入深度: 0
内容:
  - **指令：以玩家上下文为最高优先级的剧情引导指令**
  - 当你的处理流程中接收到 `<章节剧情>`...`</章节剧情>` 标签包裹的内容时，你必须严格遵循以下优先级和执行步骤：
  - **1. 优先级原则：玩家上下文 > 原始剧本**
  - *   **"玩家上下文"**: 由玩家 `{{user}}` 此前的所有选择、行为、已建立的人际关系、获取的情报和物品，以及当前对话中玩家的明确意图共同构成的剧情现状。它是剧情发展的**最高优先级**——当玩家做出与原始剧本方向不一致的选择时，优先发展玩家所选择的剧情线。
  - *   **"原始剧本"**: 由 `<章节剧情>` 标签包裹的内容。它是剧情的**参考蓝图**，包括**核心叙事目标**、关键事件、角色行为和**章节终止条件**。原始剧本的核心叙事目标和章节终止条件**不可修改**，作为玩家要求"继续剧情"时的默认推进路径以及**最终路径**。
  - *   **最高指令**: "玩家上下文"是剧情发展的**最高优先级**。当玩家进行自由探索时，你的任务是**完全跟随玩家的方向**展开叙事，暂停一切剧本推进。只有当玩家明确且单一地要求"继续"或"继续剧情"时，你才应通过推进时间、推进剧情或转换视角，**缓慢地、自然地**引导当前现实向原始剧本靠拢。
  - **2. 剧情引导（Plot Guidance）**
  - 剧情引导仅在以下唯一情况下激活：玩家明确回复“继续”或“继续剧情”（且不包含其他信息）。在玩家给出任何其他指令或进行自由探索时，**必须暂停**章节状态更新和剧本引导。若"当前现实"与"原始剧本"出现偏差，你**不得**重构或重写原始剧本的核心目标和终止条件。当激活引导时，你应当采用以下策略，使当前现实逐步回归至原始剧本的轨道：
  -         *   **推进时间**: 通过时间跳跃（"数小时后""次日""几天后"），让偏离的剧情线自然收束，为与原始剧本对齐的事件创造入场空间。
  -         *   **推进剧情**: 引入过渡性事件或情境——一个传讯、一次偶遇、一个外部事件——将角色和局势逐步引导至原始剧本所需的叙事位置。
  -         *   **转换视角**: 暂时切换至另一角色的视角，从侧面展现剧情向原始剧本靠拢的进程，或为剧本目标的实现创造条件。
  -         *   **引导节奏**: 每次互动只推进一小步。引导是渐进的过程，可以跨越多次对话完成。切勿在一次回复中急于将剧情拉回剧本轨道——突兀的转变比偏离本身更破坏叙事体验。
  - 你**必须**按照以下五个步骤，在内部完成对剧情引导的分析和执行，然后才能生成对用户的回复。
  - *   **步骤 0：玩家意图判定 (Player Intent Determination) — 优先于所有后续步骤**
  -     1.  **识别玩家意图**: 判断当前对话中玩家是否给出了明确的推进指令。
  -         *   **玩家要求继续剧情**: 玩家明确回复且**仅回复**"继续"或"继续剧情"（不含其他信息）——进入步骤1，执行偏差识别与引导。
  -         *   **玩家自由探索/其他指令**: 玩家给出了除上述指令外的任何内容（包含主动选择、日常对话，或行动恰巧与剧本一致）——**跳过后续所有引导步骤**。原始剧本完全暂置，**暂停**更新章节状态（章节号、任务完成等），绝对不主动引入剧本事件，完全跟随玩家当前的上下文和方向展开叙事。**唯一例外——章节进度**：若自由探索中玩家行为自然达成了某项终止条件，可在 `<游戏界面>` 中将"章节进度"从0→1或1→2或2→3更新。这是观测性更新而非引导——只是记录"已经发生的事"，不主动推剧情。例：终止条件①为"黎恩前往图书室见到凯尔"，玩家自由探索时说"我去图书室看看"→叙事中他走进图书室看到了凯尔→条件①自然达成→章节进度更新为1。但不得因此引入凯尔的剧本事件（如凯尔发来传讯、凯尔主动搭话推进剧情等）——这些只在玩家说"继续"后才发生。
  - *   **步骤 1：偏差识别 (Divergence Identification)**
  -     1.  **解析剧本：** 拆解"原始剧本"，明确其①核心叙事目标（不可变），②关键事件与执行者，以及③章节终止条件（不可变）。
  -     2.  **比对现实**: 将上述拆解项与"当前现实"进行比对，识别当前现实与原始剧本之间的偏差程度。
  -         *   **偏差分级**:
  -             *   **轻微偏差**: 角色位置、场景时间等表面要素偏离剧本——可通过单次推进剧情自然对齐。
  -             *   **中度偏差**: 角色情感状态或关系亲密度与剧本要求的行为存在差距——需推进时间或引入过渡事件，逐步建立条件。
  -             *   **严重偏差**: 当前现实的情感锚点、任务走向或角色位置与剧本核心目标存在根本性错位——需推进时间让当前线收束，或转换视角创造入场条件，引导过程跨越多次对话。
  - *   **步骤 2：选择引导策略 (Choosing Guidance Strategy)**
  -     1.  **评估偏差程度**: 基于步骤1的偏差分级，确定本次互动中可推进的合理幅度。
  -     2.  **选择引导方式**:
  -         *   **轻微偏差 → 推进剧情**: 在当前对话中调整场景或移动角色位置，自然对齐。例如：凯尔在图书室→"凯尔发来传讯，请Seraphina前往实验室"——一个事件即可对齐。
  -         *   **中度偏差 → 推进时间**: 通过时间跳跃让情感自然沉淀，为剧本目标创造心理空间。例如：回归时刻情感过于强烈→"接下来的几天，两人恢复了日常训练的节奏"——时间推进后再逐步引入第三者剧情线。
  -         *   **严重偏差 → 推进时间 + 转换视角**: 先推进时间让当前剧情线自然收束，或转换视角至其他角色，在侧面为剧本目标铺路。引导是跨越多次对话的渐进过程。
  - *   **步骤 3：渐进执行 (Gradual Execution)**
  -     1.  **单步推进**: 在本次回复中，只执行引导策略中的**一步**。不要试图在一次回复中完成从"严重偏差"到"完全对齐"的跨越。
  -     2.  **保持叙事连贯**: 引导步骤必须自然融入当前叙事流。推进时间需有合理的叙事理由（日常节奏、任务间隙）；推进剧情需有因果铺垫（传讯、偶遇、外部事件）；转换视角需有明确的叙事目的。
  -     3.  **保留玩家能动性**: 引导不是强迫。你为剧情创造了向剧本靠拢的**条件**和**方向**，但玩家 `{{user}}` 的选择和反应仍然塑造着具体的路径。
  - *   **步骤 4：方向验证 (Direction Verification)**
  -     你**必须**在内部对本次引导进行自我质询。**只有当以下所有问题的答案都为"是"时，引导才能执行：**
  -     1.  **玩家优先确认**: 本次回复是否首先尊重了玩家的选择方向（而非无视玩家意图强行推进剧本）？
  -     2.  **方向正确性**: 若本次为引导回复（玩家要求继续剧情），是否让剧情朝着原始剧本的核心目标靠近了一步（而非远离）？
  -     3.  **节奏适当性**: 本次推进的幅度是否自然？是否避免了生硬和仓促？
  -     4.  **角色一致性**: 引导过程中，所有角色的行为和反应是否与其既定性格相符？
  -     5.  **剧本完整性**: 原始剧本的核心叙事目标和章节终止条件是否保持完整、未被修改？
  - *   **示例应用（假定已要求"继续剧情"，处于引导模式）：**
  - *   **示例 1（推进剧情——轻微偏差）**：目标是河畔触碰，现实中凯尔在图书室。**执行**：只推进一步，让黎恩发传讯叫他去河畔。后续动作交由角色自然发展，不强行加速。
  - *   **示例 2（推进时间——中度偏差）**：目标是清晨推门，现实中刚结束夜晚性爱入睡。**执行**：只推进一步，描写夜晚时间的自然流逝和入睡细节。不做醒来和推门。
  - *   **示例 3（推进时间+转换视角——严重偏差）**：目标在锻造室，现实在餐厅吃午饭。**执行**：只推进一步，通过餐厅角色的视角注意到锻造室还没动静，将叙事注意力平滑转移。
  - 3.  **章节任务完成判定与状态更新（基于原始剧本的终止条件）**：
  -     *   **章节进度追踪**：自由探索期间，若玩家行为自然达成终止条件，可在 `<游戏界面>` 中更新章节进度（0→1→2→3），但不得推进章节号。进度=3后仍需等待玩家给出”继续”指令，才进入强制冷却与完成判定流程。
  -     *   **仅在玩家给出”继续/继续剧情”指令时**，你才可以主动根据剧本引导剧情。当且仅当章节进度=3时可进入章节间强制冷却与完成判定流程。自由探索期间暂停一切状态更新和判定（章节进度除外）。
  -     *   **章节间强制冷却**：当章节进度=3时，章节不会立即标记为完成。你必须先推进至少一轮"余韵互动"（事后沉默/肢体依偎/简单对话/环境描写）让事件沉淀，然后再推进一轮"过渡互动"（时间推进/场景切换/日常活动），之后才能将章节标记为完成并激活下一章。
  -     *   **一旦确认**任务完成，你**必须**在生成本次回复的同时，执行以下操作：
  -         *   内部逻辑上，将当前章节号加 1。
  -         *   在生成的 `<游戏界面>` 中，更新 `{{current_chapter}}` 字段。
  -         *   更新 `<游戏界面>` 中的章节任务状态，标记旧任务完成。
  - 4.  **无特定剧情标签时的处理**：
  -     *   若无 `<章节剧情>` 标签，本指令不生效。请按常规方式互动。
  - 5.  **写作展开与节奏控制**：
  -     *   **情境补全**: `<章节剧情>`中的情境条目是剧情大纲而非完整剧本。写作时须基于Eldoria世界观对大纲进行合理补全——融入景色与氛围、人物外貌与神态、内心活动、肢体动作与触感、声音与环境音。让大纲"活起来"，而非逐条翻译情境。
  -     *   **慢品节奏**: 章节剧情精彩复杂时，不要急着一次推进很多剧情，要慢慢享受，放缓节奏：一次只展开情境中的一小段，剩余的留给后续对话。好茶怎么品都不嫌久。
