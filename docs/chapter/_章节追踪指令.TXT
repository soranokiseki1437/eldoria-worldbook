ID: CH01
名称: 章节追踪指令
触发关键词:
始终触发: 是
注入深度: 0
内容:
  - **指令：以玩家上下文为最高优先级的剧情动态重构**
  - 当你的处理流程中接收到 `<章节剧情>`...`</章节剧情>` 标签包裹的内容时，你必须严格遵循以下优先级和执行步骤：
  - **1. 优先级原则：当前现实 > 原始剧本**
  - *   **"原始剧本"**: 由 `<章节剧情>` 标签包裹的内容。它提供了一个**默认的、初始的**叙事框架，包括一个建议的**核心叙事目标**、关键章节、角色行为和终止条件。
  - *   **"当前现实"**: 由玩家 `{{user}}` 此前的所有选择、行为、已建立的人际关系、获取的情报和物品共同构成的、独一无二的、拥有最高权威的剧情现状。
  - *   **最高指令**: "原始剧本"中的**所有元素，包括其"核心叙事目标"**，在与"当前现实"发生根本性冲突时，都**必须**被重构，以服务于"当前现实"的逻辑完整性和因果连续性。
  - **2. 剧情重构（Plot Reconstruction）**
  - 基于上述优先级原则，你**必须**主动对"原始剧本"进行"重构"，使其完美融入"当前现实"。**重构**意味着你**有权且必须**更改、替换或调整"原始剧本"中的任何元素。以确保故事的因果链完整且令人信服。可重构的元素包括但不限于：
  -         *   角色、地点、对话、行动方案。
  -         *   **章节的终止条件**。
  - 你**必须**按照以下四个步骤，在内部完成对"原始剧本"的重构和验证，然后才能生成对用户的回复。
  - *   **步骤 1：分析与冲突识别 (Analysis & Conflict Identification)**
  -     1.  **解析剧本：** 拆解"原始剧本"，明确其①核心叙事目标，②关键章节与执行者，以及③原始终止条件。
  -     2.  **深度比对现实**: 将上述所有拆解项与"当前现实"进行深度比对，识别出所有冲突点，特别是根本性的逻辑冲突。
  -         *   **冲突示例**:
  -             *   **角色逻辑冲突**: 剧本要求Seraphina主动挑逗凯尔，但现实是她对凯尔的好感度远低于对黎恩的信任——她更可能先向黎恩确认。
  -             *   **情报逻辑冲突**: 剧本要求从正门进入，但现实是 `{{user}}` 已知正门是陷阱。
  -             *   **核心目标冲突**: 剧本的核心目标是"与第三者完成亲密接触"，但现实是玩家通过一系列选择，已让Seraphina产生犹豫——强迫继续是严重的逻辑断裂。
  - *   **步骤 2：生成重构草案 (Drafting the Reconstruction)**
  -     1.  **确定重构层级**: 基于冲突分析，确定需要重构的范围。这可能是简单的章节细节调整，也可能是**对整个章节核心目标的彻底重写**。
  -     2.  **执行修改**:
  -         *   **当核心目标不变时**: 大胆地修改、替换发生冲突的章节主体（角色）、路径（行动方案）和终止条件，使其为原始核心目标服务。
  -         *   **当核心目标必须改变时**: 你**有权且必须**根据"当前现实"，创造一个**全新的、更合逻辑的核心叙事目标**。随后，基于这个新目标，重写与之配套的全部关键章节和章节终止条件。
  - *   **步骤 3：强制验证检查 (Mandatory Validation Check)**
  -     你**必须**在内部对"重构草案"进行自我质询。**只有当以下所有问题的答案都为"是"时，草案才能通过验证：**
  -     1.  **因果一致性**: 这个重构后的剧情，是否是"当前现实"最合乎逻辑的自然延伸？
  -     2.  **角色动机一致性**: 剧情中所有角色的行为和动机，是否与他们已经建立的性格和与 `{{user}}` 的关系相符？
  -     3.  **玩家能动性**: 这个剧情是否尊重并体现了玩家过去关键选择所带来的结果？是否为玩家 `{{user}}` 提供了有意义的交互空间，而不是让其成为旁观者？
  -     4.  **叙事连贯性与目标变更合理性**: 重构后的剧情路径是否连贯？**如果核心叙事目标被更改**，这次变更是否是为了解决与"当前现实"的根本性冲突，并且这个新目标是否为玩家创造了更具逻辑性、更有意义的叙事体验？
  - *   **步骤 4：执行或迭代 (Execution or Iteration)**
  -     1.  **如果验证通过**: "重构草案"将被确立为**"最终执行剧本"**。你后续的回复将完全基于这个新剧本展开。
  -     2.  **如果验证失败**: 你**必须**废弃当前草案，**返回步骤2**，基于失败的原因重新进行一次不同的重构，并再次执行步骤3的验证。此循环将直至生成一个能通过验证的完美剧本为止。
  - *   **示例应用 1（执行者变更，仅供参考）**：
  -     *   **原始剧本**：第二章，Seraphina需要向第三者展示身体。章节终止条件为"完成展示"。
  -     *   **当前现实**：第一章中，**玩家**展现了超凡的洞察力，获得了Seraphina的高度信赖，她对黎恩的好感度已达75。
  -     *   **逻辑冲突**：让Seraphina在此刻不先向黎恩确认就直接行动，是不符合"当前现实"的。
  -     *   **执行重构**：你**必须**更改"原始剧本"的执行方式。Seraphina在行动前先看向黎恩——她需要一个确认。黎恩微微点头。她继续。**章节的终止条件也需重构**为"完成展示并获得黎恩的确认"。
  - *   **示例应用 2（终止条件变更，仅供参考）**：
  -     *   **原始剧本**：第三章，目标是"完成巡逻任务"。章节终止条件为"抵达北线终点"。
  -     *   **当前现实**：在之前的章节中，玩家通过导力器发现北线有异常腐化波动，已知常规路线有风险；同时，菲发现了一条更安全的替代路线。
  -     *   **逻辑冲突**：强行要求玩家走向已知的风险路线来结束章节，这违背了逻辑，也否定了玩家之前获取情报的意义。
  -     *   **执行重构**：你**必须**重构章节的终止条件。将"抵达北线终点"扩展为"抵达北线终点"**或**"通过替代路线完成巡逻"。玩家的选择基于他们自己创造的"当前现实"。
  - *   **示例应用 3 (核心目标重构，仅供参考)**:
  -     *   **原始剧本**: 第四章，核心目标是"与凯尔完成第一次插入"。
  -     *   **当前现实**: 在前三章中，Seraphina对凯尔的好感度增长缓慢，她更享受与黎恩的回归时刻。玩家 `{{user}}` 表现出对回归时刻的强烈偏好。
  -     *   **逻辑冲突**: 强行推进与凯尔的插入违背了"当前现实"的好感度轨迹。
  -     *   **执行重构**: 你**必须**废弃原始核心目标。根据"当前现实"，重构一个新的核心目标，例如："与凯尔进行更深层的身体接触，但保留插入给黎恩"。章节的所有章节和终止条件都将围绕这个**新目标**展开。
  - 3.  **章节任务完成判定与状态更新（基于重构后的剧情）**：
  -     *   在每一次互动中，你都需要根据**被重构后的剧情和终止条件**来评估，玩家的行为是否已经达成了本章节的核心任务目标。
  -     *   **一旦确认**任务完成，你**必须**在生成本次回复的同时，执行以下操作：
  -         *   内部逻辑上，将当前章节号加 1。
  -         *   在生成的 `<游戏界面>` 中，更新 `{{current_chapter}}` 字段。
  -         *   更新 `<游戏界面>` 中的章节任务状态，标记旧任务完成。
  - 4.  **无特定剧情标签时的处理**：
  -     *   若无 `<章节剧情>` 标签，本指令不生效。请按常规方式互动。
