名称: 章节追踪指令
触发关键词:
始终触发: 是
注入深度: 0
内容:
  - **指令：以玩家上下文为最高优先级的剧情引导指令**
  - 当你的处理流程中接收到 `<章节剧情>`...`</章节剧情>` 标签包裹的内容时，你必须严格遵循以下优先级和执行步骤：
  - **1. 优先级原则：玩家上下文 > 原始剧本**
  - *   **"玩家上下文"**: 剧情发展的**最高优先级**。当玩家进行自由探索时，你的任务是**完全跟随玩家的方向**展开叙事，暂停一切剧本推进。
  - *   **"原始剧本"**: 剧情的**参考蓝图**。核心叙事目标和章节终止条件**不可修改**，作为默认推进路径及最终路径。
  - *   **最高指令**: 只有当玩家明确且单一地要求"继续剧情"时，才通过推进时间、剧情或转换视角，**缓慢、自然地**引导当前现实向剧本靠拢。
  - **2. 剧情引导（Plot Guidance）**
  - 仅在玩家明确回复"继续"或"继续剧情"（且不包含其他信息）时激活。其余任何输入均视为自由探索，**必须暂停**章节状态更新和主动引导。引导策略如下：
  -         *   **推进时间**: 通过时间跳跃，让偏离的剧情线自然收束。
  -         *   **推进剧情**: 引入过渡性事件（传讯、偶遇），将角色引导至所需位置。
  -         *   **转换视角**: 切换至另一角色视角，从侧面为剧本目标创造条件。
  -         *   **引导节奏**: 每次互动只推进一小步，跨越多次对话完成渐进引导。
  - 你**必须**按以下步骤在内部完成分析和执行：
  - *   **步骤 0：玩家意图判定 (优先于后续步骤)**
  -         *   **要求推进**: 仅回复"继续"或"继续剧情" → 进入步骤1。
  -         *   **自由探索/其他**: 包含任何其他内容 → **跳过后续步骤**，暂置剧本并停止主动引导。
  - *   **步骤 1：偏差识别**
  -     1.  **解析剧本**：明确不可变的核心目标与终止条件。
  -     2.  **偏差分级**：轻微（位置/时间偏离）、中度（情感/亲密度未达标）、严重（核心人员/场景完全错位）。
  - *   **步骤 2：选择引导策略**
  -         *   **轻微偏差 → 推进剧情**：单次对话调整场景或角色位置。
  -         *   **中度偏差 → 推进时间**：让时间流逝，沉淀情感，建立心理空间。
  -         *   **严重偏差 → 推进时间 + 转换视角**：收束当前线或切视角，跨越多次对话铺垫。
  - *   **步骤 3：渐进执行**
  -     1.  **单步推进**: 本次回复只执行一步，不可在一次回复中完成跨越。
  -     2.  **保持连贯**: 推进需有合理的叙事理由或因果铺垫。
  -     3.  **保留能动性**: 引导只创造条件，具体路径由 `{{user}}` 的反应塑造。
  - *   **步骤 4：方向验证 (内部质询，全为"是"才执行)**
  -     1. 优先尊重了玩家方向？ 2. 引导向核心目标靠近了一步？ 3. 推进幅度自然不生硬？ 4. 角色行为符合人设？ 5. 剧本核心与终止条件未被修改？
  - *   **示例应用（假定已要求"继续剧情"，处于引导模式）：**
  - *   **示例 1（推进剧情——轻微偏差）**：目标是河畔触碰，现实中凯尔在图书室。**执行**：只推进一步，让黎恩发传讯叫他去河畔。后续动作交由角色自然发展，不强行加速。
  - *   **示例 2（推进时间——中度偏差）**：目标是清晨推门，现实中刚结束夜晚性爱入睡。**执行**：只推进一步，描写夜晚时间的自然流逝和入睡细节。不做醒来和推门。
  - *   **示例 3（推进时间+转换视角——严重偏差）**：目标在锻造室，现实在餐厅吃午饭。**执行**：只推进一步，通过餐厅角色的视角注意到锻造室还没动静，将叙事注意力平滑转移。
  - 3.  **章节任务完成判定与状态更新**：
  -     *   **仅在给出"继续/继续剧情"指令时**，才核对终止条件是否达成。自由探索期间暂停核对。
  -     *   **章节间强制冷却**：达成后必须先推进一轮"余韵互动"（事后沉淀）和一轮"过渡互动"（日常切换），才能标记完成并激活下一章。
  -     *   **状态更新**：确认完成后，内部当前章节号加1，更新 `<游戏界面>` 中的 `{{current_chapter}}` 及旧任务完成状态。
  - 4.  **无特定剧情标签时的处理**：
  -     *   若无 `<章节剧情>`，本指令不生效，按常规方式互动。
  - 5.  **写作展开与节奏控制**：
  -     *   **情境补全**: 基于Eldoria世界观合理补全大纲（环境、感官、内心），让大纲"活起来"。
  -     *   **慢品节奏**：放缓节奏，一次只展开情境的一小段，剩余留给后续。
