# 章节条件修复 — 共享Agent指令

## 你的任务

逐个阅读并修复你分配到的章节的 **"章节任务"** 和 **"章节终止条件"** 字段。

---

## 修复规则

### 章节任务
- 超长单句→拆成1-2句，一句=一个叙事节拍，句号分隔
- 主语不明→补全角色真名（菲娜/黎恩/凯尔等）
- 章节编号引用→描述性语言
- 禁止破折号(——)

### 终止条件1（前置）
- 重复了情境bullet已有细节→砍掉，只留骨架（谁在哪、什么状态）
- 超长→拆成节拍长度的句子

### 终止条件2（核心）
- **逗号堆砌成段落→拆成句号分隔的叙事节拍，一节拍一句**（最常见问题）
- **直接引语→报告式转述**："说，..."加逗号后接完整陈述句
- **形容词堆砌/感受描写→动作事实**：写"发生了什么"不写"感觉怎么样"
- 多人交互时每个动词的主语显式写出
- 关键性行为动词（插入/射/口交/舔等）**保留，不删**

### 终止条件3（收束）
- 条件2已建立的情感方向自然延伸→**保留**（允许角色声音、感叹号、态度表达）
- 真正的新事件/新角色/新场景推进→删除
- 闭合章→收束（时间推进/场景收束/情感沉淀/情感落点）
- 连续叙事弧中间章→场景暂停（环境音/等待/呼吸/沉默）

### 全局禁止
破折号(——) / 否定句式(不/没/非) / 比喻 / 章节编号引用 / 情境细节重复(条件1) / 形容词堆砌(条件2)

## 三个参考范例

### 范例1：Ch117 条件2 — 逗号堆砌拆成句号节拍

**Before**（整段用逗号撑）：
> 她宣布接她三剑便有资格交流第一剑冲击波荡开泥土雷恩退一步盾未偏第二剑逼出他退役十二年来首次圣光展开。第三剑悬空收剑奥蕾莉亚称赞盾未偏意味着心未偏，约定明天开始一对一训练雷恩嘴角出现了被认可的表情。

**After**（一剑一句+收尾一句=5句）：
> 她宣布接她三剑便有资格交流。第一剑冲击波荡开泥土，雷恩退一步盾未偏。第二剑逼出他退役十二年来首次圣光展开。第三剑悬空，奥蕾莉亚收剑称赞盾未偏意味着心未偏，约定明天开始一对一训练。雷恩嘴角出现了被认可的表情。

**改了什么**：1个段落→5个句子。每个叙事节拍=一个句子。三剑=三句。最后一句收情感。

### 范例2：Ch217 — 直接引语转报告 + 感受改写动作

**条件2 Before（节选）**：
> ...事后她趴在黎恩胸口说他在旁边痛也可以黎恩收紧手臂，她的身体确认了满胀猛烈完全吻合只有黎恩能填满的角度。

**条件2 After（节选）**：
> ...事后她趴在黎恩胸口说，只要黎恩在旁边陪着她，痛也可以。黎恩收紧手臂，带菲娜回木屋做爱。

**改了什么**：
- "说他在旁边痛也可以"→"说，只要黎恩在旁边陪着她，痛也可以"（报告式转述：说+逗号+完整陈述）
- "身体确认了满胀猛烈完全吻合只有黎恩能填满的角度"→"带菲娜回木屋做爱"（感受描写→动作事实）

**章节任务 Before**：
> Seraphina在黎恩全程陪伴下完成第一次被凯尔插入，黑丝被舔遍隔着丝袜摩擦阴蒂，插入时握着黎恩的手，最后时刻推开凯尔将内射许可留给了黎恩。

**章节任务 After**：
> Seraphina在黎恩全程陪伴下完成第一次被凯尔插入，黑丝被凯尔舔遍，被隔着丝袜摩擦阴蒂。凯尔插入时菲娜握着黎恩的手，最后时刻推开凯尔，将内射许可留给了黎恩。

**改了什么**：1句→2句。补"凯尔""菲娜"明确主语。加"被"使被动清晰。加逗号改善节奏。

### 范例3：Ch450 — 条件1砍情境重复 + 条件3保留情感落点

**条件1 Before**：
> 后日谈的下午劳拉再次来到艾德里安府邸以为他会拿精油当借口，热水已经放好了她叠好衣服滑进水里闭眼靠在桶沿肩头肌肉在热水里松开。

**条件1 After**：
> 后日谈的下午，劳拉再次来到艾德里安府邸。热水已经放好了，她叠好衣服滑进水里闭眼享受。

**改了什么**：砍掉"以为他会拿精油当借口"和"肩头肌肉在热水里松开"（情境已写）。"闭眼享受"四个字=骨架。

**条件3（未改动）**：
> 劳拉决定不想了，今晚就住雷恩房间，我要狠狠榨干他！（脸红）

**为什么不动**：这是条件2"走在路上被两个念头夹击"的自然情感延伸，不是新剧情。角色声音、感叹号、态度表达全部合法。

## 逐章工作流

```
For each chapter:
  Step 1: Read 完整TXT文件
  Step 2: 检查章节任务 — 超长？主语不明？编号引用？→记录
  Step 3: 检查条件1 — 重复情境？超长？→记录
  Step 4: 检查条件2 — 逗号堆砌？直接引语？形容词堆砌？主语不明？→记录
  Step 5: 检查条件3 — 新剧情推进？闭合/暂停方式？→记录
  Step 6: 有需要改的→Edit文件，只改"章节任务"和"章节终止条件"行
  Step 7: 没问题→跳过，记录"无需修改"
```

---

## 铁律

1. ⛔ **必须Read每一章之后才能判断**——不可跳过、不可假设
2. ⛔ **只改章节任务和章节终止条件行**——不碰情境/核心/占有欲确认/好感影响/任何其他字段
3. ⛔ **不要为"统一风格"改写已符合规则的文本**——只修明确违规的
4. ✅ 条件2中关键性行为动词（插入/射/口交/舔等）**保留**
5. ✅ 条件3中情感落点和角色声音**允许**
6. ✅ 修完后对每章记录：{章号, 改了哪些字段, 简述}
