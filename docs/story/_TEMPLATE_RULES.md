## 一、架构现状

- 纯数字编号，线性叙事，无分支
- 无触发条件、无玩家选择、无路线标签、无游戏变量
- 好感值仅12角色，0-100，纯叙事用途

## 四、对白温度——创作时第一标准

> **这是本章节最重要的部分。** 对白质量必须前置到创作时——写每个 bullet 之前先想清楚人物怎么说完整的话。优秀章节范例（写前必读）：《暖岩石上——他以为她在等》《沼泽灯笼虫——他让她碰了尾巴》《猎人的图画——笔记本》《鳞甲的颜色——意外进入》《再访暖岩——我们俩》《告诉法林——她说了》。

### 4.0 活人感——最优先原则

**写的是人，不是文学装置。** 情境是叙事大纲，把剧情讲清楚即可——谁做了什么、感觉到了什么、为什么。不必写每一句对话、每一个动作。保留承载性格或弦外之音的对话，概述纯功能性对话。

- **对话是人在说话**：人物说完整的句子。禁止AI式碎片对话——"她说的那位。""嗯。""你也被她。""嗯。"这种短句接龙不是人在交流，是机器在模仿海明威然后把自己摔碎了
- **情绪直接写，不绕弯**：菲娜吃醋就说她吃醋了。动作细节（"菲娜把茶杯放回桌面，响了一声"）是承载情绪的，但不能替代情绪——不要让读者去猜人物是什么感受
- **内心活动是模糊的**：人心里想事情是缠绕的、来回修正的——不是排比句（"泡友。愿意。她的男人。也愿意。"），不是金句（"你是被算进去的，她一开始就在里面"），不是哲学辨析。黎恩心里想的和嘴里说的都不会像演讲稿
- **不发明人造概念**：人物不用自创术语来解释自己的关系。"被算进去"——没有人会这样想自己的处境，这是作者替角色做的分类学
- **类人种族说话与人类无异**：蜥蜴人/矮人/狼人等类人种族在对话上与人类没有区别，不要为了区分种族而故意写得冷漠机械（省略号断句、两字蹦字、"职业自称"都不是区分方式，反而会毁掉人物）。写之前代入角色想：以他的人设（阳光开朗？憨厚真诚？稳重内敛？）和此刻心情，这句话会怎么说完整？

### 4.0.1 关键节点对白清单（每章必查）

以下节点的对话**必须写完整人话**，禁止概述化、禁止碎片化：

| # | 节点 | 必须做到 | 优秀范例（多弧线） |
|---|------|---------|---------|
| 1 | **相遇/开场问候** | 完整问候语：称呼+语气词+兴奋/关心 | 艾玛弧（《暖岩石上——他以为她在等》）："卡兹尔！！你怎么在这里呀~又在追什么猎物吗？" |
| 2 | **请求/邀约/决定** | 完整句子表达诉求，禁"帮我。""好。" | 菲娜×凯尔弧（《意外的请求——踩踏与羞耻》）："...我想请你踩我。" |
| 3 | **情感高点**（表白/道歉/承诺/解释） | 完整句+称呼+语气词，禁断句列举 | 菲娜弧（《黎恩的独占欲——重新占有》）："你是我的。"；艾玛弧（《暮色里的通讯——暖岩石上的意外》）："能遇到你，是运气啊。" |
| 4 | **性爱中的互动** | 呻吟原词+调情半句，嵌入引号内 | 菲娜弧："太深了""到了"；艾玛弧："...就是...那里嘛~" |
| 5 | **事后第一句话** | 短但承载内容，禁无信息空句 | 菲娜弧（《意外的请求——踩踏与羞耻》）："你都让我刚才说了什么呀..."；艾玛弧（《暮色里的通讯——暖岩石上的意外》）："...那块石头。" |
| 6 | **收束对话** | 最后一轮对话有温度，禁两字冷收尾 | 法林弧（《告诉法林——她说了》）："我在等。"；黎恩弧（《意外的请求——踩踏与羞耻》）："当然陪，我不会让你一个人面对这种事。" |

**写作流程**：写每个 bullet 前，先确定"这个 bullet 里谁对谁说了什么"——在心里把它说成完整的人话，再落笔。落笔时对照 §4.0.2 对白铁律。

### 4.0.2 对白铁律

**写对白的唯一铁律：结合人物心理和情境，思考他/她此刻会说什么。** 把角色当人——以他的性格、她的处境、这一刻的心情，这句话会怎么说出口。下文所有示例与速查表仅供参考，不得直接机械套用。

**判定**：把对话读出声。像两个真人聊天→合格。不像→重写。"看似留白实则费解"的两字蹦字不算留白，是碎片。

**拒绝与同意是完整人话**："不行。"两个字不是拒绝——代入角色性格说出完整的话（艾玛的"不行的……你不能碰那里。""这种事……我做不来的。"）。同意也一样：拒绝后立刻同意是假的，要有拉扯——拒绝→对方退开→软磨硬泡（退而求其次/低语/观察她的动摇）→部分让步→最终决定，至少两轮。

### 4.0.5 大纲详略原则——详略得当，不是切碎

**情境大纲是详略得当的叙事稿**：精彩的关键剧情节点**详细保留**（完整对白+完整互动），过渡与功能性环节**概述**。大纲不是把剧情和对白都切成碎片的一行提纲，也不是逐字剧本。

| 详（完整展开） | 略（概述即可） |
|------|------|

### 4.1 情境结构模板

```
bullet 1:   起因 + 场景设定：环境/状态/为什么此刻此地此人 + 相遇问候（完整人话）
bullet 2-4: 上升：渐进身体接触，每步有心理伴随，对话用完整句
bullet 5-6: 高潮：最强体验 + 内心独白 + 性爱声音原词
bullet 7:   余韵：身体痕迹 + 第一句话/第一个眼神
```

### 4.2 bullet格式铁律

- 每条**1-3句话**，不超过80字（情感描写或性张力需要更长时允许突破）
- 按**时间顺序**排列，不在一条bullet里跳时间
- **第三人称**叙事，用角色名字或代词
- **情境是叙事大纲，非逐字剧本**：把剧情讲清楚即可——谁做了什么、感觉到了什么、为什么。概述功能性对话，保留承载性格或弦外之音的对话。但角色在性爱中的声音/呻吟/喘息词（如"嗯啊""太深了""到了"等）必须保留，不可叙事化
- 全事件**4-8条bullet**，超过8条必须合并精简。NSFW事件因场景结构（触发→铺垫→渐进→高潮→余韵）可放宽至10条
- 相邻bullet**不得同义重复**：两句话能合并为一句就不写两句

### 4.3 bullet禁止事项

| 禁令 | 说明 |

| ❌ 无动因的笑 | 禁角色突然"笑了""闷笑一声"而没有前因。笑必须有心理触发（被逗到、释放紧张、自嘲、被干到脑子不清醒）。先写触发，再写笑 |

| ❌ 目录/字段信息重复 | 禁在情境正文中重复章节名/阶段名等文件路径或字段已承载的信息。如事件已在`8：后日谈/`目录且阶段字段已标注"后日谈"，情境不写"后日谈的某个下午"，写"某个下午" |

### 4.4 身体语言写作原则

每个人物表达紧张/兴奋/害羞的方式不同。禁止用通用模板套在不同角色身上。

| ❌ 千篇一律 | ✅ 角色独有 |

### 4.5 标点使用规则

#### 破折号（——）全局禁令

破折号是强停顿符。**情境·核心·章节任务·章节终止条件中，非必要不可用。** 目标：全章0破折号。仅在思维断裂/突然转折时允许1处，且需能自辩"换句号丢了什么"。

**替代优先级**（一律优先替代，不保留）：
1. 句号 `.` — 完整的动作/情感断句
2. 逗号 `,` — 连续动作中的轻停顿
3. 不用标点直接续 — 紧凑的连续动作

|错误示例|正确示例|
|--------|--------|
| "她整个人弹了一下——痒——和舒服无关" | "她整个人弹了一下，感觉痒痒的" |
| "他低下头——舌尖贴上花瓣——她没有躲" | "他低下头，用舌尖贴上她的花瓣，她没有躲。" |
| "她开始喘——很自然的喘——一点都不压抑" | "她开始很自然地喘。" |


**破折号硬禁令**（以下场景0容忍）：

| 禁用场景 |错误示例 |正确示例|
|---------|--------|--------|
| **不与转折词叠用** | "只是——她比较的对象是黎恩" | "只是她比较的对象是黎恩"（"只是"已标记转折） |

#### 在方案/新增章节写作中的应用

任何新增方案或章节里写菲娜，先代入她——她是谁（320岁的精灵守护者）、她此刻在想什么、眼前发生了什么。人物行为结合人物形象，根据当时的心理和情境去推断，才能写对。上面的示例是帮助理解她人物形象的参考。

**零容忍缺项**：菲娜不管在什么阶段，都会脸红、都可爱、都甜美——娇羞+妩媚+甜美是叠加不替换的底色，从序章到后日谈不变。这一条是硬底线；上面10条指纹写哪些、写多少，由这一章的情境和她的心理决定。

菲娜在后期可能偏主导，但娇羞底色不褪——主导得越彻底，紧随其后的红耳朵、藏脸、小声撒娇越要写出来。

#### 事后余韵的具体写法

事后余韵不是"做完了"三个字。它是事件的情感落点，不可跳过、不可概述。必须写具体的感官细节和身体残留。

**《意外的请求——踩踏与羞耻》示范（踩踏后的余韵）**：
- "过了很久，菲娜先开口：'你都让我刚才说了什么呀...'她把脸埋进膝盖里。"（身体动作承载羞耻）
- "她赤脚走到门口，脚心上还有他精液的温度。"（感官残留：温度）
- 当晚告诉黎恩后，"她把鼻尖蹭进他肩窝，然后抬起头笑。"（回归时刻的具体身体接触）

**《黑丝的学术观察——第一次羞辱实践》示范（羞辱实践后的余韵）**：
- "菲娜把脸埋进床单里，闷闷地说了一句：'我也是。'然后从床单里抬起一只眼看黎恩。琥珀色的眼睛先弯了，然后整个人又把脸藏回去了。"（从藏→抬眼看→眼睛弯→又藏回去——四层动作承载复杂情绪）
- 事后黎恩抱她问下次，"她没立刻回答，把脸埋在他胸口。过了一会儿，闷闷的声音才从怀里传出来：'...嗯。'耳朵尖又开始红了。黎恩收紧手臂，下巴搁在她头顶。他没再说话，但她能感觉到他笑了一下——胸腔轻轻震了一下。"（回归时刻：犹豫的时间感+身体反应+黎恩无声的笑）

**《矮人之屋的清晨——清理与裸足的唤醒》示范（初夜次日清晨的余韵+aftercare）**：
- 艾德里安aftercare："湿毛巾，热的，擦掉她小腹上的精液时动作很轻，然后又去倒了一杯温水放在床头柜上，把被子拉上来盖到她胸口，把蜡烛吹灭了两支留一支最远的还在亮，把窗户开了一条缝让新鲜空气进来。"（aftercare的每一个具体动作：毛巾、水温、盖被子、留蜡烛、开窗缝）
- 次日清晨回归："黎恩推开门...他把被子往下拉，拉到露出锁骨，然后更往下。她的乳头在晨光里立起来。他含住了。她醒了，琥珀色眼睛对上青紫瞳，花了半秒，然后脸红了。"（重新占有的每一个感官细节）

**写作铁律**：
1. 事后必须有一个具体的感官细节（温度、湿度、触感、光、声音）
2. 菲娜事后必须有身体动作承载情绪（藏脸、蹭枕头、蜷手指、从指缝看人）
3. 回归时刻必须有黎恩的物理反应（收紧手臂、手指穿发丝、胸腔震、下巴搁头顶）
4. 不写"她满足了""他很满意"等标签——写他们具体在做什么
5. 菲娜提出重大决意/请求时是忐忑+坚定的混合：声音轻、带犹豫（"如果那里可以让他们解脱...那我..."），说完接一个甜美落点（"嗯呐~"）——不是斩钉截铁
6. 回归时刻对白有来有回：黎恩怕她受伤、菲娜反过来安抚他（"我好好的黎恩，有你在我不怕哦"）——相互支撑，不是单方面观察

### 4.7 修饰融入动词

写即是示。不先写动作再挂破折号解释状态，直接写一个带有状态的动词。

| ❌ 后挂解释（拖沓） | ✅ 融入动词（紧凑） |
|-------------------|-------------------|
| "嘴唇贴上脖子——很轻的吻。然后滑到锁骨。" | "嘴唇轻轻贴上脖子，然后滑到锁骨。" |
| "她关上门——动作很轻。" | "她轻轻关上门。" |
| "他低下头——舌尖贴上花瓣——她没有躲。" | "他低下头，舌尖贴上她的花瓣。" |

中文动词系统有丰富的副词/补语来表达方式与程度。"很轻的吻" = "轻轻贴上"。"很快的跑" = "冲出去"。

### 4.8 功能性对话可概述

如果一段对话的唯一作用是传递"接下来要做什么"的信息（没有性格、没有弦外之音、没有情绪纹理），改为概述叙事。

**判断标准**：删掉这段对话后，读者是否失去了对角色的某种理解？如果只是失去了"他们决定做X"的信息，概述即可。

| ❌ 功能对话（可用概述替代） | ✅ 概述 |
|--------------------------|--------|
| `"帮我一个忙。""什么。""一起。让凯尔知道他不是不行。"` | `她神秘地让亚莉莎帮她一个忙。` |
| `"罗恩会在意吗。""不会。满月的时候他自己都说狼人不太一样。""那就来。"菲娜站起来拉她。` | `菲娜确认了"罗恩不会在意"之后，站起来拉亚莉莎。` |

**概述的好处**：保留悬念、消除已知信息的冗余复述、缩短篇幅腾出空间给真正有性格的对话。

**必须保留的对话**：承载性格（凯尔的碎碎念）、情绪（亚莉莎的傲娇）、潜台词（菲娜的"你是我的"）、性爱中的声音（呻吟/喘息原词）、**关键节点对话（见§4.0.1）**。这些不可概述。

### 4.9 碎片句用于强调，不用于叙事流水

三字句/四字句的连续轰炸适合情绪爆发的顶点，不适合平实的记忆回溯或动作描写。

| ❌ 碎片过载（平实场景） | ✅ 适度合并 |
|----------------------|-----------|
| "她想起了月语者。后入的时候。满月形态。那个尺寸。" | "她想起了月语者后入的时候。"（"满月形态""那个尺寸"已隐含） |
| "她站起来。走到门口。推开门。回头看。" | "她推开门，回头看。"（连续动作用逗号串） |

**判断标准**：此刻的情绪是"断裂"还是"流动"？断则碎（高潮、震惊、顿悟），流则合（回忆、移动、日常动作）。

### 4.10 工具格"用"字不省

中文需要工具格标记：

| ❌ 缺"用" | ✅ 完整 |
|----------|--------|
| "嘴替代了手" | "用嘴替代了手" |
| "手指擦掉精液" | "用手指擦掉精液" |
| "舌头舔过冠状沟" | "用舌头舔过冠状沟"（或"舌尖舔过"（"尖"已含工具义）） |

**例外**：身体部位直接作主语时不需要"用"。"嘴唇裹住龟头""舌尖画圈""手握住茎身"均合法，因为这些部位本身就是动作的发出者。

### 4.11 相邻叙事单元衔接

**一bullet一功能**：每个情境bullet承担单一叙事功能。读一遍bullet，能用一个短语概括它在做什么（"建立场景"/"菲娜内心挣扎"/"行动决定"）。如果不能，拆。

**bullet间必须有因果/时序桥梁**：相邻bullet之间需要一个词/短语建立连接。

| ❌ 无桥梁 | ✅ 有桥梁 |
|---------|---------|
| Bullet 1: …她神秘地让亚莉莎帮她一个忙。| Bullet 1: …她神秘地让亚莉莎帮她一个忙。|
| Bullet 2: 亚莉莎的脸从粉色变成了红色。| Bullet 2: **听完菲娜的请求，**亚莉莎的脸从粉色变成了红色。|

常用桥梁："听完……之后""与此同时""不一会儿""在……的同时""然而""与此相对"。

### 4.12 连续对话归属

当两个角色交替说话且上下文无法明确判断说话者时，必须加归属。如果前文已明确谁在对谁说话，且对话内容本身能判断说话者（凯尔不会说"黎恩的大鸡巴"、菲娜不会说学者的碎碎念），可不加归属。

### 4.13 菲娜（Seraphina）害羞全场景链路

菲娜的害羞是**持续状态**，贯穿事前→事中→事后全场景。修改时不能只改一个点，必须从头到尾确保每个阶段都有对应体征。

```
事前：结巴（"我我我"）、想起黎恩→脸红、害羞嗔怪（"你问我我怎么知道...."）
事中：害羞到无法点头/无法回应（"正害羞着呢，哪有心思管他"）、被问话时沉默（"......"）
事后：脸红红地赶紧跑了、想赶快回到黎恩旁边、把脸埋进毛巾里闷闷地说话
```

**阶段对应的害羞方式与事后回归已并入 §4.6 菲娜阶段特征表。**

**贯穿铁律**：菲娜永远是强者内核。淫荡是主动迎接。任何时候都保有"随时结束"的能力。娇羞+妩媚+甜美始终是底色——一章里菲娜没有害羞体征、没有妩媚质感、没有甜美回归，就是写偏了。

### 4.14 标点细则：省略号 / 波浪号 / 对话内部逗号

#### 省略号 `...` — 犹豫/害羞/自我谈判

| 类型 | 形式 | 示例 | 说明 |
|------|------|------|------|
| 犹豫 | `...` | `"黎恩..."` `"还好...你动"` | 语流中断 |
| 结巴 | `...`+重复 | `"那个...我我我"` | 念头断成几截 |
| 沉默 | `......` | 被问"疼？"→`"......"` | 六个点。害羞到说不出话 |
| 嗔怪/渐弱 | `....` | `"你问我我怎么知道...."` | 四个点。声音渐弱到消失 |

> 点数越多，害羞越深：`...`犹豫 → `....`渐弱 → `......`彻底沉默。
> 省略号 vs 破折号：省略号=迟疑/悬停/渐弱；破折号=打断/突然转折。不可互换。

#### 波浪号 `~` + `啦` — 撒娇甜美标记

只在撒娇/甜美时刻使用。尾音上扬的轻软感。

| 场景 | 不用 | 用 |
|------|------|-----|
| 事后留宿 | `"今晚。我在这里睡。"` | `"今晚我在这里睡~"` |
| 拒绝黎恩来接 | `"不用。"` | `"不用啦黎恩"` |

> "啦"+人名不加逗号，形成亲昵的呼唤+陈述一体感。"啦"和波浪号择一即可。每事件`~`不超过2处。

#### 对话内部逗号串联

对话内短句之间用逗号，不用句号切断：

| ❌ | ✅ |
|----|-----|
| `"没事。你继续。"` | `"没事，你继续。"` |
| `"进来。床冷。"` | `"进来，床冷。"` |
| `"好。明早我来接你。"` | `"好，明早我来接你。"` |

#### 问句用问号，惊呼用感叹号

| ❌ | ✅ |
|----|-----|
| `"多尔金呢。"` | `"多尔金呢？"` |
| `"你们什么时候说的——"` | `"你们什么时候说的？"` |

### 4.15 禁止句式补充

#### 修饰后挂

修饰语以逗号短尾挂在动作后违规，须前置融入动词。

| ❌ | ✅ |
|----|-----|
| `他笑了一下，很轻。` | `他轻轻笑了一下。` |
| `她点头，很慢。` | `她慢慢点头。` |
| `她轻声说，然后含进去，缓慢，一寸一寸。` | `她轻声说，然后一寸一寸缓慢地含进去。` |

**判定**：逗号后只挂无主语的短修饰（很轻/缓慢/一寸一寸）即违规。

**新写/重写同样适用**：本规则不止用于修复旧文，新增或重写的句子也必须过这一条。写完把新段落读出声，两种形态一律前置改写：①"动词+逗号+短修饰"（"她开口，声音更轻""他点头，很慢"）；②"名词+逗号+短修饰"的定语后挂（"脚心贴上龟头，柔软，微微凉"→"柔软微凉的脚心直接贴上龟头"）。

#### 后置解释句

叙事展示完毕，后面再补短句贴标签——直接删除。

| ❌ | ✅ |
|----|-----|
| `黎恩当晚的占有比任何一次都凶。是确认。` | `黎恩当晚的占有比任何一次都凶。` |
| `"不要，"她说得很干脆——是对他说的，也是对自己说的。` | `"不要，"她说得很干脆。` |
| `黎恩看懂了——是"满意了吗"。` | `黎恩看懂了。` |

**判定**：删掉"是X"后前文完整无损→删。后置部分无新信息→删；有新信息→融进叙事句。

**注意**：人物态度与意图是新信息，不是后置解释。"他硬得发疼，但她的手交叉在胸前，没有要帮他的意思。"——"不帮"是她的戏弄，保留；只有重述已展示内容的标签（"黎恩看懂了，是'满意了吗'"）才删。

#### 连续破折号链

一句内≥2个`——`即违规。合并为逗号或句号。

| ❌ | ✅ |
|----|-----|
| `她的额头抵着他的额头——鼻尖碰鼻尖——嘴角翘着。` | `她的额头抵着他的额头，鼻尖碰鼻尖，嘴角翘着。` |

角色对话中的断续破折号（`"我——我——不是——"`）不算——那是口吃/紧张。

#### 碎片句

碎片句（三字句/四字句连续轰炸）仅用于情绪断裂时刻（高潮/震惊/顿悟）。平实的动作/回忆/移动用逗号串联。

| ❌（流动场景） | ✅ |
|----|-----|
| `她生气了。瞪着他。不说话。` | `她生气了，瞪着他，不说话。` |
| `一下。两下。节奏不快。` | `一下、两下，节奏不快。` |

### 4.16 否定句式细则

禁的是**"否定A→断言B"的pivot结构**，不是禁"不是""没有"这些词本身。

**基准（"不是A，是B"）**：
- ❌ `"不是质问——是问诊"` → ✅ `"她在问诊"`
- ❌ `"不是犹豫，是在找说法"` → ✅ `"在找说法"`
- 删掉"不是A"部分，句子还完整→直接写B

**变体1（"没有A，也没有B"成对否定）**：
- ❌ `"那一个字里没有犹豫，也没有试探"` → ✅ `"那一个字干脆笃定"`
- ❌ `"她没有说话，也没有说不要"` → ✅ `"她没说好也没说不好，只是红着脸沉默"`

**变体2（"不是A，不是B，是C"双重否定链）**：
- ❌ `"不是滴不是落，是砸"` → ✅ `"砸在屋顶上"`

**变体3（"没X，只是Y"）**：
- ❌ `"没脱衣服，只是把上衣解开，敞开了"` → ✅ `"把上衣解开"`
- 先写没做什么再写做了什么 = pivot否定。直接写做了什么。扩展："没有X，只是Y"同属此类
- 此规则也适用于角色对话："没有，就是..." → 直接说是什么

**合法用法**：角色对话中的直接否定（`"不是...黎恩？等一下。"`）、必要的事实否定（`"暴雨又不是我安排的"`）、习语（`"是不是"`疑问）、单一否定无pivot（`"照明不是它的目的"`）。

### 4.17 对话嵌入动作

#### 4.17.0 不让任何两行纯对话相邻

> 金标准章节：《意外的请求——踩踏与羞耻》（凯尔踩踏请求）、《黑丝的学术观察——第一次羞辱实践》（黎恩找凯尔安排）。新增方案写作时直接参照。

**原则**：任何连续两句对话之间，必须插入至少一句动作/表情/身体反应描写。人物说每句话之前或之后，必须有身体在做什么——手在动、耳朵在变色、呼吸在变浅变深。

**《意外的请求——踩踏与羞耻》示范——凯尔说出请求的全过程**：

凯尔说"我想请你踩我"之前：先写"她每从梯子上下来赤脚踩在木地板上的声音很轻，但他每次都听见了"→"学者长袍下面撑得很明显"→她的脸先红了→"凯尔，你是不是又在想。"→凯尔推眼镜摘下来再戴上→他低下头→沉默了很久→才说出口。全程没有任何两行纯对话相邻。每一句对话前后都有动作、表情或身体反应。

**《黑丝的学术观察——第一次羞辱实践》示范——黎恩找凯尔的全过程**：

黎恩找凯尔：凯尔"全程低着头，耳朵尖是红的"→黎恩说话→凯尔"推了三次眼镜才说出话，声音小到黎恩差点没听清"→黎恩站起来说时间→"轻轻拍了拍凯尔的肩膀，拍完手就收回去了"→"菲娜说她上次也很紧张，紧张是正常的"→凯尔抬起头的时候黎恩已经推门出去了。每句对话都嵌在动作流中。

**写作自检**：写完任一段对话后，遮掉引号只看叙事。叙事里有角色在感知对方、触碰对方、对方有身体反应、声音有质地吗？如果叙事在空转（只有"他说""她说"），对话也在空转，两者加在一起等于什么都没写。

#### 4.17.1 短对话问题形态速查（Forms A-G，创作时即避免）

| 形态 | 描述 | 典型示例 | 避免方法 |
|------|------|---------|---------|
| **A** | 单字回应重大提案 | 菲娜提重大决定→黎恩回"好。" | 补表情+停顿+身体+语气+为什么同意 |
| **B** | 关键词充当对话 | `"感谢。"` → 大纲词直接进引号 | 展开为自然对话或叙述化 |
| **C** | 句号断句型 | `"我不知道。就是。想要。"` | 省略号替代句号做自然停顿 |

| **F** | 叙事自曝数字数 | `"多尔金说了两个字。不错。"` | 删除数字计数，用描述性动作替代 |
| **G** | 对话零引号 | `直接问黎恩: 听说你喜欢脚` | 加中文引号 `"..."` |

**核心法则**：修复短对话≠扩写。修复=在对话前后补**感知+触碰+对方反应+声音质地+情绪效果**（情感填充五层）。遮掉引号看叙事——叙事空转+对话空转=什么都没修。**创作时直接避免，不要等修复**。

### 4.18 关键时刻不插场景细节

角色正在做关键动作（解开上衣、推门进入、说出重要台词、第一次身体接触）时，不在此刻插入物件的历史描写或场景背景。场景细节放在动作之前或之后，不在动作顶点抢镜头。

| ❌ 打断节奏 | ✅ 细节前置或后移 |
|-----------|----------------|
| "她解开上衣，敞开了。凳子是那把有裂纹的木凳，她坐过无数次，现在是他坐着，她站着。" | 凳子裂纹在前一段或后一段提及，不在她解开上衣的那一刻 |

**判断标准**：读一遍bullet，找到动作顶点（她做了什么决定/他做了什么动作）。顶点句的前后半句是否被场景细节隔开了？如果是，移走细节。

### 4.19 修饰一次就够

一个感官维度只用一个修饰词。不追加同义修饰。

| ❌ 重复修饰 | ✅ 一次到位 |
|-----------|-----------|
| "声音压得很低，尾音往下沉" | "声音压得很低"（"很低"已含方向性） |
| "耳尖红透了，从粉红一路烧到耳根" | "耳尖红透了"（"透了"已含程度） |

**判断标准**：删掉第二个修饰后，前一个是否已经传达了同样的信息？如果是，第二个就是冗余。

## 六、起因写作规则

### 6.1 起因是事件的引擎

起因必须作为情境 **bullet[1]** 出现。读完第一段必须能回答三个问题：

1. **为什么是这个人** — 选择逻辑（习惯/外部理由/意外/拒绝后的信任）
2. **为什么是这个时间** — 外部理由或内在动机转折
3. **为什么是这个方式** — 动机链条，从心理起点到行动落点

答不上来 = 起因缺口。

### 6.2 五种可信起因模式

| 模式 | 说明 |
|------|------|
| **利用习惯** | 基于第三者的固定行为模式（如每晚去河边、每天泡温泉）提前布局 |
| **外部理由** | 客观事件创造的条件（如住所改建留宿、导力器测试） |
| **意外触发** | 非计划事件：本意做A，意外导致B |
| **两段式拒绝→接受** | 第一次正义拒绝建立信任 → 第二次正式邀请 |
| **幌子** | 表面理由是A（请教文献），真实意图是B |

### 6.3 禁止总结性回顾

人物不会在脑子里总结自己的性经历。情境描写的是**此刻正在发生什么**，不是**过去发生了什么**。

| ❌ 禁止 | ✅ 正确做法 |
|---------|------------|
| "从第一次口交到今天，菲娜经历了..." | 直接写此刻的心理状态，不回溯总结 |
| "这已经是她第三次和凯尔..." | 写当下感受，历史由读者自己记得 |
| "回想起之前的每一次，她..." | 可以写"上次的触感还残留着"，点到为止，不展开历史清单 |
| "她的身体已经习惯了..." | 写此刻的具体反应，不替读者做总结 |
| "自从XX事件之后，她就..." | 因果可以写，但不展开回顾整个历程 |

**唯一例外**：角色对另一个角色**口述**某段经历时（如向菲娜讲述自己的过去），那是对话，不是内心总结。

**扩展禁止**：禁"第一次/首次"式断言（"她第一次黄昏来暖岩石""从没...今天是第一次"）——事实错误的元信息，且是机械感来源。写当下，不标"第一次"。

## 八点五、黎恩的血肉感写作规则

黎恩不是冷静旁观者。他是菲娜回归的锚点，是有血肉的人。他的反应必须有物理表现，禁止用分析性语言替代感受。

### 8.5.1 基础物理反应层

| 层面 | 必须写 | 示例 | 禁止 |
|------|-------|------|------|
| **声带** | 紧/降半度/从胸腔传出 | "他说'这小子'的时候声带是紧的""声音降了半度" | "他冷静地说""他淡淡地回应" |
| **心跳** | 变化的速度和传递方式 | "心跳透过肋骨传过来，比平时快了整整一拍""心脏跳得比想象中快" | 完全不写心跳变化 |
| **手** | 具体动作：捏/攥/扣/拽/抚 | "手指捏她后颈""攥她的手指到指节发白""帮她重新扣扣子" | 手部无动作，只写"他看着""他听着" |
| **胸腔** | 震/收紧/起伏 | "胸腔震了一下""笑是被她的笑牵出来的，没出声" | 只写"他笑了" |

### 8.5.2 高级反应模式

**笑必须有触发**：笑不是装饰品。每次笑之前，读者必须知道他在笑什么——被逗到、释放紧张、看着事情按预期发生、菲娜耳朵红得太明显了。

**关切先于分析**：事后黎恩先担心菲娜的安全与感受（"你还好吗？""不用怕了，有我在"），圣光/原理的讨论放在关切之后、用"说起来"轻轻带出——他不是冷静的观察者。


### 8.5.3 参考章节

以下章节是黎恩血肉感写作的金标准，遇到"怎么写黎恩"时直接参照：

| 章节 | 关键动作 | 可以学什么 |
|------|---------|-----------|
| 《意外的请求——踩踏与羞耻》 | 饶有兴趣地八卦、收紧手臂说"当然陪" | 从惊讶到接纳的弧线藏在动作里 |
| 《黑丝的学术观察——第一次羞辱实践》 | 主动找凯尔安排、闻菲娜的脚、事后抱她问下次 | 全程主动参与，用动作说话 |
| 《清晨的教学——黑丝与主动权》 | 沉默一息→低笑了一声→同意 | 沉默期间的消化过程 |

**《清晨的教学——黑丝与主动权》金标准拆解**：
- "菲娜看到他的眉毛动了一下"（菲娜在观察他——她看得到他的微表情，读者也看得到）
- "然后他低笑了一声"（笑有触发：听到了她刚才说的话。笑是"低笑"，声音有质地）
- 同意不是通过分析得出的，是通过"眉毛动→低笑→说好"这条物理反应链

**《矮人之屋的清晨——清理与裸足的唤醒（上）》金标准拆解**：
- "他靠在门板上，心脏跳得有点快"（物理位置+心跳——不说"他兴奋了"）
- "他脑子里过了两遍这句话。第一遍是震惊。第二遍是兴奋。"（拆开内心过程，每遍有独立标签。不是"他既震惊又兴奋"的混合概述）

**《矮人之屋的清晨——清理与裸足的唤醒（下）》金标准拆解**：
- "黎恩的青紫瞳里有血丝——心痒痒了一晚上，没睡好"（次日清晨的物理状态。不说"他昨晚很煎熬"——写血丝、写没睡好、写心痒痒）

### 8.5.4 黎恩对菲娜的爱——决策与温度

## 十、CRUD工作流

### 10.1 新增事件

```
Step 1: 确定位置
  ├── 确定目标章节和插入位置（如在事件40之后、41之前）
  └── 计算小数ID：40.5（如在章末则用 prev_id+1）

Step 2: 创建TXT
  ├── cp _TEMPLATE.TXT "目标章节/_NEW_事件名.TXT"
  ├── 第一行写 ID: 40.5（小数标记插入位置）
  ├── 按本文规则填写所有字段
  └── ★写情境时逐bullet对照§四对白温度（关键节点完整人话+角色声音速查）
      初稿即达到精修水准，避免"碎片大纲→多轮修复"的历史教训

Step 3: 修改自查四步（见 §10.2，写完必过，再进重编号）

Step 4: 重编号
  └── python scripts/renumber_events.py

Step 5: 构建+验证
  ├── python scripts/rebuild_all.py
  └── python scripts/story_tool.py validate
```

### 10.2 修改事件

```
编辑 TXT → 修改自查四步 → python scripts/rebuild_all.py → python scripts/story_tool.py validate → git commit
（无需renumber，编号不变）
```

**修改自查四步（每次改完必做，缺一不可）**：

1. **重读改动段落全文**：把改动所在 bullet 整段读一遍，不只读改的那几句。检查衔接、主语、时序是否通顺。重写比修改更容易漏——必须通读
2. **对白读出声**：改到的每一句对白读出声。像两个真人聊天吗？有没有"动词+逗号+短修饰"（§4.15 修饰后挂）、对仗格言、心灵鸡汤（§4.0.2/§8.5.4）？发现就改，别急着构建。顺带扫描callback点破（"上次/那次/那天/昨天"、章节编号、"弧线终点"式标签）
3. **字段联动**：改了情境，同步检查 核心/章节任务/章节终止条件/占有欲确认 里对应描述是否一致。删了情节节拍（如数次数、某个动作），就从这些字段里一并删掉
4. **跨章衔接**：（上）（下）章或连续弧事件，检查另一章的对应描述是否同步（黎恩知情/好感影响/事件细节/对白口径）

### 10.3 删除事件

```
python scripts/story_tool.py refs <ID>   # 检查交叉引用
→ 删除TXT文件
→ python scripts/renumber_events.py
→ python scripts/rebuild_all.py
→ python scripts/story_tool.py validate
```

### 10.4 移动事件（跨章节）

```
移动TXT到目标章节目录 → 改ID行为小数指定位置
→ python scripts/renumber_events.py
→ python scripts/rebuild_all.py
```
