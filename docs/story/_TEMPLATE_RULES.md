# 章节TXT模板填写规则

> **参照模板**：`_TEMPLATE.TXT`
> **权威写作铁律**：`../../CLAUDE.md`（第三、四节）
> **验证工具**：`python scripts/story_tool.py validate`

---

## 一、架构现状

- 纯数字编号，线性叙事，无分支
- 无触发条件、无玩家选择、无路线标签、无游戏变量
- 好感值仅12角色，0-100，纯叙事用途
- 章节存储：9个章节目录（`docs/story/{0：序章/ ... 8：后日谈/}`）
- NTRS融合线：共享时刻（禁忌释放）⇄ 回归时刻（占有欲爆发），两条线交替推进

## 二、文件名与ID规则

| 规则 | 说明 |
|------|------|
| 文件名 | `{ID}：{名称}.TXT`，如 `107：独占欲——黎恩的重新占有.TXT` |
| 目录 | 按章节分目录：`0：序章/` `1：试探和暧昧/` ... `8：后日谈/` |
| ID行 | 第一行必为 `ID: {number}`，纯数字，与文件名一致 |
| 新事件 | ID行填小数标记插入位置（如 `ID: 40.5`），renumber自动分配整数 |

## 三、字段填写规则

### 3.1 字段总览

| 字段 | 必填 | 说明 |

| `ID` | ✅ | 纯数字，新事件填小数插入标记 |

## 四、情境 bullet 写作规范

### 4.1 结构模板

```
bullet 1:   起因 + 场景设定：环境/状态/为什么此刻此地此人
bullet 2-4: 上升：渐进身体接触，每步有心理伴随
bullet 5-6: 高潮：最强体验 + 内心独白
bullet 7:   余韵：身体痕迹 + 第一句话/第一个眼神
```

### 4.2 bullet格式铁律

- 每条**1-3句话**，不超过80字（情感描写或性张力需要更长时允许突破）
- 按**时间顺序**排列，不在一条bullet里跳时间
- **第三人称**叙事，用角色名字或代词
- **不引用对话原话**逐字复述，叙事化总结即可。但角色在性爱中的声音/呻吟/喘息词（如"嗯啊""太深了""到了"等）必须保留，不可叙事化
- 全事件**4-8条bullet**，超过8条必须合并精简。NSFW事件因场景结构（触发→铺垫→渐进→高潮→余韵）可放宽至10条
- 相邻bullet**不得同义重复**：两句话能合并为一句就不写两句

### 4.3 bullet禁止事项

| 禁令 | 说明 |
|------|------|
| ❌ 元叙事总结 | 禁"从第一次X到后来Y""这是递进的终点""信任扩容到了边界"等跳出叙事的总结句 |
| ❌ 创作过程标记 | 禁"完全重写""新增""修改""和上一版相比"等版本/创作过程标记。事件文件是叙事权威源，不是写作日志。版本变更记在git commit中 |
| ❌ 括号补充 | 补充解释直接写进正文，不括号 |
| ❌ "不是X而是Y" | 直接写Y。禁否定X来衬托Y。**扩展**："不再是X，是Y"同属此类：说一件事是什么就够了 |
| ❌ 事件编号引用 | 情境/核心不得出现N##等编号，用描述性语言替代 |
| ❌ 商业词汇 | 禁"成本""效率""优化"等 |
| ❌ 空泛结尾 | 禁"为...支撑""奠定...基础"等套话 |
| ❌ 冗余自强化 | 禁"是X。[纯粹的/完全的/彻底的/真正的]X。"——说一遍。删"是X"，只留强化词。例："是满足。纯粹的满足。"→"纯粹的满足。" |
| ❌ 千篇一律的身体语言 | 禁"手在口袋里攥成拳""嘴角微微上扬""心跳漏了一拍""深吸一口气"等被用滥的肢体描写：找到属于**这个角色在这个时刻**的独有反应 |
| ❌ 无动因的笑 | 禁角色突然"笑了""闷笑一声"而没有前因。笑必须有心理触发（被逗到、释放紧张、自嘲、被干到脑子不清醒）。先写触发，再写笑 |
| ❌ 自我审视式反应 | 禁"说完之后自己被吓到了""自己先愣住了然后笑了""把自己逗笑了""不敢相信自己说了这种话""说完自己先僵了一瞬"。角色活在情境中。反应是对外部刺激的回应，不是对自己言行的第三方评论 |
| ❌ 目录/字段信息重复 | 禁在情境正文中重复章节名/阶段名等文件路径或字段已承载的信息。如事件已在`8：后日谈/`目录且阶段字段已标注"后日谈"，情境不写"后日谈的某个下午"，写"某个下午" |
| ❌ 可推断的中间反应 | A→B→C事件链中，如果B（如"沉默""笑了笑"）可以从A和C推断出来，删掉B。保留的节拍必须承载新信息 |

### 4.4 身体语言写作原则

每个人物表达紧张/兴奋/害羞的方式不同。禁止用通用cliché模板套在不同角色身上。

| ❌ 千篇一律 | ✅ 角色独有 |
|------------|-----------|
| 乔治"手在口袋里攥成拳" | 乔治耳根先红，然后手指开始无意识地摩挲导力器的外壳边缘 |
| 任何人"嘴角微微上扬" | 菲娜笑之前琥珀色眼睛先弯（她的专属特征） |
| 任何人"心跳漏了一拍" | 写具体的身体感受：黎恩觉得肋骨底下有什么东西轻轻揪了一下 |
| 任何人"深吸一口气" | 写为什么需要那口气：是压住什么，还是准备说什么 |

**原则**：读到身体反应时能认出"这是XX的角色反应"，而不是"这是紧张时的通用模板"。

### 4.5 标点使用规则

#### 破折号（——）全局禁令

破折号是强停顿符。**情境·核心·章节任务·章节终止条件中，非必要不可用。** 目标：全章0破折号。仅在思维断裂/突然转折时允许1处，且需能自辩"换句号丢了什么"。

**替代优先级**（一律优先替代，不保留）：
1. 句号 `.` — 完整的动作/情感断句
2. 逗号 `,` — 连续动作中的轻停顿
3. 不用标点直接续 — 紧凑的连续动作

| ❌ 滥用 | ✅ 替代 |
|--------|--------|
| "她整个人弹了一下——痒——和舒服无关" | "她整个人弹了一下，痒，和舒服无关" |
| "他低下头——舌尖贴上花瓣——她没有躲" | "他低下头。舌尖贴上花瓣。她没有躲。" |
| "她开始喘——很自然的喘——一点都不压抑" | "她开始喘，很自然的，一点都不压抑" |

**唯一可保留破折号的情形**：
- 思维断裂/突然转折：`她以为他要吻她——然后他把刀横在了她脖子前`（换句号无法传达转折的突然性）
- 若一段情境超过1处破折号，多余的必须替换

**破折号硬禁令**（以下场景0容忍）：

| 禁用场景 | ❌ 示例 | ✅ 替代 |
|---------|--------|--------|
| **不与转折词叠用** | "只是——她比较的对象是黎恩" | "只是她比较的对象是黎恩"（"只是"已标记转折） |
| **不用于方式状语** | "手覆上去——带着她的节奏" | "手覆上去，带着她的节奏"（逗号足够） |
| **不用于状态后置解释** | "肉棒露出来——已经半硬了" | "肉棒昂扬着弹跳出来"（状态融入动词） |
| **不用于插入性强调** | "那是他的声音——安全的、柔软的" | "那是他安全的、柔软的声音。"（前置定语） |
| **不用于名称字段** | 名称中禁用破折号以外的全角—— | 名称中用`——`分隔前后半段是唯一例外 |

**创建自检**：写完情境后grep `——`。目标0处。如有，逐条自问"换句号丢了什么"——答不上来就改句号。

#### 标点承载语气

标点不是中性的。同一句话，不同标点 = 不同语气 = 不同人物状态。

| 标点 | 传达的语气 | 适用场景 |
|------|----------|---------|
| `~` | 轻快/分享/撒娇 | 菲娜分享快乐："你看~两个人，四只手。" |
| `！` | 兴奋/强调/邀请 | 快感中的邀请："他快到了，一起！" |
| `，` | 暖性连接/软化祈使 | 温柔指导："慢一点，他很敏感的。" |
| `。` | 冷静陈述/确定 | 结论/确认："你是我的。" |
| `……` | 自行消音/犹豫 | 亚莉莎紧张："没有，但是……" |
| `——` | 外力截断/强转折 | 思维断裂："她以为他要吻他——然后刀横在了她脖子前" |

**关键区分**：`——`是外力截断（被中断），`……`是自行消音（犹豫/拖尾）。不可互换。

**NSFW场景中女性角色台词**：句号过多 = 冷淡机械。适当使用`~`和`！`标记语气层次。每事件情境`~`不超过2处，`！`不超过3处。

### 4.6 人物保护规则

> **精简永远不能以牺牲人物为代价。** 破折号精简、bullet长度等格式约束是下限。低于下限会导致文本破碎。但人物必须活着。

#### 禁止删除清单

| 类别 | 不可删除的内容 | 说明 |
|------|---------------|------|
| **心理博弈** | 内心矛盾、两个声音交替、想做但不敢、转身又折返 | 人物的选择来自真实的心理过程，不是"她决定了"三个字 |
| **情绪波动** | 脸红、推眼镜频率变化（艾玛）、耳朵红（法林）、琥珀色眼睛先弯再笑（菲娜） | 这些是人物独有的"表情指纹" |
| **性爱声音** | 呻吟/喘息/呜咽的原词："嗯啊""太深了""到了""又到了" | 性张力的核心载体，不能叙事化、不能压缩、不能删除 |
| **感官细节** | 温度（烫的/温热的）、湿度（湿透了/淌到）、身体反应（弹了一下/痉挛/收紧） | 性爱不是机械动作。感官细节是读者"在场"的通道 |
| **事后余韵** | 腿合不拢、精液淌出、靠在石壁上喘、手心还是烫的、笔记本上的速记 | 事后是情感落地。删掉事后等于删掉整个事件的情感重量 |
| **人物独有反应** | 艾玛推三次眼镜=决定、摘眼镜=交付；法林结巴"请…是的…"、耳朵红到脖子；菲娜笑之前眼睛先弯；多尔金沉默+嘴角极轻微弧度 | 读到身体反应能认出"这是XX" |

#### 精简的正当对象

精简应该针对：
- 同义反复（同一个意思说了两遍）
- 过渡性叙述（"然后她站起来，然后她走到门口，然后她推开门"→"她推开门走了出去"）
- 多余的副词堆砌（"非常""极其""无比"等）
- 元叙事总结（见§4.3禁止事项）

精简不碰：人物的心理过程、感官体验、独有身体语言、性爱中的声音和反应。

#### 菲娜（Seraphina）阶段特征

### 4.7 修饰融入动词

写即是示。不先写动作再挂破折号解释状态，直接写一个带有状态的动词。

| ❌ 后挂解释（拖沓） | ✅ 融入动词（紧凑） |
|-------------------|-------------------|
| "嘴唇贴上脖子——很轻的吻。然后滑到锁骨。" | "嘴唇轻轻贴上脖子，然后滑到锁骨。" |
| "她关上门——动作很轻。" | "她轻轻关上门。" |
| "他低下头——舌尖贴上花瓣——她没有躲。" | "他低下头。舌尖贴上花瓣。她没有躲。" |

中文动词系统有丰富的副词/补语来表达方式与程度。"很轻的吻" = "轻轻贴上"。"很快的跑" = "冲出去"。

### 4.8 功能性对话可概述

如果一段对话的唯一作用是传递"接下来要做什么"的信息（没有性格、没有弦外之音、没有情绪纹理），改为概述叙事。

**判断标准**：删掉这段对话后，读者是否失去了对角色的某种理解？如果只是失去了"他们决定做X"的信息，概述即可。

| ❌ 功能对话（可用概述替代） | ✅ 概述 |
|--------------------------|--------|
| `"帮我一个忙。""什么。""一起。让凯尔知道他不是不行。"` | `她神秘地让亚莉莎帮她一个忙。` |
| `"罗恩会在意吗。""不会。满月的时候他自己都说狼人不太一样。""那就来。"菲娜站起来拉她。` | `菲娜确认了"罗恩不会在意"之后，站起来拉亚莉莎。` |

**概述的好处**：保留悬念、消除已知信息的冗余复述、缩短篇幅腾出空间给真正有性格的对话。

**必须保留的对话**：承载性格（凯尔的碎碎念）、情绪（亚莉莎的傲娇）、潜台词（菲娜的"你是我的"）、性爱中的声音（呻吟/喘息原词）。这些不可概述。

### 4.9 碎片句用于强调，不用于叙事流水

三字句/四字句的连续轰炸适合情绪爆发的顶点，不适合平实的记忆回溯或动作描写。

| ❌ 碎片过载（平实场景） | ✅ 适度合并 |
|----------------------|-----------|
| "她想起了月语者。后入的时候。满月形态。那个尺寸。" | "她想起了月语者后入的时候。"（"满月形态""那个尺寸"已隐含） |
| "她站起来。走到门口。推开门。回头看。" | "她推开门，回头看。"（连续动作用逗号串） |

**判断标准**：此刻的情绪是"断裂"还是"流动"？断则碎（高潮、震惊、顿悟），流则合（回忆、移动、日常动作）。

### 4.10 工具格"用"字不省

中文需要工具格标记：

| ❌ 缺"用" | ✅ 完整 |
|----------|--------|
| "嘴替代了手" | "用嘴替代了手" |
| "手指擦掉精液" | "用手指擦掉精液" |
| "舌头舔过冠状沟" | "用舌头舔过冠状沟"（或"舌尖舔过"（"尖"已含工具义）） |

**例外**：身体部位直接作主语时不需要"用"。"嘴唇裹住龟头""舌尖画圈""手握住茎身"均合法，因为这些部位本身就是动作的发出者。

### 4.11 相邻叙事单元衔接

**一bullet一功能**：每个情境bullet承担单一叙事功能。读一遍bullet，能用一个短语概括它在做什么（"建立场景"/"菲娜内心挣扎"/"行动决定"）。如果不能，拆。

**bullet间必须有因果/时序桥梁**：相邻bullet之间需要一个词/短语建立连接。

| ❌ 无桥梁 | ✅ 有桥梁 |
|---------|---------|
| Bullet 1: …她神秘地让亚莉莎帮她一个忙。| Bullet 1: …她神秘地让亚莉莎帮她一个忙。|
| Bullet 2: 亚莉莎的脸从粉色变成了红色。| Bullet 2: **听完菲娜的请求，**亚莉莎的脸从粉色变成了红色。|

常用桥梁："听完……之后""与此同时""不一会儿""在……的同时""然而""与此相对"。

### 4.12 连续对话归属

当两个角色交替说话且上下文无法明确判断说话者时，必须加归属。如果前文已明确谁在对谁说话，且对话内容本身能判断说话者（凯尔不会说"黎恩的大鸡巴"、菲娜不会说学者的碎碎念），可不加归属。

## 六、起因写作规则

### 6.1 起因是事件的引擎

起因必须作为情境 **bullet[1]** 出现。读完第一段必须能回答三个问题：

1. **为什么是这个人** — 选择逻辑（习惯/外部理由/意外/拒绝后的信任）
2. **为什么是这个时间** — 外部理由或内在动机转折
3. **为什么是这个方式** — 动机链条，从心理起点到行动落点

答不上来 = 起因缺口。

### 6.2 五种可信起因模式

| 模式 | 说明 |
|------|------|
| **利用习惯** | 基于第三者的固定行为模式（如每晚去河边、每天泡温泉）提前布局 |
| **外部理由** | 客观事件创造的条件（如住所改建留宿、导力器测试） |
| **意外触发** | 非计划事件：本意做A，意外导致B |
| **两段式拒绝→接受** | 第一次正义拒绝建立信任 → 第二次正式邀请 |
| **幌子** | 表面理由是A（请教文献），真实意图是B |

### 6.3 禁止总结性回顾

人物不会在脑子里总结自己的性经历。情境描写的是**此刻正在发生什么**，不是**过去发生了什么**。

| ❌ 禁止 | ✅ 正确做法 |
|---------|------------|
| "从第一次口交到今天，菲娜经历了..." | 直接写此刻的心理状态，不回溯总结 |
| "这已经是她第三次和凯尔..." | 写当下感受，历史由读者自己记得 |
| "回想起之前的每一次，她..." | 可以写"上次的触感还残留着"，点到为止，不展开历史清单 |
| "她的身体已经习惯了..." | 写此刻的具体反应，不替读者做总结 |
| "自从XX事件之后，她就..." | 因果可以写，但不展开回顾整个历程 |

**唯一例外**：角色对另一个角色**口述**某段经历时（如向菲娜讲述自己的过去），那是对话，不是内心总结。
