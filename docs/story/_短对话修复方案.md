# 短对话修复方案

> **目标**：修复章节中因大纲关键词直接放入引号而产生的机器人式短对话。
> **原则**：质量唯一指标。无脚本，无捷径，每章LLM逐章精修。

---

## 一、问题定义

### 1.1 根因

早期章节大纲被压缩后，关键词直接充当了对话。LLM生成情境文本时未将大纲占位符展开为自然语言，而是保留了电报式短句。

### 1.2 七种问题形态

| 形态 | 描述 | 典型示例 |
|------|------|---------|
| **A. 单字回应重大提案** | 对复杂情感/重大决定的全部回应≤2字 | 菲娜问能否和别人做→黎恩回"好。"(Ch268)；菲娜提让腐化入体→黎恩回"好。"(Ch517) |
| **B. 关键词充当对话** | 大纲关键词直接放进引号 | 黎恩提议菲娜找矮人→"感谢。"(Ch165)；让菲娜去和别人做→"去吧。"(Ch386) |
| **C. 句号断句型** | 句子被句号劈成碎片 | "我不知道。就是。想要。"(Ch155凯尔)；"雷恩让我，给他，用手。"(Ch194菲娜) |
| **D. 电报式指令** | 给出指令像下达军令 | "坐那边。""裤子脱了。"(Ch158菲娜对凯尔)；"后天傍晚。来我们房间。"(Ch158黎恩) |
| **E. 短促交替型** | 两人对话每句都1-3字来回 | 黎恩"那就再试。"菲娜"你陪我吗。"黎恩"陪。"(Ch155) |
| **F. 叙事自曝型** | 叙事文本数字数 | "他说了一个字"(Ch342)；"两个字"(Ch275/Ch448)；"三个字"(Ch612) |
| **G. 对话零引号** | 大纲直译对话不带引号，冒号裸挂或混入叙事 | `直接问黎恩: 听说你喜欢脚`(Ch172)；全章对话无引号(Ch202) |

**形态E的三个子类**：

- **E1 — 情感足够型**：对话短但上下文已承载情感（"然后呢？""舒服。"）。**不需要修。**
- **E2 — 信息空洞型**：对话短且上下文无补充情感（"忘了""没什么""陪。"）。**必须修**——修法不是扩写对话本身，而是补说话时的表情+身体+语气。
- **E3 — 纯沉默型**：`"..."`——空的无信息沉默。必须替换为内心过程或动作过渡。

### 1.3 判断标准

一句话是否需要修复，取决于**语境**，而非字数：

- ✅ **正常的短**：情绪激动说不完整（高潮后、哭泣中、极度疲惫）、角色刻意简洁（菲的沉默、多尔金的锻造专注）、一句话已包含完整信息（"我会等他"Ch536）
- ❌ **需要修的短**：短句是大纲关键词的直译、回应与情境情感重量不匹配、叙事自曝"说了X个字"、多个1-3字对话连续出现形成电报感

### 1.4 黎恩：核心角色特殊说明

**黎恩不是"少话人设"**。他是温柔、有幽默感、喜欢吐槽的灰色骑士。

- 禁止把他写成只会点头、只会"嗯"、只会平静注视的角色
- 简洁要有情感纹理："如果你确定的话""那就试——我会在旁边"，而非"好。""可以。"
- 原文黎恩全程无表情/语气词/内心活动→补表情+身体+语气三件套
- 对菲娜：温柔中有调侃，认真中有温度（"你跑回来就是为了问我"）
- 对同伴：有距离感但不冷漠，吐槽点到为止，指令带解释
- 对重大决定：不是"好"一个字，而是表达出他为什么同意、他在想什么
- 会八卦、会尴尬地笑、会说"呃""啊""对不起啊菲娜"

**黎恩温度的语言学特征**（补对话时的工具箱）：

| 元素 | 示例 | 功能 |
|------|------|------|
| 语气词 | `呃` `呀` `啊` | 非正式、放松、人类 |
| 称呼名字 | `菲娜` | 亲密关系的锚点 |
| 道歉句式 | `对不起啊` | 温柔、在意对方感受 |
| 旁白定性 | `带着歉意温柔地` | 为动作注入情感矢量 |
| 笑容分层 | `尴尬地笑` `笑容里带着点坏` | 不同笑对应不同情绪，而非模板"微微一笑" |
| 问号 | `...没什么呀？` | 上扬语调=心虚/调皮，区别于陈述句的冷 |

## 二、修复方法

### 2.1 两种修复路径

| 路径 | 适用场景 | 做法 |
|------|---------|------|
| **路径1：展开为叙述** | 短对话承担的是"功能传递"而非"性格表达" | 删除引号，将关键词融入叙事。如"感谢。"→"黎恩觉得矮人们帮了这么多，是该好好谢谢他们。" |
| **路径2：展开为自然对话** | 短对话所在情境需要角色间有真实交流 | 保留引号，将短句扩展为带角色性格的自然语言。如"陪。"→"当然陪你。这种事我不会让你一个人。" |

**选择判断**：
- 场景依赖角色间言语互动推进情感/关系？→ 路径2
- 短句只传递功能性信息（"去吧""好"）且可转化为叙事？→ 路径1

### 2.2 核心模型：情感填充五层

**AI的默认心智模型：对话 = 信息传递。** 这是修复失败的根本原因。

```
原始：菲娜看了他很久。然后她说了两个字。"明早。"
Agent修复：菲娜看了他很久。然后她说："明早。"            ← 删触发词，对话没碰
AI建议： 菲娜看了他很久。然后她说："明天早上，镜湖边。"   ← 信息更完整，还是在传话
用户修复：菲娜眨了眨眼睛，她察觉到凯尔心里有一股沉重的情绪。菲娜摸了摸凯尔的头，惹得凯尔坚毅的脸庞染上一抹红晕。菲娜温柔的声音让凯尔忐忑的心情逐渐平复下来，她说："放心吧凯尔，明天早上我陪你一起去。"
```

用户修复版补了五层：**感知**（察觉到沉重情绪）→ **触碰**（摸了摸头）→ **对方反应**（脸染红晕）→ **声音质地**（温柔的声音）→ **情绪效果**（心情逐渐平复）→ 最后才是对话。

**正确的模型：对话 = 情感连接 + 信息传递。** 情感在前，信息在后。

**修复前必须问的三个问题**：

1. **说话的人在感知什么？** 她在看对方的哪一点？她察觉到了什么情绪？
2. **说话的人和对方有没有身体接触？** 如果没有，现在这个情境里该有吗？
3. **对方有没有反应？** 听的人听了之后脸上/身体/呼吸有什么变化？

三个问题全部答不出 = 你正在做信息填充，不是情感填充。

**判定测试**：遮掉引号内的对话，只看引号外的叙事。叙事里有没有角色在感知对方、触碰对方、对方有身体反应、声音有质地？叙事空转（"看了他很久""然后她说"）+ 对话空转（"明早。"）= 两个加在一起还是空的。

### 2.3 单字回应的解法

单字回应读起来像机器人，**根因在于角色说那个字的同时没有表情、没有停顿、没有身体反应、没有语气词。** 字数从来不是问题。

修复单字回应 ≠ 把单字扩成长句。修复 = 给单字加上人类说出来之前和之后的全部反应。

**规则1：单字回应必须配上"怎么说"的信息。** 每句引号内对话都要回答：脸上什么表情？身体在做什么？语气是怎样的？

**规则2：沉默（`"..."`）不能空着。** `"..."`不是对话——是对话的缺席。必须换成：内心过程（"在思考怎么说"）、动作描写（"他手指往下"）、或直接删除沉默用动作过渡。

**规则3：短对话可以是好的。** "然后呢？""舒服。"——好的短对话，情感已在上下文中。坏的短对话是那种**需要情感但只有信息**的短对话。

### 2.4 各形态修复示例

**形态A（单字回应）**：
```
修复前：她说出那个念头时声音很轻：下次，让它们进到里面。黎恩收紧手指。"好。"
修复后：她说出那个念头时声音很轻：下次，让它们进到里面。黎恩收紧手指。沉默了一息。"你确定？"她点头。他没有立刻回答，拇指在她手背上慢慢画了一个圈。"如果你确定——那就试。但我会在旁边。全程。"
```

**形态B（关键词充对话）**：
```
修复前：他一边指交一边说："多尔金和哈根。你可以去找他们。""找他们，嗯，干嘛。""感谢。"
修复后：他一边指交一边说："多尔金和哈根——你不觉得他们帮了我们很多吗？""找他们...你是说——"她的声音被手指打断了一拍。"嗯。""用那种方式感谢？""如果你愿意的话。"琥珀色眼睛瞪大，然后被手指扣到说不出话。
```

**形态C（句号断句）**：
```
修复前："我不知道。就是。想要。"
修复后："我也不知道为什么。就是...想要。"（保留断句感但用省略号做自然停顿，而非机械句号）
```

**形态D（电报指令）**：
```
修复前："后天傍晚。来我们房间。"
修复后："后天傍晚，来我们房间吧。三个人一起试一次——也许没那么可怕。"
```

**形态E（短促交替）**：
```
修复前："那就再试。""你陪我吗。""陪。"
修复后："那就...再试一次。""你陪我吗？"黎恩收紧手臂。"当然陪。我不会让你一个人面对。"
```

**形态F（叙事自曝）**：
```
修复前：多尔金改完后看了他一眼。不错。两个字。
修复后：多尔金改完后看了他一眼，下巴点了一下。那是他表达"不错"的方式——从来不需要多说。
```

**形态G（对话零引号）**：
```
修复前：菲娜直接问黎恩: 听说你喜欢脚
修复后：菲娜看着黎恩，声音轻得几乎听不见："听说你喜欢脚？"
```

### 2.5 修复中的常见错误

#### 破折号滥用

叙事流中用`——`替代`。`，导致文本布满破折号：

```
❌ 咬了一下嘴唇——她很少咬嘴唇      ✅ 咬了一下嘴唇。她很少咬嘴唇
❌ 伸手握住他的肉棒——脚趾在黑丝下蜷紧  ✅ 伸手握住他的肉棒，脚趾在黑丝下蜷紧
❌ 僵了一秒——菲娜跪在床上           ✅ 僵了一秒。菲娜跪在床上
❌ 回头看他——琥珀色眼睛             ✅ 回头看他，琥珀色眼睛
```

破折号`——`仅限三种用途：**标题分隔**（`名称: 前半段——后半段`）、**对话被打断**（`"你怎么——"`）、**对话中声音延长/中断**。叙事描写和分析字段一律禁止使用`——`。

修复碎片化句号堆砌时，**禁止用`——`机械连接两个碎片**——那不是修复，是把句号换成了破折号，碎片还是碎片。正确做法是：
- 用逗号串联为连贯叙事流：`A，B，C。`
- 用句号做真正的句子边界（两句话确实是两个独立意思）
- 必要时增删句子，让信息有机融入前后文，而非在两个旧碎片之间插一个标点完事

#### 短句句号堆砌（`A。B。→ A，B。`）

两句都是短句，用`。`断开，且B是A的直接延续（同一角色的连续动作/同一条观察链/同一个因果链）→ `。`改`，`合并：

```
❌ 那是他在数步子。她认出来了。           → ✅ 她认出来了，那是他在数步子。
❌ 他在头痛中停住脚步，看了片刻。然后叹了一口气。 → ✅ 他在头痛中停住脚步，看了片刻，然后叹了一口气。
❌ 她打了一个酒嗝。然后靠在了菲娜肩上。     → ✅ 她打了一个酒嗝，然后靠在了菲娜肩上。
❌ 她撅起了嘴。嘴唇因为酒精比平时红润。     → ✅ 她撅起了嘴，嘴唇因为酒精比平时红润。
❌ 他卡壳了。她的耳尖红了。               → ✅ 他卡壳了，她的耳尖红了。
❌ 他闭上眼。深呼吸。                     → ✅ 他闭上眼，深呼吸。
❌ 他射了。精液涌进蜜穴最深处。            → ✅ 他射了，精液涌进蜜穴最深处。
❌ 劳拉别过脸去。在忍笑。                 → ✅ 劳拉别过脸去，在忍笑。
```

**判定**：读一遍。A句号B——脑子里有没有"断开再重连"的感觉？如果有，且A和B是同一个人的连续动作/同一条观察，就合并。两句是不同角色、不同场景、或有意的节奏停顿→保留`。`。

注意：合并是改标点不改句子——不增删词语，只把`。`换`，`。如果合并后句子过长（超过约40字），考虑保留句号或调整断句位置。

把`。`改成`，`或`...`或`——`，但句子本身没变——这是标点替换，不是修复。**增删句子才是血肉，标点只是骨架。**

修复一章时先问：
1. **有什么可以删？** 数据卡碎片、无信息增量的引导句、静态外貌陈列
2. **缺了什么因果？** 角色此刻在想什么？为什么说这句话？情感转变的触发点？
3. **角色有没有说话的空间？** 沉默的角色需要内心，活跃的角色需要动作

#### 短对话修复 ≠ 扩写

修复1-3字短对话的**第一反应**不是把字数变多，而是**在对话前后补情感层**：

```
修复前："明早。"
修复后：菲娜看了他很久。凯尔在等她拒绝——他习惯了被拒绝。但她的琥珀色眼睛在他脸上读到了一些他没有说出口的东西。"明早。镜湖边，天一亮就去。"
```

✅ 补了感知 + 对方心理状态 + 对话顺势扩展
❌ 只把"明早"改成"明天早上" → 字数变了，情感没变

## 三、写作规则与边界判定

修复过程中必须遵守以下规则。这些不是在修对话之外多做的事——是修复对话过程中必须同时完成的工作。

### 3.1 标点织体

中文句号是重分隔符。叙事流内部的连贯动作/感知/情感不应被句号切割。句号只用于真正的句子边界。

| 原始 | 改为 | 功能 |
|------|------|------|
| `。` | `，` | 碎叙事句合并为流水叙述 |
| `。` | `...` | 对话中的犹豫/害羞/声音破碎 |
| `。` | `？` | 疑问句必须以问号结尾 |
| `。` | `！` | 撒娇/兴奋/情感爆发 |
| `。` | `——` | 序列引导（破折号+顿号替代句号列表）|

### 3.2 去角色数据卡化

叙事不是角色设定卡。身高、外貌、状态描述不应以独立句陈列。外貌信息嵌入动作和推理链中，而非作为独立碎片。

```
❌ 175cm的学者仰面躺着。
❌ 脸是红的。眼睛是琥珀色的。
✅ 黎恩稍微有点惊讶，紫青色的眼瞳微微睁大了，黎恩之前以为凯尔只是有点足控，没想到凯尔还有点这方面的癖好。
```

**数据卡碎片的精确边界**：

| 例句 | 违规？ | 原因 |
|------|:--:|------|
| `175cm的学者仰面躺着。` | ❌ | 身高与画面无关，纯档案陈列 |
| `脸是红的。眼睛是琥珀色的。` | ❌ | 静态外貌碎片 |
| `D罩杯的胸脯在满月下泛着淡蓝的光。` | ✅ | 罩杯嵌在感官画面里，数值在做修辞 |

**判定**：身体数值/规格词是否嵌在感官画面中、服务于当下的视觉/情色强调？是→保留。是否独立成句只报数据？→删或融入动作流。

### 3.3 禁止句式

#### "不是...是..."迂回否定 — 禁的是结构，不是词汇

禁的是**"否定A→断言B"的pivot结构**，不是禁"不是""没有"这些词本身。

**基准形态**：

| 例句 | 违规？ | 原因 |
|------|:--:|------|
| `"不是质问——是问诊"` | ❌ | 否定A→断言B，标准pivot |
| `"不是在结巴。是在想怎么排列"` | ❌ | 否定A→断言B |
| `"照明不是它的目的"` | ✅ | 只有否定，没有pivot到B |
| `"不是别人的"` | ✅ | 对话中的直接否定，无pivot |

**三类变体**：

| 变体 | 模式 | 示例修复 |
|------|------|---------|
| 成对否定 | `没有A，也没有B` | `那一个字里没有犹豫，也没有试探` → `那一个字干脆笃定` |
| 双重否定链 | `不是A，不是B，是C` | `不是滴不是落，是砸` → `砸在屋顶上` |
| 标准pivot | `不是A，是B` | `不是犹豫，是在找说法` → `在找说法` |

**判断测试**：删掉"不是A"部分，句子还完整吗？
- ❌ "不是质问——是问诊" → 直接写"她在问诊"
- ✅ "照明不是它的目的" → "不是"承载信息，不删

**修复公式**：`"不是A，是B"` → 直接写B。`"没有A，也没有B"` → 直接写肯定句。`"不是A，不是B，是C"` → 直接写C。

> **警惕**：修迂回否定时不能顺手加`——`变成破折号+解释。`"没有犹豫"→"干脆笃定"`即可，不要写成`"干脆笃定——他比她自己更清楚"`。

#### Form F "说了X个字" — 数字是信息还是修辞？

禁的是**把数字本身当信息**的机械计数。允许**借数字强调角色特征**的修辞用法。

| 例句 | 违规？ | 原因 |
|------|:--:|------|
| `"两人全程没超过十个字"` | ❌ | 数字=全部信息 |
| `"多尔金说了两个字"` | ❌ | 在数多尔金说了几个字 |
| `"但她只说了一个字：嗯"` | ✅ | "一个字"在强调劳拉寡言，修辞而非计数 |
| `"三个词，一个比一个轻"` | ✅ | 数字服务于情感推进 |

**变体：数词+情感后缀**（"X个字"后挂情感解释）：
- ❌ `"脚酸。"两个字被呼气的尾音托着，软软的` → ✅ `"脚酸。"尾音软软的`
- ❌ `"走。"一个字，但那双黄绿眼睛...` → ✅ `"走。"那双黄绿眼睛...`
- ❌ `"好。"一个字，但里面有他...` → ✅ `"好。"里面有他...`

**判断测试**：删掉"X个字"部分，句子损失的是信息还是修辞？损失信息→Form F违规。损失修辞→可能OK。

### 3.4 修饰后挂（状语类）

状语修饰语以逗号短尾挂在动词后违规，必须前置融入动词。

- ❌ `他笑了一下，很轻。` → ✅ `他轻轻笑了一下。`
- ❌ `她点头，很慢。` → ✅ `她慢慢点头。`
- ❌ `她轻声说，然后含进去，缓慢，一寸一寸。` → ✅ `她轻声说，然后一寸一寸缓慢地含进去。`

**判定**：逗号后只挂无主语的短修饰（很轻/缓慢/一寸一寸）即违规；带主语的完整小句不算。

**修复公式**：把所有后挂修饰移到动词前作状语或融入动词，动作短语一口气写完。

### 3.4b 定语后挂 — 修饰名词的成分被逗号切到名词之后

**原理**：中文定语天然前置（`X的N`）。当定语被逗号切到名词后面独立成句，形成`N，X的。`结构时，读者需要回跳补上修饰关系，阅读流被切断。

这不是标点问题——是"修饰方向"问题。英文习惯后置定语从句（the scales, which weren't there before），中文必须前置（以前没有的鳞片）。

**核心模式**：`[名词]，[修饰该名词的定语]的。` → `[定语]的[名词]。`

```
❌ 他吻部周围多了几片浅灰鳞，以前没有的。       → ✅ 他吻部周围多了几片以前没有的浅灰鳞。
❌ 一条弯弯曲曲的线，从页面上方垂到下方，李子色的。 → ✅ 一条李子色的弯弯曲曲的线从页面上方垂到下方。
❌ 心脏还在狂跳，被雷吓的。                    → ✅ 被雷吓得心脏还在狂跳。
❌ 她的头发，李子色，刚洗过，扫在他的吻部侧面。    → ✅ 她刚洗过的李子色长发扫在他的吻部侧面。
```

**四种子类型**：

| 类型 | 模式 | 示例（错→对） |
|------|------|--------------|
| **形容词定语后挂** | `N，adj的。` | `浅灰鳞，以前没有的。` → `以前没有的浅灰鳞。` |
| **颜色/形态定语后挂** | `N，颜色/形态的。` | `一条线，李子色的。` → `一条李子色的线。` |
| **被字结构后挂** | `动作，被X的。` | `心脏狂跳，被雷吓的。` → `被雷吓得心脏狂跳。` |
| **所属/来源定语后挂** | `N，来源的。` | `一个调子，她妈妈唱的。` → `她妈妈唱的一个调子。` |

**判定测试**：逗号后面那段`...的`描述的是谁/什么？如果答案是逗号前面的名词 → 定语后挂，前置修复。如果`...的`自成独立判断（如"这是对的。"）→ 不属于此模式。

**注意区分**：
- 同位语（`他定住了，猎人的绝对静止。`）→ 不修，这是有意停顿的修辞
- 对话中的后挂（`"那种。我认得的。"`）→ 角色声音，不修
- `A的，B的`对举（`暖的贴凉的，软的贴鳞片。`）→ 有意节奏，不修
- 真正的定语后挂（`N，修饰N的。`）→ **必修**

**修复公式**：把`，...的。`中的定语移到它修饰的名词前面，删除逗号，必要时微调语序使其通顺。

### 3.5 后置解释句

叙事已把内容展示完，后面再补一句短解释贴标签——完全多余。直接删除。

```
❌ 黎恩当晚的占有比任何一次都凶。是确认。    → ✅ 黎恩当晚的占有比任何一次都凶。
❌ "不要，"她说得很干脆——是对他说的，也是对自己说的。 → ✅ "不要，"她说得很干脆。
❌ 黎恩看懂了——是"满意了吗"。              → ✅ 黎恩看懂了。
```

**变体：`，是XX` / `。是XX`判断句**——叙事已呈现完画面，句末用`，是XX`或`。是XX`补一个判断标签。同样删除或有机融入：

```
❌ 青紫瞳里有一层极少展示的光，是饶有兴致的戏谑。  → ✅ 青紫瞳里有一层极少展示的光，显示出饶有兴致的戏谑。
❌ 碰了一下自己的耳尖。是烫的。                → ✅ 碰了一下自己烫烫的耳尖。
❌ 坐垫歪了一个，是独自坐了很久的证据。          → ✅ 坐垫歪了一个，都是独自坐了很久的证据。
❌ 是在读。他在读她的身体语言。                 → ✅ 他在读她的身体语言。（删"是在读"）
❌ 是被这段对话吓得肾上腺素接管了神经系统。       → ✅ 被这段对话吓得肾上腺素接管了神经系统。（删"是"）
```

**判定**：删掉`是XX`部分，前文表达是否完整无损？完整→删。`是XX`部分有前文没有的新信息？有→保留新信息融入前句，去掉`是`。

### 3.6 叙事破折号禁令

叙事描写和分析字段中，`——`一律禁止——无论一句内出现几个。破折号仅限三种用途：标题分隔、对话被打断（`"你怎么——"`）、对话中声音延长/中断。修复：叙事流中出现`——`一律改为逗号或句号。两个碎片被`——`机械连接→拆回两句或有机融合为一句话。

- ❌ `她的额头抵着他的额头——鼻尖碰鼻尖——嘴角翘着。` → ✅ `她的额头抵着他的额头，鼻尖碰鼻尖，嘴角翘着。`

角色对话中的断续破折号（`"我——我——不是——"`）不算——那是口吃/紧张的表现，属角色声音。

### 3.7 逗号悬停与文艺腔

收尾短动词不需要用逗号隔出戏剧化停顿：

- ❌ `她蹲在玲伸手就够得到的地方，等着。` → ✅ `她蹲在玲伸手就够得到的地方等着。`

补写叙事取最短直路，不绕弯：

- ❌ `陪玲把这场哭哭完。` → ✅ `陪玲哭完。`

文言词不得混入现代叙事流：

- ❌ "便无处遁形""便在同伴面前炸开" → ✅ 走当代白话直路

### 3.8 头部字段AI元评价

核心/章节任务/章节终止条件中出现的AI/系统层面元评价必须删除：

```
❌ 核心: ……让玩家自由探索（减少AI酒馆故事的记忆压力）
✅ 核心: ……让玩家自由探索
```

判定：句子谈论AI、酒馆、记忆压力、token等叙事外层面→删；谈论故事内设计意图→留。

### 3.9 事实与连续性检查

修复时必须验证：

1. **外貌canon**：瞳色/发色/发型对照角色文件
2. **外貌代称指代**："紫发少女"类代称是否指错了人
3. **物理场景**：户外无天花板，隔衣物看不见颜色形状
4. **镜头可知性**：视角持有者不知道的事不写
5. **计数与前文一致**："第三次"必须真有前两次
6. **跨章道具/状态连续**：上章挂脖子上的东西，本章不能从口袋掏出
7. **跨章复制句**：同一句抒情旁白不得出现在相邻章节，补写时句子眼熟就grep确认唯一性

## 五、工作流

每次处理一个阶段（用户指定）。分**四步**串行：**诊断A → 诊断B → 修复 → 复查**。

核心经验：Form F/AI元评价（诊断A）和短对话碎片（诊断B）是**两类不同问题**，需要两轮独立扫描。诊断A靠主对话逐章精读，诊断B靠grep精确抓取后人工过滤。

---

### 5.1 诊断A — 逐章精读（Form F + AI元评价 + 形态G）

主对话逐章阅读全部章节，重点在**肉眼可辨的七形态问题和元数据污染**。

#### Step 0 — 准备

1. 必读：`docs/character/黎恩.TXT` `docs/character/Seraphina.TXT`
2. **通读三个金标准章节全文**（用户逐句精修定稿，修复文风最高参照，只读不改）：
   - `docs/story/3：渐进接触/155：意外的请求——踩踏与羞耻.TXT`
   - `docs/story/3：渐进接触/158：黑丝的学术观察——第一次羞辱实践.TXT`
   - `docs/story/3：渐进接触/165：枕边的提议——口交中的闲聊.TXT`
3. 阅读该阶段涉及的其他角色文件（≥3个关键角色）

#### Step 1 — 逐章阅读

1. 读取TXT全文（5章/批）
2. 重点扫描"情境"字段中的对话：形态A(单字回应)、B(关键词充对话)、C(句号断句)、D(电报指令)、E2(信息空洞)、E3(纯沉默)、G(对话零引号)
3. 在"核心""章节任务""章节终止条件"中检查：Form F 和 AI元评价

#### Step 2 — 输出诊断A清单

保存到 `世界书\方案\短对话诊断_{阶段名}.md`。

```markdown
## Ch275 — 太刀符文的蓝图

| 位置 | 原文 | 类型 | 诊断 | 建议修复方向 |
|------|------|------|------|------|
| 章节任务 | `多尔金改后用两个字认可` | Form F | 元数据中"两个字"机械计数 | 改为描述性动作 |
| 终止条件 | `说了"不错"两个字` | Form F | 同上 | 改为"说了声不错" |
```

> 诊断A不负责发现所有1-3字短对话——那由诊断B完成。

---

### 5.2 诊断B — grep精确扫描（1-3字短对话碎片）

诊断A完成后，用grep扫描全部1-3字引号内对话。

**扫描命令**：
```
Grep: pattern = "[^"]{1,3}"  |  path = {阶段目录}  |  output_mode = content  |  -o  |  head_limit = 0
```

**人工过滤**：

| 类别 | 说明 | 处理 |
|------|------|:--:|
| **情境角色对话** | 情境文本中角色说出的1-3字对话 | → 进入修复清单 |
| **meta字段概念引用** | 核心/章节任务/终止条件中的 `"跨过去"` 等 | 跳过 |
| **专有名词/歌谣/符文** | `"冰焰"`（酒名）`"家不散"`（歌谣） | 跳过 |
| **叙事内引用** | 叙事中 `说了声"晚安"` 等 | 跳过 |

> 此扫描是**强制性**的——诊断A肉眼阅读无法可靠捕获所有1-3字短对话。

---

### 5.3 修复执行

**问题少（≤10处）**：主对话直接修复。
**问题多（>10处）**：启动子Agent，传入完整方案 + 诊断清单 + grep过滤后的修复清单。

#### 子Agent启动材料

1. 本方案全文
2. 诊断A清单文件
3. 诊断B过滤后的修复清单（归类为"情境角色对话"的条目）
4. 指令：严格按清单逐条修复，不得跳过，对每条先读上下文再动刀

#### 修复法则

1. **先做减法**：删除无信息增量的碎片句和冗余引导
2. **标点重构**：叙事流内句号→逗号；对话中标点按情境改为.../？/！/——
3. **对话处理**：优先叙述化（路径1），保留引号的对话按2.2和2.3补全情感层
4. **补充内心**：静态外貌→动态推理/感受/反应
5. **补充因果**：确保每个新增都有"为什么"
6. 如果"核心""章节任务""章节终止条件"中有Form F或AI元评价，同步修改
7. **只改情境文本中的对话和与短对话直接相关的叙事句。不改章节头信息。**

#### 自检验证

逐条检查：

1. ✅ 修改后的对话读出来像人话吗？（朗读测试）
2. ✅ 遮掉对话看叙事——叙事里有感知/触碰/反应/声音质地吗？（情感填充测试）
3. ✅ 说话的人OOC了吗？（对照§四角色速查）
4. ✅ 改后的情感重量匹配情境吗？
5. ✅ 有没有引入新模板化表述、破折号滥用、修饰后挂、后置解释句？
6. ✅ 章节头信息完整未动吗？
7. ✅ "说了X个字"类叙事自曝全部清除了吗？
8. ✅ AI元评价全部清除了吗？

**不通过则回到上一步重新修改。**

---

### 5.4 复查（主对话）

修复完成后，主对话执行四轮独立复查：

#### 复查A：Form F残留扫描

```
grep pattern = "\d+个字|两个字|三个字|四个字" path = {阶段目录}
```

逐条判定：修辞用法→pass；机械计数→修复。

#### 复查B：短对话碎片残留扫描

```
grep -o pattern = '"[^"]{1,3}"' path = {阶段目录}
```

人工过滤meta字段/专有名词后，情境中残留的→修复。**目标：0残留。**

## 七、金标准参考

以下示例来自用户逐句精修的Ch155/158/165，展示了修复的真正标准。修复任何章节前必须通读这三章全文。

### 7.1 新增内容的因果

用户新增的每一处都能回答"为什么加这个"：

| 新增（Ch155） | 功能 |
|------|------|
| `"守护者大人，不...菲娜小姐，原谅我"` | 凯尔社交腼腆→自我贬低→对守护者的敬畏 |
| `菲娜脸红又觉得很新奇，好像又有点兴奋` | 菲娜不是被动承受者，有自己的探索欲 |
| `黎恩稍微有点惊讶...以为只是足控...没想到` | 黎恩有推理链，不是"点头机器" |
| `黎恩饶有兴趣地向菲娜八卦` | 黎恩温柔有幽默感，会八卦 |
| `菲娜害羞地打了一下黎恩` | 菲娜会撒娇，不是永远端庄 |
| `拼命点头` | 凯尔的反应是具体动作而非抽象陈述 |

| 新增（Ch158/Ch165，最终版） | 类型 |
|------|------|
| `好像不扣住它就会自己撤回那条消息` | 菲娜紧张的具体化 |
| `黎恩说得太自然了，好像闻她的脚是这世上最理所当然的事。她耳朵尖烧起来。` | 菲娜内心因果（直接肯定句） |
| `还听到自己吞口水的声音` | 凯尔感官 |
| `她没立刻回答...过了一会儿，闷闷的声音才从怀里传出来："...嗯。"` | 菲娜犹豫的时间感 |
| `她知道这个笑容。每次黎恩在盘算什么的时候嘴角就是这副弧度。` | 菲娜对黎恩的阅读 |
| `她喜欢这种时候——嘴里塞着他的肉棒聊着营地的事，好像这是全世界最普通的一个夜晚。` | 菲娜的满足感 |
| `黎恩没敢告诉她刚才自己在想什么。那个画面让他自己都吃了一惊。` | 黎恩内心因果 |
| `她需要先说出这两个字，然后再给他答案。他听得出来。` | 黎恩对菲娜的阅读 |

### 7.2 应删除的碎片类型

以下类型的文本应直接删除而非展开：

- `脸是红的。眼睛是琥珀色的。` → 静态外貌
- `耳尖、脖子、锁骨、胸口。` → 数据卡列表
- `175cm的学者仰面躺着。` → 角色数据
- `传教士。` `后入式。` → 体位标签
- `"不只是脚。"` `"没有推开，握住了。"` `"脚没有移开。"` `"每一句都。"` → 无信息增量的碎片句
- `"躺下。"` → 功能性指令，叙述化（`温柔地轻声让凯尔躺下吧`）
