# 短对话修复方案

> **原则**：质量唯一指标。无脚本，每章LLM逐章精修。所有1-3字短对话都需修复，无例外。

---

## 一、七种问题形态速查

| 形态 | 描述 | 示例 |
|------|------|------|
| **A. 单字回应重大提案** | 对复杂决定的回应≤2字 | 菲娜问能否和别人做→黎恩回"好。" |
| **B. 关键词充当对话** | 大纲关键词直接放进引号 | 黎恩提议找矮人→"感谢。" |
| **C. 句号断句型** | 句子被句号劈成碎片 | "我不知道。就是。想要。" |
| **D. 电报式指令** | 指令像下达军令 | "坐那边。""裤子脱了。" |
| **E. 短促交替型** | 两人对话每句1-3字来回 | "那就再试。""你陪我吗。""陪。" |
| **F. 叙事自曝型** | 叙事文本数角色说了几个字 | "他说了一个字""两个字""三个字" |
| **G. 对话零引号** | 大纲直译不带引号 | `直接问黎恩: 听说你喜欢脚` |

**形态E的三种表现**：
- **信息空洞型**："忘了""没什么""陪。" — 短且无情感补充
- **纯沉默型**：`"..."` 空的无信息沉默
- **短促交替型**：两句以上1-3字对话连续出现，上下文有情感铺垫也产生碎片感

---

## 二、修复方法

### 2.1 两种路径

| 路径 | 适用 | 做法 |
|------|------|------|
| **路径1：叙述化** | 短句只传递功能性信息 | 删引号融入叙事。"感谢。"→"是该好好谢谢他们。" |
| **路径2：展开为对话** | 场景需要角色间真实交流 | 保留引号，扩展为带性格的自然语言。"陪。"→"当然陪你。" |

### 2.2 情感填充五层（核心模型）

AI默认模型：对话 = 信息传递 → **错误**。正确模型：对话 = **情感连接** + 信息传递。

```
修复前：菲娜看了他很久。然后她说了两个字。"明早。"
修复后：菲娜眨了眨眼睛，她察觉到凯尔心里有一股沉重的情绪。菲娜摸了摸凯尔的头，惹得凯尔坚毅的脸庞染上一抹红晕。菲娜温柔的声音让凯尔忐忑的心情逐渐平复下来，她说："放心吧凯尔，明天早上我陪你一起去。"
```

### 2.3 各形态修复示例

**形态A（单字回应）**：
```
修复前：她说出那个念头时声音很轻：下次，让它们进到里面。黎恩收紧手指。"好。"
修复后：她扭捏了很久，最后说出那个念头时声音很轻："下次...要让它们进到里面吗？"黎恩收紧手指，沉默了一息。"你确定？"她红着脸犹豫地点点头。他没有立刻回答，只是安慰一般抚摸着她的背，说:"如果你不怕的话，那我们可以试一下，我会全程在旁边陪着你的。"
```

**形态B（关键词充对话）**：
```
修复前：他一边指交一边说："多尔金和哈根。你可以去找他们。""找他们，嗯，干嘛。""感谢。"
修复后：他一边指交一边说："多尔金和哈根，你不觉得他们帮了我们很多吗？""找他们...你是说..."她的声音被手指打断了一拍，只剩含糊的鼻音。"用那种方式感谢？""如果你愿意的话？"琥珀色眼睛瞪大，然后被手指扣到说不出话。
```

**形态C（句号断句）**：
```
修复前："我不知道。就是。想要。"
修复后："我也不知道为什么啊，就是...想要..."
```

**形态D（电报指令）**：
```
修复前："后天傍晚。来我们房间。"
修复后："后天傍晚，来我们房间吧。三个人一起试一次，也许没那么可怕。"
```

**形态E（短促交替）**：
```
修复前："那就再试。""你陪我吗。""陪。"
修复后："那就...再试一次？"菲娜有点不安地问:"你陪我吗？"黎恩收紧手臂。"当然陪你，这种事我不会让你一个人面对。"
```

**形态F（叙事自曝）**：
```
修复前：多尔金改完后看了他一眼。不错。两个字。
修复后：多尔金改完后看了他一眼，下巴点了一下。他表达"不错"的方式从来不需要多说。
```

**形态G（对话零引号）**：
```
修复前：菲娜直接问黎恩: 听说你喜欢脚
修复后：菲娜看着黎恩，声音轻得几乎听不见："听说你喜欢脚？"
```

## 三、修复中的常见错误

### 破折号滥用

叙事描写中`——`一律禁止。仅限三种用途：**标题分隔**、**对话被打断**（`"你怎么——"`）、**声音延长/中断**。

```
❌ 咬了一下嘴唇——她很少咬嘴唇      ✅ 咬了一下嘴唇。
❌ 伸手握住肉棒——脚趾在黑丝下蜷紧   ✅ 伸手握住肉棒，脚趾在黑丝下蜷紧
❌ 回头看他——琥珀色眼睛            ✅ 用琥珀色的眼睛回头看他
```

### 短句句号堆砌

同一角色的连续动作/观察/因果链，`。`改`，`合并：

```
❌ 他闭上眼。深呼吸。                 ✅ 他闭上眼，深呼吸。
❌ 他卡壳了。她的耳尖红了。           ✅ 他卡壳了，她的耳尖红了。
❌ 那是他在数步子。她认出来了。       ✅ 她认出来了，那是他在数步子。
❌ 他射了。精液涌进蜜穴最深处。       ✅ 他射了，精液涌进蜜穴最深处。
❌ 劳拉别过脸去。在忍笑。             ✅ 劳拉别过脸去，在忍笑。
❌ 她打了一个酒嗝。然后靠在了菲娜肩上。 ✅ 她打了一个酒嗝，然后靠在了菲娜肩上。
```

**判定**：读一遍。A。B — 脑子里有"断开再重连"的感觉？A和B是同一人连续动作→合并。

### 修饰后挂

修饰语以逗号短尾挂在动词后→前置融入动词：

```
❌ 他笑了一下，很轻。                         ✅ 他轻轻笑了一下。
❌ 她点头，很慢。                             ✅ 她慢慢点头。
❌ 她轻声说，然后含进去，缓慢，一寸一寸。       ✅ 她轻声说，然后一寸一寸缓慢地含进去。
```

### 后置解释句

叙事已展示完，后面再补短解释贴标签→直接删除：

```
❌ 黎恩当晚的占有比任何一次都凶。是确认。     ✅ 黎恩当晚的占有比任何一次都凶。
❌ "不要，"她说得很干脆，是对他说的，也是对自己说的。 ✅ "不要，"她说得很干脆。
❌ 黎恩看懂了，是"满意了吗"。               ✅ 黎恩看懂了。
❌ 碰了一下自己的耳尖。是烫的。              ✅ 碰了一下自己烫烫的耳尖。
```

### "不是...是..."迂回否定

禁pivot结构，直接写B：

```
❌ "不是质问，是问诊"     ✅ "她在问诊"
❌ "不是犹豫，是在找说法" ✅ "在找说法"
❌ "不是滴不是落，是砸"   ✅ "砸在屋顶上"
❌ 那一个字里没有犹豫，也没有试探 → ✅ 那一个字干脆笃定
```

### Form F 叙事自曝

禁"说了X个字"的机械计数。修复：删掉"X个字"，保留内容：

```
❌ "脚酸。"两个字被呼气的尾音托着，软软的 → ✅ "我的脚好酸啊..."尾音软软的
❌ "走。"一个字，但那双黄绿眼睛...       → ✅ "那我们走吧？"那双黄绿眼睛...
```

### 定语后挂

中文定语前置。`N，修饰N的。` → `修饰N的N。`：

```
❌ 几片浅灰鳞，以前没有的。              ✅ 几片以前没有的浅灰鳞。
❌ 一条线，李子色的。                    ✅ 一条李子色的线。
❌ 心脏还在狂跳，被雷吓的。              ✅ 被雷吓得心脏还在狂跳。
❌ 脚心贴上龟头，柔软，微微凉。           ✅ 柔软微凉的脚心直接贴上龟头。
```

### 角色数据卡化

外貌数据嵌入动作流，不独立陈列：

```
❌ 175cm的学者仰面躺着。
❌ 脸是红的。眼睛是琥珀色的。
✅ 黎恩稍微有点惊讶，紫青色的眼瞳微微睁大了，之前以为凯尔只是有点足控，没想到还有这方面的癖好。
```

## 四、角色速查（OOC防护）

### 黎恩
温柔有幽默感喜欢吐槽，说话完整带温度。
- ❌ "好。""可以。""去吧。""嗯。"
- ✅ "当然陪，我不会让你一个人面对这种事。""安排是我安排的，吃醋是它自己来的。""对不起嘛菲娜，我擅自给你做决定了。如果还有下次的话，我一定会先问你的。"

### Seraphina（菲娜）
强者内核，害羞时把脸埋起来。命令时声音会抖但话完整。
- ❌ "坐那边。""裤子脱了。"
- ✅ "你...坐那边去。"

### 菲
话少但句句有重量。修复时保留短句，补全叙事中的表情、动作、语气层。

### 多尔金
沉默专注但不是哑巴。禁止叙事写"说了X个字"来数他说的话。

### 凯尔
社交腼腆学术自信。断句型对话需修：腼腆但不结巴。

### 亚尔缇娜
报告体本身就是特色，不用改。

## 五、工作流

每次处理一个阶段，四步串行：**诊断A → 诊断B → 修复 → 复查**。

### 5.1 诊断A — 逐章精读

**准备**：
1. 必读：`docs/character/黎恩.TXT` `docs/character/Seraphina.TXT`
2. 通读三个金标准章节全文（只读不改）：
   - 《意外的请求——踩踏与羞耻》
   - 《黑丝的学术观察——第一次羞辱实践》
   - 《枕边的提议——口交中的闲聊》
3. 阅读该阶段其他角色文件（≥3个）

**逐章扫描**（5章/批）：读TXT全文，重点扫描"情境"字段中的形态A-G对话，检查"核心""章节任务""章节终止条件"中的Form F和AI元评价。

**输出诊断A清单** → `世界书\方案\短对话诊断_{阶段名}.md`：

```markdown
## {章节标题}

| 位置 | 原文 | 类型 | 诊断 | 建议修复方向 |
|------|------|------|------|------|
| 章节任务 | `多尔金改后用两个字认可` | Form F | 机械计数 | 改为描述性动作 |
```

### 5.2 诊断B — grep精确扫描

诊断A完成后，grep扫描全部1-3字引号内对话：

```
Grep: pattern = "[^"]{1,3}"  |  path = {阶段目录}  |  output_mode = content  |  -o  |  head_limit = 0
```

**人工过滤**：

| 类别 | 处理 |
|------|:--:|
| 情境中角色说出的1-3字对话 | → 进入修复清单 |
| meta字段概念引用 / 专有名词 / 歌谣 / 符文 | 跳过 |
| 叙事内引用（`说了声"晚安"`） | 跳过 |

### 5.3 修复执行

≤10处主对话直接修；>10处启动子Agent。

**修复法则**：
1. **先做减法**：删无信息增量的碎片句和冗余引导
2. **标点重构**：叙事流内句号→逗号；对话中标点按情境改为.../？/！/——
3. **对话处理**：优先叙述化（路径1），保留引号的补全情感层
4. **补充内心**：静态外貌→动态推理/感受/反应
5. **补充因果**：每个新增都要有"为什么"
6. Form F或AI元评价在头部字段中的同步修改
7. **只改情境文本**，不改章节头信息

**自检（8条，不通过回到上一步）**：
1. ✅ 修改后的对话读出来像人话吗？
2. ✅ 遮掉对话看叙事，有感知/触碰/反应/声音质地吗？
3. ✅ 说话的人OOC了吗？（对照角色速查）
4. ✅ 情感重量匹配情境吗？
5. ✅ 有没有引入新模板化表述、破折号滥用、修饰后挂、后置解释句？
6. ✅ 章节头信息完整未动吗？
7. ✅ "说了X个字"类叙事自曝全部清除了吗？
8. ✅ AI元评价全部清除了吗？

### 5.4 复查（四轮）

**复查A — Form F残留**：
```
grep pattern = "\d+个字|两个字|三个字|四个字" path = {阶段目录}
```

**复查B — 短对话碎片残留**（目标：0残留）：
```
grep -o pattern = '"[^"]{1,3}"' path = {阶段目录}
```

**复查C — 迂回否定 + 破折号滥用**：
```
grep pattern = "不是.{1,20}是[^的]" path = {阶段目录}
grep pattern = "没有.{1,20}也没有" path = {阶段目录}
grep pattern = "——[^。]*——" path = {阶段目录}
grep pattern = "——是.{1,30}。" path = {阶段目录}
```

**复查D — 构建验证**：
```bash
python scripts/build_eldoria.py && python scripts/story_tool.py validate
```

四步全部通过 → 该阶段完成。

## 六、禁止事项

1. ❌ 禁止用脚本批量替换
2. ❌ 禁止跳过章节 / 只读前半部分 / 不读角色文件就修改
3. ❌ 禁止修改章节头信息（仅Form F/AI元评价清除时可改核心/章节任务/终止条件）
4. ❌ 禁止修改性行为内容
5. ❌ 禁止引入新角色崩坏 / 模板化修饰词堆砌
6. ❌ 禁止信息填充冒充情感填充（遮掉引号叙事空转=没修）
7. ❌ 禁止跳过诊断清单中的条目，不得擅自判定"不需要改"
8. ❌ 禁止跳过复查，0残留才算完成

### 应删除的碎片类型

以下直接删除而非展开：

- `脸是红的。眼睛是琥珀色的。` → 静态外貌碎片
- `耳尖、脖子、锁骨、胸口。` → 数据卡列表
- `175cm的学者仰面躺着。` → 角色数据卡
- `传教士。` `后入式。` → 体位标签
- `内射。` `事后。` `木屋。` → 阶段/时间/地点标签，直接并入叙事流（"黎恩先射，精液涌进她蜜穴深处""她躺在草地上动不了""回到木屋，黎恩再次进入"）
- `"不只是脚。"` `"没有推开，握住了。"` `"脚没有移开。"` → 无信息增量碎片句
- `"躺下。"` → 功能性指令，叙述化
