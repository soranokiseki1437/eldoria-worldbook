# 章节终止条件 & 章节任务 全量修复方案

> **目标**：501章全部过一遍LLM，逐章阅读后修改终止条件和章节任务
> **铁律**：禁止脚本修改。每章必须被LLM完整阅读后手改。

---

## 一、修复范围

每章检查并修复以下字段：

### 1.1 章节任务

| # | 检查项 | 修复方式 |
|---|--------|---------|
| ① | 是否挤成一句超长句 | 拆成1-2句，一句=一个叙事节拍 |
| ② | 主语是否明确 | 补全"菲娜""黎恩""凯尔"等角色真名 |
| ③ | 是否有章节编号引用 | 改为描述性语言 |

### 1.2 终止条件1（前置）

| # | 检查项 | 修复方式 |
|---|--------|---------|
| ① | 是否重复了情境的细节描写 | 砍掉，只留骨架（谁在哪、什么状态） |
| ② | 是否一句超长 | 拆句，一节拍一句 |

### 1.3 终止条件2（核心）

| # | 检查项 | 修复方式 |
|---|--------|---------|
| ① | 是否逗号堆砌成段落 | 拆成句号分隔的叙事节拍序列 |
| ② | 是否有直接引语 | 转为报告式转述："说，..."加逗号接完整陈述 |
| ③ | 是否有形容词堆砌/感受描写 | 改为动作事实：写"发生了什么"不写"感觉怎么样" |
| ④ | 主语是否明确（多人交互时） | 每个动词的主语显式写出 |
| ⑤ | 关键性行为动词（插入/射/口交等） | 保留，不删 |

### 1.4 终止条件3（收束）

| # | 检查项 | 修复方式 |
|---|--------|---------|
| ① | 是否合理承载了情感落点 | 条件2已建立的情感方向自然延伸→保留 |
| ② | 是否引入了全新事件/角色/场景 | 删除真正的新剧情推进 |
| ③ | 是否符合闭合/暂停规则 | 闭合章→收束；中间章→场景暂停 |

#### 1.4.1 条件3核心铁律

**条件3 = 摄影机撤出。不写任何新剧情。**

条件3是章节的"句号"——叙事在条件2已经结束，条件3只是让摄影机退场。

| 违规类型 | 示例（❌） | 正确写法（✅） |
|---------|-----------|-------------|
| 重复条件2情节 | "交接时她从艾德里安手里转到法林手里，每个关节找到了位置。艾德里安脚步逃命。" | "矮人祖厅的符文灯暗了一阶，哈根翻了个身，口袋里的碎石块沙沙响了一声。" |
| 新角色动作 | "爱丽榭困惑求证，凯尔开语义学分析被乔治按住，雷恩面面相觑。" | "餐厅里的空气还绷着。艾德里安的茶杯在桌面上留下了一圈水渍，留在那里。" |
| 事后对话/行为 | "事后她告诉他留住符文比以前更亮了，说她注意到了。" | "符文灯暗绿的微光不动，金属扣上的留住比掌心里那道更亮，两个人抱在一起的呼吸慢慢同了拍。" |

#### 1.4.2 连续叙事弧的两种条件3模式

> **判定**：是否有后续章节紧接着？有→中间章；无→闭合章。

**中间章（场景暂停）**：环境音 / 等待 / 呼吸 / 沉默

```
✅ "篝火旁横七竖八的酒瓶和东倒西歪的坐垫，营地陷入醉意的安静。"
✅ "营地各处灯光逐一熄灭，只剩橡树顶上的星光和远处矮人祖厅符文灯的暗绿微光。"
✅ "符文灯暗绿的微光不动，毯子下两个人的呼吸开始同步加速。"
✅ "月光从窗帘缝里滑进来。她还站着，他还跪着。她的手还在他手里。"
✅ "符文灯暗绿的微光不动，金属扣上的留住比掌心里那道更亮，两个人抱在一起的呼吸慢慢同了拍。"
```

**闭合章（收束）**：时间推进 / 场景收束 / 情感沉淀 / 情感落点

```
✅ "夜色降临后亚莉莎走出石窟回了营地，罗恩独自留在洞穴中。"（空间分离）
✅ "凯尔回到营地时午后的阳光正穿过树冠洒在书房门口，玲还蹲在那里等他。"（回到日常+回响）
✅ "营房的灯熄了，雷恩躺下后月光慢慢从剑刃上滑落。"（诗意单画面淡出）
✅ "他把脸埋进手里，指缝间漏出一声半像笑半像叹的气声。"（情感落点）
```

> **中间章条件3本质**：叙事暂停但时间未推进。读者知道接下来还有事发生。不允许出现"XX离开了""XX回到了哪里"等人物位移——那是闭合章的事。

#### 1.4.3 NSFW章节在连续弧中的条件3

NSFW中间章的条件3**与其他中间章一致**：场景暂停（环境音/呼吸/沉默）。不写"事后对话""清理身体""穿衣离开"等——这些是情节，属于条件2。

NSFW闭合章的条件3可包含：简单空间分离（"走出石窟回了营地"）、情感落点（"一声半像笑半像叹的气声"）、或诗意画面淡出。

#### 1.4.4 条件3合格性自检

写完后对条件3问三个问题：
1. 这句话里有没有人做了任何动作？（有→删，环境音/光影除外）
2. 这句话能不能直接接下一章的标题？（能→中间章合格；不能→可能是闭合章，检查收束感）
3. 这句话是不是条件2已经写过的？（是→删）

## 三、Agent指令模板

每个Agent收到以下完整指令：

```
你是章节条件修复Agent。你的任务是逐个阅读并修复你负责的章节。

## 你的章节范围

{章节列表，每行：章号 文件名}

## 修复规则

### 章节任务
- 如果挤成一句超长句→拆成1-2句，一句=一个叙事节拍
- 主语不明确→补全角色真名（菲娜/黎恩/凯尔等）
- 有章节编号引用（"第X章""比086那晚"）→改为描述性语言
- 禁止破折号(——)

### 终止条件1（前置）
- 重复了情境已有细节→砍掉，只留骨架（谁在哪、什么状态）
- 超长句→拆句

### 终止条件2（核心）  
- 逗号堆砌成段落→拆成句号分隔的叙事节拍，一节拍一句
- 直接引语→报告式转述："说，..."加逗号后接完整陈述句
- 形容词堆砌/感受描写→改为动作事实（写"发生了什么"不写"感觉怎么样"）
- 多人交互时每个动词的主语显式写出
- 关键性行为动词（插入/射/口交等）保留

### 终止条件3（收束）
- 条件2已建立的情感方向自然延伸→保留（如"走在路上被两个念头夹击"后"决定住他房间"）
- 真正的新事件/新角色/新场景推进→删除
- 闭合章→收束（时间推进/场景收束/情感沉淀/情感落点）
- 连续叙事弧中间章→场景暂停（环境音/等待/呼吸/沉默）

### 全局禁止
- 破折号(——)
- 否定句式（不/没/非）
- 比喻
- 章节编号引用
- 情境细节重复（条件1）
- 形容词堆砌/感受描写（条件2）

## 工作流

对每一章，严格按以下步骤：

Step 1: Read 完整TXT文件
Step 2: 检查章节任务 — 超长？主语不明？→记录需要改什么
Step 3: 检查终止条件1 — 重复情境？超长？→记录
Step 4: 检查终止条件2 — 逗号堆砌？直接引语？形容词堆砌？主语不明？→记录
Step 5: 检查终止条件3 — 新剧情推进？闭合/暂停方式是否正确？→记录
Step 6: 如果以上5步有任何需要改的→Edit文件，只改章节任务和终止条件行，不动情境/核心/其他字段
Step 7: 记录日志：{章号, 改了哪些字段, 具体改动简述}

## 重要

- 必须Read每一章之后才能修改
- 只改"章节任务"和"章节终止条件"行，不碰情境/核心/占有欲确认/好感影响
- 如果某章检查后没有问题，跳过并记录"无需修改"
- 不要为了"统一风格"而改写已经符合规则的文本
```
