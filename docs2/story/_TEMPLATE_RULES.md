## 一、 文件名与 ID 规则

* **文件名格式**：`{ID}：{名称}.TXT`，例如 `003：封闭十四年的水闸——独角狮火漆协议.TXT`。
* **ID 规范**：三位纯数字编号（如 `001`），文件首行必为 `ID: 001`，与文件名严格一致。

## 二、 字段规范与填写要求

### 1. 字段总览

| 字段 | 必填 | 格式与说明 |
| :--- | :---: | :--- |
| `ID` | ✅ | 三位纯数字编号（如 `001`）。 |
| `名称` | ✅ | 具象双半段标题，遵循 `前半段——后半段` 格式（如 `焦黑的黄铜徽章——平原林道启程`）。**彻底打破 4+4 假对仗限制**，长短自由结合；严禁仙侠玄学术语（敕印/探阵/微澜/法印等）。 |
| `NSFW` | ✅ | `是` 或 `否`。 |
| `性行为等级` | ✅ | `0-10`（`NSFW: 是` 章节填写对应等级；常态非 NSFW 章节该字段留空）。 |
| `黎恩知情` | ✅ | 描述（涉及背德/第三者接触时填写；常态非 NSFW 章节或不适用时留空）。 |
| `主要人物` | ✅ | 角色名称，以逗号分隔（如 `雷恩, 菲, 黎恩, 菲娜, 艾玛`）。不可为空。 |
| `总情境数` | ✅ | 纯数字 N，与下方情境列表条目总数严格一致。 |
| `情境` | ✅ | 标号列表（`- 1. `, `- 2. `...）。**严禁全员哑剧流水账**：单章必须有 2~4 条情境嵌入角色直接对白（`“...”`）；**严禁公文汇报腔**（如“平静说出”、“明确敲定”等）；第 N 条以纯物象收束全章。情境列表与核心内禁止使用破折号（——）。 |
| `核心` | ✅ | 1~2 句话：本章事件核心驱动力与戏剧功能。禁止破折号，禁止 AI 元评价，禁止剧透后续章节。 |

### 2. 字段顺序（固定）

```text
ID → 名称 → NSFW → 性行为等级 → 黎恩知情 → 主要人物 → 总情境数 → 情境 → 核心
```

## 三、 文风与叙事法典（正向文学质感与防御）

1. **大纲颗粒度：详略得当，拒绝过度繁杂**：
   - **大纲定位警醒**：这是章节大纲（Outline），绝非正文逐字描写！必须做到详略得当；
   - **详写重点**：核心戏剧冲突、精彩交锋、人物关键台词、即时微表情与关键动作；
   - **略写次要**：过于琐碎的道具参数、微观物理、过度繁复的环境工笔画坚决不加入，避免喧宾夺主。
2. **JRPG 轻小说原声、吐槽与内心 OS**：
   - 拒绝冷冰冰的任务流水账！角色必须有呼吸感与台词表达；
   - **穿插吐槽与内心 OS**：拒绝沉闷压抑的正剧脸！同伴间要有轻松有趣的善意吐槽（乔治对工具的抱怨、菲的冷面幽默、亚莉莎的傲娇吐槽、黎恩温和无奈的苦笑打趣），关键节点适度展现角色生动可爱的内心独白（内心 OS）；
   - **声线保真**：黎恩温和敏锐爱吐槽、菲娜娇羞可爱有底气、雷恩沉稳苍凉、艾德里安优雅机锋与冰冷嘲弄，全员拒绝哑剧。
3. **纯正日式 RPG 剑与魔法西幻基准（彻底消灭古风与雕琢感）**：
   - 坚守 JRPG 轻小说细腻羁绊、王道冒险与市井生活流呼吸感；
   - 彻底杜绝中式武侠、仙侠修真、传统度量衡（斤/两/尺/寸/里）、以及世俗军队称谓；
   - **杜绝雕琢式伪文雅**：消灭“绝不可”、“落入……眼中”、“指节微白”等雕琢过度的书面语，使用清澈、自然的现代口语化轻小说表达。
4. **王国零导力隐蔽铁律**：
   - 维里迪亚王国全境无导力文明，原住民视发光机械与电弧为异端妖术；
   - 帝国战术导力器必须装配浸油皮革遮蔽盒，战斗依托冷兵器与战技体术。
5. **摄影机法则 (Show, Don't Tell)**：
   - 旁白直呼本名（黎恩、菲娜），零形容词代称；
   - 严禁会议总结式间接转述（严禁“平静说出”、“明确敲定”等），用即时微表情与现场直接对白推进；
   - 末尾情境以可被镜头捕捉的客观物理画面收束闭合，不替角色定性结论。
